## 1. 신규 파일 (4개, 기존 코드 수정 0)

| 파일 | 내용 | Unity 원본 |
|------|------|-----------|

| `Park3D/Source/Park3D/CarPlacementLibrary.h/.cpp` | 순수 계산 라이브러리(UBlueprintFunctionLibrary) + JSON 입출력 | CarObject 계산/저장 로직 |
| `Park3D/Source/Park3D/Tests/CarPlacementLibraryTest.cpp` | 자동화 유닛테스트 6종 | (신규) |

**ParkingCarTypes.h 핵심 결정 반영:**
- `FCarVec3 { float x, y, z; }` — **소문자 멤버명**으로 Unity `SVector3` JSON 키(`x/y/z`)와 정확히 일치(설계 §7/§8.5 A안 확정). `FVector` 직접 사용 시 UE가 대문자 `X/Y/Z`로 직렬화되어 Unity 비호환되는 문제 회피.
- `FCarPos` 8필드 모두 **소문자 시작 멤버명**(`id/type/presetId/slotId/prefabId/pos/rotY/isFront`) → FJsonObjectConverter 직렬화 키가 Unity와 일치.
- `type` = `ECarType` 정수 직접 매핑(0=None=미설정).

**CarPlacementLibrary 주요 함수:**
- 좌표: `UnityPosToUE(FCarVec3,U=100)→FVector` = `(x·U, z·U, y·U)` / `UEToUnityPos` 역변환. Unity z(전방)→UE Y, Unity y(높이)→UE Z.
- 회전: `UnityRotYToUEYaw`/`UEYawToUnityRotY`(1차 항등) + `AddYawDeg`(정규화). **메시 정면축 ±90° 보정은 3단계 액터에서 별도 적용**(주석 명시).
- 자동배치: `AutoPlacePosition(Base, RightDir, Index1Based, Spacing, bVertical, U)`.
- ID/이름: `MakeCarId`(현재 시각) / `MakeCarIdFromParts`(테스트용 시각 주입) / `GetCarTypeName`.
- JSON: `SaveCarDatasToJson` / `LoadCarDatasFromJson` (`FJsonObjectConverter`, ParkingPresetManager와 동일 패턴).
