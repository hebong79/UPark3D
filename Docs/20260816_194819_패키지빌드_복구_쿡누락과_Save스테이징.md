## 2. 차량 메시가 쿡에서 통째로 빠졌다 (에디터에서는 안 보이는 회귀)

### 증상

패키지는 정상 기동하고 데이터도 다 읽는데 **차량이 하나도 안 보였다.**

```
[CarPlacement] 메시 프리로드: 0개(캐시 총 0개)      ← 에디터에서는 23개
car.catalog → 23종 전부 meshLoaded:false
```

### 원인

`DT_CarCatalog` 를 없애고 `car_catalog.json` 의 `meshDir` 로 **런타임에 문자열을 조립해**
메시를 로드하도록 바꾼 뒤(같은 날 커밋 `07c2de4`), `/Game/Actors/Car/Meshs/*` 를 가리키는
**에셋 참조가 프로젝트에 하나도 남지 않았다.**

쿠커는 에셋 참조 그래프만 따라간다. 문자열은 따라가지 않는다.
→ 차량 메시 23종이 쿡 대상에서 제외 → `.pak/.ucas` 에 아예 없음.

**에디터는 디스크에서 직접 읽으므로 멀쩡해 보인다.** 패키지를 실행해 보기 전에는 드러나지 않는
종류의 회귀다. 예전에는 `WBP_CarPlacement → DT_CarCatalog → 메시` 라는 하드 레퍼런스 사슬이
있어서 쿠커가 알아서 끌고 갔다.

### 조치 — `DefaultGame.ini`

```ini
[/Script/UnrealEd.ProjectPackagingSettings]
+DirectoriesToAlwaysCook=(Path="/Game/Actors/Car/Meshs")
```

재질·텍스처는 메시가 참조하므로 따라 쿡된다.

### 검증

| | 수정 전 | 수정 후 |
|---|---:|---:|
| `Park3D-Windows.ucas` | 254 MB | **1,780 MB** |
| `[CarPlacement] 메시 프리로드` | 0개 | **23개** |
| `car.catalog` | `meshLoaded:false` ×23 | 치수(`lengthM/widthM/heightM`) 정상 반환 |

`meshLoaded` 는 **실패했을 때만** 나오는 필드다(설계대로). 성공하면 실측 치수가 대신 온다.

## 3. `Save/` 가 스테이징되지 않았다

### 증상

`Package/Windows/` 에 `Save/` 가 없어 패키지가 **카탈로그·프리셋·카메라·차량배치를 하나도
못 읽는다.** 기동은 되지만 빈 화면이 된다.

`Park3DDataPaths::GetSaveRootDir()` 는 `ProjectDir()/Save` 가 없으면
`ProjectDir()/../Save`(= 스테이지 루트)를 본다. 즉 `Package/Windows/Save` 에 있어야 하는데
`BuildPackage.bat` 이 그걸 복사하지 않았다(지금까지 수동으로 넣어 온 것으로 보인다).

### 조치 — `BuildPackage.bat` 아카이브 뒤에 스테이징 단계 추가

```bat
robocopy "%~dp0Park3D\Save" "%ARCHIVE%\Windows\Save" /MIR /XD Sim /NFL /NDL /NJH /NJS /NP > nul
if errorlevel 8 ( ... exit /b 1 )
```

- `Sim` 은 제외한다 — 리플레이 프레임은 실행마다 생기는 산출물이지 입력 데이터가 아니다.
- robocopy 는 0~7 이 정상이라 `errorlevel 8` 로 판정한다.

### 검증

```
[CarCatalog] 차량 프리팹 인덱스 23종 적용: .../Package/Windows/Save/Config/car_catalog.json
[Config] 프리셋 적용   ← .../Package/Windows/Save/3D/Preset/001_Preset_23Face_Seoshin.json
[Config] 카메라위치 적용 ← .../Package/Windows/Save/3D/CameraPos/CamPos_23Face_Seoshin.json
[Config] 차량배치 적용   ← .../Package/Windows/Save/3D/CarPos/CarPos_23Num_서신.json
```

## 5. 알아 둘 것

- **패키지가 실행 중이면 빌드가 실패한다.** `BuildPackage.bat` 이 시작할 때
  `Park3D.exe` 프로세스를 검사해 막는다(스테이지 파일 잠금 때문). 다시 빌드하려면 먼저 종료할 것.
- 앞으로 **런타임 문자열로만 참조하는 에셋을 추가하면 반드시 `DirectoriesToAlwaysCook` 도 같이
  손봐야 한다.** 에디터 테스트만으로는 절대 드러나지 않는다.
