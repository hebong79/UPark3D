# 바닥 번호 `numberMode: "anchorsOnly"` + `cam.setSlotNumbers` (보드 #1146)

## 요청
SettingManager 가 바닥 번호를 DB `slot_id` 로 맞춘다(면마다 `cam.setSlotNumber {face, slot, count:0, auto:false}`).
DB 에 없는 면에도 자동 순번 글자가 그대로 그려져 DB 번호와 겹쳤다(예: `preset:1#1` 의 1 이 `level:BP_ParkingSlot_C_1#0` = slot 1 옆).
마스터 확인(댓글): **면을 숨기는 게 아니라 면 안의 숫자 글자만 숨긴다** — 라인·데칼·`preset.numbers` 항목·Ctrl+클릭 스냅·`sim.slots` 는 그대로.

## 변경

| 대상 | 내용 |
|---|---|
| `FParkingSlotNumberInfo::bAnchored` | 번호가 기준점에서 왔는가(기준 면 + 그 기준점이 count/auto 로 이어 매긴 면). `ApplyNumberAnchors` 가 채운다 |
| `AParkingPresetManager::bNumbersAnchorsOnly` | 번호 모드. false=`auto`(기본, 기존 동작), true=`anchorsOnly`. 비-UPROPERTY |
| `AParkingPresetManager::ShouldDrawNumber(S)` | `!bNumbersAnchorsOnly \|\| S.bAnchored` — 렌더와 `preset.numbers.drawn` 이 같은 판정 |
| `RebuildSlotNumbers` | 그리지 않는 면은 건너뛴다(풀 커서는 그린 수만큼). 로그에 `모드 auto/anchorsOnly`, 면 수와 표시 수를 따로 |
| `preset.setView {numberMode}` | `"auto"` \| `"anchorsOnly"`. 다른 값은 **아무것도 바꾸기 전에** -32602(`bad_params`) |
| `preset.getView` / `setView` 응답 | `numberMode` 추가 (SettingManager 가 이 키를 보고 자동으로 anchorsOnly 를 켠다) |
| `preset.numbers` | 루트 `numberMode`, 항목마다 `drawn`(이 글자를 그리나)·`anchored`. 목록은 여전히 모든 면 |
| `cam.setSlotNumbers` (신규, 요청의 Optional) | `{list:[{face, slot, count?, auto?}], replace?:false, save?, fileName?/fullPath?}`. 항목을 전부 먼저 검사(하나라도 틀리면 -32602, 무변경) → 순서대로 적용 → 바닥 반영 1회. `replace:true` 는 기존 지정을 지우고 갈아 끼움(빈 list + replace = 전부 해제). 응답 `{ok, changed, applied, slotNumbers}` |

## 규칙 메모
- "기준점이 있는 면" = 기준 면 + 그 기준점이 이어 매긴 면. SettingManager 는 `count:0, auto:false` 라 면 한 장씩이다.
- `numberMode` 는 `showNumbers` 와 같이 **월드 매니저에 한 벌, 저장 안 함**(재기동·레벨 전환 = auto). SettingManager 가 매번 켠다.
- 패널(카메라 패널 '수정'/'열기')과 RPC 의 기준점 목록은 여전히 "마지막에 넘긴 쪽이 이긴다". `replace:true` 는 시작 때 카메라 파일이 넣은 기준점까지 덮는다(실측: 객리단 시작 기준점으로 8장 → replace 후 1장).
- `state.snapshot` 은 `showNumbers` 와 마찬가지로 `numberMode` 를 담지 않는다.

## 검증
- 게임 타깃 빌드 성공.
- **에디터 타깃 빌드·Automation 미실행** — 사용자 에디터(UnrealEditor, 17:32 기동)가 Live Coding 을 잡고 있어 UBT 가 거부(`Unable to build while Live Coding is active`). 추가한 테스트: `Park3D.ParkingDecal.SlotNumbers` TN-11, `Park3D.Rpc.CamModule` 의 setSlotNumbers 블록.
- 작업본 `Package/Work13540`(13540, 객리단길) exe 교체 후 실 RPC:
  - `preset.setView {numberMode:"bogus"}` → -32602 `bad_params`
  - `preset.setView {numberMode:"anchorsOnly"}` + `cam.setSlotNumbers {list:[{face:"level:BP_ParkingSlot_C_1#0", slot:1}], replace:true}` → `preset.numbers` 13면 중 `drawn:true` 는 `C_1#0`(1) 하나, 로그 `주차면 번호 1개 표시(면 13 … 모드 anchorsOnly)`
  - 오타 키 `numberMod` → `warnings[{kind:unknownParam, key:numberMod}]`
  - 메인 뷰 탑다운 캡처(차량 숨김): `shots/20261002_number_anchors_only/a_anchors.jpg`(1번만) vs `a_auto.jpg`(1~4) — 면 라인은 동일
- 기동 직후 첫 프레임 GPU timeout 2회(PTZ 카메라 SceneRender, 정본·에디터와 GPU 공유) 뒤 회복 — 이번 변경과 무관한 렌더 경로.
- 정본(13510)·`.10` 미배포. OmiPark3D(`world/slotnumbers.py`)는 이 저장소 밖이라 미작업.
