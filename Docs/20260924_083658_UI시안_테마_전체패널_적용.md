# UI 시안 테마를 전체 패널에 적용 (색·모양만, 배치 유지)

## 요청과 범위
- 요청: "시안대로 작업을 진행해줘" → 범위 질문에 **"전체 패널 스타일"** 선택.
- 한 일: 시안(https://claude.ai/artifact/DnXVtWCbXgtZ29eq86FJ8w, "부품·색·글자")의 색·둥근 모서리·버튼 상태를 모든 패널에 입혔다.
- 안 한 일: 배치 변경. WBP 는 손대지 않았고 UPROPERTY 도 추가·삭제하지 않았다. 따라서 패키지 재쿡 없이 exe 교체로 반영된다.

## 구조
`Park3DPanelStyle.h` 에 테마를 모으고, 각 패널 `NativeConstruct` **맨 끝**에서 `ApplyTheme(WidgetTree, RootBorder)` 를 한 번 부른다. 맨 끝이어야 하는 이유는 두 가지다. 패널 코드가 앞에서 칠한 흰 칸·검은 글자를 덮어야 하고, C++ 로 끼운 줄(PTZ 패드·시작 슬롯·랜덤 모드·주차면 번호)도 칠해야 하기 때문이다.

| 함수 | 역할 |
|---|---|
| `Theme::*` | 색 16개(카드 `#0E1419` 93%, 입력칸 `#18222A`, 테두리 `#2E3B45`, 글자 `#E6ECF0`, 강조 `#35C8B4`, 위험 `#E5746A` 등) |
| `ApplyTheme` | 트리 순회. 카드는 둥근 카드로 바꾼다. 밝은 단색 Border 는 어두운 바탕으로, 버튼 밖의 어두운 글자는 흰 글자로 바꾼다. 버튼·입력칸·콤보·체크박스·슬라이더는 각 Style 함수로 넘긴다 |
| `ClassifyButton` / `StyleButtonAs` | 라벨로 종류를 정한다. 저장·적용 = 강조 채움, 배치 시작·작업모드 시작·랜덤 적용·입차·출차 = 강조 테두리, 삭제·초기화·종료·정지 = 빨간 글자, 아이콘뿐인 버튼 = 투명(독) |
| `SetButtonActive` | 켜짐 상태 = 빨간 테두리·글자. 카메라 피킹, 배치 시작, 작업모드 세 곳에 쓴다 |
| `StyleEditableText` / `StyleCombo` / `StyleListRow` / `StyleComboItemText` | 입력칸, 드롭다운, 목록 행(선택 = 강조색 글자), 콤보 항목 글자 |

색을 이름이 아니라 **밝기로** 가르는 이유가 있다. 패널마다 위젯 이름이 제각각이고, 실제로 바꿔야 할 대상은 "어두운 카드 위에 남은 흰 칸과 검은 글자"이기 때문이다. 이미지 브러시와 배치용 투명 Border 는 건너뛴다.

## 패널별 변경
- **카메라**: 흰 드롭다운 람다와 입력칸 검정 지정을 지웠다. 피킹 버튼은 `SetBackgroundColor` 대신 `SetButtonActive` 를 쓴다(비-UPROPERTY `PickBtnDefaultColor` 삭제). 콤보 항목은 흰 글자로 바꿨다.
- **차량 배치**: 배치 시작을 `SetButtonActive` 로 바꿨다(`GPlaceOn/OffColor` 삭제). 콤보 항목은 흰 글자로 바꿨다. 목록 행(`CarListItemWidget::Setup`)은 `StyleListRow` 를 쓴다. `SelectedColor`/`NormalColor` 는 쿠킹된 WBP UPROPERTY 라 남겼다.
- **주차면 프리셋**: 목록 행을 `StyleListRow` 로 바꿨다(`GRow*`/`GText*` 삭제). `ApplyPresetWhiteDropdown` 과 입력칸 검정 지정을 지웠다. 방향 콤보에는 글자 생성 함수를 연결했다. 작업모드 버튼은 `SetButtonActive` 를 쓴다(`OffsetPickOriginalColor` 삭제).
- **차량 랜덤**: 모드 콤보 글자 생성 함수를 추가했다(UFUNCTION 추가만).
- **조명·시뮬 HUD·메뉴 독·맵 크기·거리 측정 창**: 흰 칸·검은 글자·올리브 배경 지정을 걷고 `ApplyTheme` 을 부른다.

## 함정 (다음 세션용)
1. **엔진 5.8 `UEditableTextBox::SetWidgetStyle` 은 Slate 위젯이 이미 있으면 인자 주소 `&InStyle` 을 넘긴다**(EditableTextBox.cpp:397). 지역 변수를 넘기면 포인터가 매달린다. 다음 프레임 `SEditableTextBox::DetermineFont` 에서 접근 위반으로 **기동 직후 죽었다**. 대책은 `Box->SetWidgetStyle(Box->GetWidgetStyle())` 로 멤버를 다시 넘기는 것이다. Button·ComboBoxString·CheckBox·Slider·Border 에는 이 문제가 없다(grep 확인).
2. **`UWidgetTree::ForWidgetAndChildren` 은 자식만 훑고 자기 자신은 건너뛴다.** 글자 하나짜리 버튼(대부분)의 라벨을 못 찾아 투명 버튼으로 잘못 분류됐다. 대책은 내용이 TextBlock 인지 먼저 보는 것이다.
3. **콤보 글자 생성 함수는 첫 선택(`SetSelectedOption`)보다 먼저 연결해야 한다.** 늦게 연결하면 닫힌 본문 글자가 WBP 색 그대로 남아 어두운 칸에 묻힌다.
4. **프리셋 패널 `Btn_OffsetPick` 만 반투명 바탕이 불투명 강조색으로 칠해졌다.** 같은 스타일의 "배치 시작"은 정상이었다. 틱 로그로 본 스타일 값은 알파 0.14 그대로였다. 원인은 WBP 의 배경색 바인딩으로 추정하지만 확인하지 못했다. 대책으로 반투명 대신 카드 위에 미리 섞은 불투명 색(`#132D2F`/`#173F3E`, 켜짐 `#302326`/`#462D2E`)을 쓴다.
5. 하위 폴더(Light/Map/Sim) 파일은 `#include "../Park3DPanelStyle.h"` 로 넣는다(모듈 루트가 include 경로에 없음).
