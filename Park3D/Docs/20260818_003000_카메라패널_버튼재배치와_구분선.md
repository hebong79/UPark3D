# 카메라 컨트롤 패널 — 버튼 재배치 · 그룹 구분선 · 독 아이콘 축소

- 날짜: 2026-08-18
- 브랜치: `feat/camera-panel-buttons`
- 요청
  1. 하단 동작 버튼을 PTZ 패드 오른쪽 빈 칸으로 옮기고 그룹 구분선을 넣을 것
  2. 저장/열기/초기화/카메라 피킹 시작 네 개는 패드 아래 전체 폭에 두고, 나머지 셋만 옆 칸으로
  3. 패널 폭은 디자이너 값 그대로 둘 것
  4. 독 버튼 크기를 약 80%로

## 1. 무엇을 바꿨나

| 대상 | 변경 |
|---|---|
| `MainMenuWidget` | 독 아이콘 22 → 18px(`DockIconSize`), WBP 생성 스크립트도 같은 값 |
| `CameraControlWidget::BuildPtzPad` | 패드 행에 세 번째 칸(`PtzSideColumn`) 추가. 최소 폭 120px |
| `RelocateActionButtons`(신규) | 폴대 보기 · 거리 측정 · PTZ 가져오기 세 줄을 옆 칸으로 이동 |
| `InsertGroupDividers`(신규) | 프리셋 / 위치 슬라이더 / PTZ 패드 / 하단 버튼 줄 경계에 1px 가로선 |
| `FitPanelToContent` | 1회 → 매 틱, 여백(chrome)은 상수가 아니라 실측 |
| `GPtzPadScale` | 1.5 → 1.0 |

버튼은 **옮기기만** 한다(부모만 바뀜) — 바인딩·클릭 핸들러·라벨 갱신 경로는 손대지 않았다.

## 2. 밟은 함정 넷

### ① "적용이 안 됐다"고 본 것이 실은 카드 밖으로 나간 것

첫 시도에서 화면은 예전 배치 그대로였다. 로그를 심어 보니 `버튼 재배치 — 옮길 줄 4개`로
**코드는 정상 실행 중**이었고, 옮긴 버튼이 어두운 카드 **바깥**(3D 화면 위)에 배경 없이
글자만 떠 있었다. 카드 폭이 캔버스 슬롯에 고정인데 `FitPanelToContent`가 **높이만** 맞추고
있었기 때문이다.

> 교훈: UI 변경이 "안 먹은 것처럼" 보이면 코드 실행 여부부터 로그로 가른다.
> 이 프로젝트에서 값이 들어갔는데 화면이 다른 사례는 이번이 세 번째다(조명 `light.get`, 아이콘 브러시).

### ② 폭을 늘리는 해법은 지시로 되돌렸다

카드를 본문 폭에 맞춰 넓히면 해결되지만 "패널 폭은 원래대로"라는 지시가 있었다.
그래서 **패드를 줄여서**(배율 1.5 → 1.0) 원래 폭 안에 옆 칸 자리를 만들었다.
네 버튼이 한 줄인 `저장/열기/초기화/피킹`은 좁은 옆 칸에서 라벨이 잘려("카메라 피킹 시…")
패드 아래 전체 폭에 남겼다.

### ③ 구분선을 검정으로 그어 배경에 묻혔다

카드가 어두운 회색인데 검정 28%로 그으니 아무것도 안 보였다. 흰색 35%로 바꾸니 나온다.
**"안 보인다"는 좌표보다 대비를 먼저 의심한다**(뷰어 십자 때와 같은 실수).

### ④ 여백을 상수로 찍어 하단 줄이 잘렸다

`GPanelChromeHeight = 16`은 제목줄 높이를 포함하지 않는다. 카드 높이를 `본문 + 16`으로
잡으니 하단 버튼 줄이 반쯤 잘렸다. 상수 대신 **레이아웃에서 잰다** —
`카드 높이 − 스크롤 영역 높이 = 본문 밖에 쓰인 높이`. 매 틱 다시 재므로 스스로 수렴한다.
`FitPanelToContent`를 1회 실행으로 잠갔던 것도 함께 풀었다 — 첫 성공 시점의 본문 높이는
줄 이동·구분선 삽입이 반영되기 전 값이라 최종값이 아니다.

## 3. 검증 환경 메모

- 개발 exe 단독 실행은 에디터의 Zen 스토리지에 붙는다. 에디터가 죽으면
  `Failed sending request to storage server`로 같이 죽는다 → 패키지를 복제(`Package/Work13530`)하고
  exe만 갈아끼워 확인했다(RPC 13530, 사용자 실행창 13510은 건드리지 않음).
- 창 캡처는 `PrintWindow(PW_RENDERFULLCONTENT)`로 하면 가려져 있어도 그려진다(포커스 안 뺏음).
  단 **클릭은 실제 입력이어야 한다** — `PostMessage`로 보낸 마우스 메시지는 Slate가 무시한다.
- 좌표 클릭은 위험하다. 창 크기가 캡처 때와 다르면 엉뚱한 버튼을 누른다 —
  실제로 `종료`를 눌러 인스턴스를 끈 적이 있다. 클릭 전 **창 크기 일치**와
  **대상 창이 맨 앞인지**를 검사하도록 스크립트에 가드를 넣었다.

## 4. 남은 것

- 카메라 위치를 카메라 단위로 공유하는 동작(이전 커밋)은 여전히 화면 검증 전이다.
- 패키지 재쿠킹은 하지 않았다 — C++ 만 바뀌었으므로 `Package/Windows` 에 exe 만 갈아끼우면 된다.
