# 시나리오 1단계 — `light.*` RPC 신설 + `cam.aimSlot`

- 날짜: 2026-08-13
- 대상: `Rpc/Modules/LightRpcModule.{h,cpp}`(신규), `Rpc/Modules/CamRpcModule.cpp`, `Rpc/RpcServerSubsystem.{h,cpp}`
- 근거 설계: [20260813_210842 시나리오 파일 스키마와 scenario.* RPC 설계](20260813_210842_시나리오_파일스키마와_scenario_RPC_설계.md) §7 ①②

## 왜 이 둘이 1단계인가

가림 연출 시나리오를 파일로 저장·재현하려면 두 구멍을 먼저 막아야 했다.

1. **조명이 RPC에 없었다.** 등록 모듈이 8개(Cam·Car·Map·Measure·Preset·Random·Sim·View)뿐이었다.
   가림률을 픽셀 수로 재는데 측정 중 노출이 바뀌면 수치가 통째로 오염된다.
2. **카메라 구도가 레이아웃 전용 숫자였다.** `pan 58.1 / tilt 21.7 / zoom 4.9` 는 office 배치에서만 뜻이 있다.
   다른 주차장에 올리면 사람이 다시 계산해야 한다.

## `light.*` (5)

백엔드는 조명 설정 패널과 같다 — `ALightControlManager::ApplySettings/CaptureCurrent/GetLastApplied` +
`ULightControlLibrary::SaveToFile/LoadFromFile/SetDefaultFile`. 새 로직을 만들지 않고 결선만 했다.

| method | 동작 |
|---|---|
| `light.get` | 현재 레벨 조명을 되읽는다. `fromWorld` 로 월드에서 읽었는지 마지막 적용값인지 구분 |
| `light.set` | 전달한 항목만 바꿔 즉시 적용(부분 수정) |
| `light.save` | 현재 상태를 `Save/3D/Light/<fileName>.json` 으로 |
| `light.load` | 파일을 읽어 적용. `apply:false` 면 값만 반환 |
| `light.setDefault` | 기동 시 적용되는 기본 파일 포인터 갱신 |

필드: `exposureEV100` `sunIntensity` `sunAltitudeDeg` `sunAzimuthDeg` `skyIntensity` `sunColor{x,y,z}`(RGB 0~1).

`light.set` 의 기준은 **마지막 적용값이 아니라 현재 월드 상태**다(`CaptureCurrent` 우선).
마지막 적용값에서 출발하면 사용자가 패널로 바꿔 둔 값을 조용히 되돌려 버린다.

## `cam.aimSlot`

```
cam.aimSlot {camId, presetIdx, slot, widthSlots=3}
  → {ok, camId, pan, tilt, zoom, hfovDeg, distM, slotCenter{x,y,z}}
```

주차면 한 칸을 겨냥하도록 PTZ를 계산해 적용한다. 기하 권위는 `ComputeSlotCorners` —
라인·데칼·차량배치와 같은 사각형 위에서 계산하므로 렌더와 어긋나지 않는다.

```
슬롯 중심 = 바닥 사각형 4점의 평균 (slot 은 1부터, FaceIndex 는 0부터)
pan  = atan2(ΔY, ΔX)                      // UE Yaw, 0°=+X, +방향=+Y
tilt = atan2(-ΔZ, 수평거리)                // 양수가 하향
zoom = HFovToZoom( 2·atan( (widthSlots·xSize/2) / 슬랜트거리 ), Cam->MaxZoom, Cam->DefaultHFov )
```

화각은 슬랜트 거리(3D)로 잡는다. 수평거리로 잡으면 내려다보는 각이 클수록 화면이 좁아진다.
`MaxZoom`/`DefaultHFov` 는 **액터 인스턴스 값**을 쓴다(라이브러리 기본 인자는 config 오버라이드를 모른다).

이제 시나리오 파일에 각도를 적지 않고 "1번 프리셋 6번 면을 화면 폭 3칸으로"라고 쓸 수 있다.

## 검증 (전부 실행 확인)

빌드 `Result: Succeeded`. 카탈로그에 `cam.aimSlot`, `light.get/set/save/load/setDefault` 등록 확인(총 101개).

**`light.*`**

- `light.get` → `fromWorld:true`, `exposureEV100 -1.02 / sunIntensity 5 / altitude 44.478 / azimuth 304.535 / sky 1`.
- `light.set {exposureEV100:-0.5}` → 반환 -0.5. 이어서 `light.get` 이 **월드에서** -0.5 로 읽힘(`fromWorld:true`)
  → 값만 기억하는 게 아니라 실제로 적용된다. -1.02 로 원복함.

**`cam.aimSlot {camId:1, presetIdx:1, slot:6, widthSlots:3}`**

```
pan 58.0635  tilt 22.8716  zoom 4.9769  hfov 12.324°  거리 34.734m
slotCenter (-19.371, 13.559, 0)
```

- `slotCenter` 가 기획서의 손계산값 `(-19.371, 13.56)` 과 일치.
- `pan 58.06` 도 손계산 `58.1` 과 일치. `tilt 22.87` 은 손계산 `21.7` 과 다른데,
  손계산이 대상 높이 0.75 m 를 가정했고 이쪽은 지면(z=0)을 겨냥하기 때문이다 — 예상된 차이.
- `cam.getPTZ` 로 되읽어 세 값이 그대로 유지됨을 확인.
- **캡처로 실측**: 1280×720 PNG 에 주차면이 약 3칸 폭으로 잡혔다 →
  설계서 미확인 #1(zoom 식이 실제 캡처와 맞는가)이 **해소**됐다.

## 작업 환경 변경 — 별도 포트 작업본

사용자 지시(2026-08-13): **본래 실행창을 건드리지 말고 새 RPC 포트 + 새 빌드 사본으로 작업할 것.**

```
원본   Package/Windows       RPC 13510, cam 13601~13650   ← 건드리지 않는다
작업본 Package/Work13520     RPC 13520, cam 13701~13750   ← 빌드 검증은 여기서
```

- 작업본은 `robocopy /MIR` 로 복제(3.6 GB) 후 exe 만 새 빌드로 교체한다.
- 기동: `Park3D.exe -RpcPort=13520` (커맨드라인이 config 보다 우선).
  작업본의 `Save/Config/config_pmaker.json` 도 13520/13701~13750 으로 바꿔 뒀다 —
  **카메라 스트림 포트 대역이 겹치면 두 인스턴스가 충돌한다.**
- MCP 브리지는 호출별 `port` 인자를 실제로 따른다(확인: `system.health {port:13520}` → `port:13520`).
- `Package/` 는 `.gitignore` 에 있어 작업본은 커밋되지 않는다.

## 미해결 — 13510 인스턴스에서 zoom 이 먹지 않았다

작업본을 만들기 전 원본 인스턴스(13510)에서는 같은 호출이 이상하게 동작했다.

| 호출 | 13510 (원본) | 13520 (작업본) |
|---|---|---|
| `cam.aimSlot` 후 `getPTZ` zoom | **2.22** (요청 4.977) | 4.977 ✅ |
| `cam.setZoom {zoom:5}` 후 `getPTZ` | **16.24** | 5.000 ✅ |
| `cam.get` 의 pan vs `cam.getPTZ` 의 pan | **61.48 vs 58.06** (불일치) | — |

pan/tilt 는 들어갔는데 zoom 만 엉뚱한 값이 되고, 읽을 때마다 값이 달랐다.
**깨끗한 인스턴스에서는 재현되지 않는다** → 코드 버그가 아니라 그 인스턴스 쪽 간섭으로 판단한다.
카메라 컨트롤 패널이 열려 있어 슬라이더 값이 매 틱 덮어썼을 가능성이 가장 크지만 **확인하지 못했다**.

관련해서 남기는 사실: 이 진단 과정에서 **13510 의 카메라 PTZ 와 조명을 내가 바꿨다**.
조명은 -1.02 로 원복했으나 카메라는 슬롯 6 을 겨냥한 상태로 남아 있다.
되돌리려면 `cam.loadPreset {camId:1, presetId:N, fileName:"CamPos_office"}`.
