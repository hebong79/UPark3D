## 종합 판정
- **고위험 회귀 없음**. 빌드 + 자동화 8개 + HTTP 스모크 전부 통과. 매니저/액터/라이브러리 코드 무수정이라 회귀면 최소.
- **교차 관측(실패 아님)**: pos 규약이 Unity 원본(y=높이)과 축 대응이 다르다(이 프로젝트는 z=높이). Phase 1 전역 결정 사항으로 measure 국소 문제 아님. 전역 좌표 어댑터는 별도 과제로 사용자 판단 필요 → 문서에 명시.
- 미검증(선택): 실제 PIE에서 Landscape 히트 기반 cameraHeight 실측(헤드리스는 폴백 경로 검증). 로직·거리·각도·상태는 검증 완료.
