## 1. 마젠타의 출처 — **엔진이 아니라 웹이었다**

22:05 작업에서 "마젠타가 재현되지 않는다"로 남겨 둔 건이 **정본 RPC 로그 한 줄로 갈렸다**.

```
[RPC] 192.168.0.221 car.select    {"carNameId":"1-23.36.13"}
[RPC] 192.168.0.221 car.setColor  {"carNameId":"1-23.36.13","r":1,"g":0,"b":1}   ← 마젠타
...
[RPC] 192.168.0.221 car.resetColor {"carNameId":"1-23.36.13"}                    ← 해제
```

SettingManager 웹이 **차량을 선택할 때마다 `car.select` 바로 뒤에 `car.setColor {1,0,1}` 을 같이
쏘고**, 선택을 옮길 때 `car.resetColor` 로 되돌린다. 내가 정본에서 A/B 를 뜰 때는 `car.select` 만
불렀으므로 마젠타가 나올 수 없었다 — **재현 실패의 원인은 호출 주체가 달랐던 것**이다.

그러므로 화면의 "두 가지"는 한 머티리얼의 두 효과가 아니라 **서로 다른 두 주체**였다.

| # | 주체 | 수단 |
|---|---|---|
| ① | 웹(192.168.0.221) | `car.setColor {1,0,1}` — 차체 **도색을 통째로** 마젠타로 |
| ② | 엔진 | 오버레이 머티리얼 `/Game/UI/M_CarSelect` |

22:05 에 고친 것은 ② 뿐이라 ①이 그대로 남아 "아직도 2개"로 보였다.

**①은 이 저장소에서 못 고친다** — 호출자는 다른 PC(192.168.0.221)의 웹이고, 이 PC 의
`D:\Work\Parking3D\Agent\baro\SettingManager` 소스에는 `car.setColor` 호출이 없다(메서드 카탈로그
항목뿐). 선택 시 마젠타를 없애려면 **그쪽에서 `car.select` 뒤의 `setColor`/`resetColor` 두 줄을
빼야 한다**. 엔진 쪽 표시만으로 충분해진 상태다.

## 2. 엔진 표시 — 프레넬을 떼고 균일한 반투명으로

`/Game/UI/M_CarSelect` 의 블렌드·셰이딩(Unlit · Translucent · TwoSided)은 그대로, **입력 두 개만
상수로 갈아끼웠다**.

```
전: Fresnel(Exponent=2.5, Base=0) ─┬─ × Constant3Vector(0, 10, 13) ─→ EmissiveColor
                                   └───────────────────────────────→ Opacity

후: Constant3Vector(0.35, 0.72, 1.0) ─→ EmissiveColor
    Constant(0.45)                   ─→ Opacity
```

- 프레넬이 두 입력을 모두 몰던 것이 **"테두리"와 "색 입힘"이 한 머티리얼에서 같이 나오던 이유**다.
  떼어내면 면 방향과 무관한 균일한 필름이 된다.
- 덤으로 **거리에 따라 테두리가 얇아져 사라지던 문제도 같이 없어졌다**(09-22 실측: 23 m 에서 한두 픽셀).
  상수 불투명도는 거리와 무관하다.
- 프레넬·곱셈 노드는 **지우지 않고 연결만 끊었다** —
  `MaterialEditingLibrary.delete_all_material_expressions` 는 `Assertion failed: !IsRooted()` 로
  commandlet 을 죽인다(UE 5.8).

값의 정본은 `Tools/car_select/build_select_material.py`(`Content/` 는 git 밖). 재적용 명령은 그 파일
docstring 에 있다.

| 값 | 선택 이유 |
|---|---|
| 색 `(0.35, 0.72, 1.0)` | Unlit 이라 이 값이 화면에 그대로 나간다. 1 을 넘기지 않아 흰 차·밝은 노면 위에서 형광으로 튀지 않는다 |
| 불투명도 `0.45` | 차종·도색·번호판이 비쳐 보이면서도 선택 여부가 한눈에 갈린다 |

### 함정

- 카메라에서 차량 방위각을 잴 때 `atan2(dx, dy)` 로 계산해 **엉뚱한 차를 선택하고는 "표시가 아예
  안 나온다"고 오판했다**. UE yaw θ 의 전방은 `(cosθ, sinθ)` 이므로 **`atan2(dy, dx)`** 다.
  화면에 안 보이는 차를 선택해 놓고 머티리얼을 의심한 시간이 있었다 — 선택 대상이 **프레임 안에
  있는지부터** 확인할 것(A/B 차분 픽셀 수로 가른다).
- 실행 중 인스턴스는 머티리얼을 메모리에 들고 있어 `.uasset` 을 고쳐도 핫리로드되지 않는다.
