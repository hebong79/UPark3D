# 콤보박스 드롭다운 메뉴 배경색 변경 (흰색계열 회색)

작성일: 2026-06-23
대상: `PresetMakerWidget` 의 `Combo_DirType` (UComboBoxString, Dir Type 선택)
작업 유형: UI 스타일 수정 (사소 변경 — 설계 게이트 경량 처리)

---

## 1. 요구사항
- 콤보박스의 **드롭다운 메뉴 배경색**을 흰색계열의 회색으로 변경.

## 2. 설계 생략 사유 (CLAUDE.md 0번 규칙)
- 자료구조/인터페이스/흐름 변경 없음. 콤보박스 스타일 1개 속성 조정만 해당하는 사소 변경이므로
  전체 설계서를 생략하고 본 문서에 결정 근거만 기록함.

## 3. 변경 방식 결정
- 드롭다운 메뉴 배경은 `UComboBoxString`의
  `WidgetStyle.ComboButtonStyle.MenuBorderBrush`(FSlateBrush)가 결정한다.
- `Combo_DirType`는 NativeConstruct에서 옵션을 채우는 기존 블록이 있으므로, **같은 블록에서 C++로 스타일을 지정**한다.
  - 근거: ① 옵션 세팅과 같은 위치라 응집도 높음, ② 코드라 버전관리/추적 가능,
    ③ `GetWidgetStyle()`/`SetWidgetStyle()` API가 UE 5.7에 존재.
- 배경을 **단색 박스 브러시**(DrawAs=Box)로 교체하여, 기존 어두운 메뉴 이미지에 의존하지 않고
  원하는 밝은 회색을 결정적으로 표현한다.

## 4. 구현 내용
파일: [PresetMakerWidget.cpp](../Source/Park3D/PresetMakerWidget.cpp)
함수: `UPresetMakerWidget::NativeConstruct()` — `Combo_DirType` 설정 블록

```cpp
// 드롭다운 메뉴 배경색을 흰색계열의 밝은 회색으로 변경(가독성).
// 메뉴 배경은 WidgetStyle.ComboButtonStyle.MenuBorderBrush 가 결정한다.
FComboBoxStyle ComboStyle = Combo_DirType->GetWidgetStyle();
FSlateBrush MenuBrush;
MenuBrush.DrawAs = ESlateBrushDrawType::Box;
MenuBrush.TintColor = FSlateColor(FLinearColor(0.85f, 0.85f, 0.85f, 1.0f));
ComboStyle.ComboButtonStyle.MenuBorderBrush = MenuBrush;
Combo_DirType->SetWidgetStyle(ComboStyle);
```

- 적용 배경색: `FLinearColor(0.85, 0.85, 0.85, 1.0)` — 흰색에 가까운 밝은 회색.
- `DrawAs = Box` + `TintColor` 로 단색 채움(별도 이미지 리소스 없이 균일한 배경).

## 5. 검증 (CLAUDE.md 1·2번 규칙)
- **컴파일**: Live Coding 컴파일 성공 — `Park3D.log`: `06:56:41 Live coding succeeded`.
- **동작 확인(미완)**: 스타일은 `NativeConstruct`(위젯 생성 시) 적용되므로 기존에 떠 있는 위젯에는
  즉시 반영되지 않는다. → **WBP_PresetMaker UI를 다시 열거나 Play 시** 콤보박스를 펼치면 밝은 회색 배경 표시.
  시각 확인은 사용자가 드롭다운을 펼쳐 진행 필요(자동 PIE 검증은 크래시 이슈로 미수행).
- 단위 테스트: UMG 시각 속성이라 별도 자동 단위 테스트 미작성(검증은 시각 확인으로 대체).

## 6. 영향도 분석 (CLAUDE.md 4번 규칙)
- **범위**: `PresetMakerWidget.cpp` 단일 파일, `Combo_DirType` 블록 내 코드 추가. 헤더 변경 없음.
- **의존성**: 추가 include 불필요(`Components/ComboBoxString.h` 이미 포함, FSlateBrush/FComboBoxStyle 전이 포함).
- **기존 기능 영향**: 없음. 드롭다운 표시 색상만 변경하며 옵션 목록·선택 로직과 무관.
- **다른 콤보박스**: 현재 위젯의 콤보박스는 `Combo_DirType` 1개뿐 → 영향 대상 단일.
- **회귀 위험**: 낮음. 배경이 밝아져 글자(어두운 색)와 대비가 충분한지 시각 확인 권장.

## 7. 조정 방법(참고)
- 더 희게: 값 키움(예: `0.92`).  더 진한 회색: 값 낮춤(예: `0.75`).
- 항목(행) 배경/선택색까지 바꾸려면 `ItemStyle`(FTableRowStyle)의
  `EvenRowBackgroundBrush`/`OddRowBackgroundBrush`/`ActiveBrush` 등을 추가 조정.
- 위치: [PresetMakerWidget.cpp](../Source/Park3D/PresetMakerWidget.cpp) `MenuBrush.TintColor`.
