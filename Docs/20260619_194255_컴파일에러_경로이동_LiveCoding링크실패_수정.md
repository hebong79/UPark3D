## 2. 원인

**프로젝트 폴더를 `D:\Work\Unreal\Test\Parking` → `D:\Work\Unreal\Project\Parking`로 이동(복사)했으나, 빌드 캐시에 옛 경로(`Test`)가 그대로 박혀 있었음.**

근거(실측):
- 입력 obj 파일 경로 = `...\Project\Parking\...` (현재 위치, 정상)
- 출력 patch 파일 경로 = `...\Test\Parking\...` (옛 위치, **존재하지 않음**)
- 옛 경로 `D:\Work\Unreal\Test\Parking` → 디렉터리 자체가 삭제되어 없음
- `Intermediate` 내 캐시에 `Test` 경로 다수 잔존:
  - `SourceFileCache.bin`, `ActionHistory.bin`, `DependencyCache.bin`
  - 링커 응답 파일 `*.rsp.old` (출력 경로가 `Test`로 기록됨)

Live Coding은 빌드 캐시에 기록된 원본 모듈 경로 옆에 patch(.lib/.exp/.dll/.exe/.pdb)를 기록하는데, 그 경로(`Test`)가 사라져 쓰기에 실패 → 링크 깨짐.

> 소스 코드 결함이 아니라 **빌드 환경(경로 캐시) 문제**였다.
