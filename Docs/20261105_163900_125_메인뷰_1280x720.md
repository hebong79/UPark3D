# .125 메인 뷰 1280×720 전환

2026-11-05, w-sim-unreal2(.125). BOOK c5719, c5723.

승인: PM 명령 2건.

- 1차 마스터 원문은 목록 1번에 대한 「1,2,3, 진행해줘.」, 원 요청은 「사후 복구 프로그램에서는 시뮬레이터에서 메인 화면을 1280*720 해상도로 전송할수 있게 설정해줘.」이다.
- 2차 마스터 원문은 「AA 만 끄고 재측정 (권장)」이다.

## 1. 지금 상태

정본 `Package\Windows\Park3D\Saved\Config\Windows\Game.ini`. git 밖 파일이고 코드·exe·쿡은 그대로다.

```
[/Script/Park3D.CamStreamSubsystem]
MainWidth=1280
MainHeight=720
```

AA 줄을 지우면 쿡된 `DefaultGame.ini` 의 `bMainDisableAntiAliasing=True` 로 돌아가므로 AA 는 꺼진다. 측정에서 `guard.antiAliasingDisabled: true` 로 확인했다.

되돌리기: 이 파일을 지우고 재기동하면 960×540, AA 꺼짐이다.

## 5. 판정

**설정은 먹었다. 그러나 AA 를 꺼도 tickFps 는 약 14 로 PM 이 정한 기준 15 에 못 미친다.**

- AA 를 끄면 tickFps 는 약 1.5 오르고 프레임 용량은 약 9 % 늘어난다.
- 기동 약 1~2 분 뒤 측정이라 더 긴 시간의 값은 모른다. AA 꺼짐 2 회가 1 회보다 조금 높다.
- 10-23 AA 켬 설정은 tickFps 18.9 였다(#1760 c5120). 그 뒤 10-29 에 캡처 Lumen 복구가 들어갔는데, 이것이 이번 차이의 원인인지는 재지 않았다.
- 프레임 화질은 눈으로 보지 않았다. 확인한 것은 JPEG 머리글의 크기다.

**마스터 결정(PM 세션 선택): 「1280×720 유지 (권장)」.** 지금 설정(AA 꺼짐)을 유지하고 재기동하지 않았다. M16 실시험에서 사람 10명일 때 다시 잰다.
