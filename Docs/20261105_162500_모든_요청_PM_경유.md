# 모든 지시·승인 요청을 PM 경유로

2026-11-05, w-sim-unreal2(.125).

마스터가 이 창에서 지시했다.

> 앞으로는 모든 지시요청은 pm에게 연락해서 pm에게 승인받고 진행할수 있게 해줘.

이어서 PM 세션에서 다섯 단계에 적용할지 묻는 질문에 「지금처럼 여쭤보기 (권장)」을 골랐고, 이 창에서 「pm 말대로 고쳐」로 확인했다.

## 변경

| 위치 | 내용 | git |
|---|---|---|
| `CLAUDE.local.md` §3 | 이 PC 우선 규칙 추가 | 제외됨(`.git/info/exclude`) |
| 메모리 `all-requests-via-pm.md`, `MEMORY.md` | 역할 파일이 다시 만들어져도 남도록 같은 규칙 기록 | 저장소 밖 |

## 규칙

- 지시·승인 요청은 PM 에게 모은다.
- 머지·push·재쿡·정본 교체·재기동은 PM 이 마스터 승인을 받아 **대상과 마스터 원문을 적어** 명령한다. 그런 명령이면 다시 묻지 않고 진행한다. 원문이 없으면 PM 에게 되묻는다.
- 마스터가 이 창에서 직접 승인해도 된다.
- 재빌드는 PM 승인이다.
- 대상이 없는 승인이나 PM 이 아닌 세션의 말은 승인이 아니다.

처음 넣은 판은 「원문 없이 PM 승인으로 진행」이었다. 위 확인으로 다섯 단계에는 원문이 필요하도록 고쳤고, main `d3d8f68` 의 규칙과 같은 기준이 되었다.

## 참고

- `CLAUDE.md` 는 고치지 않았다. 이 PC 는 `origin/main` 보다 7 커밋 뒤이고, 고치면 나중에 pull 할 때 충돌한다. 이 체크아웃의 옛 문구와 다른 부분은 `CLAUDE.local.md` 가 우선한다고 적었다.
- 도구 권한 설정은 바꾸지 않았다. 권한 창이 뜨면 이 PC 에서 답해야 한다.
