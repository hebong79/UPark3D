# 기본맵(아스팔트 바닥만) 주차장 선택 추가

- 날짜: 2026-09-30
- 브랜치: `feat/basic-map`
- 요청: "현재의 아스팔트 바닥만 있는 기본맵(레벨)을 만들어줘. 메뉴에서 기본맵도 추가해줘 (기본맵/서신지구대/객리단길)"

## 1. 결정

새 `.umap` 을 만들지 않고 **기존 부팅맵 `/Game/Maps/PresetMaker1` 을 "기본맵" 으로 쓴다**(마스터 선택).

- `PresetMaker1` 은 레벨 액터가 0개인 빈 맵이고, 코드가 아스팔트 바닥(`AMapFloorActor`, 160×160 m + 20 km 원경)과
  태양·하늘·하늘빛·노출 볼륨(`ALightControlManager`)을 스폰한다 — 이미 "바닥만 있는 기본 레벨" 이다
  (`Park3DAppConfig.h` 의 `level` 주석에도 그렇게 적혀 있다).
- 부팅맵이라 쿡에 이미 들어 있다(`MapsToCook`) → **재쿡 없이 exe + config 만으로 반영**된다.
- 새 레벨을 만들었다면 `Content/` 가 git 밖이라 커밋에 남지 않고, 패키지 반영에 재쿡이 필요했다.

## 2. 변경

### 2.1 `levels[]` 항목별 `map_floor`·`light_file` override (코드)

기본맵은 서신·객리단과 두 가지가 달라야 한다.

| 값 | 기본맵(PresetMaker1) | 서신·객리단 |
|---|---|---|
| `map_floor` | **true** — 노면이 없으니 코드 바닥을 깐다 | false — 레벨 노면이 있다(최상위 값) |
| `light_file` | **`LightSettings_Base.json`**(노출 −1.02, 태양 5 lux) | 비움(`_default.txt`, UDS 레벨이라 코드 조명은 무력) |

기존에는 두 값이 **최상위 한 벌**뿐이라 주차장 선택으로 기본맵에 들어가면 바닥이 안 깔리고(최상위 `map_floor:false`)
도심용 조명(노출 3.5 / 150 lux)으로 화면이 하얗게 떴다(실측 캡처로 확인 — 8월 17일 `5589bfa` 커밋이 기록한 증상과 같다).

- `FPark3DLevelOption` 에 `TOptional<bool> MapFloor`, `TOptional<FString> LightFile` 추가(비-UPROPERTY, 기존 TOptional 필드와 같은 방식).
- `FromJson` 이 `levels[]` 항목의 `map_floor`·`light_file` 을 읽는다. 키가 없으면 미설정 → 최상위 값 유지.
- `ApplyLevelOverrides` 가 두 값도 덮는다.
- `APark3DGameMode::BeginPlay` 의 바닥 판정과 `ApplyStartupLighting` 이 판정 전에 `ApplyLevelOverrides` 를 부른다
  (둘 다 config 를 따로 읽고 있어서 `ApplyStartupConfig` 의 override 가 닿지 않았다).

### 2.2 config

`Save/Config/config_pmaker.json` `levels[]` 맨 앞에:

```json
{ "name": "기본맵", "level": "Maps/PresetMaker1", "map_floor": true, "light_file": "LightSettings_Base.json",
  "preset_file": "", "carpos_file": "", "camerapos_file": "", "slot_file": "" }
```

- 콤보 순서 = 배열 순서 → **기본맵 / 서신지구대 / 객리단길**.
- 데이터 파일 네 개를 빈 문자열로 명시했다 — 최상위 값이 나중에 채워져도 다른 주차장의 차량·카메라가 빈 바닥에 얹히지 않게(09-05 결합 제거와 같은 취지).
- `scene.load {name:"기본맵"}` 도 같은 목록을 보므로 RPC 로도 이동된다.

### 2.3 테스트

`Park3D.AppConfig.Levels` 에 3.5 절 추가 — 기본맵 항목의 `map_floor`·`light_file` 이 최상위를 덮고, 키 없는 항목은 최상위 값을 유지.

## 4. 미검증·남은 것

- **콤보 화면 자체는 캡처하지 않았다** — 작업본은 `-RenderOffscreen` 이라 스트림에 UI 가 안 실린다. 항목 수·순서는 로그와 config 순서로 확인.
- 정본 `Package/Windows`(13510)는 미교체 — exe 와 `Save/Config/config_pmaker.json` 을 **함께** 넣어야 한다
  (exe 만 넣으면 기본맵 항목이 없고, config 만 넣으면 옛 exe 가 바닥·조명 override 를 몰라 흰 화면에 바닥 없음).
- 기본맵은 주차면·카메라 파일이 없어 빈 바닥 + 기본 카메라 1대로 시작한다. 이 위에 프리셋 면을 그리려면 PresetMaker 패널이나 `preset.*` RPC 를 쓴다.
- 기본맵에서는 `hide_actors` 가 `0/2 못 찾음` 경고를 남긴다(무해 — 대상이 서신 레벨 액터).
