# 온스크린 메시지 좌하단 이동 (커스텀 뷰포트 클라이언트)

- 날짜: 2026-07-01 18:29:50
- 대상: `Park3D/Source/Park3D/ParkGameViewportClient.h/.cpp`(신규), `Park3D/Config/DefaultEngine.ini`
- 유형: 신규 기능(엔진 렌더링 훅)
- 요청: "화면 좌상단에 출력되는 로그(엔진 온스크린 메시지)를 좌하단에 출력. UI(좌상단 패널)가 가리지 않게."

## 1. 원인 / 배경

- 좌상단 빨간 메시지("RAY TRACING GEOMETRY … MEMORY … BUDGET")는 **엔진이 출력하는 온스크린 디버그 메시지**(레이트레이싱 지오메트리 메모리 예산 경고)다. 우리 코드(`CarPlacementWidget::Notify`)는 화면이 아니라 로그(UE_LOG)만 쓴다.
- 엔진 온스크린 메시지는 `UGameViewportClient::Draw` → `DrawStatsHUD` → `UEngine::DrawOnscreenDebugMessages` 경로로 **좌상단(MessageStartY≈45/100)에서 아래로** 그려진다. 좌상단은 차량배치 패널이 가린다.

## 2. 설계 (엔진 소스 분석 기반, UE 5.8)

엔진 코드 분석으로 확인한 사실:
- `AddOnScreenDebugMessage`(메시지 수집)는 멤버 `UEngine::bEnableOnScreenDebugMessages` 로 게이트 → **전역 `GAreScreenMessagesEnabled` 를 꺼도 메시지는 계속 쌓인다.**
- 엔진의 좌상단 그리기(`DrawStatsHUD` 내부)는 전역 `GAreScreenMessagesEnabled` 로 게이트.
- `UEngine::DrawOnscreenDebugMessages(World, Viewport, Canvas, CanvasObject, MessageX, MessageY)` 는 **public**(직접 호출 가능). 지정 `MessageY`에서 아래로 그리고, 만료(시간 경과)까지 처리(프레임당 1회).
- 호출 순서: `PostRender(DebugCanvasObject)` → (이후) `DrawStatsHUD`. 즉 **PostRender 가 엔진 좌상단 그리기보다 먼저** 실행된다.

→ 전략: 커스텀 `UGameViewportClient::PostRender` 에서
1. 좌하단 좌표로 `DrawOnscreenDebugMessages` 를 **직접 호출**해 메시지를 그린다.
2. `GAreScreenMessagesEnabled = false` 로 그 프레임의 엔진 좌상단 재그리기를 억제한다(메시지 수집은 유지되므로 다음 프레임도 정상).

메시지 배열(`PriorityScreenMessages`/`ScreenMessages`)은 UEngine에서 **private** 라 직접 접근 불가 → 배열을 읽지 않고 공개 함수 `DrawOnscreenDebugMessages` 를 재호출하는 방식으로 우회.

## 3. 변경 내용

### 신규: `ParkGameViewportClient.h/.cpp`
```cpp
void UParkGameViewportClient::PostRender(UCanvas* Canvas)
{
    Super::PostRender(Canvas);
    if (GEngine && Canvas && Canvas->Canvas)
    {
        if (UWorld* MyWorld = GetWorld())
        {
            const float MessageX = 40.f;
            const float MessageY = FMath::Max(60.f, Canvas->SizeY - 260.f); // 좌하단
            GEngine->DrawOnscreenDebugMessages(MyWorld, Viewport, Canvas->Canvas, Canvas, MessageX, MessageY);
        }
    }
    GAreScreenMessagesEnabled = false; // 엔진 좌상단 재그리기 억제
}
```

### `DefaultEngine.ini` — 뷰포트 클라이언트 등록
```ini
[/Script/Engine.Engine]
GameViewportClientClassName=/Script/Park3D.ParkGameViewportClient
```

## 4. 영향도 분석

- **모듈/의존성**: `UGameViewportClient`/`UCanvas`는 Engine, `GAreScreenMessagesEnabled`는 Core — Build.cs에 이미 포함. 신규 의존성 없음.
- **적용 범위**: 게임(PIE/standalone) 뷰포트 전체의 온스크린 디버그 메시지 위치가 좌하단으로 변경. 우리 및 엔진 메시지 모두 포함.
- **부수 효과**: `GAreScreenMessagesEnabled` 를 매 프레임 끄므로, `DrawStatsHUD` 의 온스크린 메시지 블록에 함께 묶인 일부 항목(맵 경고/버전 문자열 등)은 좌상단에 표시되지 않게 됨. `DrawOnscreenDebugMessages`가 담당하는 메시지(레이트레이싱 경고 포함, AddOnScreenDebugMessage 계열)는 좌하단에 정상 표시. `stat` 계열 통계는 별도 경로라 영향 없음.
- **셰이더/쿠킹**: 무관. 데이터/JSON 무관.
- **회귀 위험**: 렌더링 표시 위치 변경만. 게임 로직·차량배치 기능과 독립.

## 5. 검증 / 주의

- **컴파일**: Ctrl+Alt+F11.
- **설정 반영 주의**: `GameViewportClientClassName` 은 **엔진 시작 시 1회 해석**되어 `GEngine`에 캐시된다. 따라서:
  - **Standalone(새 프로세스)**: 새 프로세스가 ini를 새로 읽어 커스텀 뷰포트가 적용됨 → **standalone 실행으로 검증 권장**.
  - **에디터 PIE**: 이미 실행 중인 에디터는 기존 값을 캐시하므로, 적용하려면 **에디터 재시작** 필요할 수 있음.
- **확인 항목**:
  1. Standalone 실행 → 레이트레이싱 경고 등 온스크린 메시지가 **좌하단**에 표시되는지.
  2. 좌상단 패널과 겹치지 않는지.
  3. 차량배치/이동/회전/랜덤배치 등 기존 기능 정상.

## 6. 후속 참고

- 메시지가 많아 좌하단에서 아래로 넘칠 경우, `MessageY` 시작값(현재 SizeY-260)을 늘리거나 위로 쌓는 레이아웃으로 개선 가능(별도 커스텀 렌더링 필요).
- 특정 메시지(예: RT 경고)만 숨기고 싶으면 별도로 cvar/필터를 추가할 수 있음.
