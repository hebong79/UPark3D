# 선택바 숨기기 체크박스 재정의 — 선택 프리셋을 원래 색으로 표시

- 작성일: 2026-06-22 23:18:31
- 작업 유형: 기능 수정(체크박스 동작 재정의). 함수 본문만 변경.
- 대상: `Park3D/Source/Park3D/PresetMakerWidget.cpp`

## 1. 요구사항
"선택바 숨기기" 체크박스는 **선택된 프리셋 오브젝트의 선택 강조색을 끄고 원래 색으로 보이게** 하는 기능이어야 한다.

## 2. 현황(수정 전)
- `HandleHideBarChanged`는 프리셋 **리스트 패널(`PresetList_Border`)의 표시/숨김**을 토글 → 요구와 다름.
- 3D 렌더: `DrawPreset`에서 `Color = bSelected ? SelectColor : LineColor`. `bSelected = (i == SelectedIndex)`.

## 3. 수정 (최소·외과적, 위젯만)
선택 강조 여부는 `RebuildAll`에 넘기는 선택 인덱스로 결정된다. 체크 시 `INDEX_NONE`을 넘기면 어떤 면도 `bSelected`가 되지 않아 모두 원래 색(LineColor)으로 그려진다 → 매니저/시그니처/신규 멤버 변경 불필요.

### RefreshView
```cpp
const bool bHideSelection = Check_HideBar ? Check_HideBar->IsChecked() : false;
const int32 SelForView = bHideSelection ? INDEX_NONE : SelectedIndex;
Mgr->RebuildAll(Presets, SelForView, b3D);
```

### HandleHideBarChanged
```cpp
void UPresetMakerWidget::HandleHideBarChanged(bool /*bIsChecked*/)
{
    RefreshView();   // 체크 상태를 RefreshView 가 읽어 즉시 반영
}
```
- 기존 리스트 패널 숨김 동작은 제거(요구에 맞춰 용도 변경).

## 4. 동작
- 체크 ON → 선택된 프리셋도 원래 색(LineColor)으로 표시(강조 없음).
- 체크 OFF → 선택된 프리셋은 SelectColor 로 강조(기존).
- 선택/추가/수정/이동 등 RefreshView 호출 경로 모두 체크 상태를 반영.

## 5. 영향도
- `PresetMakerWidget`의 두 함수 본문만 변경. 헤더·신규 UPROPERTY·매니저 변경 없음.
- **`PresetList_Border` 멤버가 코드상 미사용으로 전환됨**: `BindWidgetOptional` UI 바인딩이라 제거 시 헤더/리플렉션 변경이 추가되어, 무해성을 고려해 멤버는 **유지**(향후 재사용 여지). 제거를 원하면 알려주면 정리.
- JSON/저장 데이터/카메라/입력 무관. 시각화만 변경.

## 6. 검증 상태 (정직 보고 — 미완료)
1. **재빌드 미수행**: 본 변경은 함수 본문만이라 가볍지만, 선행 단계(AParkFlyPawn 등 신규 UCLASS/UPROPERTY) 미빌드가 남아 있어 함께 전체 재빌드 필요. 현재 미컴파일.
2. **수동 검증(재빌드 후)**:
   - 프리셋 선택 → 강조색 표시 확인 → "선택바 숨기기" 체크 → 선택 프리셋이 원래 색으로 바뀌는지.
   - 체크 해제 → 다시 강조색.
   - 다른 프리셋 선택 시에도 체크 상태대로 동작.
   - PIE 크래시 이력 → standalone 권장.
