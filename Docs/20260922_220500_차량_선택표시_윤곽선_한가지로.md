# 차량 선택 표시를 "색 입힘 + 반투명" 두 가지에서 **윤곽선 한 가지**로

- 작성: 2026-09-22 22:05
- 요청: "선택된 차량 색상+투명쉐이더인데 한 가지로만 해 달라. 더 보기 좋은 것으로 골라 달라"
- 결정(사용자 확인): **윤곽선(림)만 남긴다** — 차량 원래 도색·차종을 보존한다
- 브랜치: `feat/car-select-rim-only`

## 1. 선택 표시의 실체

`ACarActor::ApplySelectionVisual()` 이 메시에 오버레이 머티리얼 하나를 덧입히는 것이 전부다.

```cpp
MeshComp->SetOverlayMaterial(bShowMark ? SelectionOverlayMaterial : nullptr);  // /Game/UI/M_CarSelect
MeshComp->SetRenderCustomDepth(bShowMark);                                     // 외곽선 PP 는 없다(미사용)
```

`/Game/UI/M_CarSelect` 는 Unlit · Translucent · TwoSided 이고 그래프는 이렇다.

```
Fresnel(Exponent=4, BaseReflectFraction=0.04~0.05) ─┬─ × Constant3Vector(0, 2.5, 3) ─→ EmissiveColor
                                                    └──────────────────────────────→ Opacity
```

**사용자가 말한 "두 가지"는 서로 다른 두 기능이 아니라 이 한 머티리얼이 동시에 내던 두 효과다** —
발광색(색 입힘)과 프레넬 불투명도(반투명). 코드에도 RPC 에도 선택 시 도색하는 경로는 없다
(`car.select` → `SetSelectedIndices` → 오버레이가 전부이고, `car.setColor` 를 부르는 곳도 없다).

### 화면의 마젠타는 재현되지 않았다

사용자 캡처의 선택 차량은 마젠타인데, **정본(13510)에서 `car.select` A/B 를 떠 보면 나오는 색은
청록**이다(`Docs/shots/20260922_car_select_rim/01_·02_`). 메인 뷰 스트림(13600) 프레임으로도
선택 전후에 눈에 띄는 변화가 없었다 — 종전 표시는 원거리에서 사실상 안 보인다.
마젠타의 출처는 이번에 확정하지 못했다(§5).

## 2. 무엇을 바꿨나 — `BaseReflectFraction` 하나

배선은 손대지 않고 노드 값만 바꿨다.

| 값 | 전 | 후 | 이유 |
|---|---|---|---|
| `Fresnel.BaseReflectFraction` | 0.04 · 0.05 | **0.0** | 이것이 이 변경의 전부다. 0 보다 크면 **시야에 수직인 면까지** 바닥 불투명도가 깔려 차체 전체가 그 색으로 덮인 반투명 차가 된다. 0 이면 정면 면의 Opacity 가 0 = 완전히 비어 **차량 원래 도색이 그대로 보이고 실루엣에만 테두리가 남는다** |
| `Fresnel.Exponent` | 4 | **2.5** | 테두리 폭. 실측으로 정했다(§3) |
| 발광색 | (0, 2.5, 3) | **(0, 10, 13)** | Unlit 발광이라 1 을 넘겨야 밝은 노면·흰 차 위에서 읽힌다. 불투명도가 낮은 띠 바깥도 Emissive 는 그대로 더해지므로 **원거리 가독성은 이 값이 좌우한다** |

`Content/` 는 git 밖이라 `.uasset` 이 커밋되지 않는다 → **값의 정본은 `Tools/car_select/build_select_material.py`**
(plate_kinds 선례). 재적용:

```
"C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" ^
    Park3D\Park3D.uproject -run=pythonscript -script=Tools\car_select\build_select_material.py ^
    -EnablePlugins=PythonScriptPlugin,EditorScriptingUtilities -DisablePlugins=EasyFileDialog ^
    -NullRHI -unattended -nop4 -nosplash -NoSound
```

## 3. 테두리 폭은 실측으로 정했다

처음에 `Exponent=5` 로 잡았더니 **4 m 근접에서는 선명한데 23 m 에서는 한두 픽셀로 줄어 화면에서
사라졌다**(카메라 뷰 캡처로 확인 — 값이 아니라 화면으로 판정). 프레넬 림은 태생적으로 거리에 따라
얇아진다. 2.5 로 낮추니 20 m 에서 선택 차량이 한눈에 갈린다.

- 근접(4 m, zoom 2): `03_after_closeup.jpg` — 곡면 테두리·필러·미러만 청록, **보닛·루프 평면은 흰색 그대로**
- 20 m(zoom 1): `04_after_20m_off.jpg` / `05_after_20m_on.jpg` — 선택 차만 발광, 이웃 차 무영향

폭을 더 좁히고 싶으면 `RIM_EXPONENT` 를 올리면 된다(원거리 가독성과 맞바꾼다).
**거리와 무관하게 일정한 두께의 윤곽선이 필요하면 프레넬이 아니라 CustomDepth 포스트프로세스
외곽선**이어야 한다 — `SetRenderCustomDepth(true)` 는 이미 켜 두었으니 PP 머티리얼만 붙이면 된다(미구현).

## 4. 함정

- **`unreal.MaterialEditingLibrary.delete_all_material_expressions` 로 그래프를 다시 지으려 하면
  `Assertion failed: !IsRooted()` 로 commandlet 이 죽는다**(UE 5.8). 에셋은 무손상이었다 →
  기존 노드 **값만** 고치는 쪽으로 돌렸고, 결과적으로 변경이 최소가 됐다.
- `get_editor_property("constant")` 가 돌려주는 `LinearColor` 는 **노드를 가리키는 참조**다 —
  set 한 뒤에 print 하면 바뀐 값이 찍혀 "안 바뀐 것처럼" 보인다(로그 `(0,10,13) → (0,10,13)`).
- 검증용 `-game` 인스턴스는 RPC 포트만 옮겨도(`-RpcPort=13530`) **메인 뷰 13600 · 카메라 13611+ 은
  정본과 겹친다**. 먼저 뜬 정본이 포트를 쥐고 있어 이번엔 정본이 무사했지만, 순서가 반대면
  사용자 화면의 스트림이 죽는다. 스트림을 쓸 거면 대역을 같이 옮길 것(08-13 기록).
- 실행 중 인스턴스는 머티리얼을 메모리에 들고 있어 **`.uasset` 을 고쳐도 핫리로드되지 않는다** —
  값을 바꿀 때마다 `-game` 을 다시 띄워야 한다.
