# 프리셋 주차면 표시 아이콘 제거

- 날짜: 2026-09-01
- 대상: `Park3D/Source/Park3D/Park3DGameMode.h`, `Park3D/Source/Park3D/Park3DGameMode.cpp`
- 요청: 화면의 프리셋 주차면 위에 떠 있는 표시 아이콘을 없앨 것

## 1. 아이콘의 정체

화면에 떠 있던 원형 아이콘은 두 종류였고, **요청 대상은 그중 주차면 쪽 6개**다.

| 아이콘 | 소유 액터 | 위젯 | 개수 |
|--------|-----------|------|------|
| 주차면 | `BP_ParkingSlot_C` | `/Game/Widgets/Components/ActorIcon/WBP_ActorIcon` (텍스처 `T_Parking`) | 6 |
| 카메라 | `BP_Camera_C` | `/Game/Widgets/Components/ActorIcon/WBP_CameraIcon` | 4 |

판정 근거:

- `env.list nameLike=ParkingSlot` → `BP_ParkingSlot_C_0..6` **6개**, 사용자 스크린샷에서 빨간 상자로 지목한 아이콘도 **6개**.
- `env.list nameLike=camera` → `BP_Camera_C` **4개**, 상자 밖 파란 아이콘도 **4개**.
- 두 블루프린트 `.uasset` 의 문자열을 직접 훑어 컴포넌트 구성을 확인했다
  (`BP_ParkingSlot` → `WidgetComponent` + `WBP_ActorIcon` + `EWidgetSpace::Screen` + `SetIconTexture`,
  `BP_Camera` → `WidgetComponent` + `WBP_CameraIcon`).

즉 아이콘은 **레벨 블루프린트 액터가 들고 있는 `UWidgetComponent`(Screen 스페이스)** 이며,
C++ 소스 어디에서도 만들지 않는다(`grep` 으로 `WidgetComponent`/`Billboard`/`Sprite` 를 훑어 확인).

## 2. 왜 블루프린트를 고치지 않았나

가장 직관적인 해법은 `BP_ParkingSlot` 에서 Widget 컴포넌트를 지우는 것이지만 두 가지가 막는다.

1. **`Park3D/Content/` 는 `.gitignore` 대상**이다. 블루프린트를 고쳐도 커밋에 남지 않아
   다른 기계·다음 재구성에서 아이콘이 되살아난다(이 프로젝트가 `DT_CarCatalog` 로 이미 겪은 함정).
2. 이번 세션에서 **Unreal 에디터 MCP 서버가 연결 불가**(`ConnectionRefused`)라 에셋 편집 경로 자체가 없다.

그래서 `hide_actors` 선례와 같은 자리(게임모드 `BeginPlay`)에서 **런타임에 끄는** 방식을 택했다.
코드에 남으므로 커밋되고, 콘텐츠 재쿡 없이 exe 교체만으로 반영된다.

## 3. 변경 내용

`APark3DGameMode::HideParkingSlotIcons()` 신설. `BeginPlay` 의 `ApplyConfigHiddenActors()` 바로 뒤에서 1회 호출.

```cpp
for (TActorIterator<AActor> It(World); It; ++It)
{
    if (!It->GetClass()->GetName().StartsWith(TEXT("BP_ParkingSlot"))) { continue; }

    TInlineComponentArray<UWidgetComponent*> Icons(*It);
    for (UWidgetComponent* Icon : Icons) { Icon->SetVisibility(false); ++Hidden; }
}
UE_LOG(LogTemp, Log, TEXT("[Env] 주차면 표시 아이콘 %d개를 껐습니다."), Hidden);
```

설계상 결정 세 가지:

- **액터를 통째로 숨기지 않는다.** `env.hide`/`hide_actors` 로 `BP_ParkingSlot` 을 숨기면
  아이콘과 함께 **주차면 지오메트리(스토퍼·박스)** 까지 사라진다. 위젯 컴포넌트만 끈다.
- **클래스 이름 문자열로 고른다.** 주차면은 C++ 타입이 없는 레벨 블루프린트 액터라 `Cast` 로 못 잡는다.
  반대로 위젯 클래스(`WBP_ActorIcon`)로 고르면 같은 아이콘 위젯을 쓰는 다른 액터까지 함께 꺼진다
  (그 위젯은 `E_ActorType` 열거형과 `T_Car` 기본 텍스처를 갖고 있어 범용으로 쓰이도록 만들어져 있다).
- **카메라 아이콘은 건드리지 않는다.** 요청 범위 밖이고 위젯도 다르다(`WBP_CameraIcon`).

`SetVisibility(false)` 가 실제로 화면에서 빼는 근거는 엔진 코드다 —
`UWidgetComponent::UpdateWidgetOnScreen()`(`WidgetComponent.cpp:1317`)이 `IsVisible()` 이 거짓이면
`RemoveWidgetFromScreen()` 을 부른다. Screen 스페이스 위젯은 뷰포트 레이어에서 통째로 빠진다.

## 4. 검증 (실측)

빌드: `Build.bat Park3D Win64 Development` → `Result: Succeeded` (Park3D.exe 링크 완료).

실행 중인 정본(13510)을 건드리지 않기 위해 **패키지를 복제 → exe 만 교체 → 다른 포트로 기동**했다.

- 복제: `Package\Windows` → `Package\Work13520` (robocopy /MIR, 4.0GB / 247 파일)
- 포트 분리: `rpc_port 13520`, `main_port 13700`, `cam_port 13711~13750`
- exe 교체: `Park3D/Binaries/Win64/Park3D.exe` → 복제본 `Park3D/Binaries/Win64/`

결과:

1. 기동 로그에 `[Env] 주차면 표시 아이콘 6개를 껐습니다.` — **6개**로 주차면 액터 수와 일치.
   바로 윗줄의 `[Env] config hide_actors 적용: 2/2 숨김` 도 정상.
2. `view.set` 으로 정본(13510)과 **같은 시점**(pos `-15,0,33` / pitch `-52.6` / yaw `18.3`)을 준 뒤
   `PrintWindow(PW_RENDERFULLCONTENT)` 로 창 캡처 — 주차 구역 위 아이콘이 **전부 사라졌고**,
   카메라 아이콘 2개(그 시점에서 보이는 것)는 그대로 남았다.

값이 아니라 화면으로 판정했다(이 프로젝트에서 "값은 들어갔는데 화면은 그대로"에 여러 번 속은 전례를 따른다).

검증 후 복제 인스턴스는 종료했다. `Package\Work13520` 폴더는 빌드 산출물이라 커밋에 포함되지 않는다.

## 5. 반영 방법 / 남은 것

- 현재 **실행 중인 정본(13510)에는 아직 옛 exe** 가 물려 있어 아이콘이 그대로 보인다.
  반영하려면 그 인스턴스를 종료한 뒤 `Park3D/Binaries/Win64/Park3D.exe` 를
  `Package/Windows/Park3D/Binaries/Win64/` 로 덮고 재기동하면 된다(콘텐츠 재쿡 불필요).
- 아이콘은 `WBP_ActorIcon` 안에 **버튼**을 갖고 있다(`BndEvt__WBP_ActorButton_BT_Button_...OnButtonClickedEvent`).
  다만 그 클릭 이벤트를 받는 `/Game/Core/BP_PlayerController` 는 현재 게임모드가 쓰지 않으므로
  (기본 `APlayerController`) 아이콘을 꺼서 잃는 상호작용은 없다.
- 되돌리려면 `HideParkingSlotIcons()` 호출 한 줄을 지우면 된다.
