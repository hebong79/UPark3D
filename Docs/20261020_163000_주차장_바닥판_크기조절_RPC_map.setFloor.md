# 주차장 바닥판 크기 조절 RPC — `map.setFloor` / `map.clearFloor`

- 날짜: 2026-10-20
- 브랜치: `feat/map-floor-placement`
- 요청: 마스터 "브랜치를 따서 주차장 바닥면 크기조절 rpc 로 만들어줘"(직전 질문 문서 `Docs/20261020_160000_*`)
- 대상 선택: 마스터가 "주차장 영역 바닥판"을 골랐다. 레벨의 도로 조각(BP_Road_Creator 14개)을 늘리는 안은 고르지 않았다.

## 1. 무엇을 했나

레벨 바닥은 판 하나가 아니다(객리단길 = `BP_Road_Creator` 도로 조각 14개 + 보도·연석·지형). 그래서 레벨 메시는 건드리지 않았다.
대신 기본맵이 쓰는 코드 바닥(`AMapFloorActor`, `MI_Asphalt_no_Markings` 평면)을 **크기·중심·yaw·높이를 가진 바닥판**으로 키워 주차장 위에 깐다.

| 메서드 | 변경 | 내용 |
|---|---|---|
| `map.setFloor` | 신규 | `{sizeX?, sizeY?(=sizeZ), center?{x,y}, yaw?, z?, save?=true}`(m·도). 생략한 값은 현재값을 유지한다. 바닥이 없는 레벨에서는 **원경 없이** 새로 깔고, 이때는 sizeX·sizeY 가 필수다(없으면 -32000 bad_params). z 생략 = 판 아래 노면(정적 질의 3×3 표본 중앙값, 주차면 판은 제외) + 0.5 cm, 노면을 못 찾으면 2 cm. 레벨 파일 `Save/3D/MapFloor/MapFloor_<레벨>.json` 에 저장한다 |
| `map.clearFloor` | 신규 | `{keepFile?=false}`. RPC 로 깐 판(원경 없음)은 지운다. 기본맵 바닥(원경 있음)은 160 m·원점으로 되돌린다. 레벨 파일도 지운다 |
| `map.get` | 변경 | **바닥을 스폰하지 않는다**. 없으면 `exists:false`·크기 0. `sizeY`·`center`·`yaw`·`z`·`backdrop`·`file`·`fileExists` 추가(`sizeX`·`sizeZ` 유지) |
| `map.resize` | 변경 | 응답에 클램프된 실제 크기와 배치를 싣는다(`{ok:true}` → 상태 객체). 바닥이 없는 레벨에서 새로 깔 때 원경을 숨긴다. 저장은 여전히 안 한다 |
| `map.save`/`map.load` | 동작 같음 | 바닥이 없을 때 새로 깔면 원경을 숨긴다(`GetMapFloor` 공통) |

기동·레벨 전환 때 `APark3DGameMode::ApplyStartupConfig` 가 레벨 파일을 읽어 복원한다(lot·lamp 와 같은 자리, config 와 무관).

- `Rpc/Modules/MapRpcModule.*` — 위 표. 헬퍼 이름은 유니티 빌드 충돌을 피해 `Map` 접두사.

## 3. 왜 이렇게 했나

- **원경 숨김**: 기본맵 바닥에는 지평선을 메우는 20 km 판(`BackdropMesh`, z −2 cm)이 붙어 있다. 지형이 있는 레벨에 그대로 깔면 낮은 지형을 덮는다. 그래서 "map_floor 로 깔린 바닥이면 원경 유지, RPC 로 새로 깔면 원경 숨김"으로 갈랐다. `map.clearFloor` 도 이 표시로 지울지 되돌릴지 정한다.
- **z 기본값 노면 + 0.5 cm**: 객리단 주차면 판은 노면 +1.1 cm 에 있다. 판이 그보다 낮아야 주차면 선이 덮이지 않는다. 노면 질의에서 `BP_ParkingSlot`·프롭 면을 빼는 이유도 같다(주차면 판에 맞으면 판이 면보다 높아진다).
- **`map.get` 무스폰**: 조회만 해도 160 m 판이 생기던 문제(직전 질문 문서에서 지적)를 고쳤다. 응답 키는 덧붙이기만 했다.
- `map.resize` 는 저장하지 않는 옛 계약을 유지했다. 영속이 필요하면 `map.setFloor`.

## 5. 한계·미검증

- **크기 하한 10 m**(`UMapFloorLibrary::MinSizeM`, 패널·`map.resize` 와 공용). 폭 6 m 같은 좁은 띠는 만들 수 없다. 낮출지는 마스터 결정.
- 판은 직사각형 하나뿐이다(레벨당 1개). 다각형 영역은 `lot.set`(반투명 덧그림)과 별개다.
- 판 안의 도로 표시·맨홀 등은 덮인다. 보도·연석처럼 노면보다 높은 것은 판 위로 나온다.
- 노면이 기울었거나 높이가 섞인 주차장에서는 판이 평면이라 일부가 묻히거나 뜰 수 있다(z 로 직접 지정).
- 패널(`UMapSizeWidget`)은 크기만 다루고 배치는 모른다. 패널에서 크기를 바꿔도 레벨 파일에는 저장되지 않는다.
- 정본(`Package/Windows`)·패키지 빌드 미반영. 작업 시점에 정본 프로세스는 떠 있지 않았다(Work13540 만 실행 중, 손대지 않음).
- 파일 안의 `level` 키는 기록용이고 읽을 때 검사하지 않는다(파일 이름이 레벨).
