# 차량 자동생성 — 선택 차량 옆(로컬 right) 배치 수정

- 날짜: 2026-07-01 15:00:58
- 대상 파일: `Park3D/Source/Park3D/CarPlacementWidget.cpp` (`UCarPlacementWidget::AutoCreate`)
- 유형: 버그 수정
- 요청: "차량 배치 시 CarPlacementWidget 자동생성 버튼을 누르면 선택된 차량의 옆(local right vector)으로 차량 개수만큼 간격값에 맞춰 생성되어야 한다."

## 1. 증상 / 원인

자동생성 버튼(`Btn_AutoCreate` → `HandleAutoCreate` → `AutoCreate`)이 **선택된 차량과 무관하게** 동작했다.

기존 코드는 배치 기준을 다음 두 고정값으로 사용했다.

```cpp
const FVector RightDir(0.f, 1.f, 0.f); // 항상 월드 +Y
... AutoPlacePosition(AutoBaseWorld, RightDir, i + 1, Spacing, bVertical, MetersToUU);
```

- **기준점**: `AutoBaseWorld`(기본값 `(0,0,0)`) — 선택 차량 위치가 아님.
- **방향**: 월드 +Y 고정 — 선택 차량의 로컬 right 아님.

즉, 어떤 차량을 선택하든 항상 월드 원점에서 +Y 방향으로만 생성되어 "선택 차량 옆에 나란히"라는 요구를 만족하지 못했다.

순수 계산 함수 `UCarPlacementLibrary::AutoPlacePosition`(가로: `Base + Right*(i*Spacing*U)`)은 정상이며 유닛테스트(`Park3D.CarPlacement.AutoPlace`)도 통과 상태였다. **버그는 위젯이 이 함수에 잘못된 인자(고정 기준점/방향)를 넘긴 것**이었다.

## 2. 수정 내용

`AutoCreate()`에서 배치 기준을 **선택된 차량**으로부터 산출하도록 변경.

```cpp
FVector BaseWorld = AutoBaseWorld;
FVector RightDir(0.f, 1.f, 0.f); // 폴백(선택 없음)
float BaseRotY = 0.f;
bool bBaseFront = true;
if (ACarPlacementManager* Mgr = GetCarManager())
{
    if (CarData.datas.IsValidIndex(PrimaryIndex))
    {
        if (ACarActor* SelCar = Mgr->GetCar(PrimaryIndex))
        {
            BaseWorld = SelCar->GetActorLocation();
            RightDir  = SelCar->GetActorRightVector(); // 메시 정면 보정이 반영된 실제 '옆' 방향
        }
        BaseRotY  = CarData.datas[PrimaryIndex].rotY;   // 회전 상속
        bBaseFront = CarData.datas[PrimaryIndex].isFront;
    }
}
// 이후 루프에서 BaseWorld/RightDir/BaseRotY/bBaseFront 사용
```

핵심 결정 사항:

1. **기준점 = 선택 차량 월드 위치** (`GetActorLocation`).
2. **방향 = 선택 차량 로컬 right** (`GetActorRightVector`). 액터 회전에는 메시 정면 보정(`MeshForwardYawOffset=180`)이 이미 반영되어 있어, 사용자가 화면에서 보는 차량의 실제 '옆' 방향과 일치한다.
3. **회전 상속**(`rotY`/`isFront`): 생성 차량이 선택 차량과 **나란히** 보이도록 전후면·회전을 상속. (요구 문구 "옆으로 나란히 생성"의 자연스러운 해석 — 상속하지 않으면 회전된 차량 옆에 정북향 차량이 흩어져 보임.)
4. **폴백**: 선택 차량이 없으면 기존 동작(`AutoBaseWorld` + 월드 +Y) 유지 — 최초 배치 등에서 버튼이 여전히 동작.
5. **간격**: 인덱스 `i+1`(1-based) 유지 → 첫 생성 차량은 선택 차량에서 `Spacing`만큼 떨어진 위치. 선택 차량 위에 겹치지 않음.

## 3. 범위 밖 / 한계

- **세로배치(`Check_Vertical`) 모드**: `AutoPlacePosition`의 세로 분기는 `RightDir`를 무시하고 여전히 월드 +Y를 사용한다. 이번 요청(로컬 right)의 대상이 아니므로 기존 동작을 유지했다. 필요 시 후속 작업에서 선택 차량의 forward 벡터 기반으로 확장 가능.
- **타입/프리팹**: 생성 차량의 `type`/`prefabId`는 기존과 동일하게 콤보 선택값을 따른다(선택 차량 상속 아님) — 자동생성 UI의 콤보가 생성 대상을 정의하는 기존 설계 유지.

## 4-1. 정정 (2차 수정, 배치 축 오류)

1차 수정에서 방향으로 `GetActorRightVector()`를 사용했으나, 실제 결과는 차량들이 **길이 방향(앞뒤)으로 일렬**로 겹쳐 생성됐다(사용자 스크린샷 1).

- **원인**: 차량 메시의 **길이축이 액터 로컬 Y축**에 정렬돼 있다(`CarActor.h` 주석: "길이축이 로컬 Y"). 로컬 Y = `GetActorRightVector`이므로, right 벡터를 쓰면 차량의 길이 방향으로 늘어선다.
- **수정**: 차량의 **옆(폭) 방향 = 액터 forward(로컬 X) = `GetActorForwardVector()`**로 변경. 이로써 선택 차량 옆으로 나란히(스크린샷 2) 생성된다.

```cpp
SideDir = SelCar->GetActorForwardVector(); // 차량 옆(폭) 방향 (기존: GetActorRightVector → 길이 방향 오배치)
```

> 좌/우 어느 쪽으로 나가는지(부호)는 메시 기준에 따라 결정된다. 원하는 방향과 반대면 `SideDir`를 부호 반전(`-SideDir`)하면 된다.

## 4-2. 정정 (3차 수정, 방향 부호 + 세로배치 뒤쪽)

사용자 요청: (1) 가로배치가 **왼쪽**으로 생성됨 → **우측**으로. (2) 세로배치 체크 시 차량 각도 기준 **뒤쪽(local backward)**으로 생성.

- **가로(우측)**: 2차 수정의 `+GetActorForwardVector()`가 차량의 왼쪽으로 나갔으므로, 우측 = **`-GetActorForwardVector()`**.
- **세로(뒤쪽)**: 메시 길이축이 액터 로컬 Y(`GetActorRightVector`)에 정렬. UE 좌표계 유도(`left = Up × Front`, 프레임 `Forward×Right=Up`)로 앞쪽 = `-GetActorRightVector`, 따라서 **뒤쪽 = `+GetActorRightVector()`**.
- `AutoPlacePosition`의 내부 세로(월드 +Y) 분기는 차량 각도를 반영하지 못하므로, 위젯에서 방향을 직접 계산해 항상 `bVertical=false`로 호출하도록 변경(라이브러리 미변경).

```cpp
Dir = bVertical ? SelCar->GetActorRightVector()      // 뒤쪽(local backward)
                : -SelCar->GetActorForwardVector();  // 우측(local right)
...
AutoPlacePosition(BaseWorld, Dir, i + 1, Spacing, /*bVertical=*/false, MetersToUU);
```

> 부호는 실제 메시 기준 관측값에 근거. 컴파일 후 반대 방향이면 해당 항의 부호만 반전하면 된다.

## 5. 검증

- **유닛테스트**: 순수 로직(`AutoPlacePosition`)은 미변경이라 기존 `Park3D.CarPlacement.AutoPlace` 테스트가 계속 커버. 위젯의 액터 기반 로직은 UWorld/액터 스폰이 필요해 자동화 유닛테스트 대상 밖.
- **동작 확인(사용자 필요)**: 에디터 상시 실행 중이므로 **Ctrl+Alt+F11로 Live Coding 컴파일** 후 아래 시나리오 확인 권장.
  1. 차량 1대 배치 → 리스트/뷰포트에서 선택.
  2. 개수=5, 간격=2.5 입력 후 자동생성 → 선택 차량의 **옆(로컬 right)** 방향으로 5대가 2.5m 간격으로 생성, 선택 차량과 **같은 방향**으로 정렬되는지 확인.
  3. 선택 차량을 회전(회전 모드 좌우키) 후 자동생성 → 생성 줄이 회전된 옆 방향을 따라가는지 확인.
  4. 선택 없음 상태에서 자동생성 → 폴백(원점 +Y) 동작 확인.
