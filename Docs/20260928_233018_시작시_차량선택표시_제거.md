# 시작·레벨 로딩 때 차량 선택 표시 제거

## 요청
처음 실행할 때와 레벨을 로딩할 때 차량 한 대가 반투명 하늘색(선택 표시)으로 보인다. 이 표시가 나오지 않게 해 달라(UI 와 상관 없음).

## 원인
기동과 레벨 전환 때 `APark3DGameMode::ApplyStartupConfig` 가 차량 배치 패널의 "열기" 본체인
`UCarPlacementWidget::LoadFromJsonFile` 을 그대로 부른다. 이 함수는 끝에서 **첫 차량(0번)을 선택**하고
`RefreshView` → `ACarPlacementManager::RebuildAll(..., SelectedIndices)` 로 월드에 반영한다.
그래서 사용자가 아무것도 고르지 않았는데 0번 차량에 선택 표시가 켜졌다.

레벨 전환은 GameMode 를 새로 만들고 `BeginPlay` → `ApplyStartupConfig` 를 다시 돌리므로 같은 경로다.

## 변경
| 파일 | 내용 |
|------|------|
| `CarPlacementWidget.h/.cpp` | `ClearSelection()` 신설 — `SelectedIndices`·`PrimaryIndex` 를 비우고 `SyncSelectionVisuals()`(목록 강조 + 월드 선택 표시)로 반영. **UFUNCTION 이 아닌 C++ 전용**(쿠킹된 WBP 베이스 규약 — 함수 추가라 exe 교체로 반영 가능) |
| `Park3DGameMode.cpp` | 자동 로딩의 차량배치 람다에서 `LoadFromJsonFile` 성공 뒤 `ClearSelection()` 호출 |

바꾸지 않은 것:
- 패널 **"열기" 버튼**은 종전대로 첫 차량을 선택한다(요청 범위가 기동·레벨 로딩뿐이다).
- "선택 표시" 설정(`car.getSelectionMark` visible=true)은 그대로 켜져 있다. 이번 수정은 표시를 끈 것이 아니라 **선택 자체를 비운 것**이라, 이후 클릭이나 `car.select` 로 고르면 선택 표시가 평소처럼 나온다.
- 상세 필드(`FillDetailFields`)는 0번 차량 값이 채워진 채로 남는다. 화면 표시와는 무관하다.

- 작업본 `Package/Work13540`(13540)에 exe 를 교체해 기동하고 카메라 캡처로 확인했다(`Docs/shots/20260928_no_car_selection_on_start/`).
  1. 기동(서신지구대, 차량 23대): cam1 에서 0번 차량(맨 왼쪽)이 흰색 → `01_seoshin_start_cam1.jpg`
  2. 대조군으로 `car.select` 0번 → 같은 차가 하늘색 → `02_...`(0번 차량이 화면 안에 있다는 증거)
  3. 0번을 선택한 상태에서 `scene.load {name:"객리단길"}` 로 전환(차량 14대): 8대 카메라 모두 하늘색 차량 없음, cam5 맨 끝 차량 흰색 → `03_...`
  4. 대조군으로 객리단 첫 차량 `car.select` → cam5 맨 끝 차량이 하늘색 → `04_...`
- Automation 테스트는 돌리지 않았다(HTTP·RPC 계약 변경 없음).
- 참고: 작업본 기동 직후 첫 프레임에서 `GPU timeout ... 5초` 경고와 GPU breadcrumb 덤프가 한 번 찍혔다(PSO 컴파일 중, 정본과 GPU 공유). 그 뒤 정상 진행했고 이번 변경과 무관하다.
