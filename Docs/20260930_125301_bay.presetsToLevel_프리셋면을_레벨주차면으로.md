# bay.presetsToLevel — 프리셋 면을 레벨 주차면(ISM_Slot)으로

## 1. 요청

> 프리셋 메이커로 작업한 주차면(json 파일을 올려서 만든 주차면 오브젝트들)을 실제 주차장 맵(레벨)의 리소스화 하는 rpc 를 만들어줘.

## 2. 해석과 가정

- "레벨의 리소스" = **레벨 `BP_ParkingSlot` 액터의 `ISM_Slot` 인스턴스(레벨 면)**. 바닥 번호(`preset.numbers`)·차량 스냅(Ctrl+클릭, `car.placeAtWorld`)·주차 시뮬(`sim.slots/start/exit`)·`bay.*` 레벨 편집이 모두 이것을 본다.
- **`.umap` 자체는 고치지 않는다.** `Content/` 는 git 밖이고 에디터 MCP(`unreal`)도 이 세션에서 연결되지 않았다. 대신 기존 규약(2026-09-22 `slot_file`) 그대로 — 런타임에 인스턴스를 넣고 스냅샷 파일(`Save/3D/Bay/*.json`, kind=levelSlots)로 남겨 config `slot_file` 로 기동 때 복원한다.
- 기존 `bay.fromPresets` 는 프리셋을 **프롭 면(`ABayPropActor`)** 으로 바꾼다 — 번호·스냅·시뮬 대상이 아니다. 그래서 새 메서드를 둔다.

## 3. 계약

```
bay.presetsToLevel {
  source?:  "auto"(기본) | "panel" | "memory"
  presetFile?: 프리셋 JSON — Save/3D/Preset 기준 이름 또는 경로 (주면 source 무시, source="file")
  actor?:   넣을 레벨 액터 이름(ISM_Slot 보유). 기본 = 번호순 마지막 BP_ParkingSlot
  replace?: false — true 면 그 액터의 기존 인스턴스를 비우고 넣는다
  clearPresets?: true — 출처(패널 목록 / 메모리 StoredPresets)를 비운다. file 출처는 해당 없음
  saveFile?: 레벨 면 스냅샷 저장(bay.saveLevel 과 같은 형식). 이름만이면 Save/3D/Bay/<이름>.json
}
→ { ok, source, presetCount, count, actor, bays[](level:<액터>#<n>), replaced, z, clearedPresets,
    saved?{path, fileName, count, level} | saveError }
```

- **출처 auto**: 프리셋 메이커 패널 목록이 있으면 패널, 없으면 메모리(`ResolvePresets` — StoredPresets, 비면 config `preset_file`). 패널(`UPresetMakerWidget::Presets`)과 RPC 메모리(`AParkingPresetManager::StoredPresets`)는 원래 별개 목록이라 둘 다 받는다. "JSON 파일을 올려서 만든 주차면" 은 보통 패널 목록이다.
- **대상 액터 기본값 = 마지막 액터**: 레벨 면 번호는 액터 번호순 → 인스턴스순이라, 뒤 액터 뒤에 붙여야 기존 면의 번호와 키(`level:<액터>#<n>`, `slot_numbers` 기준점)가 밀리지 않는다.
- **축·높이**: 대상 액터 첫 인스턴스의 축 규약(LV_Park_03 은 로컬 X=길이, LV_Park_01 은 X=폭)과 바닥 높이를 따른다. 인스턴스가 없으면 X=폭, 프리셋 높이.
- **판 크기 = 프리셋 xSize × zSize(m)** 를 그대로 판 외측으로 쓴다(선 여유를 더하지 않는다). 기존 레벨 면은 2.64×5.14(bay 규약상 내측 2.5×5 + 선 0.07×2)라, 같은 크기를 원하면 프리셋 크기를 그만큼 크게 줘야 한다. 레벨 판 재질이 선을 판 안쪽에 그리는지는 캡처로 대략 봤을 뿐 수치로 재지 않았다.
- 면 중심·방향은 `ComputeSlotCorners`(프리셋 선·데칼·스냅이 쓰는 그 함수)로 계산한다 — 면회전·그룹회전·사선 보정 규약이 그대로 따라온다.
- 끝나면 바닥 번호를 다시 그린다(패널 출처면 패널 `RefreshView`, 아니면 매니저).
- `saveFile` 저장이 실패하면 면은 이미 들어간 상태로 `ok:false` + `saveError` 를 돌려준다(숨기지 않는다).

### 영구화 절차

1. `bay.presetsToLevel { ..., saveFile: "LevelSlots_XX" }` (또는 뒤에 `bay.saveLevel`)
2. `config_pmaker.json` 의 그 레벨 `levels[].slot_file` 에 파일 이름 지정 → 재기동 시 복원

## 6. 미검증·한계

- **패널에서 실제로 JSON 을 연 뒤 `source:auto/panel` 로 변환하는 화면 왕복은 안 했다**(파일 대화상자 자동 입력 필요). 패널 목록을 읽는 코드는 `Presets` 복사뿐이고 파일 출처와 같은 변환 경로를 탄다.
- 모든 면이 한 액터에 들어간다. 프리셋별로 다른 액터에 나누려면 `actor` 를 바꿔 여러 번 부른다(`presetIds` 필터는 두지 않았다 — 한 번에 출처 전체).
- 새 면의 type 은 크기로 가장 가까운 종류로 표시된다(`bay.list` 의 type). 장애인면 표시(텍스처)는 레벨 판 재질이 정하므로 프리셋의 slotType 은 반영되지 않는다.
- 메모리 출처가 config `preset_file` 폴백이면 지울 수 없다(`clearedPresets` 0) — 그 경우 config 의 `preset_file` 을 비워야 선이 두 겹으로 남지 않는다.
- 정본(Package/Windows, 13510) 미배포, 패키지 빌드 미실행.
