# 프리셋 그룹 이동/회전 구현

- 날짜: 2026-07-01 16:37:33
- 대상: `Park3D/Source/Park3D/CarPlacementWidget.h`, `CarPlacementWidget.cpp` (`NativeTick` 이동/회전 로직)
- 유형: 기능 구현
- 요청: "프리셋 그룹(Check_PresetGroup)이 체크되면, 선택 차량과 같은 프리셋 소속(presetId 동일)인 차량이 이동·회전 시 함께 움직여야 한다. (현재는 선택 차량만 이동/회전)"

## 1. 요구사항 정리

- 배치 모드에서 WASD/방향키로 선택 차량을 이동, 회전 모드에서 좌우키로 회전한다(기존).
- `Check_PresetGroup` **체크 시**: 선택 차량과 `presetId`가 같은 모든 차량이 함께 이동/회전.
- **미체크 시**: 기존과 동일하게 선택 차량 1대만.
- "회전 시 모두 움직여야 한다" → 그룹 회전은 **선택 차량(피벗) 기준 전체 회전**(다른 차량은 위치도 변함)으로 해석.

## 2. 설계

### 대상 인덱스 (`GetActiveIndices`)
- `Check_PresetGroup`(BindWidgetOptional, null 가드) 체크 시: `presetId == 선택차량.presetId`인 인덱스 전부.
- 아니면 `{PrimaryIndex}` 하나.
- 선택 없음(`PrimaryIndex` 무효)이면 빈 배열.

### 이동 (`ApplyGroupTranslation(DeltaMove)`)
- 기존 3개 이동 경로(월드축 이동/카메라 상대 이동)가 계산하던 **평행이동 델타 벡터**를 그대로 받아, 대상 전원 액터에 `SetActorLocation(loc + DeltaMove)` 적용 후 각 `CarData` 갱신.
- 모두 같은 벡터로 이동 → 대형(상대 위치) 유지.

### 회전 (`ApplyGroupRotation(DeltaYaw)`)
- 피벗 = 선택 차량 위치. 대상 전원에 대해:
  - 위치: `NewLoc = Pivot + FRotator(0,DeltaYaw,0).RotateVector(CarLoc - Pivot)`
  - 회전: `NewYaw = 액터.Yaw + DeltaYaw`
- 선택 차량 자신은 오프셋 0 → 위치 불변, yaw만 변경. **따라서 단일(그룹 미사용) 경우 기존 동작과 정확히 동일**(회귀 없음).
- 선택 차량 `rotY`를 상세 필드(`Field_RotY`)에 반영(기존 동작 유지).

### 통합
- 단일 이동/회전은 "원소 1개짜리 그룹"의 특수 케이스 → 분기 없이 헬퍼 하나로 처리. `NativeTick`의 이동/회전 3개 지점은 헬퍼 호출로 대체(로직 중복 제거).

## 3. 변경 내용

**CarPlacementWidget.h** — private 헬퍼 3종 선언:
```cpp
TArray<int32> GetActiveIndices() const;
void ApplyGroupTranslation(const FVector& DeltaMove);
void ApplyGroupRotation(float DeltaYaw);
```

**CarPlacementWidget.cpp**
- `NativeTick`:
  - 월드축 이동: `ApplyGroupTranslation(Dir.GetSafeNormal() * CarMoveSpeed * InDeltaTime)`
  - 회전: `ApplyGroupRotation(Side * CarRotateSpeed * InDeltaTime)`
  - 카메라 상대 이동: `ApplyGroupTranslation(Dir.GetSafeNormal() * CarMoveSpeed * InDeltaTime)`
- `GetActiveIndices` / `ApplyGroupTranslation` / `ApplyGroupRotation` 구현 추가(GetCarManager 다음).

## 4. 영향도 분석

- **범위**: `CarPlacementWidget`의 이동/회전 경로 한정. 헤더 신규 include 없음(`CarActor.h`·`Components/CheckBox.h` 기존 포함).
- **데이터/스키마**: `FCarPos.presetId`(기존 필드) 사용. JSON 스키마·저장 포맷 불변.
- **presetId 출처**: 상세 패널 `Field_PresetId`(→ `ApplyDetailFields`에서 `presetId`)로 지정. 자동생성 차량은 기본 `presetId=1`이므로, 그룹을 나누려면 각 차량의 P.Idx(PresetId)를 다르게 지정해야 함(안내).
- **회귀**: 그룹 미체크 시 대상=선택 1대, 회전 피벗=자기 자신(오프셋 0) → 기존 동작과 동일. `Ctrl+좌클릭 배치`·저장/열기·자동생성 등 타 경로 무변경.
- **성능**: 매 틱 그룹 크기만큼 액터 이동/데이터 갱신. 대수는 수십 대 규모라 부담 없음.

## 5. 검증

- **유닛테스트**: 이동/회전은 UWorld·액터·틱·입력 의존이라 자동 유닛테스트 대상 밖. (순수 계산부는 별도 로직 없음 — 회전은 UE `FRotator::RotateVector` 사용.)
- **동작 확인(사용자, Ctrl+Alt+F11 컴파일 후)**:
  1. 차량 여러 대 생성, 일부를 **같은 P.Idx(PresetId)**로 지정(수정 버튼).
  2. `배치 시작` → 그룹 내 한 대 선택.
  3. **프리셋 그룹 체크 해제**: 이동/회전 시 선택 차량만 변하는지(기존 동작).
  4. **프리셋 그룹 체크**:
     - 이동(WASD/Shift+방향키): 같은 presetId 차량이 **대형 유지한 채 함께 평행이동**.
     - 회전(회전 모드 좌우키): 같은 presetId 차량이 **선택 차량을 중심으로 함께 회전**(위치·방향 모두 변경).
  5. 다른 presetId 차량은 영향 없는지 확인.

## 6-1. 정정 (회전 방식 변경: 제자리 회전)

사용자 요청으로 **프리셋 그룹 회전을 "피벗 기준 전체 회전" → "각 차량 제자리(로컬 중심) 회전, 위치 고정"** 으로 변경했다.

- 변경 전: 선택 차량을 피벗으로 그룹 전체가 공전(다른 차량 위치·방향 모두 변경).
- 변경 후: 대상 전원이 각자 자리에서 yaw만 회전. **위치는 고정.**

```cpp
void UCarPlacementWidget::ApplyGroupRotation(float DeltaYaw)
{
    ACarPlacementManager* Mgr = GetCarManager();
    if (!Mgr) return;
    for (int32 Idx : GetActiveIndices())
    {
        if (ACarActor* C = Mgr->GetCar(Idx))
        {
            const float NewYaw = C->GetActorRotation().Yaw + DeltaYaw;
            C->SetActorRotation(FRotator(0.f, NewYaw, 0.f)); // 위치 유지, yaw만
            CarData.datas[Idx] = C->ToCarPos(MetersToUU);
        }
    }
    if (Field_RotY && CarData.datas.IsValidIndex(PrimaryIndex))
        Field_RotY->SetText(FText::FromString(FString::SanitizeFloat(CarData.datas[PrimaryIndex].rotY)));
}
```

- 단일(그룹 미체크) 회전은 기존과 동일(원소 1개 제자리 회전).
- 이동(`ApplyGroupTranslation`)은 변경 없음(그룹 전원 동일 평행이동).

## 6. 한계 / 후속

- 회전 피벗은 **선택 차량** 고정. "그룹 중심(centroid) 기준 회전"이 필요하면 후속에서 피벗 계산만 교체 가능.
- 그룹 이동/회전 중 다른 차량의 리스트 강조·상세 필드는 갱신하지 않음(선택 대상은 여전히 1대). 위치 데이터는 정상 갱신됨.
