## 2. Goal/Loop 예외

Goal/Loop 요청은 일반 역할 배정 대신 다음 규칙을 사용한다.

- `gpt-5.6-terra`: 설계, 영향도, C++ 수정, 사전점검, 수동 컴파일 게이트 안내, 실행, Automation/PIE 검증, 재설계와 반복 결정까지 전 과정 단독 담당
- `gpt-5.6-luna`: 모든 성공 조건이 끝난 뒤 최종 `Docs/yyyyMMdd_HHmmss_이름.md` 한글 문서 작성만 담당

## 3. 검증 및 제약

로컬 Codex CLI 모델 카탈로그에서 Sol, Terra, Luna가 모두 가용함을 확인했다. 다섯 역할 TOML의 모델 문자열, 일반 작업 규칙, Goal/Loop 예외 규칙도 설계와 일치한다.

현재 대화의 서브에이전트 호출 인터페이스는 Luna를 직접 지정하는 선택지를 노출하지 않는다. 이 경우 Luna를 다른 모델로 자동 대체하지 않고 가용성 제한을 보고하도록 하네스에 명시했다. Park3D C++/Blueprint/에셋/JSON/MCP 설정은 변경하지 않았다.
