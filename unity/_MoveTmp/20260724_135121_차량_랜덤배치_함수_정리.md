# 차량 랜덤 배치 함수 및 호출 위치 정리

작성일: 2026-07-24
대상: `Assets/Scripts` 전역 차량 랜덤 배치 관련 코드

---

## 1. 개요

Parking3D의 차량 랜덤 배치는 **세 개의 파이프라인**으로 나뉜다.

| 파이프라인 | 배치 기준 | 진입점 | 핵심 클래스 |
|---|---|---|---|
| VLA PTZ 뷰포트 | PTZ 카메라 화각 안 자유 배치 | `CVlaPSImgMakerGameUI` | `CVehicleCountRandomizer`, `CPtzSpaceVehiclePlacer`, `CPtzRandomCameraPlacer` |
| VLM 슬롯 점유 | 프리셋 주차면(CFaceRect) 기반 | `CVlmPSimGameUI` | `CPSimBaseGameUI`, `CCarObjListUI` |
| 프리셋 메이커 UI | 프리셋 슬롯 수동/랜덤 | `CCarPlacementDlg` | `CPresetSlotPlacer`, `CCarObjListUI` |

공통적으로 `UnityEngine.Random`을 사용하며, 재현이 필요한 지점은 `Random.InitState(seed)`로 시드를 고정한다.

## 2. 함수별 상세

### 2.1 VLA PTZ 뷰포트 파이프라인

#### CVehicleCountRandomizer.Pick()
- **위치**: `Assets/Scripts/04_ParkSimMaker_VLA/CVehicleCountRandomizer.cs:4`
- **역할**: 1~7대 중 GT 분포(평균 ≈ 4.4)를 따르는 가중 확률로 차량 대수 반환
  - `2% 1대 / 5% 2대 / 13% 3대 / 30% 4대 / 30% 5대 / 15% 6대 / 5% 7대`
- **Random**: `Random.Range(0, 100)` (`:6`)
- **호출처**: `CVlaPSImgMakerGameUI.Enum_CaptureAtPTZ()` (`CVlaPSImgMakerGameUI.cs:356`)

#### CPtzSpaceVehiclePlacer.PlaceVehicles()
- **위치**: `Assets/Scripts/04_ParkSimMaker_VLA/CPtzSpaceVehiclePlacer.cs:36`
- **시그니처**:
  ```csharp
  public static List<CObjCar> PlaceVehicles(
      CObjCamera cam, CCarObjListUI carListUI, int count,
      float groundY = 0f, float insetRatio = 0.05f,
      int maxRetryPerCar = 40, float minVehicleSpacingM = 4f,
      Vector3 boxMin = default, Vector3 boxMax = default,
      float maxScreenOverlapRatio = 0.05f)
  ```
- **역할**: PTZ 뷰포트 안에 `count`대 배치. 6단계 검증
  (뷰포트 UV 랜덤 → 지면 레이캐스트 → XZ 간격(≥4m) 검사 → 스폰 → 번호판 가시성 → 2D 화면 겹침 검사)
- **Random**: `Random.Range(margin, 1-margin)` U좌표(`:96`), `SampleDistanceUniformV()` V좌표(`:97`), `Random.value ×2`(`:484~485`), 폴백 UV(`:537,:545`), 거리 샘플(`:553`)
- **호출처**: `CVlaPSImgMakerGameUI.Enum_CaptureAtPTZ()` (`CVlaPSImgMakerGameUI.cs:358`)

#### CPtzSpaceVehiclePlacer.SpawnCar() `[private]`
- **위치**: `CPtzSpaceVehiclePlacer.cs:587`
- **역할**: 프리팹 목록에서 랜덤 선택 후 단일 차량 스폰(풀 우선, 없으면 Instantiate)
- **Random**: `Random.Range(0, carListUI.m_PrefabList.Count)` (`:589`)

#### CPtzRandomCameraPlacer.GetRandomXZInBox()

- **역할**: 맵 경계 박스 안에서 카메라 XZ 위치 랜덤 반환

- **호출처**: `CVlaPSImgMakerGameUI.Enum_RandomCamSweep()` (`CVlaPSImgMakerGameUI.cs:636`)

### 2.4 프리셋 슬롯 배치 (CPresetSlotPlacer, CCarPlacementDlg)

#### CPresetSlotPlacer.PlaceVehiclesOnSlots()
- **위치**: `Assets/Scripts/06_PtzCameraSim/CPresetSlotPlacer.cs:106`
- **시그니처**:
  ```csharp
  public static List<CObjCar> PlaceVehiclesOnSlots(
      CCarObjListUI carListUI, IReadOnlyList<CFaceRect> slots, int presetId,
      Camera cam, bool bRandom, int randomSeed = 0,
      bool persistToCarPosData = false, bool randomColor = false)
  ```
- **역할**: 프리셋 주차면 각각에 차량 1대씩 배치
  - `bRandom=false`: 슬롯 순서대로 결정적 배치, 차종 `i % prefabCount`
  - `bRandom=true`: 차종 랜덤 + 회전 ±5° + X ±0.15m / Z ±1.0m 오프셋
- **Random**: 시드(`:131`), 차종 `Range(0, prefabCount)`(`:159`), 회전(`:160`), X(`:162`), Z(`:164`)
- **상수**: `DRAND_OFFSET_X=0.15f`, `DRAND_OFFSET_Z=1.0f`, `DRAND_ANGLE=5f`
- **호출처**: `CCarPlacementDlg.ResetRandomPlacement()` (`CCarPlacementDlg.cs:1081`, `bRandom=true`)

#### CCarPlacementDlg.ResetRandomPlacement()
- **위치**: `Assets/Scripts/01_PresetMaker/CarObejct/CCarPlacementDlg.cs:1081`
- **시그니처**: `public void ResetRandomPlacement(ERandomResetMode eMode, int nPresetId)`
- **역할**: 3가지 모드 랜덤 초기화

- **호출처**: `CCarPlacementDlg.OnClicked_ResetRandom()` (`:1066`, 버튼 이벤트)

#### CCarPlacementDlg.ShuffleSlots()
- **위치**: `CCarPlacementDlg.cs:1200`
- **역할**: Fisher-Yates로 슬롯 리스트 제자리 셔플
- **Random**: `Random.Range(0, i+1)` (`:1205` 부근)
- **호출처**: `ResetRandomPlacement()` (`CountObjectAndColor` 모드)
