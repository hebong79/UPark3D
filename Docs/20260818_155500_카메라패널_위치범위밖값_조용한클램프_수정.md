# 카메라 컨트롤 패널 — 파일의 위치가 패널 범위 밖이면 조용히 잘리던 문제

- 날짜: 2026-08-18
- 브랜치: `fix/camera-pos-range-clamp`
- 대상 파일: `Park3D/Source/Park3D/CameraControlWidget.cpp`
- 선행 작업: `20260818_145200_카메라패널_파일열기_위치미적용_수정.md` 에서 "범위 밖으로 남긴 것"으로
  적어 둔 항목을 이번에 처리했다.

## 1. 증상

카메라 프리셋 JSON 을 열 때, 파일에 적힌 높이·X·Z 가 패널의 현재 min/max 밖이면
**아무 알림 없이 경계값으로 잘려서** 카메라가 엉뚱한 자리에 선다.

실측(패키지 실행, 기동 시 자동 로딩으로 확인):

```
파일:      pos = (x 75, y -63, z 22)     ← 세 축 모두 패널 기본 범위 밖
수정 전:   pos = (50, 0, 5)              ← X 는 상한 50 으로 잘리고, 나머지는 직전 값
수정 후:   pos = (75, -63, 22)           ← 파일값 그대로
```

패널 기본 범위는 `GCtrlDefaults` 기준으로 높이 3~15 m, X −50~50 m, Z −50~50 m 이다.

## 2. 원인

`FCamDir` 에는 **Pan/Tilt/Zoom 의 범위만**(`ptzmin`/`ptzmax`) 들어 있다. 위치 3종은 범위가 없다.
그래서 `FillControlsFromDir` 은 Pan/Tilt/Zoom 의 min/max 만 파일에서 갱신하고, 위치는 화면에
남아 있던 범위를 그대로 쓴다. 그 다음 값 세팅이 그 범위로 클램프한다.

```cpp
auto SetVal = [this](ECamCtrl Kind, float V)
{
    const float Clamped = FMath::Clamp(V, FMath::Min(Min, Max), FMath::Max(Min, Max));
    ...
};
SetVal(ECamCtrl::X, Dir.pos.x);   // ← 범위 밖이면 여기서 잘린다
```

넓은 주차장(±50 m 초과)이나 사용자가 범위를 좁혀 둔 뒤 다른 파일을 여는 경우에 걸린다.
**잘렸다는 로그도 표시도 없다** — 파일을 열었는데 카메라가 다른 데 서 있는 것으로만 보인다.

## 3. 수정

범위를 파일 형식에 추가하지 않는다(데이터 계약 변경). 대신 **값을 담을 수 있도록 경계를 넓힌다.**

```cpp
// 위치 3종은 범위가 파일에 없어 이전 화면의 범위가 그대로 남는다. 그 밖의 값이 오면
// 잘라 내는 대신 경계를 그 값까지 넓힌다 — 파일에 적힌 자리는 언제나 그대로 서야 한다.
auto ExpandRange = [this](ECamCtrl Kind, float V) { ... };
ExpandRange(ECamCtrl::X,      Dir.pos.x);
ExpandRange(ECamCtrl::Height, Dir.pos.z);
ExpandRange(ECamCtrl::Z,      Dir.pos.y);
```

- 값이 아래로 벗어나면 아래 칸을, 위로 벗어나면 위 칸을 그 값으로 바꾼다.
- 사용자가 min/max 를 뒤집어 적어 둔 경우까지 감안해 **실제 아래/위 칸을 골라** 넓힌다.
- 이후 `SetVal` 의 클램프는 그대로 둔다 — 넓힌 뒤에는 no-op 이고, 이 클램프는 정상 범위 안의
  값을 다루는 다른 호출자에게도 필요한 안전장치다.

값을 클램프하지 않고 그냥 넣는 방법도 있었으나 택하지 않았다. 그러면 `Cur ∈ [Min, Max]` 라는
패널의 불변식이 깨져 슬라이더는 끝에 붙어 있는데 입력칸은 다른 값을 가리키게 되고, 다음에
슬라이더를 건드리는 순간 값이 튄다.

## 4. 검증

패키지 복제(`Package/Work13520`)에 exe 만 갈아끼우고, 범위 밖 값만 담은 시험용 파일
(`pos = (75, -63, 22)`, `isUnreal: true`)을 `camerapos_file` 로 지정해 기동 직후 `cam.list` 로 읽었다.
기동 시 자동 로딩은 패널의 파일열기와 **같은** `LoadFromJsonFile` 을 탄다.

| | Camera-1 pos |
|---|---|
| 파일 | (75, -63, 22) |
| 수정 전 exe | (50, 0, 5) |
| 수정 후 exe | (75, -63, 22) |

검증 후 `Work13520` 의 `camerapos_file` 은 `CamPos_Seosin.json` 으로 되돌리고 시험 파일은 지웠다.

## 5. 부수 효과

- 범위 밖 파일을 열면 패널의 min/max 입력칸 값이 그 파일에 맞춰 넓어진다. 되돌리려면
  사용자가 직접 적어 넣으면 된다(원래 사용자가 편집하는 칸이다).
- 저장(`CollectDirFromControls`)은 위치 범위를 파일에 쓰지 않으므로 저장 형식은 그대로다.
