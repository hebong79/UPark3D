## 2. 신규·변경 RPC

### `car.rotateAll` (신규)
```
{ deltaRotY?: deg | rotY?: deg   // 정확히 하나
  carNameIds?: string[] | selected?: bool }   // 둘 다 없으면 전체
→ { ok, changedCount, cars:[{carNameId, rotY}], notFound }
```
- 각 차량이 **자기 중심에서 제자리 회전**(위치 불변). 0..360 정규화(`AddYawDeg`).
- 숨긴 차 포함. 없는 id 는 실패가 아니라 `notFound`.
- `deltaRotY`·`rotY` 둘 다/둘 다 없음, `carNameIds`+`selected` 동시 → -32000.

### `car.moveAll` (신규)
```
{ delta:{x, y, z?}   // UE 미터, z=높이
  carNameIds?: string[] | selected?: bool }
→ { ok, changedCount, cars:[{carNameId, pos}], notFound }
```
- 같은 delta 만큼 평행 이동, 회전 불변, `ApplyTransformFromData` 로 지면 재안착.

### `car.select` (확장, 기존 계약 유지)
- 기존 `{carNameId}` → 응답 `{ok:true}` 그대로.
- 신규 `{carNameIds: string[], additive?: bool}` → `{ok, selectedCount, carNameIds, notFound}`. 빈 배열 = 선택 해제, `additive` 는 현재 선택에 더한다.
- **패널 인스턴스가 있으면 패널을 거쳐 선택**(`UCarPlacementWidget::SetSelectionFromRpc`) — 목록 강조·상세 필드·다음 방향키 이동 대상이 RPC 선택과 같아진다. 없으면 매니저만.

### `car.getSelection` (신규)
- `{}` → `{ok, selectedCount, carNameIds}`. 월드 액터의 `IsSelected()` 기준.

## 3. 구현

- `CarRpcModule.cpp`
  - 익명 네임스페이스 `ResolveBatchTargets` — carNameIds / selected / 전체 → 매니저 인덱스. `moveAll`·`rotateAll` 공용.
  - 네 메서드 모두 `SetMethodMeta` 등록(`system.describe` 에 노출).
- `CarPlacementWidget.*` (C++ 전용, UFUNCTION/UPROPERTY 추가 없음 — 쿠킹된 WBP 베이스 규약)
  - `FindInWorld(World)` — 체크박스 유무와 무관하게 패널 인스턴스를 찾는다.
  - `SetSelectionFromRpc(Indices)` — `SelectedIndices`·`PrimaryIndex`(마지막) 갱신 후 `SyncSelectionVisuals`.
  - `SyncCarDataFromWorld(Indices)` — RPC 가 옮긴 차의 월드 값을 패널 `CarData` 로 되읽는다(id 가 같은 칸만). **안 하면 패널의 다음 `RefreshView`(RebuildAll)가 옛 값으로 되돌린다.** `moveAll`·`rotateAll` 끝에서 호출.
  - 참고: 기존 단건 RPC(`car.setRotationY`·`car.setPosition`·`car.groupRotate` 등)는 이 동기화를 하지 않아 같은 되돌림 위험이 남아 있다(이번 범위 밖, 미수정).
