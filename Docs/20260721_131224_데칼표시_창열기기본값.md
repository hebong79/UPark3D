## 1. 변경 파일

| 파일 | 내용 |
|---|---|

## 2. 동작 변경

PresetMaker 창이 처음 만들어질 때와 메뉴에서 다시 열릴 때 `데칼 표시` 체크박스를 명시적으로 켠다. 이로써 WBP 에셋에 저장된 체크 기본값과 무관하게 `RefreshView()`가 데칼 렌더 경로를 기본으로 선택한다.

사용자가 창을 연 뒤 체크를 해제하는 기존 동작, JSON 저장/로드, 위젯 바인딩 이름 및 매니저 API는 변경하지 않았다. `Check_UseDecal`이 없는 구형 WBP도 기존 Optional 널 가드로 안전하게 유지된다.

## 3. 영향도 및 검증

- 빌드 모듈·헤더·Blueprint/에셋 참조·JSON 스키마 변경 없음.
- UE 5.8 Unreal Build Tool 최신 로그에서 `Module.Park3D.cpp` 컴파일과 `Result: Succeeded`를 확인했다.
- 코드상 `SetIsChecked(true)` → `RefreshView()`의 `IsChecked()` → `RebuildDecals(..., bUseDecal)` 경로를 확인했다.
- PIE 실제 화면에서 시작/재열기 시 체크 표시와 데칼 렌더, 사용자가 Off로 전환했을 때의 디버그 라인 복귀는 이 세션에 UI 조작 도구가 없어 미검증이다.
