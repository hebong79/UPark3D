## 1. 작업 내용

- 기존 평면 세로 스택 → **목업 구조로 전면 재구성**. WBP를 재생성(부모 `UCarPlacementWidget` 유지)하고 위젯 트리를 구조적으로 배치.
- BindWidget 22개(콤보2/체크·라디오6/입력7/버튼7/리스트1)는 **이름·타입 그대로 보존** → C++ 바인딩 무변경, 컴파일 성공.

## 3. 텍스트 가시화 (글자색)

- **섹션/필드/옵션 라벨**(어두운 패널 위): 밝은 회청색 `(0.85,0.85,0.9)`. 섹션 헤더 "차량 오브젝트"는 초록 `(0.55,0.85,0.5)`.
- **버튼 라벨**(밝은 회색 버튼 위): 어두운색 `(0.05,0.05,0.05)` — 저장/열기/초기화/자동생성/수정/선택삭제/배치시작.
- 입력박스(EditableTextBox)·콤보: 기본 어두운 글자(밝은 배경) → 가시.
- 라벨 신규 추가분: 차량 프리팹/차량 타입/이동/회전/프리셋 그룹/개수/배치간격/세로배치/Idx/Preset Id/Face Id/Rot Y/Front/Back + 7개 버튼 텍스트.

## 5. 한계 / 후속

- **세부 정렬·간격·크기·타이틀바 닫기버튼·색상 강조는 목업과 1:1 픽셀 정합은 아님**(구조·그룹·가시성 우선). 필요 시 슬롯 패딩/Fill/SizeBox로 추가 정렬.
