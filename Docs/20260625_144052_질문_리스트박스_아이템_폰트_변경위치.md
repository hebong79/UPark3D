# [질문 답변] 리스트박스 아이템 텍스트 크기 변경 위치 (WBP 디자이너)

- **일시**: 2026-06-25 14:40
- **질문**: WBP 디자이너에서 차량 오브젝트 리스트박스 아이템 텍스트 크기를 바꾸는 위치는?

---

## 결론: 디자이너에 항목이 없음 → C++에서만 조정

차량 오브젝트 리스트 항목은 **실행 시 C++(`RebuildCarList`)가 동적 생성**한다(`UButton + UTextBlock`을 차량 수만큼 만들어 `CarList_Scroll`에 추가). 디자이너의 `CarList_Scroll`(ScrollBox)은 **빈 컨테이너**라 항목 위젯이 디자이너 트리에 없다. 따라서 항목 텍스트 크기는 디자이너에서 못 바꾸고 코드에서 설정한다.

### 변경 위치 (CarPlacementWidget.cpp `RebuildCarList`)
```cpp
FSlateFontInfo LabelFont = Label->GetFont();
LabelFont.Size = 16;     // ← 항목 텍스트 크기
Label->SetFont(LabelFont);
```
(현재 16으로 설정됨. C++ 수정 후 Live Coding Ctrl+Alt+F11 컴파일 필요.)

## 디자이너에서 조정하려면 (선택: 리팩터)
UMG 표준은 **항목 전용 위젯 블루프린트**(예: `WBP_CarListItem`)를 만들어:
1. 그 위젯 안에 TextBlock 배치 → **폰트/색/레이아웃을 디자이너에서 지정**
2. C++ `RebuildCarList`는 raw UButton+TextBlock 생성 대신 **그 엔트리 위젯 클래스를 스폰**(예: `CreateWidget<UCarListItem>` 또는 `WidgetTree->ConstructWidget`로 리페어런트 클래스)
3. (대량 항목이면) `UListView` + `IUserObjectListEntry` 패턴으로 전환 가능

이렇게 하면 항목 스타일을 디자이너에서 관리할 수 있다. 현재는 동적 생성이라 코드에서만 조정.

## 요약
- **현재 구조**: 디자이너 위치 없음 → `RebuildCarList`에서 `Label->SetFont(...Size=16...)`.
- **디자이너 조정 원하면**: `WBP_CarListItem` 엔트리 위젯으로 리팩터(요청 시 작업 가능).
