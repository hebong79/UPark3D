# 프리셋 열기/저장에 파일 대화상자 연결

작성일: 2026-06-23
대상: `PresetMakerWidget` (WBP_PresetMaker 베이스 클래스)
작업 유형: 신규 기능 (UI 동작 변경 + 빌드 의존성 추가)

---

## 1. 요구사항
- **열기 버튼**: 클릭 시 파일 **열기** 대화상자를 띄워 사용자가 선택한 JSON을 로딩.
- **저장 버튼**: 클릭 시 파일 **저장** 대화상자를 띄워 사용자가 지정한 경로/이름으로 저장.

## 2. 설계 (CLAUDE.md 0번 규칙)
### 2.1 방식 결정
- 네이티브 OS 파일 대화상자는 `DesktopPlatform` 모듈의
  `IDesktopPlatform::OpenFileDialog()` / `SaveFileDialog()` 로 띄운다.
- 기존 `SaveToJsonFile()` / `LoadFromJsonFile()` (직렬화/역직렬화)는 **그대로 재사용**하고,
  "경로를 어떻게 얻느냐"만 고정 경로 → 대화상자로 교체한다.
- 경로 획득을 헬퍼 2개로 분리: `PromptOpenFilePath()`, `PromptSaveFilePath()`.
  핸들러(`HandleOpen`/`HandleSave`)는 경로 획득 → 기존 로드/세이브 호출만 담당(단일 책임).

### 2.2 핵심 제약 / 대안 비교
- **DesktopPlatform은 Shipping에서 제외되는 개발자 모듈**이다.
  - 채택: `Target.Configuration != Shipping` 일 때만 모듈을 링크하고 `PARK3D_USE_FILE_DIALOG=1` 정의.
    → **에디터 + Development(standalone) 빌드에서 동작**. Shipping에서는 기본 경로로 폴백.
  - 대안(미채택): 커스텀 UMG 파일 브라우저 위젯 → Shipping까지 지원 가능하나 구현 비용 큼.
    현재 도구는 에디터/Development 저작용이므로 과한 선택으로 판단.

### 2.3 처리 흐름
```
[저장] HandleSave → PromptSaveFilePath(대화상자) ─취소→ "저장 취소"
                          └─확정→ SaveToJsonFile(경로) → OnSavePreset → 알림
[열기] HandleOpen → PromptOpenFilePath(대화상자) ─취소→ "열기 취소"
                          └─확정→ LoadFromJsonFile(경로) → OnOpenPreset → 알림
```

## 3. 구현 내용
### 3.1 Build.cs — [Park3D.Build.cs](../Source/Park3D/Park3D.Build.cs)
```csharp
if (Target.Configuration != UnrealTargetConfiguration.Shipping)
{
    PrivateDependencyModuleNames.Add("DesktopPlatform");
    PublicDefinitions.Add("PARK3D_USE_FILE_DIALOG=1");
}
else
{
    PublicDefinitions.Add("PARK3D_USE_FILE_DIALOG=0");
}
```

### 3.2 헤더 — [PresetMakerWidget.h](../Source/Park3D/PresetMakerWidget.h)
```cpp
bool PromptOpenFilePath(FString& OutPath) const; // 취소 시 false
bool PromptSaveFilePath(FString& OutPath) const; // 취소 시 false
```

### 3.3 구현 — [PresetMakerWidget.cpp](../Source/Park3D/PresetMakerWidget.cpp)
- 조건부 include: `DesktopPlatformModule.h`, `IDesktopPlatform.h`, `Framework/Application/SlateApplication.h`.
- `HandleOpen`/`HandleSave`: 대화상자에서 경로 획득 후 기존 로드/세이브 호출(취소 시 알림 후 중단).
- `PromptOpenFilePath` / `PromptSaveFilePath`:
  - 필터 `Preset JSON (*.json)|*.json|All Files (*.*)|*.*`, 기본 디렉터리는 기존 기본 경로 폴더.
  - 저장 시 확장자 미입력이면 `.json` 자동 보정.
  - 부모 윈도우는 `FSlateApplication::FindBestParentWindowHandleForDialogs` 로 지정.
  - 모듈 미가용/비대화상자 빌드(Shipping)에서는 기본 경로로 폴백.

## 4. 검증 (CLAUDE.md 1·2번 규칙)
- **컴파일/링크**: Game 타깃 풀 빌드 성공 —
  `Build.bat Park3D Win64 Development` → `Result: Succeeded`
  (PresetMakerWidget.cpp 컴파일 + Park3D.exe 링크에 DesktopPlatform 의존성 정상 반영 확인).
- **에디터 반영 (대기)**: ⚠️ **Build.cs(모듈 의존성) 변경은 Live Coding으로 반영 불가.**
  현재 실행 중인 에디터에 적용하려면 **에디터를 종료한 뒤 에디터 타깃을 풀 리빌드**해야 한다.
  (에디터 DLL이 점유 중이라 실행 상태에서는 링크 불가.)
- **동작 확인 (대기)**: 에디터 리빌드 후 WBP_PresetMaker UI에서 열기/저장 버튼 클릭 →
  OS 대화상자 표시 및 선택/취소 동작 시각 확인 필요.
- 단위 테스트: OS 대화상자는 사용자 상호작용/플랫폼 의존이라 자동 단위 테스트 부적합 → 시각 확인으로 대체.

## 5. 영향도 분석 (CLAUDE.md 4번 규칙)
- **빌드 시스템**: `DesktopPlatform` 모듈 의존성 신규 추가(비-Shipping). Build.cs 변경 →
  **풀 리빌드 필요(Live Coding 불가)**, 에디터 종료 전제.
- **코드 범위**: `PresetMakerWidget.h`(+2 선언), `.cpp`(핸들러 2개 수정 + 헬퍼 2개 추가 + 조건부 include).
- **기존 기능 영향**: `SaveToJsonFile`/`LoadFromJsonFile`/`GetDefaultPresetFilePath` 시그니처·동작 불변(재사용만).
  BP 훅 `OnSavePreset`/`OnOpenPreset` 호출 유지.
- **동작 변화**: 기존엔 고정 경로(`Saved/3D/Preset/preset.json`)로 즉시 저장/열기 → 이제 대화상자 경유.
  사용자가 취소하면 아무 동작 안 함(기존엔 취소 개념 없었음).
- **Shipping 빌드**: 대화상자 비활성 → 기존처럼 기본 경로 사용(회귀 없음).
- **회귀 위험**: 낮음~중. 핵심 위험은 "에디터 리빌드 미수행 시 에디터에 미반영". 빌드 자체는 검증 완료.

3. 에디터 재실행 → WBP_PresetMaker 의 열기/저장 버튼 클릭하여 대화상자 동작 확인.
