# Unreal MCP 사용 가능 여부 확인

- 작성일시: 2026-07-15 17:14:47
- 확인 대상: Unreal MCP 연결 및 읽기 전용 에디터 상태 조회

## 확인 결과

**현재 Unreal MCP를 사용할 수 있다.**

| 확인 항목 | 결과 |
|---|---|
| MCP 툴셋 목록 조회 | 성공 |
| `EditorToolset.EditorAppToolset.IsPIERunning` | 성공, `false` |
| `EditorToolset.EditorAppToolset.GetCameraTransform` | 성공 |
| 현재 PIE 상태 | 실행 중 아님 |

## 읽힌 에디터 카메라 상태

- 위치: `(-1500, 0, 1500)` cm
- 회전: Pitch `-45.000002`, Yaw `173.582649`, Roll `0`
- 스케일: `(1, 1, 1)`

## 결론

Unreal MCP 서버와 에디터 툴셋이 연결되어 있으므로, 이후 에셋 조회·월드 상태 확인·PIE 실행·UMG/Blueprint 작업을 MCP로 진행할 수 있다. 현재 PIE가 실행 중이 아니므로 PIE 기반 검증은 별도로 시작해야 한다.
