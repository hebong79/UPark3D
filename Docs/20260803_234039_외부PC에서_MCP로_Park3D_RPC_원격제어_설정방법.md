# 외부 PC에서 MCP로 Park3D RPC를 원격 제어하는 설정 방법

- 작성일: 2026-08-03 23:40:39
- 분류: 질문 답변 / 설계 검토 (코드 변경 없음)

## 1. 먼저 정할 것 — 브리지를 어디에 두는가

MCP 브리지(`park3d-rpc-mcp/server.py`)와 Park3D(RPC 서버)가 **다른 PC에 있어도 된다.**
어느 쪽을 원격으로 넘기느냐에 따라 두 가지 안이 나온다.

### A안 (권장) — 브리지는 외부 PC에, RPC만 원격 호출

```
[외부 PC]                                          [Park3D PC]
Claude Code ──stdio──> park3d-rpc(server.py) ──HTTP──> Park3D :13120
```

- **코드 수정 0.** `server.py`가 이미 `PARK3D_RPC_URL` 환경변수를 읽는다
  (`park3d-rpc-mcp/server.py:24`). `.mcp.json`의 값만 바꾸면 끝.
- stdio 전송이라 MCP 쪽 네트워크 설정이 아예 필요 없다.
- 열어야 하는 포트는 Park3D의 13120 하나뿐.

### B안 — 브리지도 Park3D PC에 두고 MCP를 HTTP로 노출

```
[외부 PC]                      [Park3D PC]
Claude Code ──HTTP(MCP)──> park3d-rpc(streamable-http) ──localhost──> Park3D :13120
```

- `server.py`를 stdio → `transport="streamable-http"`로 바꿔야 한다(코드 수정 필요).
- 외부 PC에 파이썬/uv 설치가 불필요하고, RPC 포트를 외부에 안 열어도 된다는 장점.
- 대신 MCP 엔드포인트 자체의 인증을 직접 붙여야 한다.

**결론: 지금 상태에서는 A안.** 아래는 A안 기준 절차다.

## 2. A안 설정 절차

### 2-1. RPC 서버의 리슨 주소 확인 (필수 선행 확인)

`RpcServerSubsystem.cpp:194-211`은 언리얼의 `FHttpServerModule`을 쓴다.
이 모듈은 통상 모든 인터페이스(0.0.0.0)에 바인드하지만, **실제로 확인하고 진행해야 한다.**

Park3D를 띄운 상태에서 Park3D PC에서:

```powershell
netstat -ano | Select-String "13120"
```

| 결과 | 의미 | 조치 |
|------|------|------|
| `0.0.0.0:13120` | 모든 인터페이스 리슨 | 그대로 진행 |
| `127.0.0.1:13120` | 루프백 전용 | 외부 접속 불가 → 3장의 SSH 터널 방식 사용 |

> **실측 결과 (2026-08-03 23:4x, Park3D 실행 중 확인):**
> `TCP 127.0.0.1:13120 LISTENING (PID 21208, Park3D)` — **루프백 전용이다.**
> 따라서 2-2 방화벽 개방만으로는 외부 PC에서 접속할 수 없고, **3장의 SSH 터널 방식이 사실상 유일한 무수정 해법이다.**
> 같은 시점에 MCP 브리지는 정상 동작(`park3d_catalog` 78개 메서드 응답)했고, 포트 8000(`unreal` MCP)은 리슨하지 않았다.

### 2-2. Park3D PC 방화벽 인바운드 허용

**출발지 IP를 반드시 한정한다.** 인증이 없기 때문이다(3장 참조).

```powershell
New-NetFirewallRule -DisplayName "Park3D RPC 13120" `
  -Direction Inbound -Protocol TCP -LocalPort 13120 `
  -RemoteAddress 192.168.0.50 -Action Allow
```

`-RemoteAddress`를 빼면 네트워크 전체에 열린다. 넣을 것.

### 2-3. 외부 PC의 `.mcp.json` 수정

```json
{
  "mcpServers": {
    "park3d-rpc": {
      "type": "stdio",
      "command": "uv",
      "args": ["run", "<외부PC의 server.py 경로>"],
      "env": {
        "PARK3D_RPC_URL": "http://192.168.0.10:13120",
        "PARK3D_RPC_TIMEOUT": "30"
      }
    }
  }
}
```

- `PARK3D_RPC_URL`: Park3D PC의 IP. 여기가 유일한 핵심 변경점.
- `PARK3D_RPC_TIMEOUT`: 기본 15초. 네트워크 지연 + 캡처 같은 무거운 호출을 감안해 30초 권장.
- `server.py` 파일은 외부 PC에도 복사돼 있어야 한다(uv가 로컬 실행하므로).

### 2-4. 연결 확인

외부 PC에서 먼저 HTTP 레벨로 확인:

```powershell
curl http://192.168.0.10:13120/health
```

응답이 오면 Claude에서 `park3d_catalog` → `park3d_rpc`로 진행.

## 3. 보안 — 이게 가장 중요하다

**현재 RPC 서버에는 인증이 전혀 없다.** 확인된 사실:

- `RpcServerSubsystem.cpp:79-81` — CORS `Access-Control-Allow-Origin: *`
- 토큰/API키/헤더 검증 코드 없음
- 즉, **포트에 닿을 수 있는 누구나 `car.*`/`preset.*`/`cam.*` 79개 메서드를 전부 호출할 수 있다.**
  카메라 캡처 이미지 유출, 씬 조작, 프리셋 삭제가 무인증으로 가능하다.

따라서:

| 상황 | 권장 방식 |
|------|-----------|
| 같은 사무실 LAN | 방화벽 출발지 IP 한정 (2-2) |
| 다른 건물/재택 | **VPN (Tailscale, WireGuard)** 위에서 사설 IP로 접속 |
| 인터넷 경유 | **절대 포트포워딩 금지.** SSH 터널 또는 VPN 필수 |

### SSH 터널 방식 (가장 안전, 루프백 전용일 때도 동작)

Park3D PC에 OpenSSH Server를 켜고, 외부 PC에서:

```powershell
ssh -N -L 13120:localhost:13120 user@192.168.0.10
```

이러면 `.mcp.json`의 `PARK3D_RPC_URL`은 **`http://localhost:13120` 그대로 두면 된다.**
방화벽에 13120을 열 필요도 없고, SSH의 인증·암호화를 그대로 얻는다.

**루프백 전용인데도 동작하는 이유:** 터널의 마지막 구간은 sshd가 Park3D PC **내부에서** `localhost:13120`으로 접속하는 것이다.
즉 RPC 서버 입장에서는 로컬 접속으로 보이므로 `127.0.0.1` 바인드가 그대로 허용한다.
2-1 실측 결과가 루프백 전용이므로, 이 방식이 코드 수정 없이 되는 유일한 경로다.

**Park3D PC 사전 준비 (실측 상태):** `sshd` 서비스는 이미 설치돼 있으나 `Stopped` / `StartType=Manual` 상태다. 관리자 권한으로 기동·자동시작 설정이 필요하다.

```powershell
# 관리자 PowerShell
Start-Service sshd
Set-Service sshd -StartupType Automatic
Get-NetFirewallRule -Name *OpenSSH-Server* | Select-Object Name,Enabled
```

## 4. 운용상 주의점

1. **Park3D가 실행 중이어야 한다.** 에디터 PIE 또는 패키지 exe가 떠 있어야 13120이 리슨한다. 꺼져 있으면 브리지는 연결 실패 error를 반환한다.
2. **포트는 13120.** 소스 기본값은 13110이지만 `DefaultGame.ini`에서 13120으로 덮는다. 커맨드라인 `-RpcPort=`가 최우선.
3. **캡처 응답 크기.** `cam.captureJPG/PNG`는 base64 이미지를 반환한다. 원격이면 전송량과 타임아웃을 함께 고려할 것.
4. **`unreal` MCP(8000)는 별개.** 언리얼 에디터 조작용이며 이 설정과 무관하다. 원격으로 쓰려면 별도 검토가 필요하다.
5. **`.mcp.json` 중복 정의.** 루트 `.mcp.json`과 `Park3D/.mcp.json`에 unreal 서버가 이름·주소가 다르게 두 번 정의돼 있다(`unreal` / `unreal-mcp`, `localhost` / `127.0.0.1`). 이번 작업과 직접 관련은 없으나 정리 대상으로 기록해 둔다.

## 5. 영향도

- 저장소 코드 변경 없음. 본 문서는 설정 방법 답변 기록이다.
- A안 실행 시 변경되는 것은 **외부 PC의 `.mcp.json` 1개 파일**과 **Park3D PC의 방화벽 규칙**뿐이다.
- B안을 택하면 `park3d-rpc-mcp/server.py`의 전송 방식 변경 + 인증 추가가 필요하며, 별도 설계·QA 단계를 거쳐야 한다.
