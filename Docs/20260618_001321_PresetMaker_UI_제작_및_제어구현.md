## 1. 요청 내용

> 첨부 이미지(Preset Maker)와 같은 UI를 만들고, **제어가 가능하게** 만들어줘.

제어 구현 방식은 사용자 선택에 따라 **C++ 베이스 클래스 방식**으로 진행했다.

---

## 2. 결과 요약

- `WBP_PresetMaker` 위젯 블루프린트를 이미지와 동일한 레이아웃으로 제작(총 위젯 78개).
- 모든 버튼/입력/체크박스/콤보/리스트의 동작을 담당하는 C++ 베이스 클래스 `UPresetMakerWidget` 작성.
- WBP를 해당 C++ 클래스로 리페어런트 → `BindWidget`으로 27개 위젯 자동 연결(컴파일 통과로 바인딩 무결성 검증).
- 추가/수정/삭제/초기화/선택/필드 IO 동작을 런타임(에디터 + PIE)에서 검증 완료.
- PIE 화면에서 패널이 이미지와 동일하게 렌더링되고, 프리셋 리스트의 선택 항목이 주황색으로 강조됨을 확인.

## 3. UI 레이아웃 구조

루트 `CanvasPanel(RootCanvas)` → 배경 `Border(RootBorder, 청록색, 중앙 410×480 고정)` → `VerticalBox(Root_VBox)` 구성.

```
RootCanvas (CanvasPanel)
└ RootBorder (Border, 배경)
  └ Root_VBox (VerticalBox)
    ├ Title_Text  ("Preset Maker")
    ├ Content_HBox (HorizontalBox)
    │  ├ LeftPanel_VBox (좌측 패널)
    │  │  ├ Lbl_PresetListTitle ("프리셋 리스트")
    │  │  ├ PresetList_Border → PresetList_Scroll (프리셋 목록, 동적 생성)
    │  │  ├ Btns_VBox → Btn_Add/Btn_Edit/Btn_Delete/Btn_Reset (추가/수정/삭제/리셋)
    │  │  ├ Row_HideBar → Check_HideBar + "선택바 숨기기"
    │  │  ├ Lbl_MoveTitle ("프리셋 이동")
    │  │  ├ Row_Radio → Radio_Move("이동") / Radio_Rotate("회전")
    │  │  ├ Lbl_Speed ("속도: Ctrl=, Ctrl-")
    │  │  ├ Lbl_LaneWidth ("주차면 폭: 2.5m")
    │  │  └ Lbl_PresetWidth ("프리셋 폭: 25m")
    │  └ RightForm_VBox (우측 입력 폼: 라벨 MinDesiredWidth=115로 정렬)
    │     ├ Preset Idx        → Field_PresetIdx (기본 1)
    │     ├ Face Count        → Field_FaceCount (기본 7)
    │     ├ Offset(x,y,z)     → Field_OffsetX/Y/Z (기본 0)
    │     ├ Group Face Rotate → Field_GroupFaceRotate (0)
    │     ├ Face Rotate       → Field_FaceRotate (0)
    │     ├ BoxSize (x, z)    → Field_BoxSizeX(5) / Field_BoxSizeZ(2.5)
    │     ├ Dir Type          → Combo_DirType (Default/Forward/Backward/Left/Right)
    │     ├ Is Base width     → Check_IsBaseWidth (기본 체크)
    │     ├ Camera idx        → Field_CameraIdx (0)
    │     ├ Use 3D            → Check_Use3D
    │     └ Preset Name       → Field_PresetName ("Preset 1")
    └ Bottom_HBox → Btn_Save/Btn_Open/Btn_Init/Btn_Create/Btn_OffsetPick
                    (저장/열기/초기화/생성/Offset Pick)
```

색상: 배경 청록, 라벨 청록, 추가/수정/삭제 베이지, 리셋/초기화 주황, 저장/열기/생성 녹색, Offset Pick 파랑(이미지와 동일 톤).

## 4. C++ 제어 클래스 `UPresetMakerWidget`

### 4.1 핵심 설계
- `UUserWidget` 상속, `PARK3D_API`.
- 모든 위젯을 `UPROPERTY(meta=(BindWidget))` 로 선언 → WBP의 동일 이름 위젯과 자동 바인딩.
- `NativeConstruct()` 에서 버튼 `OnClicked`, 체크박스 `OnCheckStateChanged` 델리게이트를 핸들러에 바인딩.
- 프리셋 한 개를 표현하는 `USTRUCT FParkingPreset`(폼 필드와 1:1 대응).

### 4.2 외부에서 호출 가능한 제어 API (BlueprintCallable)
| 함수 | 기능 |
|------|------|
| `GatherFromFields()` | 현재 폼 값을 `FParkingPreset`로 수집 |
| `ApplyToFields(Preset)` | 프리셋 값을 폼에 반영 |
| `ResetFields()` | 폼을 기본값으로 |
| `AddCurrentPreset()` | 현재 폼을 새 프리셋으로 추가 |
| `UpdateSelectedPreset()` | 선택 프리셋을 현재 폼 값으로 갱신 |
| `DeleteSelected()` | 선택 프리셋 삭제 |
| `ClearAll()` | 전체 비우고 폼 초기화 |
| `SelectPreset(Index)` | 인덱스 선택 → 폼 로드 + 리스트 갱신 |
| `RebuildPresetList()` | 프리셋 목록 UI 재구성(선택 항목 강조) |

### 4.3 디자이너(BP) 확장 훅 (BlueprintImplementableEvent)
실제 주차 형상 생성/저장 로직은 블루프린트에서 구현하도록 훅을 노출했다.
- `OnSavePreset(Preset)` — 저장 버튼
- `OnOpenPreset()` — 열기 버튼
- `OnCreatePreset(Preset)` — 생성 버튼
- `OnOffsetPick()` — Offset Pick 버튼

### 4.4 버튼 → 동작 매핑
| 버튼 | 동작 |
|------|------|
| 추가 | `AddCurrentPreset()` |
| 수정 | `UpdateSelectedPreset()` |
| 삭제 | `DeleteSelected()` |
| 리셋 | `ResetFields()` |
| 초기화 | `ClearAll()` |
| 저장/열기/생성/Offset Pick | 해당 BlueprintImplementableEvent 호출 |
| 이동/회전(라디오) | 상호 배타 토글 → `bMoveMode` 갱신 |
| 선택바 숨기기 | 프리셋 목록 표시/숨김 |

## 5. 제작 절차

1. `/Game/UI/WBP_PresetMaker` 위젯 블루프린트 생성(부모 UserWidget).
2. MCP `add_widget`/`set_widget_properties`/`set_slot_properties`로 78개 위젯 레이아웃 구성.
   - 배경 보더 슬롯은 `LayoutData`(Anchors/Alignment/Offsets) 스키마로 중앙 고정 크기 적용.
3. C++ `UPresetMakerWidget` 작성, `Park3D.Build.cs`에 `UMG/Slate/SlateCore` 의존성 추가.
4. 에디터 종료 → `Build.bat Park3DEditor Win64 Development` 빌드 → 에디터 재실행.
5. `BlueprintEditorLibrary.reparent_blueprint`로 WBP를 C++ 클래스로 리페어런트 후 컴파일/저장.
6. 핵심 동작을 `BlueprintCallable`로 승격 후 재빌드(외부 제어성 + 검증 목적).

## 7. 영향도 분석

- **모듈 의존성**: `Park3D.Build.cs`에 `UMG, Slate, SlateCore` 추가. 게임 모듈이 UMG에 의존하게 되며, 첫 빌드 시 해당 모듈 링크가 추가됨(빌드 정상).
- **신규 소스**: `PresetMakerWidget.h/.cpp` 2개 추가. 기존 코드(`Park3D.cpp/.h`)는 미변경.
- **에셋 변경**: `/Game/UI/WBP_PresetMaker` 신규 생성 + 부모 클래스가 `UserWidget` → `UPresetMakerWidget`로 변경됨. 기존 다른 에셋에는 영향 없음.
- **빌드/실행**: C++ 모듈 추가/변경으로 **에디터 재시작(또는 Live Coding) 후 빌드 필요**. 본 작업에서는 에디터 종료→빌드→재실행 절차로 반영 완료.
- **MCP/Python 제약(중요)**: MCP·에디터 Python으로는 위젯의 `OnClicked` 같은 **델리게이트 이벤트 노드(K2Node)를 생성할 수 없음**. 따라서 버튼 동작은 블루프린트 이벤트그래프가 아닌 **C++(NativeConstruct 바인딩)** 로 구현함. `BindWidget` 멤버는 protected라 Python에서 직접 접근 불가하나, `BlueprintCallable` API를 통해 제어/검증 가능.

## 8. 사용 방법

### 8.1 화면에 표시 (블루프린트)
임의의 블루프린트(레벨 BP, HUD, PlayerController 등)에서:
`Create Widget (Class=WBP_PresetMaker)` → `Add to Viewport`.

### 8.2 확장(실제 주차 형상 생성)
WBP_PresetMaker 이벤트그래프에서 `Event On Create Preset`(및 OnSave/OnOpen/OnOffsetPick) 노드를 추가하여
전달받은 `FParkingPreset` 값으로 주차면 액터 스폰 등 실제 로직을 구현하면 된다.

### 8.3 외부 제어
다른 코드에서 위젯 참조로 `AddCurrentPreset()`, `ApplyToFields()`, `SelectPreset()` 등을 호출해 프로그래밍 방식으로 패널을 제어할 수 있다.
