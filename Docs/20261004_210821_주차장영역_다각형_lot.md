# 주차장 영역 다각형 — `preview.show {polygons}` + `lot.set/get/clear` (보드 #1168)

## 요청
SettingManager 가 도면(PNG/PDF/DXF)에서 읽은 주차장 영역을 시뮬레이터 바닥에 그려야 한다(마스터: "주차장 영역을 미리보기에만 있는 게 아니라 시뮬레이터 영역에도 그려야 한다").
지금은 `preview.show` 상자(변마다 얇은 상자)로만 가능해서 ① 채움이 없고 ② 재기동·레벨 재로딩에 사라지고 ③ `.8` 에는 `preview.*` 자체가 없다.

## 변경 (추가만, 기존 계약 불변)

### 1. `preview.show` 에 `polygons`
```
preview.show {id, polygons:[{points:[{x,y}], z?, fill?=true, opacity?=0.25, line?=true, lineWidth?=0.3, dashed?=false, color?}], color?}
```
- 단위 m(UE 지면 x·y). 점 3..2000개, 열린/닫힌(첫 점 반복) 둘 다 받는다. 연속 중복 점은 걷어낸다.
- `z` 생략 = 꼭짓점 아래 노면(정적 오브젝트 질의, 최대 64점 표본의 중앙값) + 0.02 m. 못 찾으면 0.03 m. 응답 `zSource: param|ground|default`.
  - 정적 질의인 이유는 `CarActor` 접지와 같다 — LV_Park_01 노면은 Visibility 를 무시하고, 차량(WorldDynamic)은 걸러진다.
- 채움은 귀 자르기(오목 다각형 OK). 자기교차면 윤곽만 그리고 채움은 일부/생략될 수 있다(`filled:false`).
- 응답에 `polygons:[{points, triangles, filled, z, zSource}]`. 기존 `faces/boxes` 그대로, `rot` 규약 그대로.
- 다각형 색 생략 = 묶음 `color`.

### 2. 영속 영역 `lot.*`
| method | 내용 |
|---|---|
| `lot.set {points, z?, fill?, opacity?, line?, lineWidth?, dashed?, color?='#ff9f1c', save?=true}` | 영역 하나(덮어씀). `Save/3D/Lot/Lot_<레벨>.json` 에 저장 |
| `lot.get` | `{lot:{points,z,fill,opacity,line,lineWidth,dashed,color,triangles}|null, file, fileExists}` |
| `lot.clear {keepFile?=false}` | 화면+파일 삭제(keepFile 이면 화면만) |

- **레벨별 파일**로 둔 이유: 요청은 "preset 파일 또는 레벨과 함께 저장" 이었으나, 서신·객리단은 `preset_file=""` 라 프리셋 파일에 얹으면 실제 주차장에선 저장될 곳이 없다. 프리셋 파일은 Unity 와 공유 형식이기도 하다. 레벨 이름(`LV_Park_03`)으로 파일을 가르면 config·프리셋과 무관하게 재기동·`scene.load` 후 복원된다.
- 복원: `APark3DGameMode::ApplyStartupConfig` 맨 앞(config 읽기 전)에서 `ARpcOverlayActor::LoadLotForWorld` — config 파일이 없어도 돈다. 파일이 없으면 아무것도 스폰하지 않는다. 로그 `[Lot] 주차장 영역 N점 복원 ← <path>`.
- `preview.clear` 는 lot 을 지우지 않는다. `preview.list`/`view.getLabels` 등 덧그림 상태에 `lot:bool` 추가.
- car/preset 목록·저장 파일에 안 들어간다(덧그림 액터 `ARpcOverlayActor` 의 `ULineBatchComponent`).
