# 랜덤 차량 배치 함수 구현 (ACarPlacementManager)

작성일: 2026-07-24
작업 유형: 신규 기능 (Unity → Unreal 포팅)
대상 클래스: `ACarPlacementManager` (Unity `CCarObjListUI` 대응 = 차량 인스턴스 생성/제거/조회/선택 관리)
참조 원본: `unity/_MoveTmp/20260724_135121_차량_랜덤배치_함수_정리.md`, `unity/_MoveTmp/CCarObjListUI.cs`

## 1. 요청 요약

`unity/_MoveTmp`의 자료를 참조하여 **랜덤 차량 배치 함수**를, `CCarObjListUI`와 같은 역할을 하는 클래스에 만든다. 사용자 요청: "모든 기능을 만들어줘. 외부에서 사용 가능하게, 필요하면 파라미터를 넣어서."

## 2. 클래스 매핑 결론

| Unity | Unreal | 역할 |
|---|---|---|
| `CCarObjListUI` | **`ACarPlacementManager`** | 차량 인스턴스 관리 + 랜덤 함수군 |

Unity `CCarObjListUI`에 **실제로 존재하는** 랜덤 함수 7종을 포팅했다. 슬롯 기반 배치(`PlaceVehiclesOnSlots`)와 전/후면 지터(`SetRandomCarPos_ByParkSlot`)는 Unity에서 각각 `CPresetSlotPlacer`, `CPSimBaseGameUI` 소속이며, 주차면 슬롯(`CFaceRect`) 기하 타입이 매니저에 없으므로 **범위 밖(후속 작업)**으로 분리했다. (외과적 변경·클래스 소속 기준 우선.)

## 3. 추가된 공개 API (모두 `UFUNCTION(BlueprintCallable)` — 외부/블루프린트 호출 가능)

| 함수 | 시그니처 요약 | Unity 원본 |
|---|---|---|
| `SpawnRandomCarsInLine` | `(StartWorld, CarCount, Catalog, Spacing=2.5, bVertical=false, RightDir, RefYawDeg=180, PresetId=1, Seed=0) → TArray<ACarActor*>` | `CreateRandomCarsInLine` |
| `RebuildAllRandomMesh` | `(Data, Catalog, SelectedIndices, Seed=0)` | `Reset_CreateCarObjectList(bRandomCreate=true)` → `CreateRandomCarObjectByCarPos` |
| `HideRandomCars` | `(HideCount=0, Seed=0) → TArray<ACarActor*>` | `HideRandomCars` |
| `HideRandomNoiseCars` | `(NoiseIndices, Seed=0) → TArray<ACarActor*>` | `HideRandomNoiseCars` |
| `GetNoiseShowCount` | `(Seed=0) → int32` | `GetNoiseShowCount` |
| `NoiseShowCountForRoll` | `(Roll) → int32` (순수, 정적) | `GetNoiseShowCount` 분포식 |
| `ToggleRandomCars` | `(Count, Seed=0) → TArray<ACarActor*>` | `ToggleRandomCars` |
| `SetRandomColorOfCarList` | `(Seed=0)` | `SetRandomColorOfCarList` |

### 주요 파라미터 의미
- **Seed**: `0`이면 비결정(Unity `Random.InitState` 매회 재시드와 동일 의미), `0`이 아니면 재현 가능(유닛테스트/재생성 검증). Unreal 개선점.
- **StartWorld / RightDir**: UE 월드 좌표(cm). 내부 저장은 `WorldToUnrealMeters`로 Unreal 미터 변환.
- **NoiseIndices**: `Cars` 리스트에서 노이즈로 취급할 차량 인덱스 집합.

## 4. 구현 상세

- 난수: `FRandomStream`(`MakeStream(Seed)`). `Seed==0`이면 `FMath::Rand()` 기반, 아니면 `FRandomStream(Seed)`.
- 랜덤 차종: `RandomPrefabId()`가 `Catalog[rand].Idx`(**1-based prefabId 규약**) 반환 — 배열 인덱스 사용 시 off-by-one 회귀(과거 CatalogLookup 테스트가 방지) 방지.
- 위치식: 기존 순수 함수 `UCarPlacementLibrary::AutoPlacePosition` 재사용(중복 금지).
- 표시/숨김: `ACarActor::SetActorHiddenInGame` + `SetActorEnableCollision` 동기화(숨긴 차량은 픽/트레이스 제외). Unity `SetActive(false)` 의미 대응.
- 랜덤 색상: 기존 `ACarActor::ColorComp->SetColorByEnum(ECarColor)` 재사용. `ECarColor`는 0(White)~9(Purple) 10종.
- 스폰: 기존 `SpawnCarFromPos`(메시 캐시·좌표/forward 보정 포함) 재사용.
- 불변식: `HideRandomCars`는 활성-1 클램프로 **항상 최소 1대 표시**.
