# [질문 답변] 콤보박스 드롭다운 폰트 크기·색상 변경 위치 (WBP 디자이너)

- **일시**: 2026-06-24 15:35
- **질문**: WBP 디자이너에서 콤보박스(ComboBoxString) 드롭다운의 폰트 크기·색상을 어디서 바꾸나?

---

## 위치: 콤보 선택 → 디테일(Details) 패널 (검색창 활용)

### 1) 폰트 크기
- 콤보(예: `Combo_Prefab`) 선택 → 디테일 검색 **`Font`** → **`Font.Size`**.
- ComboBoxString의 `Font`는 **선택값 표시 + 드롭다운 항목 텍스트** 모두에 적용. (현재 16)

### 2) 글자 색상
- **드롭다운 항목 글자색**: 디테일 검색 **`Item Style`** → **`Text Color`** (선택 항목은 **`Selected Text Color`**).
- **닫힌 상태(선택값) 글자색**: 디테일 검색 **`Foreground Color`**.
- (현재 모두 검정)

### 3) 드롭다운 배경색
- **`Item Style`** → **`Even Row Background Brush`** / **`Odd Row Background Brush`** → **`Tint Color`**(배경색) + **`Draw As`**=`Rounded Box`(단색 칠).
  - 기본은 `No Draw Type`(투명)이라 어두운 메뉴 위 검정글자가 안 보임 → RoundedBox+흰색으로 변경해야 보임.
- Hover 색: 같은 곳 **`...Hovered Brush`**.

## MCP로 동일 변경 (스크립트)
```json
// 폰트: set_widget_properties(Combo_*, {"Font": {"Size": 16}})
// 항목 글자색/배경: set_widget_properties(Combo_*, {"ItemStyle": {
//   "TextColor": {"SpecifiedColor":{"R":0,"G":0,"B":0,"A":1},"ColorUseRule":"UseColor_Specified"},
//   "EvenRowBackgroundBrush": {"DrawAs":"RoundedBox","TintColor":{"SpecifiedColor":{"R":0.96,"G":0.96,"B":0.96,"A":1},"ColorUseRule":"UseColor_Specified"}},
//   "OddRowBackgroundBrush":  {"DrawAs":"RoundedBox","TintColor":{"SpecifiedColor":{"R":0.90,"G":0.90,"B":0.90,"A":1},"ColorUseRule":"UseColor_Specified"}} }})
```

## 요약
- 폰트 = `Font.Size`
- 항목 글자색 = `Item Style → Text Color`
- 닫힌 값 글자색 = `Foreground Color`
- 드롭다운 배경 = `Item Style → Even/Odd Row Background Brush`
