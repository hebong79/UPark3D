# 주차 시뮬레이션 HUD ↔ 메뉴 패널 배타 표시 (2026-08-12)

## 1. 요구사항

- 주차 시뮬레이션 컨트롤 UI가 뜨면 다른 UI는 숨겨져야 한다.
- 반대로 메뉴에서 다른 UI를 눌러 대화상자가 열리면 주차 시뮬레이션 컨트롤 UI는 숨겨져야 한다.

## 2. 문제

메뉴에서 여는 패널들(프리셋 메이커·차량 배치·카메라 컨트롤·맵 크기 변경·조명 설정)은
`UMainMenuWidget::TogglePanel` 이 `Panels` 캐시를 돌며 **자기들끼리는** 이미 배타적으로 표시하고 있었다.

그러나 주차 시뮬레이션 HUD(`UParkingSimWidget`)의 주인은 메뉴가 아니라 **게임모드**다
(F8/F9/F10 단축키가 같은 인스턴스를 쓰기 때문). 소유자가 갈라져 있어서 두 그룹이 서로를 모르고,
그 결과 스크린샷처럼 `Car Install` 패널과 시뮬레이션 HUD 가 동시에 떠 있었다.

## 3. 변경 내용

소유자가 둘이므로 **각 소유자에게 "너희 것만 접어라" 요청 함수를 하나씩 두고, 여는 쪽이 상대에게 요청**하는 방식으로 맞물렸다.
(한쪽이 남의 위젯을 직접 `RemoveFromParent` 하면 HUD 의 ZOrder·가시성 규칙이 두 곳으로 갈라진다.)

### 3-1. `MainMenuWidget.h` / `.cpp`

- `HideAllPanels()` 신설 — 캐시된 패널을 전부 뷰포트에서 뺀다.
  `TogglePanel` 안에 인라인으로 있던 순회 루프를 그대로 옮긴 것이라 기존 동작은 바뀌지 않는다.
- `TogglePanel()` 이 패널을 **실제로 표시할 때만** `APark3DGameMode::HideSimPanel()` 을 호출한다.
  - 재클릭(토글 오프)일 때는 호출하지 않는다 — 패널을 닫는 동작이 HUD 까지 끄면 안 된다.
  - `EnsurePanelConstructed()`(시작 설정 자동 로딩 경로)는 `TogglePanel` 을 거치지 않으므로 영향 없음.

```cpp
if (!bWasVisible)
{
    // 시뮬레이션 HUD 와도 배타적이다 — HUD 의 주인은 게임모드이므로 접어 달라고 요청한다.
    if (APark3DGameMode* GM = Cast<APark3DGameMode>(UGameplayStatics::GetGameMode(this)))
    {
        GM->HideSimPanel();
    }
    Panel->AddToViewport(10);
}
```

### 3-2. `Park3DGameMode.h` / `.cpp`

- `HideSimPanel()` 신설 — HUD 가 뷰포트에 있으면 빼고 로그를 남긴다.
- `ToggleSimPanel()` 이 HUD 를 **열기 직전에** `UMainMenuWidget::HideAllPanels()` 를 호출한다.

```cpp
// HUD 와 메뉴 패널은 배타적이다 — 열려 있던 패널을 먼저 접는다.
if (UMainMenuWidget* Menu = Cast<UMainMenuWidget>(MenuWidget))
{
    Menu->HideAllPanels();
}
Panel->AddToViewport(20);
```

### 3-3. 재귀 없음

`ToggleSimPanel → HideAllPanels` 와 `TogglePanel → HideSimPanel` 은 각각 **숨기기 전용 함수**를 부른다.
숨기기 함수는 상대를 다시 부르지 않으므로 상호 호출이 사이클을 만들지 않는다.

## 4. 범위에서 제외한 것 (의도적)

| 대상 | 처리 | 사유 |
|------|------|------|
| 메인 메뉴(`WBP_MainMenu`) | 그대로 표시 | 시뮬레이션 HUD 를 여는 버튼 자체가 메뉴에 있다. 숨기면 되돌아올 방법이 없다(M 키 필요). |
| 카메라 뷰어(`WBP_CameraViewer`) | 그대로 표시 | "상시 표시" 위젯이고 Ctrl+Space 로 사용자가 직접 통제한다. 요구사항의 "메뉴에서 여는 대화상자"에 해당하지 않는다. |

   신규 로그 문자열을 UTF-16LE 로 검색해 offset `280958204` 에서 찾음
   (메모리 `verify-cpp-change-in-binary`: `TEXT()` 리터럴은 ASCII grep 에 안 잡힌다).
