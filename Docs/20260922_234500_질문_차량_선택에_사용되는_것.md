# 질문 — "차량을 선택할 때 사용되는 것은 무엇인가?"

- 작성: 2026-09-22 23:45
- 배경: 같은 날 선택 표시를 윤곽선 한 가지로 바꾼 직후([20260922_220500](20260922_220500_차량_선택표시_윤곽선_한가지로.md))
- 저장소 파일 변경 없음(조사·문서만)

## 1. 한 줄 답

**선택을 거는 입구는 셋(패널 목록 클릭 · 3D 화면 좌클릭 · RPC `car.select`)이고, 셋 다
`ACarPlacementManager::SetSelectedIndices` 한 창구로 모인다. 화면에 그리는 것은
오버레이 머티리얼 `/Game/UI/M_CarSelect` 하나뿐이다.**

## 2. 입구 — 3곳

| 입구 | 코드 | 다중 선택 |
|---|---|---|
| 패널 차량 목록 항목 클릭 | `CarPlacementWidget.cpp:774` → `SelectCarWithModifiers` | Shift+클릭 = 토글 추가/해제(`UCarPlacementLibrary::ToggleSelection`) |
| 3D 화면에서 **Ctrl 없이 좌클릭**으로 차를 집기 | `CarPlacementWidget.cpp:523~535` | Shift 동시 누름 |
| RPC `car.select {carNameId}` | `Rpc/Modules/CarRpcModule.cpp:387` | **단일만** — `SetSelectedIndices({Idx})` |

**Ctrl+좌클릭은 선택이 아니다** — 배치 모드일 때 빈 바닥에 차량을 추가한다
(`CarPlacementWidget.cpp:541`). 좌클릭 위에 수정키로 기능을 겹쳐 둔 구조라 헷갈리기 쉽다.

## 3. 상태를 쥐고 있는 곳

- 패널: `UCarPlacementWidget::SelectedIndices`(배열) + `PrimaryIndex`(상세 필드가 보여 줄 1대)
- 월드: `ACarActor::bSelected`
- **창구는 `ACarPlacementManager::SetSelectedIndices` 하나다**(`CarPlacementManager.cpp:211`).
  모든 차량이 이 함수를 지나므로 **방금 스폰된 차량도 별도 처리 없이 현재 설정을 받는다** —
  표시 on/off 설정(`bSelectionMarkVisible`)도 같은 자리에서 함께 밀어 넣는다.

```cpp
void ACarPlacementManager::SetSelectedIndices(const TArray<int32>& SelectedIndices)
{
    for (int32 i = 0; i < Cars.Num(); ++i)
    {
        Cars[i]->SetSelectionMarkVisible(bSelectionMarkVisible);
        Cars[i]->SetSelected(SelectedIndices.Contains(i));
    }
}
```

## 4. 화면에 그리는 것 — 오버레이 머티리얼 하나

`ACarActor::ApplySelectionVisual()`(`CarActor.cpp:774`)

```cpp
const bool bShowMark = bSelected && bSelectionMarkVisible;
MeshComp->SetOverlayMaterial(bShowMark ? SelectionOverlayMaterial : nullptr);  // /Game/UI/M_CarSelect
MeshComp->SetRenderCustomDepth(bShowMark);                                     // 외곽선 PP 용, 현재 미사용
```

- 머티리얼은 생성자에서 `ConstructorHelpers::FObjectFinder(TEXT("/Game/UI/M_CarSelect"))` 로 잡는다
  (`CarActor.cpp:236`). 2026-09-22 에 이 머티리얼을 **윤곽선 한 가지**로 바꿨다.
- **도색(`UCarColorComponent`)은 건드리지 않는다** — 메시 위에 얹는 오버레이라 차량 원래 색과
  겹치지 않는다. 선택했다고 색이 바뀌는 경로는 코드에도 RPC 에도 없다.
- `SetRenderCustomDepth` 는 켜 두었지만 이를 받는 포스트프로세스 머티리얼이 없어 지금은 무효다.

### 표시 on/off 는 선택과 분리돼 있다

패널의 **「선택 표시」 체크박스** → `ACarPlacementManager::SetSelectionMarkVisible`.
**`bSelected` 는 건드리지 않는다** — 표시가 꺼져 있어도 이동·회전·수정·삭제 대상은 그대로
선택된 차량이어야 하기 때문이다(2026-08-18 결정). 이 스위치에는 **RPC 가 없다**.

## 5. 선택이 쓰이는 곳

- 상세 필드 채우기 — `FillDetailFields`: Idx · 프리셋 · 면(slotId) · RotY · 전면/후면
- 이동 · 회전 · 수정 · 삭제의 대상(`CarPlacementWidget.cpp:922 · 1056 · 1071`)

## 6. 주의 — 패널 목록과 RPC 는 별개다

패널은 `SelectedIndices` 를 **자기 안에** 들고 있고 RPC `car.select` 는 매니저만 바꾼다.
그래서 **RPC 로 선택을 바꾼 뒤 패널에서 아무 항목이나 누르면 패널 목록이 이긴다**(RPC 선택이 사라진다).
`CamData` ↔ `PresetMemory`, 패널 프리셋 ↔ `preset.*` 과 같은 성질의 이원화다.
