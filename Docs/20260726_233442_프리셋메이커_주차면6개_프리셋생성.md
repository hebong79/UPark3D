# 프리셋 메이커 — 주차면 6개(2.5 × 5 m) 프리셋 1개 생성

- 일시: 2026-07-26 23:34
- 작업 성격: 코드 변경 없음. 실행 중인 Park3D 인스턴스에 대한 **런타임 조작**(기존 RPC 기능 사용)
- 경로: Claude MCP 브리지(`park3d-rpc`) → Park3D JSON-RPC 서버

## 1. 요청

프리셋 메이커에서 주차면 6개짜리 프리셋 1개 생성(주차면 규격 2.5 m × 5 m).

## 2. 사전 상태 확인

| 호출 | 결과 |
|------|------|
| `system` catalog | 79개 메서드 등록, 서버 정상 리슨 |
| `preset.list` | `[]` — 등록된 프리셋 없음 |
| `map.get` | `sizeX=160, sizeZ=160` (m) |

프리셋이 0개였으므로 신규 생성 시 `idx=1`이 부여된다.

## 3. 실행

```json
// method: preset.create
{
  "offset":       { "x": 0, "y": 0, "z": 0 },
  "faceCount":    6,
  "xSize":        2.5,
  "zSize":        5,
  "dirType":      0,
  "camIdx":       1,
  "useBaseWidth": true,
  "faceRot":      0,
  "groupRot":     0,
  "presetName":   "Preset_001"
}
```

응답:

```json
{
  "idx": 1, "presetName": "Preset_001", "faceCount": 6,
  "offsetPos": { "x": 0, "y": 0, "z": 0 },
  "faceRot": 0, "groupRot": 0,
  "xSize": 2.5, "zSize": 5,
  "dirType": 0, "useBaseWidth": true, "camIdx": 1
}
```

### 파라미터 근거 (`ParkingPresetTypes.h` / `PresetRpcModule.cpp`)

- `xSize` → `FParkingPreset::BoxSizeX` = 박스 가로(폭, m) → **2.5 m**
- `zSize` → `FParkingPreset::BoxSizeZ` = 박스 세로(길이, m) → **5.0 m**
- `useBaseWidth=true` → `bIsBaseWidth=true`, 즉 `BoxSizeX`가 폭으로 해석됨 → 2.5 m 폭 / 5 m 길이 확정
- `dirType=0` (`EFaceDirType::Default`) → 월드축 정렬 가로 1줄 배치
- `faceRot=0`, `groupRot=0` → 사선 없음, 그룹 회전 없음(직각 주차)
- `offset` = 시작 위치(미터). 바닥이 원점 중심이므로 (0,0,0) = 맵 중앙에서 시작
- `camIdx=1` → 주차면 번호 할당 1순위 키

전체 배열 폭 = 2.5 × 6 = **15 m** (회전 0이므로 사선 보정 없음). 맵 160 × 160 m 안에 여유 있게 들어간다.

## 4. 검증

| 검증 | 호출 | 결과 |
|------|------|------|
| 프리셋 등록 | `preset.create` 응답 | `idx=1`, faceCount 6, xSize 2.5, zSize 5 — 요청값과 일치 |
| 3D 뷰 재빌드 | `preset.rebuildAll {showQubeBox:true}` | `ok=true, count=1` — 지오메트리 파이프라인이 1개 프리셋 처리 |
| 주차면 번호 할당 | `preset.renumber` | `camIdx=1, presetIdx=1, startFaceNum=1, faceCount=6, faceNumbers=[1,2,3,4,5,6]` |

`preset.renumber`가 1~6번을 반환한 것은 `UParkingGeometryLibrary`가 실제로 6개 면을 인식했다는 뜻이다.

### 미검증 항목

- **화면 캡처 기반 시각 확인 없음.** `cam.list`가 `{"cameras": []}` — 등록된 카메라가 없어 `cam.captureJPG`로 렌더 결과를 찍을 수 없었다. 요청 범위를 넘는 카메라 생성은 하지 않았다.
- **파일 저장 안 함.** 요청은 "프리셋 메이커에서 만들기"였으므로 매니저 메모리에만 존재한다. 디스크에 남기려면 `preset.save`(기본 경로 `Park3D/Save/3D/Preset/preset.json`) 호출이 필요하다.

## 5. 영향도

- **코드/빌드 영향 없음** — 소스 수정 및 컴파일 없음.
- **런타임 상태 변경**: `AParkingPresetManager::StoredPresets`에 항목 1개 추가, `bShow3DView = true`(rebuildAll의 `showQubeBox=true`로 설정됨), 뷰 갱신.
- **다른 기능과의 연동**: 프리셋은 주차면 번호(`camIdx` → `startFaceNum`) 체계의 입력이므로, 이후 `random.slotPlace` / `random.placeInView` 계열 차량 배치가 이 6개 슬롯을 대상으로 동작한다. 기존 프리셋이 0개였으므로 번호 충돌·재할당 회귀는 없다.
- **되돌리기**: `preset.delete {idx:1}` 또는 `preset.clear`.
