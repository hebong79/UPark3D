## 1. 배경 / 요구사항

언리얼 프로젝트를 SVN에 등록하려 한다. 언리얼은 **생성물(빌드 캐시)** 과 **원본(소스·에셋)** 이
한 폴더에 섞여 있으므로, 생성물은 제외하고 원본만 버전관리해야 한다.
특히 `Content/`는 바이너리라도 **반드시 포함**한다(맵·블루프린트·에셋 원본).

사용자 결정:
1. 빌드 산물 제외에 동의 (권장안 채택)
2. 본 문서로 Docs 문서화에 동의
3. 대상 범위는 **저장소 전체**(Park3D + 루트 폴더 모두)

## 3. 제외 대상 (❌ svn:ignore) — 빌드 산물/캐시

> 컴파일하면 재생성되며, 넣으면 합계 **~7GB가 매 빌드마다 변경**되어 저장소가 급팽창한다.
> 언리얼 표준상 반드시 제외한다. (범위 선택 문제가 아니라 필수 제외)

| 대상 | 용량 | 이유 |
|------|------|------|
| `Park3D/Intermediate/` | 2.7G | 컴파일 중간 산물 |
| `Park3D/.vs/` | 2.1G | Visual Studio 캐시 |
| `Park3D/Binaries/` | 902M | 빌드 결과(DLL/exe) |
| `Park3D/Saved/` | 67M | 로그·오토세이브·자동생성 |
| `Park3D/Save/` | 빈 폴더 | 런타임 생성 위치(CameraPos/CarPos/Preset, 현재 파일 0개) |
| `Park3D/DerivedDataCache/` | 1.9M | 셰이더/에셋 파생 캐시 |
| `Park3D/*.sln`, `*.slnx` | - | uproject에서 재생성 |
| `unreal-mcp/**/__pycache__`, `*.egg-info` | - | 파이썬 캐시 |
| `.git/` | - | Git 메타데이터(SVN과 무관) |

## 4. 적용 절차

워킹카피 루트에서 `svn_setup.ps1` 실행 (핵심 명령):

```powershell
# 1) 재귀 전역 무시 패턴 (SVN 1.8+ 상속 프로퍼티)
svn propset svn:global-ignores "__pycache__`n*.pyc`n*.egg-info`n.venv`n.vs`nBinaries`nIntermediate`nDerivedDataCache" .

# 2) Park3D 전용 폴더 무시
svn propset svn:ignore "Binaries`nIntermediate`nDerivedDataCache`nSaved`nSave`n.vs`n*.sln`n*.slnx" Park3D

# 3) 루트에서 .git 무시
svn propset svn:ignore ".git" .

# 4) 무시 규칙을 지킨 채 나머지 전부 추가
svn add --force . --depth infinity

# 5) 커밋
svn commit -m "Initial import: Park3D UE5 project + unreal-mcp + unity sources"
```

TortoiseSVN GUI 사용 시: 각 폴더 우클릭 → TortoiseSVN → Properties 에서
`svn:ignore` / `svn:global-ignores` 를 위 값과 동일하게 설정한 뒤 Add·Commit.

## 5. 현재 상태 / 남은 작업

- **미완료 사유:** 이 PC에 svn CLI가 없고(PATH·TortoiseSVN CLI 모두 부재),
  `.svn` 워킹카피와 저장소 URL도 없어 실제 커밋을 실행하지 못함.
- **준비 완료물:** 루트에 `svn_setup.ps1` 생성 (svn 준비 시 그대로 실행).
- **사용자 필요 작업:**
  1. Subversion CLI 설치(SlikSVN 등) 또는 TortoiseSVN "command line client tools" 옵션 포함 설치
  2. 저장소 URL 확보 후 이 폴더를 워킹카피로 연결(`svn checkout <URL> .`)
  3. `svn_setup.ps1` 실행
