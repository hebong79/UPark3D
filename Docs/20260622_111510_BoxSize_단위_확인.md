# BoxSize 단위 확인 — UI(m) vs 언리얼 생성값(UU/cm)

- 작성일: 2026-06-22 11:15:10
- 분류: 질문 답변 기록 (CLAUDE.md 3번 규칙)

## 질문

> UI의 BoxSize는 1m 단위로 설정되어 있다. 언리얼에서 생성된 크기도 1m 단위로 생성된 크기인가?

## 결론

**아니요.** UI 입력은 **m(미터)** 단위지만, 언리얼에 생성될 때 **×100** 변환되어 **UU(언리얼 유닛 = cm)** 단위 숫자값으로 들어갑니다.
물리적 실제 크기는 `UI 1m = 월드 1m`로 동일하지만, 언리얼 내부에 들어가는 **숫자값 자체는 1m 단위가 아니라 cm(UU) 값**입니다.

## 단위 흐름 정리

| 구분 | 단위 | 예시 (BoxSizeX = 2.5) |
|------|------|------------------------|
| UI 입력 | m | 2.5 |
| 언리얼 내부 생성값 (Xs) | UU (= cm) | 250 |
| 실제 월드 크기 | m | 2.5 |

## 배경

언리얼 엔진의 기본 단위는 `1 UU = 1 cm`이다. 따라서 m 단위 UI 값을 그대로 사용하면 실제 크기가 1/100로 축소된다.
이를 보정하기 위해 `MetersToUU = 100` 스케일을 곱해 m → cm(UU) 변환을 수행한다.
`MetersToUU`는 `UPROPERTY(EditAnywhere)`이므로 에디터에서 단위 환산 계수를 조정할 수 있다.
