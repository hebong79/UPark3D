## 1. 무엇을 만들었나

### B1 시간대·날씨 — `light.set` / `light.get` 키 추가

| 키 | 범위 | 기본맵(PresetMaker1, 우리 태양) | UDS 레벨(서신·객리단) |
|---|---|---|---|
| `timeOfDay` | 0..24 시 | 태양 고도·방위·색·광량을 시각으로 계산 | UDS `Time of Day`(0..2400) + `Animate Time of Day` 끔 |
| `nightAmbient` | 0..5 lux, 기본 1.5 | 달빛 + 밤하늘 광원 | 미지원(ignoredKeys) — UDS 가 자체 달을 가진다 |
| `fog` | 0..1 | 우리가 스폰한 ExponentialHeightFog(밀도 = fog×0.08) | UDW `Fog`(×10) + `Fog - Manual Override` 켬 |
| `cloudCoverage` | 0..1 | 미지원 | UDW `Cloud Coverage`(×10) + Manual Override |
| `rain` | 0..1 | 미지원 | UDW `Rain`(×10) + Manual Override |
| `wetness` | 0..1 | 미지원 | UDW `Material Wetness`(×1) + Manual Override |

- `light.get` 에 위 6키(적용 안 됨·몰지 않음 = `null`), `supports{timeOfDay,nightAmbient,fog,cloudCoverage,rain,wetness,lamps,carLights}`, `lamps{count,on,intensity}` 추가.
- `light.set` 응답에 `ignoredKeys` 를 **항상** 싣는다(빈 배열 = 전부 적용). 레벨이 못 하는 키는 여기에 이름이 담긴다 — 조용히 버리지 않는다(-32602 는 모르는 키만).
- 한 호출에 `timeOfDay` 와 태양 키가 같이 오면 시각을 먼저 적용하고 태양 키가 덮는다. 태양 방향이 바뀌면 `timeOfDay` 는 `null` 이 된다(더 이상 그 시각이 아니므로). 패널 '적용'도 같은 규칙.
- `light.save` 는 시간대·날씨를 선택 키(`TimeOfDay`·`NightAmbient`·`Fog`·`CloudCoverage`·`Rain`·`Wetness`, 음수 = 건드리지 않음)로 함께 쓴다. `light.load`·기동 시 `light_file` 은 그 키가 있으면 적용하고, 없으면(옛 파일·패널 저장) 시간대·날씨를 건드리지 않는다.
- `light.reset` 은 시간대·날씨도 기동 상태로 되돌린다(기본맵: 시각·안개·밤 조명 / UDS: Time of Day 값과 시간 흐름 스위치, UDW Manual Override 4개).

## 2. 왜 이렇게 했나 / 원인

- **밤이 검던 원인(보드 실측 4/255)**: 기본맵 SkyLight 는 대기(SkyAtmosphere)를 실시간 캡처하는데 대기는 대기 광원(태양)으로만 밝혀진다. 태양을 끄면 캡처된 하늘이 검어 `skyIntensity` 를 올려도 검정에 곱해질 뿐이었다.
  - 첫 구현은 달빛 하나를 대기 2번 광원으로 두었다 → **고정 노출(−1.02)에서 밤하늘이 한낮처럼 파랗게 떴다**(실기 캡처). 그래서 둘로 나눴다:
    - 달빛(직접광, 대기 광원 아님): 세기 = `nightAmbient × (1 − 지면 태양광/1 lux)` — 한낮엔 0 이라 기존 화면·`scenario.*` 기준선 불변(액터도 만들지 않는다).
    - 밤하늘 광원: 달빛의 10%, 대기 2번 광원, 라이팅 채널 전부 끔(물체는 직접 안 밝힘) → 남색 하늘과 그 캡처가 그늘 앰비언트.
  - 기본값 1.5 lux 는 실측으로 정했다(0 → 2.1, 0.5 → 4.8, 2 → 55.5, 5 → 119 / 1.5 → 38~44). 보드의 임시 밤(33)과 비슷하다.
- **UDS 변수는 블루프린트라 C++ 타입이 없다** → 리플렉션으로 표시 이름(공백 포함)으로 찾는다. 처음 한 번 로그에 타입·값을 남긴다(이 버전: `Time of Day` Double 960, `Animate Time of Day` Bool, UDW 값 Double·Override Bool). 이름이 다른 UDS 버전이면 `supports` 가 false 가 된다.
- **UDW Manual Override 는 불 스위치**다 — 값은 같은 이름의 수동 날씨 상태 변수(`Cloud Coverage` 등)에서 가져와 마지막에 덮는다(UDW 설명문 "force individual state values from the manual weather state"). 그래서 값 + 스위치를 같이 쓴다.
- **차 앞은 메시 로컬 +Y** 다. 번호판 코드(`Front = Origin.Y − MountY`)를 보고 −Y 로 두었더니 실기에서 전조등이 해치 쪽으로 나왔다 → +Y 로 고쳐 앞(그릴)에서 빔·판 확인.
- 광량 단위는 칸델라. 이 프로젝트 태양이 5 lux(고정 노출)라 실차 값(전조등 수만 cd)을 쓰면 하얗게 탄다 — 가로등 150 cd(6 m 아래 약 4 lux), 전조등 600 cd, 미등 1 cd, 제동 5 cd, 번호판등 0.6 cd 를 캡처로 맞췄다.

## 4. 한계·미검증

- 기본맵 시각 모델은 단순 모델이다(해 뜸 6·짐 18·정오 60°, **지도 북 = UE +X 가정**). 실제 위도·계절 없음.
- 기본맵의 구름·비·젖음은 없다(`supports` false). UDS 레벨 `fog 0.6` 은 눈에 띄게 약하다 — UDW Fog 배율(×10)이 맞는지 확정 못 함(값이 쓰이는 것만 확인).
- UDW 는 상태 전이가 있어 값이 몇 초에 걸쳐 바뀐다.
- UDS 레벨의 밤은 채움광(`shadowFillIntensity`·`carFillIntensity`)이 켜져 있으면 밝게 남는다 — 채움광은 시각과 무관한 고정광이다. 어두운 밤이 필요하면 0 으로.
- 차량 조명: 발광 렌즈(눈부심) 메시 없음, 저장 안 됨(차를 다시 만들면 꺼짐), 앞 번호판등은 실차에 없는 시뮬 보조, 미등이 가까운 차체를 붉게 물들인다.
- 가로등은 낮에도 켜진 채다(자동 점등 없음).
- **패키지 빌드 미실행**(새 .cpp 2개 + 테스트 1개 — 새 익명 이름은 전부 저장소에서 유일함을 grep 으로 확인).
