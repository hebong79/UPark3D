# 질문: 레벨 바닥면(주차장 바닥면)의 크기 조절 RPC 가 있나?

## 답

**코드가 까는 바닥(`AMapFloorActor`)용은 있다. 레벨에 원래 들어 있는 바닥용은 없다.**

### 있는 것 — `map.*` 4종 (`AMapFloorActor`)

| 메서드 | 파라미터 | 동작 |
|---|---|---|
| `map.resize` | `sizeX`(m, UE X), `sizeZ`(m, UE Y — 이름은 Unity 잔재) | 바닥 평면 크기 변경, 10..500 m 로 클램프. 응답은 `{ok:true}` 뿐이라 실제 값은 `map.get` 으로 |
| `map.get` | 없음 | `{sizeX, sizeZ}` (m) |
| `map.save` | `fileName`(기본 `MapSize`) | `Saved/MapData/<fileName>.json` 에 저장(엔진 `Saved/`, `Save/3D` 아님) |
| `map.load` | `fileName` | 그 파일 크기를 읽어 적용 |

근거: `Park3D/Source/Park3D/Rpc/RpcHelpTable.cpp:795-818`, 본체 `Map/MapFloorActor.cpp:115` `SetFloorSize`.

주의
- 네 메서드 모두 바닥 액터가 없으면 **스폰한다**(조회인 `map.get` 포함). `map_floor:false` 레벨(서신지구대·객리단길)에서 부르면 160×160 m 아스팔트 평면이 갑자기 생긴다.
- 크기 변경은 런타임뿐이고 기동 때 자동 복원되지 않는다(config 키 없음).
- 원경 지면(`BackdropMesh`, 20 km)은 크기와 무관하게 고정.

### 없는 것 — 레벨 지오메트리 바닥

서신지구대(`LV_Park_01`)·객리단길(`LV_Park_03`)의 주차장 바닥은 `BP_Road_Creator` 도로 슬래브 등 `.umap` 안의 메시다. 이걸 늘리거나 줄이는 RPC 는 없다(`env.*` 는 RPC 로 스폰한 프롭만, `bay.*` 는 주차면만 다룬다). 레벨 수정은 에디터에서 해야 한다.

기본맵(`PresetMaker1`, `map_floor:true`)에서는 바닥이 곧 `AMapFloorActor` 이므로 `map.resize` 가 그대로 바닥 크기 조절이 된다.
