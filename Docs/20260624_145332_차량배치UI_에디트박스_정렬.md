## 1. 원인

- 각 행이 `HBox[라벨, 입력박스]` 구조인데 라벨 텍스트 길이가 제각각("Idx" < "Rot Y" < "Face Id" < "Preset Id") → 입력박스 시작 X가 행마다 달라 들쭉날쭉.

## 2. 수정 (`TextBlock.MinDesiredWidth`)

- 라벨에 **고정 최소폭**을 부여해 라벨 칸 너비를 통일 → 입력박스가 같은 X에서 시작.

| 라벨 | MinDesiredWidth |
|------|----------------|
| Lbl_Idx / Lbl_PresetId / Lbl_FaceId / Lbl_RotY (상세 4) | 90 |
| Lbl_Count / Lbl_Spacing (개수/배치간격) | 68 |

- 입력박스 폭은 기존 동일(상세 150 / 숫자 80)이라, 시작 정렬 + 동일 폭으로 칸이 가지런해짐.

## 3. 검증
