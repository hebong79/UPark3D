# [질문 답변] WBP 디자이너에서 에디트박스 가로 크기 조정 위치

- **일시**: 2026-06-24 15:03
- **질문**: WBP 디자이너 창에서 EditableTextBox(에디트박스)의 가로 크기는 어디서 조정하나?

---

## 핵심
가로 크기는 **그 위젯의 부모(슬롯) 종류**에 따라 조정 방법이 다르다. 차량배치 대화상자(WBP_CarPlacement)의 입력칸들은 **Horizontal Box** 안에 있어 캔버스처럼 핸들 드래그가 안 되고 아래 속성으로 조정한다.

## 1) Minimum Desired Width (현재 사용 중, 가장 간단)
1. 디자이너 좌측 **계층 구조** 또는 캔버스에서 입력칸(예: `Field_Idx`) 선택
2. 우측 **디테일(Details)** 패널 검색창에 `Minimum Desired Width` 입력
3. 숫자 값 설정
   - 상세칸 `Field_Idx/Field_PresetId/Field_FaceId/Field_RotY` = **150**
   - 숫자칸 `Field_Count/Field_Spacing/Field_Rotate` = **80**

## 2) 슬롯(레이아웃)으로 늘리기 (부모가 Horizontal/Vertical Box)
- 디테일 패널 최상단 **"슬롯 (Horizontal Box Slot)"** → **Size** 를 `Auto` → **`Fill`** 로 변경하면 남는 가로폭을 채워 늘어남(Fill 비율로 형제와 분배).
- **Padding** 으로 좌우 여백 조정.

## 3) 정확한 고정폭 — SizeBox로 감싸기
- 입력칸을 **Size Box** 자식으로 넣고 Size Box의 **`Width Override`** 체크 + 값 지정 → 항상 그 폭 유지.
- (리스트 박스 `CarList_Scroll`을 이 방식으로 160×200 고정함.)

## 참고
- 부모가 **Canvas Panel**이면 디자이너에서 모서리 핸들을 드래그하거나 슬롯의 **Size X / Offsets** 로 조정.
- 라벨 길이로 입력칸 시작점이 어긋나는 정렬 문제는 **라벨(TextBlock)의 `Min Desired Width`** 로 해결(상세 90 / 개수·배치간격 68). 입력칸 자체 폭(1번)과는 별개.
- 본 프로젝트 입력칸은 Horizontal Box 기반이므로 **1) Minimum Desired Width 가 가장 직접적**.
