## 1. 신규 파일

| 파일/에셋 | 내용 |

| `/Game/UI/WBP_MainMenu` | 리페어런트 위젯 BP(버튼 8 + 한글 라벨 + 패널 클래스 연결) |

## 2. 기능

- **버튼 8(BindWidget)**: Btn_PresetMaker, Btn_CarPlacement, Btn_Camera, Btn_MapSize, Btn_DistFeature, Btn_VlaTrain, Btn_VlaSim, Btn_Exit. 라벨: 프리셋 메이커 / 차량 배치 / 카메라 컨트롤 / 맵 크기 변경 / 거리.피쳐 체크 / VLA 학습 데이터 / VLA 시뮬레이터 / Exit.
- **패널 토글**(`TogglePanel`): 뷰포트에 있으면 제거, 없으면 생성·표시(인스턴스 캐시). 약결합 `TSubclassOf<UUserWidget>`.
  - 프리셋 메이커 → `PresetMakerWidgetClass`(=WBP_PresetMaker)
  - 차량 배치 → `CarPlacementWidgetClass`(=WBP_CarPlacement)
- **Exit** → `UKismetSystemLibrary::QuitGame`.
- 카메라/맵크기/거리피쳐/VLA학습/VLA시뮬 → `BlueprintImplementableEvent`(디자이너 BP에서 구현 확장). 본 설계 범위상 골격만.

## 3. 설계 정합(영향검토 부록 B 준수)

- 패널을 `TSubclassOf` 약결합으로 참조 → **헤더 의존 사이클 없음**(MainMenu가 CarPlacement/PresetMaker 헤더를 직접 include 안 함).
- **GameMode 시작위젯은 변경하지 않음**(B-2/Q8 경고). WBP_MainMenu를 시작 화면으로 띄우는 전환은 별도(GameMode `PresetWidgetClass` 기본값 교체 — 사용자 결정 후).

## 4. 빌드/검증

- C++ Live Coding 컴파일 1차 성공.
- WBP: factory(parent=UMainMenuWidget) → 버튼 8 + 라벨 8(MCP) → 패널 클래스 2개 기본값 → compile **성공**(BindWidget 8 충족).
- 유닛테스트 10종 회귀 없음.
- 디자이너 확인: 한글 라벨 버튼 8개(`_workspace/wbp_mainmenu_designer.png`).

## 5. 미검증 / 한계
