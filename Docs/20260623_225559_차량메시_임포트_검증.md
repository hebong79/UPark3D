## 4. 설계 반영 사항 (중요)

### 4.1 B-2(차량 메시 부재) 해소
차량배치 설계서(`20260623_215100_차량배치UI_메뉴_설계서.md`)의 차단 항목 **B-2가 해소**됨 → 3~5단계(액터/색상/위젯) 구현 진행 가능.

### 4.2 ⚠ 정면 축 = **Y축** (설계 Q5 확정)
모든 차량의 **길이 방향이 로컬 Y축**(바운드 Y 익스텐트가 최대). 즉 차량 정면/후면이 **±Y**를 향한다. 언리얼 액터 기본 정면(+X)과 다르므로, JSON `rotY`(Unity Y축 회전)를 UE Yaw로 변환할 때 **±90° 오프셋 보정**이 필요할 가능성이 높다. 구현 1단계(`UCarPlacementLibrary::UnityRotYToUEYaw`)에서 실제 배치 스크린샷으로 부호·오프셋을 확정할 것(설계 §6, TP-14).

### 4.3 ⚠ 성능: 고폴리 + 단일 LOD + Nanite 미사용
- 차량당 삼각형 **73만~316만**, **LOD 1개뿐**, **Nanite 비활성**(`bEnabled=false`).
- 주차장에 수십~수백 대 배치 시 심각한 렌더 부하 예상. 설계 §8.3(풀링 "1차 미적용") 가정과 별개로 **메시 자체 최적화가 선결**일 수 있음.
- 권고(우선순위): ① 차량 메시 **Nanite 활성화**(가장 간단·효과적), 또는 ② 자동 LOD 생성, ③ 원거리 임포스터. → 배치 기능 성능 측정 단계에서 결정(설계 Q12와 연계).
