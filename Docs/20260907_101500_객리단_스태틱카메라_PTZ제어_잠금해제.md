# 객리단길 스태틱 카메라 PTZ 제어 잠금 해제

- 일시: 2026-09-07
- 대상: `Park3D/Save/3D/CameraPos/CamPos_13Face.객리단.json` (저장소 정본) + `Package/Windows/Save/3D/CameraPos/` (배포본 동기)
- 코드 변경: 없음

## 요청

1. 카메라가 스태틱이어도 제어는 되어야 한다. "Static" 은 사용 타입일 뿐이고, 외부(RPC)에서 제어할 수 있어야 한다.
2. 스태틱 카메라도 PTZ 와 똑같이 제어되어야 한다.

## 원인

2026-09-06 재작성 때 스태틱 6대(카메라 1·2·3·4·7·8)를 구분하려고 `FCamDir` 의 `ptzmin`/`ptzmax` 를
현재 값과 같게(`ptzmin == ptzmax == 값`) 적어 패널 슬라이더를 잠갔다.
`FCamDir` 에는 카메라 종류 필드가 없어 범위를 잠그는 것으로 종류를 표현한 것인데, 이 방식은 종류 표시가 아니라
**패널 제어 자체를 막는 것**이라 요청과 어긋난다.

코드에는 "Static" 을 구분하는 로직이 전혀 없다(`Source` 전체 grep 결과 `sname` 문자열을 읽는 곳 없음).
잠금의 실체는 파일의 범위 값뿐이다.

- 패널: `FillControlsFromDir` 이 `ptzmin`/`ptzmax` 를 슬라이더 Min/Max 텍스트에 넣고, `ValueToSlider` 가
  Min==Max 일 때 0 을 돌려 슬라이더가 움직이지 않는다([CameraControlWidget.cpp:796](../Park3D/Source/Park3D/CameraControlWidget.cpp#L796),
  [CameraControlLibrary.cpp:106](../Park3D/Source/Park3D/CameraControlLibrary.cpp#L106)).
- RPC: `cam.setPTZ`/`setPan`/`setTilt`/`setZoom` 은 범위를 보지 않고 액터에 바로 쓴다. 액터(`APTZCameraActor`)는
  `ptzmin`/`ptzmax` 를 갖지 않는다(`ApplyDir` 은 pos·pan·tilt·zoom 만 적용,
  [CameraControlManager.cpp:185](../Park3D/Source/Park3D/CameraControlManager.cpp#L185)). 따라서 RPC 제어는 잠금 전에도 후에도 된다.

## 변경

스태틱 6대(카메라 1·2·3·4·7·8)의 `ptzmin`/`ptzmax` 를 PTZ 카메라(5·6)와 같은 전범위로 되돌렸다.

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| ptzmin | 현재 pan / tilt / zoom 값 | p −180, t −90, z 1 |
| ptzmax | 현재 pan / tilt / zoom 값 | p 180, t 90, z 36 |

`sname` 은 `"Static 1"` 그대로 두었다. 종류 표시는 이름으로만 남고 제어에는 영향이 없다.
pos·pan·tilt·zoom 값은 손대지 않았다(diff 66줄 = 6대 × ptzmin/ptzmax 블록).

배포본 `Package/Windows/Save/3D/CameraPos/` 의 같은 파일은 변경 전 HEAD 와 동일함을 확인한 뒤 저장소 파일로 덮었다.
`Package/Work13520` 의 파일은 08-15 자 옛 작업본이라 건드리지 않았다.

## 검증 (정본 인스턴스 sim1, RPC 13510)

1. `cam.loadPreset {camId:3, presetId:1, fileName:"CamPos_13Face.객리단.json"}` → ok, `path` 가 패키지 `Save` 의 새 파일로 해석됨, `camCount: 8`.
2. `cam.setPTZ {camId:3, pan:-100, tilt:20, zoom:3}` → ok. `cam.getPTZ` 가 `(-100, 20, 3.0)` 반환.
3. `cam.captureJPG {camId:3}` 캡처에서 줌 3 배로 당겨진 차량 두 대(프리셋 원래 화각과 다름)가 보여 실제로 움직였음을 확인.
4. `cam.applyPreset {camId:3, presetId:1}` 로 복원 → `cam.getPTZ` = `(-129.57, 35.93, 1.5)`.

## 미검증 · 주의

- **실행 중인 정본의 패널은 아직 옛 범위를 들고 있다.** 패널의 `CamData` 는 RPC 모듈의 `PresetMemory` 와 별개이고, 파일을 다시 읽게
  하는 RPC 가 없다(`HandleOpen` 은 파일 다이얼로그 경유). 패널에서 **열기 → 이 파일 선택** 또는 인스턴스 재기동 후에 슬라이더가 풀린다.
- 그 전에 패널에서 **저장**을 누르면 `CollectDirFromControls` 가 패널의 잠긴 범위를 그대로 써서 파일이 다시 잠긴다. 열기를 먼저 할 것.
- 재기동 자동 로딩(config `levels[]` 객리단 `camerapos_file`)으로 패널 범위가 풀리는지는 이번에 재기동하지 않아 미확인.
