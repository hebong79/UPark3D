# 주차 시뮬레이션 HUD — 메인 메뉴 토글 + 시작 시 숨김 + 색상 통일

작성일: 2026-08-11
브랜치: `feat/camera-viewer-toggle`

좌하단에 상시 떠 있던 주차 시뮬레이션 HUD 를 **메인 메뉴 버튼으로 열고 닫도록** 바꾸고,
**시작 시에는 숨긴 상태**로 두었다. 패널 배경·글자색도 기존 패널과 같은 계열로 맞췄다.

---

## 1. 변경 요약

| 항목 | 이전 | 이후 |
|------|------|------|
| 시작 상태 | 좌하단에 상시 표시 | **숨김** (위젯은 미리 생성만) |
| 열고 닫기 | 없음 | 메인 메뉴 **"주차 시뮬레이션"** 버튼 (Exit 바로 위) |
| 패널 배경 | 어두운 남색 계열 `(0.06, 0.06, 0.07, 0.92)` | 밝은 회녹색 반투명 `(0.27, 0.29, 0.23, 0.85)` |
| 글자색 | 흰색(엔진 기본) | 검정 |
| 단축키 F9/F10 | 동작 | 동작(HUD 가 닫혀 있어도 동작) |

## 2. 변경 파일

| 파일 | 변경 |
|------|------|
| `Park3DGameMode.h/.cpp` | `ShowSimPanel()` → `EnsureSimPanel()`(생성만) + `ToggleSimPanel()`(뷰포트 넣고 빼기). BeginPlay 는 생성만 한다 |
| `MainMenuWidget.h/.cpp` | `InsertMenuButtonBeforeExit()` 헬퍼 추출, `InjectSimButton()` / `HandleSimPanel()` 추가 |
| `Sim/ParkingSimWidget.cpp` | 패널 배경색·글자색 상수화 및 교체 |

### 메뉴 버튼 삽입
기존 `InjectLightButton()` 과 같은 방식이다(WBP_MainMenu 자산에는 이 버튼이 없고 에디터 없이 자산을
고칠 수 없으므로 런타임에 끼워 넣는다). 두 번째 호출자가 생겨 삽입 로직을 헬퍼로 뽑았다.

```cpp
UButton* UMainMenuWidget::InsertMenuButtonBeforeExit(const TCHAR* WidgetName, const FText& Label);
```

`VBox_Menu` 를 이름으로 찾아 Exit 바로 앞에 넣고, 스타일·폰트·슬롯 패딩을 `Btn_MapSize` 에서 복사한다.
`NativeOnInitialized` 에서 호출해야 `ShiftChild` 로 잡은 순서가 화면에 반영된다.

### 소유권
HUD 인스턴스의 주인은 **게임모드**다(F9/F10 단축키가 같은 인스턴스를 쓴다).
메뉴 버튼은 `APark3DGameMode::ToggleSimPanel()` 을 호출만 한다 — 메뉴가 따로 만들면 인스턴스가 갈라진다.

다른 패널들과 달리 **배타 토글(`TogglePanel`)이 아니다.** 프리셋 메이커 등을 열어둔 채로
시뮬레이션 상태를 볼 수 있어야 하고, 좌하단이라 다른 패널과 겹치지도 않는다.

## 3. 색상 맞추기 (실측)

패널 배경색은 눈대중이 아니라 **화면 캡처의 픽셀을 재서** 맞췄다.

1. 기존 프리셋 메이커 패널이 바닥 위에 합성된 색을 샘플링 → sRGB `(139, 142, 127)`
2. 알파 0.85 기준으로 브러시 색을 역산 → `FLinearColor(0.27, 0.29, 0.23, 0.85)`
3. 배경이 밝아졌으므로 제목·상태·안내 글자를 검정으로 바꿈(버튼 라벨은 원래 검정)

적용 후 같은 캡처에서 다시 샘플링한 결과:

| 패널 | sRGB |
|------|------|
| 프리셋 메이커 | (144, 147, 130) |
| 주차 시뮬레이션 HUD | (137, 140, 125) |

차이 7 이하로 육안 구분이 안 되는 수준이다.

## 4. 패널 드래그 이동

다른 패널(조명 설정·프리셋 메이커 등)과 같은 방식으로 **패널을 잡고 끌어 옮길 수 있다.**

```cpp
// NativeOnMouseButtonDown : 좌클릭이면 드래그 시작 + 마우스 캡처
// NativeOnMouseMove       : PanelTranslation = 시작값 + (현재 - 시작점) → RootBorder->SetRenderTranslation
// NativeOnMouseButtonUp   : 캡처 해제
```

- 배경 프레임(`RootBorder`)을 멤버로 잡아 두고 `SetRenderTranslation` 으로 옮긴다.
  캔버스 슬롯의 좌하단 앵커는 그대로라 **기본 자리는 좌하단**이고, 드래그는 그 위에 얹히는 변위다.
- 버튼(시작/리플레이/정지) 위에서는 버튼이 클릭을 소비하므로 드래그가 걸리지 않는다 — 다른 패널과 동일.
- 위치는 저장하지 않는다(패널을 닫았다 열면 기본 자리로 돌아온다). 기존 패널들도 같다.

## 5. 검증 (2026-08-11, `-game` 인스턴스)

- 빌드 `Build.bat Park3DEditor Win64 Development` → Succeeded
- 기동 직후 캡처: 메인 메뉴에 **"주차 시뮬레이션"** 버튼이 Exit 위에 기존 버튼과 같은 모양으로 존재,
  좌하단 HUD 는 **보이지 않음**
- 버튼 클릭 → `[Sim] 주차 시뮬레이션 HUD 를 열었습니다` + 좌하단에 밝은 반투명 패널 표시
- 다시 클릭 → `[Sim] 주차 시뮬레이션 HUD 를 닫았습니다` + 해당 좌표 픽셀이 바닥색 (100, 87, 76) 으로 복귀
- 드래그: 패널 빈 영역을 좌클릭한 채 끌면 패널이 따라 움직이고, 원래 좌표 (250, 905) 는
  바닥색 (100, 88, 77) 으로 비워진다
