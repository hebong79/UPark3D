# 버그 수정 — RMB 카메라 사용 후 키보드 프리셋 이동이 멈추는 문제

- 작성일: 2026-06-22 22:33:28
- 작업 유형: 버그 수정. C++ 재빌드 필요.
- 선행: [20260622_215547 Offset Pick 이동/회전 속도조절](20260622_215547_OffsetPick_이동회전_속도조절.md)

## 1. 증상 (재현)
offsetPick = ON 상태에서:
1. 프리셋 선택 → 키로 이동(정상).
2. RMB + WASD로 카메라 이동(정상).
3. RMB 떼고 WASD → **프리셋이 안 움직임(버그)**. 카메라도 안 움직임(RMB 미보유).
4. UI에서 (다른) 프리셋을 클릭하면 다시 정상 동작.

## 2. 근본 원인 — 키보드 포커스 이탈
- offsetPick ON 시 위젯이 `SetKeyboardFocus()`로 포커스를 잡아 `NativeOnKeyDown`에서 프리셋을 제어.
- RMB로 뷰포트를 클릭하면 **키보드 포커스가 게임 뷰포트(폰)로 이동**.
- RMB를 떼도 포커스가 위젯으로 **복귀하지 않음** → WASD가 폰으로 가는데 RMB 미보유라 카메라도 안 움직이고, 위젯도 키를 못 받아 프리셋이 멈춤.
- UI 프리셋 버튼 클릭 시 포커스가 위젯으로 돌아와 정상 복구되던 것.

## 3. 수정 (`PresetMakerWidget.h` / `.cpp`)

### (1) NativeOnKeyDown — RMB 보유 중 키 양보
offsetPick ON이라도 **RMB를 누르고 있으면** 키를 소비하지 않고 `Super`로 폰에 양보 → 공용 WASD가 카메라 이동에 쓰이도록(위젯이 포커스를 가진 상태여도 카메라 동작).

### (2) NativeTick — RMB 릴리즈 엣지에서 포커스 복귀
```cpp
const bool bRmbNow = PC ? PC->IsInputKeyDown(EKeys::RightMouseButton) : false;
if (bPrevRmbDown && !bRmbNow && !HasKeyboardFocus())
    SetKeyboardFocus();   // RMB 떼는 순간 위젯이 포커스 재획득
bPrevRmbDown = bRmbNow;
```
- 추가 멤버 `bool bPrevRmbDown`로 '눌림→뗌' 전이를 감지.
- RMB와 무관한 텍스트 입력 등은 영향 없음(릴리즈 엣지가 없으므로 포커스 탈취 안 함).

## 4. 처리 흐름(수정 후)
- RMB 미보유 + WASD → 위젯이 소비 → 프리셋 이동.
- RMB 보유 + WASD → 위젯 양보 → 폰 → 카메라 이동.
- RMB 뗌 → 다음 틱에 포커스 복귀 → 다시 프리셋 이동 가능.

## 5. 영향도
