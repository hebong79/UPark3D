# 패키징 빌드를 창(Windowed) 모드로 부팅하도록 설정

작성일: 2026-07-28
대상: `Park3D/Config/DefaultGameUserSettings.ini` (신규), `Package/Windows/Park3D/Saved/Config/Windows/GameUserSettings.ini`

---

## 1. 요구사항

패키징된 `Park3D.exe`가 실행될 때 전체화면이 아니라 **창 모드**로 뜨도록 한다.

## 2. 변경 전 상태

| 항목 | 값 |
|---|---|
| `Park3D/Config/DefaultGameUserSettings.ini` | **없음** (엔진 기본값 사용) |
| 엔진 기본 창 모드 | `WindowedFullscreen`(테두리 없는 전체화면) |
| `Package/.../Saved/Config/Windows/GameUserSettings.ini` | `FullscreenMode=1` |

`FullscreenMode` 값의 의미 (`EWindowMode`):

| 값 | 의미 |
|---|---|
| 0 | Fullscreen (독점 전체화면) |
| 1 | WindowedFullscreen (테두리 없는 전체화면) — **변경 전 값** |
| 2 | Windowed (창모드) — **변경 후 값** |

## 3. 설정이 읽히는 경로 (config 계층)

`GameUserSettings`는 아래 계층으로 병합된다. 아래쪽이 우선한다.

```
Engine/Config/BaseGameUserSettings.ini        (엔진 기본)
  └ Park3D/Config/DefaultGameUserSettings.ini (프로젝트 기본)  ← 이번에 신규 추가
      └ <실행경로>/Saved/Config/Windows/GameUserSettings.ini   (사용자 저장값)
```

- 패키지 exe는 실행 시 `Saved/Config/Windows/GameUserSettings.ini`를 만들고, 종료 시 **기본값과 다른 항목만(델타)** 기록한다.
- 즉 이미 한 번 실행해 저장 파일이 생긴 패키지는, 프로젝트 기본값을 바꿔도 저장 파일이 우선하므로 **저장 파일도 같이 고쳐야** 한다.

## 4. 변경 내용

### 4-1. 신규: `Park3D/Config/DefaultGameUserSettings.ini`

```ini
[/Script/Engine.GameUserSettings]
Version=5
FullscreenMode=2
LastConfirmedFullscreenMode=2
PreferredFullscreenMode=2
ResolutionSizeX=1280
ResolutionSizeY=720
LastUserConfirmedResolutionSizeX=1280
LastUserConfirmedResolutionSizeY=720
```

**`Version=5`가 핵심이다.** `UGameUserSettings::LoadSettings()`는 읽어들인 `Version`이 엔진 상수 `UE_GAMEUSERSETTINGS_VERSION`과 다르면 `SetToDefaults()`를 호출해 하드코딩 기본값(= WindowedFullscreen)으로 되돌린다. 이 경우 위 `FullscreenMode=2`가 조용히 무시된다. UE 5.8의 현재 값은 `5`이며, 기존 저장 파일들에서 `Version=5`로 확인했다.

> 엔진을 업그레이드해 이 상수가 올라가면 위 `Version`도 같이 올려야 한다. 증상은 "설정을 바꿨는데 그냥 전체화면으로 뜬다".

### 4-2. 수정: `Package/Windows/Park3D/Saved/Config/Windows/GameUserSettings.ini`

이미 빌드되어 있던 패키지가 지금 바로 창모드로 뜨게 하기 위해 저장값 3줄을 `1 → 2`로 변경했다.

```diff
-FullscreenMode=1
-LastConfirmedFullscreenMode=1
-PreferredFullscreenMode=1
+FullscreenMode=2
+LastConfirmedFullscreenMode=2
+PreferredFullscreenMode=2
```

### 4-3. 재스테이징

`Park3D/Config/*.ini`는 스테이징 시 pak 안으로 들어간다(`Manifest_UFSFiles_Win64.txt`에 `Park3D/Config/DefaultGame.ini` 등이 등재된 것으로 확인). 따라서 신규 `DefaultGameUserSettings.ini`가 **배포 패키지에 포함되려면 재스테이징이 필요**하다. 쿠킹·컴파일은 그대로 두고 스테이징만 다시 수행했다.

```bat
"C:/Program Files/Epic Games/UE_5.8/Engine/Build/BatchFiles/RunUAT.bat" BuildCookRun ^
  -project="D:/Work/UnrealWork/Parking/Park3D/Park3D.uproject" ^
  -noP4 -platform=Win64 -clientconfig=Development ^
  -skipbuild -skipcook -stage -pak -archive ^
  -archivedirectory="D:/Work/UnrealWork/Parking/Package"
```

| 옵션 | 의미 |
|---|---|
| `-skipbuild` | C++ 재컴파일 생략(에디터 실행 중이어도 안전) |
| `-skipcook` | 기존 `Park3D/Saved/Cooked/Windows` 재사용 |
| `-stage -pak -archive` | 스테이징 → pak 재생성 → `Package/`로 아카이브 |

## 5. 검증

### 5-1. 프로젝트 설정 검증 (`-game` 독립 실행)

기존 `Park3D/Saved/Config/WindowsEditor/GameUserSettings.ini`(FullscreenMode=1)를 백업해 치우고 `-game`으로 부팅했다.

```
UnrealEditor.exe Park3D.uproject -game -RpcPort=13199
```

Win32 `GetWindowRect` / `GetWindowLong(GWL_STYLE)` 결과:

| 항목 | 결과 | 판정 |
|---|---|---|
| 창 영역 | `L=312 T=125 W=1296 H=759` | 통과 (1280x720 클라이언트 + 테두리/타이틀바) |
| 화면 해상도 | 1920x1080 | 창이 화면보다 작음 = 전체화면 아님 |
| `WS_CAPTION` | True | 통과 (타이틀바 있음) |
| `WS_THICKFRAME` | True | 통과 (크기 조절 가능) |

종료 후 재생성된 저장 파일에는 `FullscreenMode`·`ResolutionSize*`·`Version` 키가 **아예 기록되지 않았다**. 저장값이 상위 계층(=새 `DefaultGameUserSettings.ini`)과 동일해 델타가 없다는 뜻으로, 프로젝트 기본값이 정상적으로 읽히고 있음을 반증한다.

### 5-2. 패키지 exe 검증

```
Package/Windows/Park3D.exe -RpcPort=13199
```

- `Park3D.exe`(루트)는 부트스트랩이고 실제 게임 프로세스는 `Package/Windows/Park3D/Binaries/Win64/Park3D.exe`다. 창 핸들은 **후자**에 붙는다.

| 항목 | 결과 | 판정 |
|---|---|---|
| 창 영역 | `L=312 T=125 W=1296 H=759` | 통과 |
| `WS_CAPTION` | True | 통과 |
| `WS_THICKFRAME` | True | 통과 |
| 종료 후 저장값 | `FullscreenMode=2` 유지 | 통과 (다음 실행에도 지속) |

### 5-3. 재스테이징 결과 + 신규 설치 상태 검증

재스테이징 로그: `BUILD SUCCESSFUL`, `AutomationTool exiting with ExitCode=0`, 소요 17초, `ERROR`/`BUILD FAILED` 0건 (`_workspace/windowed_restage.log`).

스테이징 매니페스트에 신규 파일이 등재된 것을 확인:

```
Park3D/Config/DefaultGameUserSettings.ini	2026-07-28T07:43:54.624Z
```

이어서 **배포본 첫 실행과 동일한 조건**(저장 설정 없음)으로 검증하기 위해 `Package/Windows/Park3D/Saved/`를 통째로 치우고 실행했다.

| 항목 | 결과 | 판정 |
|---|---|---|
| 창 영역 | `L=312 T=125 W=1296 H=759` | 통과 |
| `WS_CAPTION` / `WS_THICKFRAME` | True / True | 통과 |
| 새로 생성된 `Saved/.../GameUserSettings.ini` | `FullscreenMode` 키 없음 | 통과 (pak 안 기본값과 동일 → 델타 없음) |

즉 **저장 설정이 전혀 없는 깨끗한 배포본도 창모드로 부팅한다.**

## 6. 영향도 분석

| 대상 | 영향 | 비고 |
|---|---|---|
| C++ 소스 | **없음** | `Source/` 전체에 `FullscreenMode`/`GameUserSettings` 참조 없음. 재컴파일 불필요 |
| 에디터 / PIE | **없음** | 에디터 뷰포트·PIE 창 모드는 `EditorPerProjectUserSettings`가 결정. `GameUserSettings`와 별개 |
| RPC 서버(`URpcServerSubsystem`) | **없음** | 창 모드와 무관하게 부팅 시 기동. 포트는 `DefaultGame.ini [RpcServer] Port=13120` 유지 |
| `cam.captureJPG/PNG` | 캡처 해상도가 창 클라이언트 크기(1280x720) 기준 | 이전 전체화면(1920x1080)보다 작아진다. 더 큰 캡처가 필요하면 `-resx/-resy`로 조정 |
| 기존 패키지 배포본 | 없음 (재스테이징으로 갱신) | 이미 실행해 `Saved/` 가 생긴 사본은 저장값이 우선하므로 그 파일도 고치거나 삭제해야 함 |
| 다른 플랫폼(Linux/Mac) | 동일 적용 | `DefaultGameUserSettings.ini`는 플랫폼 공통 계층 |

## 7. 운영 메모

- **일시적으로 전체화면으로 띄우기**: 설정을 되돌릴 필요 없이 커맨드라인이 우선한다.
  ```
  Park3D.exe -fullscreen
  Park3D.exe -windowed -resx=1600 -resy=900
  ```
- **창 크기 변경**: `DefaultGameUserSettings.ini`의 `ResolutionSizeX/Y`를 바꾼 뒤 재스테이징. 이미 실행 이력이 있는 사본은 `Saved/Config/Windows/GameUserSettings.ini`를 지우면 기본값으로 재생성된다.
- **"바꿨는데 안 먹는다"의 원인 2가지**: ① 대상 사본의 `Saved/Config/Windows/GameUserSettings.ini`가 우선하고 있음, ② `Version` 불일치로 `SetToDefaults()` 발동.
