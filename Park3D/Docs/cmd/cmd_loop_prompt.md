Goal:
MainMenuWidget(우측 메뉴)에 버튼 목록과 시각적으로 구분되는
① 상단 "메뉴 타이틀"(라벨)과
② 버튼들을 감싸는 배경 프레임(패널)을 추가하고,
③ 타이틀/배경프레임 영역을 마우스로 드래그해 메뉴 전체를 이동할 수 있게 한다.

Loop:
* 현재 MainMenuWidget/WBP_MainMenu 구조와 기존 패널 드래그(RootBorder,
  NativeOnMouseButtonDown/Move/Up + CaptureMouse) 선례를 분석하고 설계한다.
* 설계대로 코드를 수정한다.
* 컴파일한다. (수동 게이트)
* PIE에서 확인한다: 타이틀·배경프레임이 버튼과 구분돼 보이고,
  타이틀/프레임을 드래그하면 메뉴가 이동하며, 버튼 클릭은 그대로 동작하는지.
* 실패하면 다시 분석·재설계·수정한다.
* 성공하면 최종 결과를 설명한다.

Requirements:
* 타이틀은 버튼과 시각적으로 구분된다(폰트/배경/구분선 등).
* 배경 프레임은 버튼 뒤에 표시되고 버튼 클릭을 막지 않는다.
* 드래그는 타이틀/배경프레임 영역에서만 시작된다(버튼 위 클릭은 버튼 동작).
* 드래그 중 앱 화면제어(카메라 회전 등)에 영향이 없어야 한다.
* 기존 버튼 기능(패널 토글 등)은 그대로 동작해야 한다.
