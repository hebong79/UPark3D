### truth 구조

```
truth = {
  image {width, height, origin},
  pose {camId, pos{x,y,z} m, pan, tilt, zoom, hfov, vfov, k1, k2, intrinsics{fx,fy,cx,cy}, forward},
  cars [{index, carNameId, prefabId, prefabName, plate, plateText, plateKind, distanceM,
         bboxAmodal, bboxVisible, amodalPixels, visiblePixels, visibleFraction, truncated,
         plates [{side, plateText, quad[[x,y]×4], bboxAmodal, bboxVisible, amodalPixels, visiblePixels,
                  visibleFraction, distanceM, viewAngleDeg, truncated}]}],
  carCount, depthPasses, truthMs, frameId, timeMs
}
```

- 상자는 `[x1,y1,x2,y2]` 픽셀 가장자리 좌표(원점 왼쪽 위, y 아래, 픽셀 i 는 [i, i+1)). 보이는 픽셀이 0 이면 `null`.
- `cars` = 보이는 차량 중 화면 안에 가림 없는 픽셀이 하나라도 있는 차, 가까운 순.
- `bboxAmodal`/`amodalPixels` = 그 차만 그렸을 때(화면 밖은 잘림 → `truncated:true`).
- `quad` 순서 = 판을 정면에서 볼 때 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래.
- 번호판은 **카메라를 향한 판만** 나온다. `side` 는 기하로 정한다(차 앞 = 메시 로컬 +Y, 전조등과 같은 규약).
  - 컴포넌트 이름 `FrontPlateComp` 는 실제로는 차 뒤쪽에 붙어 있다(2026-10-08 전조등 함정과 같은 원인). 그래서 이름을 쓰지 않았다.

## 2. 방법 — 머티리얼 에셋 없이 깊이 비교

- 보드 답변에서 걱정했던 "ID 패스용 단색/스텐실 머티리얼"은 **만들지 않았다**. `Content/` 는 git 밖이고 에디터 MCP 도 연결되지 않는다.
- 대신 `SCS_SceneDepth` 로 깊이를 찍는다.
  1. 전체 장면 깊이 1장.
  2. 화면에 걸리는 차마다 `PRM_UseShowOnlyList` 로 그 차만 그린 깊이 1장. 차 바운즈를 투영한 영역만 읽는다.
  3. 두 깊이가 같은(허용 1 cm + 0.1%) 픽셀이 보이는 픽셀이다. 가까운 차부터 픽셀을 차지한다(마스크와 개수가 일치).
- 번호판은 렌더하지 않는다. 판 평면과 픽셀 광선의 교점 깊이를 전체 깊이와 비교한다(허용 1.5 cm + 0.2%).
- 전용 컴포넌트 `APTZCameraActor::TruthCapture`(R32F 타깃 `TruthDepthTarget`)는 `Capture` 의 자식이다.
  - 처음 쓸 때 만든다. 뷰어·MJPEG·`Capture` 상태는 건드리지 않는다.
  - AA/TAA 를 꺼야 한다. 지터가 있으면 두 렌더가 같은 픽셀 격자에 떨어지지 않는다.
  - 조명·GI·그림자·안개·후처리도 끈다(이름으로 찾아 끄고, 없는 플래그는 건너뛴다).
- 렌즈 왜곡(#1297): 깊이는 `CaptureInto` 와 같은 넓은 핀홀 화각으로 찍는다. 출력 픽셀마다 왜곡 전 방향으로 깊이 픽셀을 찾는다.
  - 화각 계산은 `ComputeWideTan` 한 곳으로 뽑아 렌더와 공유한다.
  - 출력→깊이 픽셀 표는 (크기·초점·k) 가 같으면 재사용한다. 다시 만들면 1280×720 에서 약 2.4 초 걸린다.
- 유리: 장면 깊이에 반투명은 안 들어간다. 앞차 유리 너머로 보이는 뒤차는 "보임" 으로 센다.

- 비용:
