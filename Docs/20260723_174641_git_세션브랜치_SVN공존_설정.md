- 대상: `D:\Work\UnrealWork\Parking` (Park3D 프로젝트 루트)
- 요청: "세션 시작할 때 브랜치를 따서 작업할 수 있나?" + "SVN을 쓰는데 git과 충돌 안 나나?"

## 1. 배경 / 문제

- `D:\Work\UnrealWork\` 가 **SVN 워킹카피 루트**(`.svn`, `wc.db` 존재). Park3D는 그 하위 폴더.
- 기존 `Parking\.git` 은 Visual Studio가 남긴 `ms-persist.xml` 스텁 하나뿐인 **가짜**였음(실제 git 저장소 아님).
- git과 SVN을 한 워킹카피에서 같이 쓸 때의 실질 마찰:
  1. **git 브랜치 전환 시 디스크 파일이 바뀌어 SVN이 대량 변경으로 인식** (가장 큰 위험)
  2. 서로의 메타데이터 폴더(`.git`/`.svn`)를 상대가 추적하려 함
  3. 동일 파일 이중 관리 혼란

## 2. 채택한 방식 (option 1b)

**작업 트리는 Parking 그대로 두고, git 메타데이터(`.git`)만 SVN 밖으로 분리.**

```
git init -b main --separate-git-dir=D:\Work\GitRepos\Parking.git .
```

결과 레이아웃:

| 항목 | 위치 |
|------|------|
| git 작업 트리 | `D:\Work\UnrealWork\Parking` (기존 그대로) |
| git 메타데이터(.git) | `D:\Work\GitRepos\Parking.git` (SVN 워킹카피 밖) |
| `Parking\.git` | 포인터 **파일** (`gitdir: D:/Work/GitRepos/Parking.git`) |

이유:
- 작업 트리가 그대로라 **언리얼 빌드 / PIE / Unreal MCP 워크플로우가 모두 정상 동작**.
- git 데이터가 SVN 트리 밖이라 **SVN이 git 히스토리를 추적하지 않음**.

## 3. 추적 범위 (.gitignore)

- **추적**: `Park3D/Source`, `Park3D/Config`, `*.uproject`, `Docs/`, `_workspace/`, `unity/`, `unreal-mcp/`, 하네스 설정(`.claude`/`.agents`/`.codex`/`*.md`/`.mcp.json`) — 합계 약 50MB, 초기 커밋 532개 파일.
- **제외**(생성물/대용량 바이너리, **SVN이 계속 authoritative**): `Content`(5.9G), `Binaries`(865M), `Intermediate`(2.8G), `.vs`(4.3G), `Saved`(72M), `DerivedDataCache`, 생성된 `*.sln/*.slnx`.

> ⚠️ **중요 경계**: Content 폴더의 UMG/머티리얼 `.uasset` 변경은 **git 브랜치에 담기지 않는다.** 에셋 이력은 SVN이 관리한다. git 브랜치를 되돌려도 에셋은 되돌아가지 않음.

## 4. 세션별 브랜치 워크플로우

```bash
# 세션 시작: 브랜치 생성
git switch -c session/2026-07-23-작업명

# 작업 중 커밋
git add -A && git commit -m "..."

# 세션 종료: main에 반영
git switch main
git merge session/2026-07-23-작업명
```

- **전진형(앞으로만 나아가는) 워크플로우에서는 SVN 오염 없음.**
- 주의: **과거 상태로 `git checkout` 하면 그때만** SVN이 파일 변경을 감지하므로, 되돌리기 후에는 다시 최신으로 복귀할 것.

## 5. 남은 수동 작업 (SVN CLI 필요 — 이 환경엔 미설치)

SVN에서 봤을 때 `Parking\.git`, `Parking\.gitignore` 는 미추적(`?`)으로 표시된다. 실수로 `svn add` 되지 않도록 무시 설정 권장:

```powershell
# D:\Work\UnrealWork\Parking 에서
svn propset svn:ignore ".git" .
# (.gitignore 는 SVN에도 커밋하고 싶으면 svn add, 아니면 위 목록에 추가)
```
