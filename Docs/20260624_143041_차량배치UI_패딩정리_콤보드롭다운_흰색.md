## 1. 콤보박스 드롭다운 (Combo_Prefab, Combo_Type)

- **원인**: `ItemStyle.EvenRowBackgroundBrush`/`OddRowBackgroundBrush`가 `NoDrawType`(투명) → 기본 어두운 메뉴 위 검정 글자라 안 보였음.
- **수정**:
  - 행 배경 `DrawAs=RoundedBox`, Tint **흰색계열**(짝 0.96 / 홀 0.90), Hover 연파랑(0.8,0.85,0.95).
  - `TextColor`/`SelectedTextColor` **검정**(0,0,0). 선택 표시 텍스트도 검정.
- 콤보 `ForegroundColor`(선택값 표시)는 이미 검정.

## 2. 패딩(간격) 정리

| 대상 | 패딩 |
|------|------|
| 행 간격(VBox_Root) | 타이틀 ↓14, 프리팹/옵션/리스트 행 ↓12, 섹션헤더 ↕6, 하단버튼 ↑4 |
| 열 간격 | 프리팹열 →16, 옵션좌열 →20, 리스트박스 →14 |
| 상세 필드 | Field_Idx/PresetId/FaceId/RotY 왼쪽 8 + 행 ↓6 |
| 숫자 입력 | Field_Count/Spacing/Rotate 왼쪽 6, 행 ↓8 |
| 체크/라디오 라벨 | 이동/회전/Front 등 좌4·우12, 프리셋그룹/세로배치 좌4 |
| 버튼 간격 | 선택삭제/열기/저장 우측 8, 자동생성 ↕, 수정 ↑8 |
| 패널 크기 | RootBorder 400×500 → **410×540**(여백 확보) |

## 3. 검증

- 컴파일·저장 성공. 슬롯 패딩/콤보 ItemStyle 설정 전부 적용 확인(set_count 정상).
- C++ 무변경 → 유닛테스트 영향 없음.
- ⚠ 디자이너 스크린샷은 **PIE 실행 중이라 에셋 편집창 열기가 차단**되어 미캡처(에셋은 정상). 실제 모습은 재생으로 확인.
