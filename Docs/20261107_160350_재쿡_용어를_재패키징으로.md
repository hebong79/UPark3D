# 「재쿡」 용어를 「재패키징」으로

- 요청: 마스터 이 창 「재쿡이 뭐지? 직관적인 용어변경해줘 pm쪽도 전달해줘.」
- 뜻: 콘텐츠(레벨·재질·메시 등)를 실행용 형식으로 다시 변환해 패키지 전체를 새로 만드는 일. `BuildPackage.bat`. 코드만 바꾼 exe 를 만드는 재빌드와 다르다.
- 바꾼 곳: `CLAUDE.md`, `.claude/skills/park3d-ops-sonnet/{SKILL,PROCEDURE}.md`. 서브에이전트 prompt 틀의 승인 항목 이름도 `재패키징=` 으로 바뀐다.
- 그대로 둔 곳: `HISTORY.md` 의 옛 행과 옛 `Docs/`. 기록 원문이라서 고치지 않고, `park3d-history` 의 `SKILL.md` 에 같은 말이라고 적었다.
- 안 바꾼 곳: `BuildPackage.bat` 과 UE 의 cook 관련 이름·로그. `D:\Work\pm\CLAUDE.md` 는 이 저장소 밖이라 pm-ff 에게 전달했다.
- 빌드·Automation 은 해당 없음(코드 변경 없음).
