---

사용자 결정(2026-08-05): **이 프로젝트는 보안을 사용하지 않는다.** 연구단계이므로 속도가 우선이다.

**금지**: 신규 인증(토큰·헤더·Origin·루프백 제한) 도입, 방화벽/OS 설정 변경 제안 및 실행, 보안 관련 `AskUserQuestion`, 설계서 미결 결정사항·QA 기준에 보안 항목 포함.

**수행**: 새 네트워크 표면은 무인증으로 바로 연다(`0.0.0.0` 바인드 포함). 외부 접속 실패 원인이 OS 방화벽일 수 있으면 사실 1줄만 고지하고 조치는 사용자에게 맡긴다. 검증된 외부 코드 이식 시 인증 관련 개조를 하지 않는다.

**기존 코드 불변**: `Rpc/RpcAuth.*`·`PassAuthOrRespond`·`[RpcServer] Token=` 은 제거도 확장도 하지 않는다(요청받지 않은 삭제 금지). 이미 `AllowAnonymous=True` 로 무력화된 상태다.

**예외**: 사용자가 명시적으로 보안을 요청할 때만, 요청한 범위만 구현한다.

상세와 적용 이력은 `.claude/skills/park3d-no-security/SKILL.md` 를 따른다.
