# 하네스 루프 현황 점검 (2026-08-04)

## 질문
"현재 하네스에 루프로 돌고있는 부분이 존재하나?"

## 결론
**지금 자동으로 돌고 있는 루프는 없다.** 루프 "정의"는 하네스에 있지만, 전부 사용자가 명시적으로 시작해야 도는 구조이며 현재 활성 인스턴스가 0건이다.

| 백그라운드 태스크 | 세션 태스크 목록 | 없음(신규 세션) |
| settings.json 훅(자동 재실행 트리거) | `.claude/settings.json` grep(`hooks`/`SessionStart`/`Stop`/`PostToolUse`) | 훅 정의 없음. 매칭된 항목은 `PowerShell(Stop-Process*)`·`Stop-Service*` 권한 문자열뿐 |
| 진행 중인 Goal/Loop 산출물 | `_workspace/*loop*` glob | ~~파일 없음~~ → **정정(2026-08-04)**: 조회 경로를 `.claude/skills/parking-dev-orchestrator/_workspace/`로 잘못 잡았다. 실제 경로는 **저장소 루트 `_workspace/`** 이며 과거 루프 반복 기록 26건이 있다(`json_coordinate_flag` 15, `camera_distance_goal_loop` 9, `car_multiselect` 2). 모두 **완료된 과거 기록**이므로 "현재 돌고 있는 루프 없음"이라는 결론 자체는 유지된다 |

## 하네스에 "정의"만 되어 있는 루프

1. **`parking-cpp-loop` 스킬** (`.claude/skills/parking-cpp-loop/SKILL.md`, Codex 쌍둥이 `.agents/skills/parking-cpp-loop/SKILL.md`)
   - 진짜 반복 루프. `[1] 설계 → [2] C++ 수정 → [3] UBT 사전 문법점검 → [4] 수동 컴파일 게이트(Ctrl+Alt+F11, 유일한 사람 개입) → [5] PIE 재기동 → [6] QA 검증 → [7] 실패 시 [1]로 자동 복귀`.
   - 무한루프 방지: 동일 원인 3회 연속 실패 시 중단·보고.
   - 기동 조건: 사용자가 Goal/Loop/Requirements를 주고 "루프 돌려" 식으로 요청할 때만. 오케스트레이터가 라우팅한다.

2. **`parking-dev-orchestrator`의 생성-검증 루프** (SKILL.md:50, 59)
   - qa-verifier가 버그를 찾으면 `SendMessage`로 unreal-implementer에 반려 → 통과까지 반복.
   - 자율 타이머 루프가 아니라 게이트 실패 시에만 되돌아가는 조건부 반복. 작업이 진행 중일 때만 존재한다.

3. **되돌리기 규칙(반복 아님, 1회성 재시도)**
   - 빌드/테스트/MCP 실패는 1회 재시도 후 실패를 명시하고 진행(SKILL.md:70, 72).
   - 주변 동작 사후점검 실패·고위험은 구현/QA 단계로 되돌림(SKILL.md:61).

4. **Claude Code 내장 `/loop` 스킬** — 하네스 자체 구성물이 아니며, 현재 호출된 적 없음.
