# UI 재구성 — 이전 블루프린트 UI 의 디자인으로 되돌리기

- 날짜: 2026-08-17
- 브랜치: `feat/unified-hud-ui`
- 요청: "이전 블루프린트로 만들어진 UI를 최대한 참조하고, 현재 UI의 내용을 모두 사용할 수 있게 변경."
  이후 스크린샷 3장(Home/Camera/Car 패널)을 받아 실제 디자인이 확인됐고, 결정은
  ① 탭이 아니라 **독립 패널** ② **렌더 패널 신설** ③ **WBP 로 제작** ④ 배경은 **검정에 가깝게**
  ⑤ 아이콘은 **원본 에셋** ⑥ VLA 버튼 2개·카메라 패널 뷰어 이미지·차량 랜덤 독 버튼 **제거**
- 결과: **화면으로 확인 완료.** 하단 아이콘 독 + 검은 카드 패널 + 슬라이더 3열이 동작한다.

## 1. 스크린샷에서 읽어낸 규약

`.uasset` 에서 위젯 이름만 뽑아 구조를 추정했을 때는 이 규약을 알 수 없었다.
사용자가 준 실제 화면 3장이 결정적이었다.

| 규약 | 내용 |
|---|---|
| 하단 아이콘 독 | 패널 전환은 화면 아래 가운데 아이콘 줄 |
| **슬라이더 3열** | 슬라이더 아래에 최소·현재·최대를 좌/중/우로 적는다 |
| 흰 입력칸 | 콤보·입력·버튼은 밝은 바탕에 검은 글자. **패널만 어둡다** |
| 검은 카드 | 패널 배경은 거의 검정(불투명도 0.94) |
| 중앙 제목 줄 | 카드 위 얇은 제목 바(`Camera`, `Parking`) |
| 세그먼트 버튼 | `수정 및 제거 | 배치`, `5M 6M 7M 8M 9M` 처럼 한 줄로 |

## 2. 만든 것

### 2.1 `Tools/wbp/ui_kit.py` — 규약을 코드로

카드 골격·구획 라벨·슬라이더 3열·아이콘 버튼·색을 함수로 두어 패널마다 같은 규칙이 나오게 했다.
색은 한 곳(`PANEL_BG` 등)에서 바꾸면 전 패널에 반영된다.

### 2.2 패널 5종 재구성

**자산을 지우지 않고 위젯 트리만 비운 뒤 다시 짓는다** — 자산을 지우면 `WBP_MainMenu` 의
`TSubclassOf` 참조가 끊긴다.

| WBP | BindWidget | 바뀐 점 |
|---|---|---|
| `WBP_MainMenu` | 6 | 우측 세로 목록 → **하단 아이콘 독** |
| `WBP_CameraControl` | 41 | **6축이 24줄 → 6줄**(슬라이더 3열) |
| `WBP_CarPlacement` | 29 | 모드·차량·랜덤·목록 구획 |
| `WBP_PresetMaker` | 38 | 프리셋·오프셋·데칼·계산 결과 |
| `WBP_RenderPanel` | 12 | 랜덤·표시 구획 |

컴파일 성공이 곧 BindWidget 검증이다(126개 전부 통과).

### 2.3 C++ 변경 (`MainMenuWidget`)

- `InsertMenuButtonBeforeExit` 가 **`HBox_Menu`(가로)를 먼저 찾고 없으면 `VBox_Menu`(세로)** 로
  폴백한다. 삽입 로직은 `UPanelWidget` 공통 API 만 쓰고, 슬롯 패딩만 가로/세로 각각 처리한다.
- `ApplyDockIcons()` / `SetButtonIcon()` 신설 — 독 버튼에 `/Game/Widgets/Icons/TabIcons` 의
  원본 텍스처를 입힌다.
- **VLA 버튼 2종 제거** — `Btn_VlaTrain`·`Btn_VlaSim` BindWidget, 핸들러,
  `OnVlaTrain`/`OnVlaSim` BlueprintImplementableEvent 까지.
- **차량 랜덤 독 버튼 제거** — `InjectRenderButton()` 호출만 뺐다. 패널·핸들러는 남아 있어
  그 한 줄을 되살리면 다시 뜬다. **지금은 그 패널에 접근할 경로가 없다.**

## 3. 아이콘 — WBP 브러시로는 안 된다

`_UnusedContent` 복원분에 이전 UI 가 쓰던 아이콘이 그대로 있었다
(`Widgets/Icons/TabIcons/T_Home·T_Car·T_PTZ·T_Parking·T_Lighting·T_Render·T_Box·T_Graph·T_Pole`).
Pretendard 한글 폰트도 함께 있다.

WBP 브러시에 텍스처를 넣는 시도는 **세 번 실패**했고, 실패 방식이 매번 달랐다.

| 시도 | 결과 |
|---|---|
| `ResourceObject` 에 경로 문자열 | 조용히 무시 — 브러시에 아무것도 안 들어감 |
| `{"refPath": ...}` 로 교정 | 브러시에는 들어갔으나 화면은 빈칸 |
| `ImageType: FullColor` 추가 | 브러시 값이 완벽해졌는데도 여전히 빈칸 |

같은 시점에 **C++ 주입 버튼(`LoadObject` + `SetBrushFromTexture`)만 정상**이었다.
그 대비가 단서가 되어 아이콘은 코드 한 경로로 통일했다.

**교훈: 브러시 프로퍼티가 맞다고 해서 그려지는 것이 아니다.** 값 확인과 화면 확인은 별개다
(이 프로젝트에서 조명 때 같은 방식으로 한 번 속았다 — `light.get` 이 넣은 값을 돌려주는 것과
화면이 그렇게 그려지는 것은 다르다).

## 4. 그 밖의 함정

- **슬롯은 `AddWidget` 응답에서 챙겨야 한다.** `GetWidgets` 로 되찾으면 `"None"` 이 와서
  패딩·앵커가 조용히 적용되지 않는다 → 독이 상단에 붙고 패널이 기본 크기로 떴다.
- **`GetWidgets` 는 BindWidget 이름을 `bInherited=true` 로 함께 준다.** 위젯이 아니라
  '채워야 할 자리'이므로 트리 조작에서 걸러야 한다.
- **`Border` 배경은 `DrawAs` 를 지정해야 그려진다.** 기본값이 이미지라 카드가 통째로 투명했다.
- **이모지 문자는 쓸 수 없다** — UE 기본 폰트에 글리프가 없어 빈 사각형이 된다.

## 5. 검증

`-game` 으로 띄워 창을 캡처했다(카메라 스트림에는 UMG 가 실리지 않는다).

| 항목 | 결과 |
|---|---|
| 하단 아이콘 독 | 7개 + 종료. 아이콘 표시·툴팁 동작 |
| 패널 카드 | 검은 배경 + 중앙 제목 줄 + 흰 입력칸 |
| 배타 토글 | 독에서 다른 패널을 누르면 이전 패널이 닫힘 |
| WBP 컴파일 | 5개 전부 성공(BindWidget 126개 충족) |
| C++ 빌드 | 성공 |

## 6. 남은 것

- **맵 아이콘(`T_Box`)이 검게 보인다.** 텍스처 자체가 어두운 것으로 보이며, 교체하거나
  밝은 틴트를 줘야 한다.
- **Preview 카드 미적용.** 카메라 뷰어는 아직 우하단 상자 그대로다.
- **차량 색상·번호판 콤보 없음.** 이전 Car 패널에는 있었지만 현재 C++ 에 대응 항목이 없어
  넣지 않았다(넣으면 눌러도 아무 일이 없는 컨트롤이 된다).
- **차량 랜덤 패널 접근 경로 없음.** 위 2.3 참조.
- 유닛 테스트는 이번에 돌리지 않았다 — UI 전용 변경이고 자동화 테스트가 위젯 트리를 보지 않는다.
