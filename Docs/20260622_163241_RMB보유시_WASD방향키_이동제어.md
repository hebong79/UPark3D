# 마우스 오른쪽 버튼 보유 시에만 WASD/방향키 이동

- 작성일: 2026-06-22 16:32:41
- 작업 유형: 신규 기능(입력 제어 변경) — 에디터 플라이캠 방식
- 처리: parking-dev-orchestrator (설계 게이트 → 구현). C++ 재빌드 필요.
- 설계서: `../Park3D/Docs/설계기록/rmb_move_architect_design.md`

## 1. 요구사항
- RMB(마우스 오른쪽 버튼)를 누른 동안에만 WASD/방향키(Up/Down/Left/Right)로 이동.
- RMB를 떼면 이동 입력 무시.

## 2. 현황 분석
- 이동은 엔진 `ADefaultPawn` 내장 바인딩(`DefaultPawn_MoveForward/MoveRight/MoveUp`, W/S/A/D + 방향키)에서 발생.
- 커스텀 Pawn/Controller·Enhanced Input 매핑 에셋·입력 C++ 전무.
- `APark3DGameMode`(GameModeBase, GlobalDefaultGameMode)는 DefaultPawnClass 미지정 → 엔진 DefaultPawn 사용.
- 이동은 `APawn::AddMovementInput()`(virtual) 경유. 마우스 회전은 `AddControllerYaw/PitchInput`(별도 경로).

## 3. 설계 (최소·외과적)
`AddMovementInput()` 한 함수만 게이트 → 회전·속도 등 기본 동작 전부 보존.

| 대안 | 채택 | 사유 |
|------|------|------|
| AddMovementInput 오버라이드 게이트 | ○ | 1함수, 기본 동작 보존, 회전 비영향 |
| 기본 바인딩 비활성 후 수동 재바인딩 | ✕ | 매핑 재정의·코드 증가 |
| Enhanced Input Chorded 신규 구축 | ✕ | IMC/IA/Pawn 전면 신설, 과도 |
| Blueprint Pawn(재빌드 회피) | ✕ | MCP 노드그래프 복잡·오류소지 |

## 4. 변경 내용

### 신규 `AParkFlyPawn : public ADefaultPawn`
- `Park3D/Source/Park3D/ParkFlyPawn.h` / `.cpp`
- `AddMovementInput(...)` 오버라이드 → `bRightMouseHeld`일 때만 `Super::` 호출.
- `SetupPlayerInputComponent`: `Super::`(기본 바인딩 유지) + `BindKey(RightMouseButton, Pressed/Released)`로 플래그 토글.

```cpp
void AParkFlyPawn::AddMovementInput(FVector Dir, float Scale, bool bForce)
{
    if (bRightMouseHeld) Super::AddMovementInput(Dir, Scale, bForce);
}
```

### `APark3DGameMode` 생성자
```cpp
DefaultPawnClass = AParkFlyPawn::StaticClass();
```

### 처리 흐름
RMB Pressed → bRightMouseHeld=true → WASD/방향키 → AddMovementInput 통과 → 이동.
RMB Released → false → AddMovementInput 무시 → 정지.

## 5. 영향도 분석
- **모듈**: 신규 UCLASS 추가 → **UHT 재생성 + 전체 재빌드 필요**(Live Coding 핫리로드 불가).
- **Build.cs**: `InputCore`·`EnhancedInput` 이미 포함 → 변경 없음.
- **정식 앱**: `Park3DGameMode` 사용 맵의 기본 Pawn이 `AParkFlyPawn`으로 바뀜. `ADefaultPawn` 하위라 스폰/프레이밍 동일.
- **테스트 픽스처**: `/Game/_Test/BP_FloorTestGM`은 자체 `DefaultPawnClass=DefaultPawn` → **영향 없음**(평범한 이동 유지).
- **RMB 충돌**: DefaultPawn은 RMB 미바인딩 → 충돌 없음. UI 텍스트필드 우클릭 컨텍스트 메뉴(AllowContextMenu)는 UI 위 동작이라 무관.
- **마우스 회전**: 미게이트(요청 범위 외) → 기존대로 동작.
- **JSON↔3D·위젯·매니저**: 무관.

## 6. 검증 상태 (정직 보고 — 미완료)
1. **재빌드 미수행**: 신규 UCLASS라 Live Coding 불가 + 에디터 실행 중 외부 빌드는 모듈 DLL 잠금 충돌. **에디터 종료 후 재빌드(또는 IDE 빌드) 필요**. 현재 코드는 미컴파일·미검증.
2. **자동 유닛테스트 부적합**: 입력 게이트는 런타임 입력 의존이라 순수 유닛테스트가 어려움. 아래 수동 검증으로 대체.
3. **수동 검증 절차(재빌드 후)**:
   - RMB 안 누른 채 WASD/방향키 → 위치 불변.
   - RMB 누른 채 WASD/방향키 → 이동.
   - 이동 중 RMB 떼기 → 즉시 정지.
   - 마우스 회전은 RMB 무관하게 기존대로.
   - PIE 시작은 크래시 이력 있으므로 standalone 권장.

## 7. 가정
- "이동(WASD/방향키)"만 게이트. 마우스 회전(look)도 RMB 게이트 원하면 `AddControllerYaw/PitchInput`도 동일 패턴으로 확장 가능.
