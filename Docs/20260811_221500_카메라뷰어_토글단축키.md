# 카메라 뷰어 표시/숨김 단축키 (Ctrl + Space)

작성일: 2026-08-11
브랜치: `feat/camera-viewer-toggle`

상시 표시되던 카메라 뷰어(우하단 렌더타깃 프리뷰)를 **Ctrl + Space** 로 켜고 끌 수 있게 했다.

---

## 1. 변경 파일

| 파일 | 변경 |
|------|------|
| `Park3DGameMode.h` | `ViewerToggleChord`(FInputChord, 기본 Ctrl+Space), `ToggleCameraViewer()`, `ViewerSavedVisibility` 추가. `Components/SlateWrapperTypes.h` 인클루드(ESlateVisibility) |
| `Park3DGameMode.cpp` | 생성자에서 기본 조합키 지정, BeginPlay 에서 바인딩, 토글 구현 |

기존 단축키(M=메뉴, F9=시뮬 시작, F10=리플레이)와 같은 자리에 붙였다.

```cpp
// 생성자
ViewerToggleChord = FInputChord(EKeys::SpaceBar, /*bShift=*/false, /*bCtrl=*/true, /*bAlt=*/false, /*bCmd=*/false);

// BeginPlay
InputComponent->BindKey(ViewerToggleChord, IE_Pressed, this, &APark3DGameMode::ToggleCameraViewer);
```

조합키라 `FKey` 가 아니라 `FInputChord` 를 쓴다(`UInputComponent::BindKey` 에 chord 오버로드가 있다).

---

## 2. 왜 RemoveFromParent 가 아니라 가시성 토글인가

메뉴 토글(`ToggleMenu`)은 `RemoveFromParent` / `AddToViewport` 를 쓴다. 뷰어에 같은 방식을 적용했더니
**로그상 재추가는 되는데 화면에 다시 나타나지 않았다.**

```
[13.08.09] 카메라 뷰어를 숨겼습니다.
[13.08.42] 카메라 뷰어를 뷰포트에 표시했습니다.   ← 로그는 찍히는데 화면에는 없음
```

뷰어는 최초 표시 때 화면비를 재서 크기를 한 번만 확정하는 구조이고
(`[CameraViewer] 기본 크기 확정: 화면비 0.4000 ... 보정 1회, 폭 768.3`),
재추가 시 이 로그가 다시 찍히지 않는다. 그래서 뷰포트에서 빼지 않고 **가시성만 바꾼다.**

```cpp
if (ViewerWidget->GetVisibility() == ESlateVisibility::Collapsed)
    ViewerWidget->SetVisibility(ViewerSavedVisibility);   // 숨기기 전 값 복원
else {
    ViewerSavedVisibility = ViewerWidget->GetVisibility();
    ViewerWidget->SetVisibility(ESlateVisibility::Collapsed);
}
```

가시성을 `Visible` 로 하드코딩하지 않고 **숨기기 직전 값을 저장했다가 복원**한다 —
뷰어는 드래그/클릭을 받으므로 히트테스트 설정을 임의로 바꾸면 조작이 죽는다.

부작용: 숨겨도 PTZ 렌더타깃 갱신 자체는 계속된다(캡처를 멈추는 기능이 아니라 화면에서 가리는 기능).

---

## 3. 알려진 제약 — UMG 입력란에 포커스가 있으면 안 먹는다

검증 중 확인한 사실이다. **이 단축키만의 문제가 아니라 기존 M 단축키도 동일하다.**

| 상황 | Ctrl+Space | M | F9/F10 |
|------|-----------|---|--------|
| 3D 뷰포트에 포커스 | 동작 | 동작 | 동작 |
| 패널 입력란(EditableTextBox)에 포커스 | **안 먹음** | **안 먹음** | 동작 |

문자·스페이스는 포커스를 가진 Slate 텍스트 위젯이 먼저 먹고, 펑션키는 텍스트 위젯이 소비하지 않아 통과한다.
빈 바닥을 한 번 클릭해 포커스를 뷰포트로 옮기면 정상 동작한다.

포커스와 무관하게 항상 받으려면 `FSlateApplication::RegisterInputPreProcessor` 로
전역 입력 프리프로세서를 두어야 한다. 기존 단축키와 동작을 맞추기 위해 이번에는 넣지 않았다.

---

## 4. 검증 (2026-08-11, `-game` 인스턴스)

빌드 `Build.bat Park3DEditor Win64 Development` → Succeeded.

3D 뷰포트에 포커스를 준 뒤 `keybd_event` 로 Ctrl+Space 를 3회:

```
[13.15.58] 카메라 뷰어를 표시했습니다.
[13.16.01] 카메라 뷰어를 숨겼습니다.
[13.16.04] 카메라 뷰어를 표시했습니다.
```

창 캡처(PrintWindow)로 각 상태를 확인했다.
- 숨김: 우하단 프리뷰 패널이 사라지고 메인 메뉴·시뮬 HUD 는 그대로
- 표시: 프리뷰 패널이 **원래 크기·위치 그대로** 복귀(레이아웃이 다시 잡히지 않음)

## 5. 조작 요약

| 단축키 | 동작 |
|--------|------|
| **Ctrl + Space** | 카메라 뷰어 표시/숨김 |
| M | 메인 메뉴 표시/숨김 |
| F9 / F10 | 주차 시뮬레이션 시작 / 리플레이 |

에디터에서 `Park3DGameMode` 의 `ViewerToggleChord` 로 조합키를 바꿀 수 있다.
