# 캡처 슈퍼샘플 — 번호판 한글(무·모) 오판독 수정 (보드 #1638)

## 1. 요약

- **증상(FIX-3, #1625 c2598)**: Oni V1 LPR 이 시뮬 번호판의 `무`를 `우`로, `모`를 `오`로 읽었다. 판이 142 px 로 크게 보여도 마찬가지였다. short_white 윗줄과 지역명도 자주 틀렸다.
- **원인**: 글자 렌더가 아니라 **캡처 방식**이다. `cam.captureJPG/PNG` 는 `SceneCapture2D::CaptureScene()` 로 한 장씩 찍는다. 이때는 TAA/TSR 이력이 없어 가장자리가 계단이 된다. 그 계단이 작은 한글의 ㅁ 안쪽을 메웠다.
- **수정**: 캡처를 출력 크기의 N배로 렌더한 뒤 CPU 에서 N×N 박스로 축소한다.
  - 우선순위: params `supersample` > config `capture_supersample` > 기본 2.
  - 렌더 크기가 3840×2160 을 넘으면 N 을 낮춘다. 렌즈 왜곡 카메라는 1이다.
- **결과(같은 FIX-3 설정 140장, 앞면, 1920/1280)**:
  - LPR 정확 일치 46 → **71**, 번호 부분 51 → **75**.
  - 판 폭 60–75 px 구간 5/20 → 15/20, 50–60 px 구간 4/26 → 12/26.
