# 기본맵 바닥을 서신지구대 도로 아스팔트로

- 날짜: 2026-09-30
- 브랜치: `feat/basic-map-road-asphalt`
- 요청: "기본맵은 바닥을 도로의 아스팔트를 깔아줘. (서신지구대 레벨의 바닥맵)"
- 선행: [20260930_133000_기본맵_주차장선택_추가.md](20260930_133000_기본맵_주차장선택_추가.md)

## 1. 무엇을 바꿨나

`AMapFloorActor` 바닥(160×160 m) 머티리얼을 `/Game/M/MI_Asphalt`(밝은 단색 계열)에서
**`/Game/Road_Creator_Pro/Materials/Asphalt/MI_Asphalt_no_Markings`** 로 바꿨다.
못 찾으면 예전 `MI_Asphalt` 로 물러나고 경고를 남긴다. 원경 지면(`MI_Ground`)은 그대로 — 바닥 경계가 보여야 맵 크기 변경이 화면에 드러난다(08-16 결정).

`AMapFloorActor` 는 `map_floor:true` 인 레벨에서만 스폰되므로 지금은 **기본맵에만** 영향이 있다(서신·객리단은 `map_floor:false`).

## 2. 왜 이 머티리얼인가

- 서신지구대(LV_Park_01) 인벤토리(`Saved/USDExport/Env/_inventory.json`)에서 바닥은 `BP_Road_Creator` 도로 슬래브이고,
  재질은 `MI_Asphalt_Double_Center_Line_Yellow*`(차선 도로)·`MI_Asphalt_MAIN`·`MI_Asphalt_no_Markings` 였다.
  주차장 면 쪽 슬래브(`BP_Road_Creator_C_15`)가 `MI_Asphalt_no_Markings` 를 쓴다 — 차선이 없는 도로 아스팔트라 넓은 바닥에 그대로 깔 수 있다.
  차선 있는 인스턴스는 도로 메시 UV 기준으로 선을 그리므로 160 m 평면 하나에 깔면 선이 엉뚱하게 늘어난다.
- 부모 `MM_Asphalt` 는 월드 위치 기반 텍스처 크기(`Asphalt Texture Size`, cm)라 평면을 키워도 늘어나지 않는다 — 캡처로 확인(균열·자갈이 실제 크기).
- LV_Park_01 이 쿡에 들어 있어 이 머티리얼도 이미 pak 에 있다 → **재쿡 불필요, exe 교체만으로 반영**.
