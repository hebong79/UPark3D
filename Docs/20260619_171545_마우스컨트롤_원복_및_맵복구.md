# 마우스 컨트롤 비정상 수정 + 기존 맵(OpenWorld) 복구

- 작성일시: 2026-06-19 17:15:45
- 작성자: Claude Code (Opus 4.8)
- 대상: `Park3D/Config/DefaultEngine.ini`, `Park3D/Config/DefaultInput.ini`, 에디터 시작 맵

---

## 1. 요청 내용

> UI 위에서 마우스 버튼을 클릭하면 바닥이 클릭되는 현상을 수정하고 난 뒤부터 마우스 컨트롤이 이상하다. 제대로 동작하지 않는다. 수정해줘. 그리고 기존 맵은 원래대로 복구해줘.

---

## 2. 원인 분석

사용자가 말한 "수정한 뒤부터"의 실제 변경은 직전 작업
[20260619_161500_마우스커서_버벅임_수정.md](20260619_161500_마우스커서_버벅임_수정.md) 에서 이뤄졌다.
그 작업이 **버벅임(렉) 해소**를 위해 다음을 바꿨고, 이것이 마우스 컨트롤 위화감과 맵 교체의 원인이다.

| 변경 대상 | 06-19 버벅임 수정에서 바뀐 값 | 부작용 |
|-----------|------------------------------|--------|
| `DefaultViewportMouseCaptureMode` | `NoCapture` | 뷰포트가 마우스를 캡처하지 않아, 게임/UI 혼합 입력(`FInputModeGameAndUI`)과 맞물려 클릭·드래그 동작이 평소와 다르게 느껴짐 |
| `DefaultViewportMouseLockMode` | `DoNotLock` | 커서 락 거동 변경 |
| `bEnableMouseSmoothing` | `False` | 입력 평활화 제거(거동 변화) |
| `GameDefaultMap` / `EditorStartupMap` | `/Game/Maps/PresetEditor` (신규 경량 맵) | 기존 맵(OpenWorld)이 시작 맵에서 빠짐 |

즉, 직전 "버벅임 수정"이 **입력 캡처 방식과 시작 맵**을 동시에 바꾸면서, 사용자 입장에서는 "마우스가 이상해지고 맵이 바뀐" 상태가 되었다.
사용자는 직전 변경 **이전 상태(원래대로)**를 원했다.

---

## 3. 수정 내용 — 직전 06-19 변경 원복

| # | 파일 | 변경 전(06-19 적용본) | 변경 후(원복) |
|---|------|----------------------|---------------|
| 1 | `DefaultEngine.ini` | `GameDefaultMap=/Game/Maps/PresetEditor` | `GameDefaultMap=/Engine/Maps/Templates/OpenWorld` |
| 2 | `DefaultEngine.ini` | `EditorStartupMap=/Game/Maps/PresetEditor` | `EditorStartupMap=/Engine/Maps/Templates/OpenWorld` |
| 3 | `DefaultInput.ini` | `DefaultViewportMouseCaptureMode=NoCapture` | `CapturePermanently_IncludingInitialMouseDown` |
| 4 | `DefaultInput.ini` | `DefaultViewportMouseLockMode=DoNotLock` | `LockOnCapture` |
| 5 | `DefaultInput.ini` | `bEnableMouseSmoothing=False` | `True` |

> C++/GameMode 코드는 변경하지 않았다(직전 작업에서도 코드는 안 건드렸음). 따라서 재빌드 불필요.
> 신규 맵 `/Game/Maps/PresetEditor` 에셋은 삭제하지 않고 남겨 두었다(시작 맵에서만 제외). 필요 없으면 별도 삭제 가능.

## 4. 검증 (에디터 내 Python 실측 — 전 항목 PASS)

| 항목 | 결과 |
|------|------|
| `capture_mode == CAPTURE_PERMANENTLY_INCLUDING_INITIAL_MOUSE_DOWN` | ✓ |
| `lock_mode == LOCK_ON_CAPTURE` | ✓ |
| `enable_mouse_smoothing == True` | ✓ |
| 에디터 현재 맵 = `/Engine/Maps/Templates/OpenWorld` (로드 성공) | ✓ |
| ini 파일 값과 런타임 InputSettings 값 일치 | ✓ |

- 실행 중 에디터의 `InputSettings` 에 원복 값을 직접 반영하고 OpenWorld 맵을 로드해 즉시 적용 확인.
- ini 파일이 영속화를 담당하므로 다음 에디터 재시작 시에도 동일하게 적용됨.

> 참고: PIE에서의 체감(클릭/카메라 거동)은 사용자가 직접 확인하는 것이 가장 정확하다. 설정·맵 복원은 위 실측으로 검증됨.

## 5. 영향도 분석

- **C++/어셈블리/에셋**: 코드 변경 없음 → 재빌드 불필요. ini 2개와 시작 맵 지정만 원복.
- **마우스 컨트롤**: 직전 변경 이전(사용자가 정상으로 인지하던) 입력 캡처 거동으로 복귀.
- **UI 위 클릭 차단**: 기존 구성(Visible 패널 + GameMode의 `FInputModeGameAndUI`)이 그대로 유지되어, "UI 위 클릭이 바닥으로 통과하지 않음"은 이번 원복 후에도 유효함(해당 차단은 입력 캡처 모드가 아니라 위젯 hit-test + 입력 모드로 동작하기 때문).
- **트레이드오프(중요)**: OpenWorld 맵 복귀로 인해, 직전에 해결했던 **"무거운 맵 → 커서 버벅임"** 증상이 다시 나타날 수 있다. 사용자가 "기존 맵 원래대로"를 명시적으로 요청해 이를 우선했다.
  - 버벅임 없이 마우스도 정상화하려면(대안): OpenWorld 대신 경량 맵을 쓰되 입력 캡처는 이번 원복 값(`CapturePermanently` + `LockOnCapture`)을 유지하는 조합을 권장. 필요 시 후속 작업으로 진행 가능.
