### 트럭 판정 — 언리얼만의 사정

`CarData.type` 이 Bongo(5)/Truck(6) **또는** 모델 이름에 `봉고`/`포터`. 이름도 보는 이유: 언리얼은 저장 장면·랜덤 배치·`car.create` 가 type 을 0/Small 로 둔다(객리단 `CarPos_13Num` 의 봉고도 type 0) — type 만 보면 트럭 규칙이 거의 안 걸린다. 옴니는 카탈로그 항목의 type 으로 판정하고 결과 3종(기아_봉고·기아_봉고_탑차·현대_포터)이 같다(옴니 확인).

## RPC

- `plate.kindWeights.get` → `{latestKind, latestRatio, source:"default"|"config"|"rpc", kinds:[{id,name,p}], truck:{kind:"commercial", p:0.5, models:[...]}}`. `p` 는 일반 차 기준(ev 0, 합 1).
- `plate.kindWeights.set {latestRatio?, latestKind?}` → get 과 같은 모양 + `changed`. 런타임만(재기동 = config 값).
- config: `Save/Config/config_pmaker.json` `"plate_kind_weights": {"latestKind": "normal_film", "latestRatio": 0.6}`. 기동 때 **프로세스에 한 번** 적용(레벨을 바꿔도 RPC 로 바꾼 값을 되덮지 않는다), 틀린 값은 경고 후 기본값.
