## 1. 결론부터

요청한 기능은 **이미 구현·설정까지 끝나 있었다.** 전날(08-17 20:36, `409a04d`) 다른 PC 에서
`config_pmaker.json` 의 `hide_actors` 에 `StaticMeshActor_188`(SM_Oak_7) 을 넣어 두었고,
그 커밋은 `main` 에 들어와 있다.

그런데 화면에는 나무가 그대로 있었다. 원인은 코드도 설정도 아니고 **배포본에 복사된 설정 파일이
낡은 것**이었다.

| 파일 | 시각 | `hide_actors` |
|------|------|----------------|
| `Park3D/Save/Config/config_pmaker.json` (저장소) | 커밋 `409a04d` 반영 | 있음 |
| `Package/Windows/Save/Config/config_pmaker.json` (실행본이 읽는 것) | 2026-08-17 18:23 | **없음** |
| `Package/.../Binaries/Win64/Park3D.exe` | 2026-08-18 09:55 | (코드는 최신) |

exe 는 최신인데 `Save/` 만 전날 18:23 자다. 이 프로젝트의 상용 절차인
**"패키지를 복제해 exe 만 갈아끼운다"** 를 쓰면 정확히 이 상태가 된다 — 코드는 갱신되고
`Save/`(JSON 참조 데이터)는 그대로 남는다.

조치는 한 줄이다.

```powershell
Copy-Item Park3D\Save\Config\config_pmaker.json Package\Windows\Save\Config\config_pmaker.json -Force
```

## 2. 다음에 또 밟지 않으려면

**"설정을 넣었는데 안 먹는다" 는 저장소 config 가 아니라 실행본이 읽는 config 를 먼저 본다.**
판정은 두 파일의 `LastWriteTime` 비교 한 번이면 끝난다. 코드 쪽은 이미 증거를 남기게 돼 있다 —
`hide_actors` 가 적용되면 로그에 이 줄이 뜬다.

```
LogTemp: [Env] config hide_actors 적용: 1/1 숨김
```

**이 줄이 아예 없으면 목록이 비었거나(= 낡은 config) 로드 실패다.** `0/1 — 못 찾음: ...` 이면
설정은 읽혔고 이름이 레벨과 안 맞는 것이라, 두 상황이 로그에서 갈린다.

`Save/` 는 `ProjectDir` 밖(`Package/Windows/Save/`)이고 `Package/` 는 `.gitignore` 대상이라
저장소로 전파되지 않는다. exe 만 교체할 때 `Save/` 도 함께 볼 것.

## 3. 대상 액터 특정 방법 (재사용 가능한 절차)

사용자가 준 것은 "화면의 이 나무"(스크린샷의 빨간 원)뿐이라 액터 이름을 역산해야 했다.

1. `view.pick { x, y }` — **픽셀 기준면은 게임 창이 아니라 메인 뷰 렌더타깃(960×540)이다.**
   범위 밖 좌표를 한 번 던지면 에러 메시지가 그 크기를 알려 준다(`x,y 는 … 범위(0~960, 0~540)`).
   스크린샷 좌표는 비율로 환산한다: `RT_x = 이미지_x / 이미지_폭 × 960`.
2. `env.list { near, radius }` — pick 이 준 월드 좌표 주변을 훑는다.
   **`near`·`radius` 단위는 cm 이고 `view.pick` 의 반환은 m 다.** 100 을 곱해야 한다.
3. 후보를 `env.hide` 로 껐다 켜며 캡처 비교로 확정한다.

`view.pick` 은 나뭇잎을 그대로 통과해 뒤쪽 지면을 맞히는 경우가 잦다(폴리곤 트레이스라 잎 카드
사이로 빠진다). **캐노피 한가운데보다 가장자리를 찌르는 편이 잘 맞았고, 결국 확정은 pick 이 아니라
`env.list` 의 바운즈 크기(1004×921×818cm = 지름 10m·높이 8.2m)로 했다.**

## 5. 검증

앱을 껐다 켜서(`Package/Windows/Park3D.exe`) 확인했다 — RPC 로 숨긴 런타임 상태가 아니라
설정에서 시작 시 적용된 것임을 분명히 하기 위해서다.

```
[2026.08.18-01.45.09:548][  0]LogTemp: [Env] config hide_actors 적용: 1/1 숨김
env.list { nameLike:"StaticMeshActor_188" } → SM_Oak_7 / hidden=True
```

재시작 후 같은 시점(`view.set` 으로 원래 카메라 자세 복원)에서 캡처 — 나무 없음, 화단판 있음.

## 6. "영구히" 의 범위

이 방식은 레벨 에셋을 건드리지 않는다. **매 실행 시작 때 숨긴다**는 뜻이고, 되돌리려면
`hide_actors` 에서 한 줄 지우면 된다. 레벨에서 실제로 삭제하려면 에디터 + 재쿡(직전 기록 기준 58분)이
필요하고 `Content/` 는 gitignore 라 다른 PC 로 전파되지도 않는다 — 채택하지 않은 이유는
선행 문서 §5 와 같다.
