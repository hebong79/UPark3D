# 레이 트레이싱 경고 메시지 숨기기 — 답변

- 작성일시: 2026-07-20 23:32:37 (+09:00)
- 작성자: Codex (korean-docs doc-writer)
- 질문: 화면 중간에 표시되는 레이 트레이싱 메모리 경고를 보이지 않게 하는 방법
- 범위: 사용자 첨부 스크린샷의 Unreal Engine 5.8 경고 메시지
- 스크린샷: 사용자 첨부 이미지(별도 파일로 저장되지 않음)

---

## 1. 결론

스크린샷의 빨간색·노란색 문구는 Park3D의 UMG 위젯이 아니라 Unreal Engine의 레이 트레이싱 지오메트리 메모리 진단 오버레이입니다. 콘솔(`~`)에서 다음 명령을 실행하면 화면 경고만 숨길 수 있습니다.

```text
r.RayTracing.ShowOnScreenWarnings 0
```

다시 표시하려면 다음과 같이 설정합니다.

```text
r.RayTracing.ShowOnScreenWarnings 1
```

## 2. 실행 단축키/대체 방법

Park3D의 `Park3D/Config/DefaultInput.ini`에는 `ConsoleKeys=Tilde`가 명시되어 있습니다. 에디터 뷰포트 또는 PIE 실행 중 `Tilde`(`~`, 백틱/물결표 키)를 눌러 콘솔을 열고, 아래 명령을 입력한 뒤 `Enter`를 누릅니다.

```text
r.RayTracing.ShowOnScreenWarnings 0
```

한국어 키보드 레이아웃이나 키 매핑에 따라 `~` 입력이 동작하지 않을 수 있습니다. 이 경우 메뉴에서 `Window > Output Log`를 열고 하단 콘솔 입력 칸에 같은 명령을 입력한 뒤 `Enter`를 누릅니다. `BaseEngine.ini`의 `Ctrl+Shift+Tilde`는 Game HUD 바인딩이므로 이 경고를 숨기는 데 필요하지 않습니다.

## 3. 매번 입력하지 않는 영구 설정

`Park3D/Config/DefaultEngine.ini`에 아래 항목을 추가하면 프로젝트 실행 시에도 경고가 숨겨집니다. 이미 `[SystemSettings]` 섹션이 있으면 그 아래에 한 줄만 추가하고, 없으면 섹션을 새로 만듭니다.

```ini
[SystemSettings]
r.RayTracing.ShowOnScreenWarnings=0
```

영구 설정을 되돌릴 때는 값을 `1`로 바꾸거나 해당 줄을 삭제합니다. 이 답변에서는 설정 파일을 직접 변경하지 않았습니다.

## 4. 경고의 의미와 한계

메시지에 표시된 `1.312 GiB / 400 MiB`(상주 메모리) 및 `1.335 GiB / 400 MiB`(요청 메모리)는 레이 트레이싱 지오메트리 풀이 예산을 초과했다는 뜻입니다. 위 명령은 진단 문구의 표시만 끄며 메모리 사용량·렌더링 비용·초과 상태를 해결하지 않습니다. 레이 트레이싱을 계속 사용할 경우 필요하면 지오메트리 수, 해상도, 관련 메모리 예산을 별도로 조정해야 합니다.

## 5. 엔진 동작 근거

UE 5.8 엔진 소스의 다음 위치에서 화면 경고 출력과 메모리 예산 검사를 확인할 수 있습니다.

- `Engine/Source/Runtime/Engine/Private/Rendering/RayTracingGeometryManager.cpp`
- 대략 145~151행: `r.RayTracing.ShowOnScreenWarnings` 콘솔 변수(경고 표시 여부) 정의
- 대략 1262행 이후: 상주/요청 레이 트레이싱 지오메트리 메모리와 예산을 비교하고 초과 경고를 출력하는 경로

현재 Park3D 저장소에는 위 엔진 소스 트리가 포함되어 있지 않아 이 세션에서 해당 외부 엔진 파일을 직접 열람·재빌드하지는 못했습니다. 경로와 행 번호는 UE 5.8 소스 기준 참고 정보입니다.

## 6. 영향도 및 변경 파일

| 구분 | 결과 |
|---|---|
| C++/Blueprint/UMG | 변경 없음. 해당 문구는 Park3D 위젯이 아님 |
| 프로젝트 설정 | 변경 없음. `DefaultEngine.ini` 적용 방법만 안내 |
| JSON/에셋/빌드 모듈 | 영향 없음 |
| 런타임 동작 | 콘솔 변수 0일 때 레이 트레이싱 경고 오버레이만 비표시 |

## 7. 검증 결과와 제약

- `Park3D/Config/DefaultInput.ini`의 `-ConsoleKeys=Tilde` 및 `+ConsoleKeys=Tilde` 항목을 확인해 기본 콘솔 키 안내를 검증했다.
- `Ctrl+Shift+Tilde`가 Game HUD 바인딩이라는 안내는 엔진 기본 설정 기준이며, 저장소에 `BaseEngine.ini`가 없어 이 세션에서 직접 열람하지 못했다.
- 명령 및 INI 문법은 UE 콘솔 변수 사용 방식에 맞춰 문서화했다.
- 사용자 첨부 스크린샷의 문구와 수치(`1.312/0.400 GiB`, `1.335/0.400 GiB`)를 답변에 반영했다.
- 이 작업은 질문 답변 문서화만 수행했으며 코드·테스트·설정 파일을 수정하거나 PIE/Automation을 실행하지 않았다.
- 따라서 실제 프로젝트에서 명령 입력 후 오버레이가 사라지는 시각 검증은 미실행 상태다.
