# 3D 화면의 카메라 아이콘 제거

- 요청: "카메라 아이콘 제거해줘 (완전 제거)" — 3D 화면 위 카메라 폴대에 떠 있는 파란 카메라 이미지. 웹 UI 의 카메라 아이콘은 대상이 아님(사용자 보충).
- 브랜치: `fix/hide-camera-icons`

## 원인 · 위치

아이콘은 C++ 이 만드는 것이 아니라 **`Content/Actors/Camera/BP_Camera.uasset` 의 `WidgetComponent`(`Widget`, Screen 스페이스, `WBP_CameraIcon`)** 다.
09-01 의 `APark3DGameMode::HideParkingSlotIcons()` 가 주차면(`BP_ParkingSlot`) 아이콘만 끄고 카메라는 명시적으로 대상에서 뺐었다.

## 변경

`Park3D/Source/Park3D/Park3DGameMode.cpp` `HideParkingSlotIcons()` — 클래스 이름 필터에 `BP_Camera` 추가.

```cpp
const FString ClassName = It->GetClass()->GetName();
if (!ClassName.StartsWith(TEXT("BP_ParkingSlot")) && !ClassName.StartsWith(TEXT("BP_Camera")))
    continue;
```

로그 문구 `주차면·카메라 표시 아이콘 N개를 껐습니다.`, 헤더 주석 갱신.

### 블루프린트를 고치지 않고 런타임에 끄는 이유
- `Content/` 는 git 밖이라 BP 수정은 커밋에 남지 않는다(09-01 과 같은 판단).
- 이 세션은 에디터 MCP(unreal) 연결 실패.
- `BP_Camera` 그래프가 `GetWidget → Cast(WBP_CameraIcon) → SetIcon` 을 호출하므로 컴포넌트를 `DestroyComponent` 하면 그래프가 None 을 만진다 → `SetVisibility(false)`. Screen 스페이스 위젯은 가시성이 꺼지면 `RemoveWidgetFromScreen()` 되어 화면에서 완전히 사라진다(09-01 근거와 동일).

## 검증

- 빌드: `Park3DEditor`·`Park3D` Win64 Development 둘 다 Succeeded.
- 실기: 정본(`Package/Windows`, 13510)은 실행 중이라 무간섭. `Package/Work13540` 으로 `robocopy /MIR` 복제 → exe 만 교체(13:40 자) → config 포트 13540/13960/13961~13999 로 분리 → 기동.
  - LV_Park_01 기동 로그: `[Env] 주차면·카메라 표시 아이콘 10개를 껐습니다.` (주차면 6 + BP_Camera 4 — 09-01 기록의 "남은 파란 아이콘 4개"와 일치)
  - `scene.load {"name":"객리단길"}` → LV_Park_03: `11개` (주차면 그룹 3 + 카메라 8)
  - `view.set` 으로 (4,5,45)m · pitch −89 로 주차열을 내려다본 창 캡처: 폴대 5개 위치에 파란 아이콘 없음(사용자 캡처의 빨간 박스 자리).
- 검증 인스턴스는 종료했다. 정본은 exe 를 갈아끼우고 재기동해야 반영된다.
