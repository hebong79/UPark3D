# Offset Pick 토글 — 키보드로 선택 프리셋 이동/회전 + 글씨 색상 표시

- 작성일: 2026-06-22 17:06:57
- 작업 유형: 신규 기능(UI 토글 + 키보드 입력 제어). C++ 재빌드 필요.
- 설계서: `../Park3D/Docs/설계기록/offsetpick_control_architect_design.md`

## 1. 요구사항 (사용자 확정)
- Offset Pick 버튼 = **클릭 토글**(ON/OFF).
- 제어 ON: 키보드(WASD/방향키)로 **선택된 프리셋의 위치/회전** 제어 (Radio_Move=이동 / Radio_Rotate=회전).
- 제어 ON 시 버튼 글씨 **빨강**, OFF 시 **원래 색** 복원.

## 2. 현황
- `HandleOffsetPick()`은 BP 이벤트 `OnOffsetPick()` + 알림만 수행(키보드 제어 미구현).
- `bMoveMode`(Radio로 갱신), `ApplyToFields()`, `RefreshView()` 기존 존재.
- `FParkingPreset.Offset`(FVector, m), `.FaceRotate`(deg).

## 3. 변경 내용 (`PresetMakerWidget.h` / `.cpp`)

### 추가된 멤버
| 멤버 | 용도 |
|------|------|
| `UTextBlock* Txt_OffsetPick` (BindWidgetOptional) | 버튼 글씨(색 변경 대상) |
| `bool bOffsetPickControl` | 키보드 제어 토글 상태 |
| `FLinearColor OffsetPickOriginalColor` | 원래 글씨색(복원용) |

### 동작
- `NativeConstruct`: `Txt_OffsetPick` 원래색 캡처 + `SetIsFocusable(true)`.
- `HandleOffsetPick()`: `SetOffsetPickControl(!bOffsetPickControl)` — 클릭마다 토글.
- `SetOffsetPickControl(bEnable)`:
  - 글씨색 = bEnable ? 빨강 : 원래색
  - ON이면 `SetKeyboardFocus()`(키 수신) + `OnOffsetPick()`(기존 훅 보존) + 알림 ON / OFF면 알림 OFF
- `NativeOnKeyDown()` 오버라이드: 제어 ON + 선택 프리셋 유효일 때
  - 이동 모드: 상/W=+Y, 하/S=-Y, 우/D=+X, 좌/A=-X (0.1 m)
  - 회전 모드: 우/상=+1°, 좌/하=-1°
  - 처리 시 `ApplyToFields`+`RefreshView` 후 키 소비(Handled) → 그 외엔 기존 동작.

### 처리 흐름
버튼 클릭 → 토글 → (ON) 글씨 빨강 + 포커스 획득 → WASD/방향키 → 선택 프리셋 Offset/FaceRotate 변경 → 필드·3D뷰 갱신. 재클릭 → (OFF) 원래색 + 키 입력 무영향.

## 4. 영향도 분석
- **재빌드 필요**: 신규 `UPROPERTY`(BindWidget) 추가 → 리플렉션 변경, Live Coding 불가. (직전 `AParkFlyPawn`과 함께 1회 재빌드)
- **WBP**: 별도 변경 불필요. `Txt_OffsetPick`는 기존 위젯명과 일치 → BindWidgetOptional 자동 바인딩. WBP는 C++ 베이스에서 색을 런타임 변경.
- **카메라(AParkFlyPawn)와 관계**: 제어 ON 중에는 위젯이 WASD를 소비하므로 카메라 이동과 동시 발생하지 않음(의도적 분리). 제어 OFF면 기존대로 키가 폰으로 전달(RMB 게이트).
- **기존 버튼 동작**: Offset Pick의 의미가 'BP 이벤트 1회 호출'에서 '토글 제어'로 변경됨. `OnOffsetPick()` 훅은 ON 시 계속 호출되어 BP 확장 보존.
- **JSON/매니저/기타 위젯**: 무관.

## 5. 검증 상태 (정직 보고 — 미완료)
1. **재빌드 미수행**: C++ 리플렉션 변경 → 에디터 종료 후 전체 재빌드 필요. 현재 미컴파일·미검증.
2. **자동 유닛테스트 부적합**: UI 포커스/입력 의존 → 수동 검증으로 대체.
3. **수동 검증 절차(재빌드 후)**:
   - 버튼 클릭 → 글씨 빨강 + "키보드 제어 ON" 알림. 재클릭 → 원래색 + OFF.
   - ON + 프리셋 선택 + 이동 모드: 방향키/WASD로 Offset 변경(필드·3D뷰 갱신).
   - ON + 회전 모드: 좌/우로 FaceRotate 변경.
   - OFF: 키 입력이 프리셋에 영향 없음.
   - 선택 프리셋 없으면 토글·색만 동작, 이동/회전은 무동작.
   - PIE 크래시 이력 → standalone 검증 권장.

## 6. 잔여/후속 가능
- 이동 스텝(0.1 m)·회전 스텝(1°)은 고정값. "속도: Ctrl=, Ctrl-"(Lbl_Speed) 연동은 미구현 — 요청 시 추가.
- 축 매핑(상=+Y, 우=+X)은 직관 기본값 — 실제 방향이 반대면 피드백으로 조정.
