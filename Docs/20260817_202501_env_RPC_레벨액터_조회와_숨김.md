# env.* RPC — 레벨에 배치된 환경 액터를 찾고 숨긴다

- 작성: 2026-08-17 20:25
- 대상: `Park3D/Source/Park3D/Rpc/Modules/EnvRpcModule.*`(신규), `Rpc/RpcServerSubsystem.*`
- 발단: 카메라 폴대 앞의 나무가 시야를 막고 있어 "이 나무 오브젝트를 제거할 수 있나?"

## 1. 왜 새로 만들었나

기존 RPC 116개는 전부 도메인 한정이었다 — `car.*` `preset.*` `cam.*` `light.*` `map.*` `sim.*`
`scenario.*` `view.*`. **레벨 자체에 배치된 액터(나무·건물·가로등)를 다루는 수단이 하나도 없었다.**
그 나무는 Park3D 가 만든 오브젝트가 아니라 `LV_Park_01` 레벨의 스태틱메시 액터다.

선택지는 둘이었다.

| 방법 | 성격 |
|------|------|
| 에디터에서 삭제 후 재쿡 | 영구적. 되돌리려면 같은 작업 반복, 레벨 에셋이 바뀐다(`Content/` 는 gitignore 라 전파도 안 된다) |
| **런타임 숨김 RPC** ← 채택 | 즉시·가역적. 레벨 에셋 불변. 가림률 실험에서 "가리는 물체를 껐다 켜며 비교"에 그대로 쓰인다 |

가림률(occlusion) 측정이 이 프로젝트의 주 작업이고 그 실험은 반복이다. 그래서 **삭제가 아니라 숨김**이다.

## 2. 메서드

```
env.list  { near:{x,y,z}?, radius?, nameLike?, limit? }
  → { actors:[{ name, label, class, pos, size, hidden, distance }], matched, returned }

env.hide  { name? | names?[], hidden? }
  → { hidden, changed:[...], notFound:[...] }
```

- `near` + `radius`(cm) 로 좁히고, 가까운 순으로 준다. `nameLike` 는 이름·라벨·클래스에 대한 부분 일치.
- `limit` 기본 30 — 레벨에는 액터가 수천 개라 통째로 주면 읽을 수 없다. **잘라 낸 사실을 알 수 있게
  `matched`(조건에 맞은 총계)와 `returned` 를 함께 준다.**
- `env.hide` 의 조작 단위는 `env.list` 가 준 `name` 이다(`label` 이 아니다 — 라벨은 중복될 수 있다).

## 3. 설계에서 정한 것

- **숨길 때 충돌도 함께 끈다.** 안 그러면 보이지 않는 벽이 남아 `view.pick` 과 바닥 트레이스가 그 자리에서
  막힌다("아무것도 없는데 클릭이 안 먹는다"가 된다). 복원 시 함께 켠다.
- **Park3D 소유 액터는 목록에서 제외한다** — 차량·PTZ 카메라·주차면·바닥은 `car.*`/`preset.*`/`cam.*` 가
  담당한다. 두 경로가 같은 대상을 다르게 만지면 상태가 갈라진다.
- **보이는 지오메트리가 있는 액터만** 낸다(등록된 프리미티브 + 바운즈 반지름 > 1cm). 컨트롤러·게임모드 같은
  것이 목록을 채우면 쓸모가 없다. 이미 숨긴 것은 목록에 남긴다 — 다시 켜려면 이름이 보여야 한다.
- **못 찾은 이름은 조용히 넘기지 않는다**(`notFound`). 오타 하나로 "숨겼는데 그대로"가 되기 때문이다.

## 4. 실사용 기록

```
env.list { near:{x:-710,y:-950,z:500}, radius:1500, limit:20 }
  → StaticMeshActor_188  라벨 SM_Oak_7  크기 1004×921×818cm  거리 783cm
     (카메라 폴대 BP_Pole_C_1 "2번 폴대" 로부터 3.3m — 그 카메라 시야를 막고 있던 나무)

env.hide { name:"StaticMeshActor_188", hidden:true }
  → changed 1건, 화면에서 사라지고 뒤의 폴대·주차면이 드러남(캡처로 확인)
```

되돌리기: `env.hide { name:"StaticMeshActor_188", hidden:false }`.

## 5. 한계 — 숨김은 실행 중에만 유지된다

`env.hide` 는 런타임 상태다. **앱을 다시 띄우면 나무는 다시 보인다.** 패키지를 다시 만들어도 마찬가지다
(코드가 아니라 그때그때의 월드 상태이기 때문).

영구적으로 감추려면 둘 중 하나가 필요하다.

1. `config_pmaker.json` 에 `hide_actors: ["StaticMeshActor_188", ...]` 를 두고 시작 시 적용 — 레벨·조명·포트와
   같은 규약(설정 한 파일). 아직 구현하지 않았다.
2. 에디터에서 레벨을 고치고 재쿡 — 영구적이지만 되돌리기 어렵고 `Content/` 는 git 으로 전파되지 않는다.
