# RPC 익명 접속 허용 플래그(AllowAnonymous) + 13510 접속 불가 원인 규명

- 작성: 2026-08-04 18:55
- 배경: 외부 클라이언트가 6시간 넘게 `http://192.168.0.125:13510/stream` 에 접속하지 못함
- 대상: `Rpc/RpcAuth.h/.cpp`, `Rpc/RpcServerSubsystem.h/.cpp`, `Config/DefaultGame.ini`, `Tests/RpcAuthTest.cpp`

---

## 1. 접속 불가의 실제 원인 (진단)

세 가지가 겹쳐 있었다. **가장 큰 원인은 방화벽이었다.**

| # | 원인 | 상태 |
|---|------|------|
| **1** | **13510 인바운드 허용 규칙이 아예 없었다** | 네트워크 프로파일이 **Public** 이고 방화벽 기본 인바운드가 차단이라, 앱이 `0.0.0.0:13510` 에 리슨해도 외부 패킷이 커널에서 버려진다. 앱 로그에는 아무것도 남지 않아 원인 파악이 어렵다 |
| 2 | 토큰 필요 | `DefaultGame.ini` 에 `Token=` 이 설정돼 있어 외부 요청은 `?token=` 없이는 401 |
| 3 | Origin 거부(D11) | 브라우저 `fetch()`/XHR 은 토큰이 맞아도 401. `<img src>` 는 무영향 |

> **교훈**: 앱이 포트를 열었는지(`netstat`)와 그 포트에 외부가 닿는지(방화벽)는 별개다. 리슨 중인데 접속이 안 되면 방화벽부터 본다. 앱 로그가 조용한 것이 오히려 방화벽 차단의 징후다.

---

## 2. 조치 ① 방화벽 규칙

```powershell
New-NetFirewallRule -DisplayName 'Park3D RPC 13510' `
  -Direction Inbound -Protocol TCP -LocalPort 13510 `
  -RemoteAddress 192.168.0.0/24 -Action Allow -Profile Any
```

- 관리자 권한 필요(UAC 승격으로 생성)
- 출발지를 **192.168.0.0/24 로 한정**했다. `-RemoteAddress` 를 빼면 공인망까지 열린다
- `-Profile Any` 라 Public 프로파일에서도 적용된다

## 3. 조치 ② 익명 접속 허용 플래그

`<img src>` 는 헤더를 못 붙이고 브라우저 `fetch` 는 Origin 때문에 막히는 등, 토큰 운반이 클라이언트마다 제각각이라 **인증을 통째로 끄는 스위치**를 넣었다.

### 켜는 법

```ini
; Park3D/Config/DefaultGame.ini
[RpcServer]
AllowAnonymous=True
```

또는 커맨드라인 `-RpcAllowAnonymous`.

### 동작

```cpp
EAuthResult Authorize(..., bool bAllowAnonymous = false)
{
    if (bAllowAnonymous) return EAuthResult::Allowed;   // ⓪ 나머지 판정 전부 건너뜀
    if (bHasOriginHeader) return DeniedBrowserOrigin;   // ①
    ...
}
```

- **토큰·Origin·루프백 검사가 모두 무력화**된다. `Token=` 값이 설정돼 있어도 무시된다
- 기본값은 **false**. 끄는 커맨드라인 스위치는 없다(끄려면 ini 를 `False` 로)
- 켜져 있으면 **매 기동마다 경고 배너**가 로그에 남는다 — 이 상태가 조용히 유지되는 것을 막기 위해서다

```
[RPC] JSON-RPC 서버 시작: http://0.0.0.0:13510/rpc (bind=any, auth=ANONYMOUS(우회), method 79개)
[RPC] ============================================================
[RPC] ⚠ 익명 접속 허용(AllowAnonymous) — 인증이 꺼져 있습니다.
[RPC]   토큰·Origin·루프백 검사를 모두 건너뜁니다.
[RPC]   0.0.0.0:13510 에 닿는 누구나 79개 메서드(저장 포함)를 호출할 수 있습니다.
[RPC]   끄기: DefaultGame.ini [RpcServer] AllowAnonymous=False
[RPC] ============================================================
```

### ⚠ 무엇을 포기했는지

`AllowAnonymous=True` 는 **13510 에 닿는 누구나 79개 RPC 메서드를 인증 없이 호출**할 수 있게 한다. 조회뿐 아니라 `preset.save`·`car.save` 처럼 **디스크에 파일을 쓰는 메서드**도 포함된다. 지금은 방화벽이 `192.168.0.0/24` 로 한정하고 있는 것이 유일한 방어선이다.

되돌리려면 `AllowAnonymous=False` 한 줄이면 되고, 그 뒤에는 `?token=` 또는 `X-Park3D-Token` 헤더가 다시 필요해진다.

## 4. 검증

### 유닛
`Park3D.*` Automation **60/60 통과, 실패 0**(기존 59 + 신규 `Park3D.Rpc.Auth.AllowAnonymous`).

신규 테스트는 양방향을 모두 고정한다.
- 켠 경우: 외부+무토큰 / 외부+틀린토큰 / Origin 있음 / 토큰미설정+외부 / peer 불명 — 전부 `Allowed`
- 끈 경우: `DeniedBadToken`·`DeniedBrowserOrigin`·`DeniedNotLoopback`·`Allowed` 종전 판정 그대로
- **기본 인자가 false 인지**(인자 생략 호출이 종전과 동일한지) 명시 검증 — 기본값이 뒤집히면 서버가 무인증으로 열린다

### 패키징

## 5. 미검증

| 항목 | 사유 |
|------|------|
| **다른 PC 에서의 실접속** | 같은 PC 에서 LAN IP 로 붙은 것은 동일 호스트 트래픽이라 **방화벽을 통과하지 않는다**. 방화벽 규칙이 실제로 유효한지는 클라이언트 PC 에서 확인해야 한다 |
| 브라우저 실제 렌더 | 원시 소켓 요청까지만 확인 |
| 무선 AP 클라이언트 격리 | 확인하지 않음. 방화벽을 열어도 이것 때문에 막힐 수 있다 |

## 6. 영향도
