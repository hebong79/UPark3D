## 1. 작업 개요

- **작업 유형**: 버그 수정. config(.ini) 파일의 회귀(regression) 복원이며, C++ 코드 변경이 없어 재빌드가 필요하지 않다.

## 2. 원인 (핵심)

선행 문서(2026-06-19 16:15, `Docs/20260619_161500_마우스커서_버벅임_수정.md`)에서 "수정 후" 값으로 기록되었던 5개 config 설정이, 실제 config 파일에는 **버그(수정 전) 상태로 되돌아가 있었다**. 즉 이전 fix가 유실(회귀)된 것이 직접 원인이다.

### 2.1 재발 경로

- 에디터가 OpenWorld 맵을 마지막 작업 맵으로 기록하면서(`EditorPerProjectUserSettings.ini`의 `LastLevel=/Engine/Maps/Templates/OpenWorld`) startup map 계열 설정이 되돌아갔고, 그 과정에서 fix가 그룹째 유실된 정황이다.

### 2.2 버벅임이 발생하는 메커니즘

- 무거운 OpenWorld 맵(Landscape 64 + HLOD 64, RayTracing / Substrate / Lumen)이 로드되면서 프레임이 저하된다.
- `CapturePermanently` / `LockOnCapture` 설정으로 소프트웨어 커서가 게임 프레임에 묶이며, 프레임 저하가 곧 커서 버벅임으로 이어진다.
- `bEnableMouseSmoothing=True`가 입력 지연을 가중한다.

## 4. QA 검증 (PASS)

검증은 MCP `execute_python`을 통한 실측으로 수행되었다.

- **디스크 ini 5개 값**: 모두 목표값과 일치 확인.
- **에셋 존재**: `/Game/Maps/PresetEditor` 에셋 존재 = True.
- **런타임 InputSettings**:
  - 최초에는 옛 값이 캐시되어 있었다. InputSettings는 엔진 시작 시 로드되므로, 실행 중인 에디터 세션에는 ini 변경이 즉시 반영되지 않는다.
  - 이에 대응하여 InputSettings CDO에 직접 `NO_CAPTURE` / `DO_NOT_LOCK` / `smoothing=False` 를 set 하여 **현재 세션에 즉시 적용**까지 재확인했다. → PASS.

## 6. 잔여 / 주의 사항

- **현재 에디터에 열린 레벨은 여전히 OpenWorld** 이다. PIE는 "현재 열린 레벨"을 실행하므로, 경량 맵으로 PIE 테스트를 하려면 `/Game/Maps/PresetEditor` 를 직접 열어야 한다.
  - 단, 마우스 캡처 fix(`NoCapture`)는 런타임 전역에 적용되어 하드웨어 커서를 사용하므로, 무거운 맵에서도 **커서 버벅임 자체는 해소**된다.
- **Standalone / 패키지 실행**은 `GameDefaultMap=PresetEditor` 설정에 따라 경량 맵을 자동으로 사용한다.
- **재발 방지 관점**:
  - `GameDefaultMap`은 에디터 자동관리 대상이 아니라 런타임에 영구 유효하다.
  - `EditorStartupMap`은 에디터가 다른 맵을 열면 다시 덮어쓸 수 있는 값이므로 주의한다(이번 회귀의 재발 경로와 직결됨).
