## 1. 주차장 선택 카드 — 구현

대상: `Park3D/Source/Park3D/LevelSelectWidget.cpp`, `.h`(주석 1줄). WBP 없음(C++ 위젯 트리), UPROPERTY 추가 없음.

| 항목 | 이전 | 이후 |
|---|---|---|
| 배경 | 올리브색 사각 판(0.27,0.29,0.23,0.85) | 어두운 카드 `#0E1419` 93%, 모서리 10, 테두리 1px `#25313A` (`FSlateRoundedBoxBrush`) |
| 글자 | 검정 | 흰색 `#E6ECF0`, 라벨은 회색 `#8A9AA6` |
| 제목 | "주차장 선택" 16pt | 강조색 점 + "주차장" 11pt |
| 콤보 | 흰 기본 콤보 | 어두운 입력칸(`#18222A`, 모서리 6, 높이 34), 마우스 올림/누름/잠김 상태별 테두리, 펼침 목록 `#111A20`, 항목 마우스 올림만 강조 |
| 아래 줄 | 늘 "고르면 그 주차장 레벨로 이동합니다." | 평소엔 현재 레벨 이름(`LV_Park_01`), 목록에 없으면 `… · 목록에 없는 레벨` |
| 이동 중 | 문구만 교체 | 강조색 `#35C8B4` "서신지구대로 이동 중…"(로/으로 받침 처리) + **콤보 잠금**(두 번 고르기 방지) |
| 크기 | 250×96 고정(아래가 빔) | 폭 248 고정, 높이 자동 |

- 헬퍼 이름은 모두 `Lv` 접두사 — 익명 네임스페이스도 유니티 빌드에서 다른 .cpp 와 한 TU 로 묶이면 C2084 로 충돌한다(09-07, 09-21 이력).
- `UComboBoxString::InitForegroundColor` 는 protected 라 못 쓴다 → 펼침 화살표 색은 `DownArrowImage.TintColor` 로 직접.
- 한글 폴백 폰트에는 Bold 가 없어 항목 글자는 굵게 지정해도 보통 굵기로 보인다.
- 시안과 다른 점: 핀 아이콘 대신 강조색 점(텍스처 없이), 펼친 목록의 "현재 항목 체크 표시"는 넣지 않았다(닫힌 본문과 목록 항목이 같은 생성 함수를 써서 구분이 안 된다).

### 검증
- `Build.bat Park3D` / `Park3DEditor` Win64 Development 둘 다 Succeeded.
- 작업본 `Package/Work13540`(RPC 13540, exe 만 교체, 정본 13510 무간섭) 기동 → 로그 `[LevelSelect] 주차장 선택 패널 표시: 항목 2개, 현재 /Game/Levels/LV_Park_01`, 창 캡처로 기본 상태 확인(`Docs/shots/20260923_level_select_restyle/`).
- **미검증: 펼침 목록·이동 중 상태 화면.** 콤보 클릭은 한 번 보냈으나 Slate 펼침 메뉴는 별도 창이라 `PrintWindow` 캡처에 안 잡혔고, 그 사이 사용자가 PC 를 쓰고 있어 합성 입력을 중단했다. 레벨 이동도 일어나지 않았다(로그 확인).
- 함정: `SetForegroundWindow` 만으로는 Windows 포커스 잠금에 막힌다 → `AttachThreadInput` 후 호출. 입력 전 전면 창 검사 가드가 실제로 한 번 입력을 막았다.

## 2. 샘플 UI 를 언리얼로 만들 수 있나 — 답

**만들 수 있다.** 샘플의 요소는 모두 UMG/Slate 에 대응이 있다.

| 샘플 요소 | 언리얼 |
|---|---|
| 둥근 카드·테두리 | `FSlateRoundedBoxBrush`(모서리·테두리 두께·색) — 이번 카드에 사용 |
| 접히는 섹션(카메라 선택/위치/방향…) | `UExpandableArea` 또는 버튼 + `SetVisibility(Collapsed)` |
| 세그먼트 토글(메인 뷰/이 카메라) | `UCheckBox` 두 개를 `ToggleButton` 스타일로, 라디오처럼 묶기 |
| 원형 방향 패드 | 원형 브러시 위 버튼 4개 + 가운데 버튼(`UOverlay`), 또는 `NativePaint` |
| 숫자 입력칸 | `UEditableTextBox`/`USpinBox` 스타일 |
| 아이콘 | 텍스처 아이콘(`SetBrushFromTexture`) — 이모지·SVG 는 직접 안 됨 |
| 한글 폰트 | Pretendard/IBM Plex Sans KR TTF 를 폰트 에셋으로 임포트(Runtime 캐시) |

걸림돌(비용):
- CSS 가 없어 호버 전환·그림자·흐림은 손으로 만든다(`UBackgroundBlur` 는 비싸다).
- 기존 패널 4종은 **쿠킹된 WBP + BindWidget C++ 베이스**다. 베이스에 `UPROPERTY` 를 늘리면 패키지가 `Bad export index` 로 죽는다(08-12) → 스타일만 C++ `ApplyToTree` 로 입히는 방식이 안전하고, 배치를 바꾸려면 WBP 를 고치거나 C++ 트리로 새로 짜야 한다.
- 08-17 에 한 번 UI 를 재구성했다가 "가독성이 떨어진다"로 원본 WBP 로 되돌린 적이 있다 → 전면 교체는 시안 승인 후 패널 하나씩.

## 3. 전체 UI 시안

디자인 캔버스: https://claude.ai/artifact/DnXVtWCbXgtZ29eq86FJ8w (비공개)

- **전체 화면(객리단길)** — 배경은 정본 메인 뷰 스트림 프레임, 뷰어는 정본 `cam.captureJPG`(카메라 1) 실캡처. 왼쪽 카메라 패널(기존 기능 전부 유지: 카메라·프리셋·시작 슬롯/갯수/자동·위치 3종 슬라이더·PTZ 패드/값/단위·위치 보기/거리 측정/PTZ 가져오기·저장/열기/초기화/피킹), 오른쪽 위 주차장 카드, 오른쪽 아래 카메라 뷰어(십자 유지), 아래 가운데 아이콘 독.
- **주차장 선택 카드** — 기본/펼침/이동 중 + 지금 모양 비교.
- **부품·색·글자** — 색 7개, 글자 크기, 버튼/입력/슬라이더/체크박스 상태.
- **나머지 패널 5종**(추가) — 차량 배치·주차면 프리셋·차량 랜덤·조명·주차 시뮬레이션. 컨트롤 목록은 각 위젯 헤더의 BindWidget 과 조명/시뮬 C++ 라벨에서 옮겼다. 조명 값은 `Save/3D/Light/LightSettings.json` 실값, 나머지 수치·이름은 `[N]`·`[차종]` 같은 자리표시.
