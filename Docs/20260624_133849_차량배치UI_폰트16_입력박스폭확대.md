## 1. 폰트 16

- **라벨 TextBlock 24개** `Font.Size` → 16 (헤더/필드명/옵션/타이틀/파일명 + 버튼 7개 라벨).
- **콤보박스 2개**(Combo_Prefab, Combo_Type) `Font.Size` → 16.
- **입력박스 7개** 텍스트 폰트: `WidgetStyle.TextStyle.Font.Size` 24 → 16.
  - 주의: EditableTextBox 글꼴은 `Font`가 아니라 **`WidgetStyle.TextStyle.Font`** 에 있음(처음 `WidgetStyle.Font`로 설정 시 무효였음 → 경로 교정).

## 2. 입력박스 폭 확대 (`MinimumDesiredWidth`)

| 필드 | 폭(px) |
|------|-------|
| Field_Idx / Field_PresetId / Field_FaceId / Field_RotY (상세) | 150 |
| Field_Count / Field_Spacing / Field_Rotate (숫자 입력) | 80 |

- 기존 0(콘텐츠 최소폭, 매우 좁음) → 위 값으로 확대. HBox가 해당 최소폭만큼 칸을 부여.
