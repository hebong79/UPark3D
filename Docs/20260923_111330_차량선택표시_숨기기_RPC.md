# 차량 선택 표시 숨기기 RPC — `car.setSelectionMark` / `car.getSelectionMark`

## 1. 요청

SettingManager 「차량 배치」 탭의 「차량 모두 숨기기」 옆(캡처의 빨간 상자)에 **「차량선택 표시 숨기기」 체크박스**를 만들어 달라.

## 2. 판단

- 화면의 선택 표시는 SettingManager 가 칠하는 것이 아니라, 웹이 `car.select` 를 부르면 **언리얼 시뮬레이터가 그리는 반투명 하늘색 오버레이**다(보드 #938, `M_CarSelect`).
- 끄는 기능은 이미 있다 — `ACarPlacementManager::SetSelectionMarkVisible` (Park3D 차량 배치 패널의 "선택 표시" 체크박스가 부르는 함수). 그러나 **RPC 가 없어** 웹이 끌 방법이 없었다.
- 체크박스가 들어갈 웹 저장소(baro/SettingManager, `SettingMain/web`)는 **이 PC 에 없다**. 이 저장소에서 할 몫은 RPC 를 여는 것까지이고, 웹 체크박스는 SettingManager 쪽 작업으로 팀 보드에 요청을 남긴다.

## 3. 변경

`Source/Park3D/Rpc/Modules/CarRpcModule.cpp` — `car.hideAll` 바로 뒤에 두 메서드 추가. 백엔드는 패널 체크박스와 같은 함수(경로를 가르지 않는다).

| 메서드 | 파라미터 | 응답 |
|---|---|---|
| `car.setSelectionMark` | `{visible: bool}` (필수) | `{ok, visible, changedCount}` — changedCount 는 화면이 실제로 바뀐(선택돼 있던) 대수 |
| `car.getSelectionMark` | 없음 | `{visible}` |

동작 규약:
- **선택 상태는 건드리지 않는다.** 끈 채로 `car.select` 해도 표시가 안 나오고, 다시 켜면 선택돼 있던 차에 표시가 돌아온다(`SetSelectedIndices` 가 매번 현재 설정을 밀어 넣기 때문).
- 값은 차량 매니저 멤버라 **레벨 전환(`scene.load`/주차장 콤보)이나 재기동 뒤 기본값(표시)으로 돌아간다**. 저장하지 않는다. 웹은 체크박스 상태를 유지하려면 전환 뒤 다시 보내거나 `car.getSelectionMark` 로 동기화해야 한다.
- Park3D 내부 패널 체크박스는 패널이 열릴 때 매니저 값을 읽으므로 RPC 로 바꾼 값이 다음 열기 때 반영된다.
- `system.describe` 메타(`SetMethodMeta`) 등록. Omniverse 공용 `extensions[]` 목록에는 넣지 않았다(언리얼 쪽만 있는 메서드).

`Source/Park3D/Tests/CarPlateRpcExtTest.cpp` — `Park3D.Rpc.CarModuleExt.SelectionMark` 신설: visible 누락 거부, 초기 true, 끄기 changedCount 1·선택 유지, 재호출 0, 꺼진 채 다른 차 선택 시 표시 없음, 켜기 1.
