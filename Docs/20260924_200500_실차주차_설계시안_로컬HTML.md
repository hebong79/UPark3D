# 실차 주차 기동 설계 시안 — 로컬 실행 HTML 사본

## 요청
claude.ai Artifact(`https://claude.ai/artifact/PgPbnsv7KKTejLRvS43RLV`)를 로컬에서 실행할 수 있도록 HTML 파일로 Docs 폴더에 저장.

## 결과
- 파일: `Docs/20260924_195249_실차주차_기동_설계시안.html` (같은 시안의 설명 문서 `20260924_195249_실차주차_기동_설계시안.md` 와 이름을 맞춤)
- 더블클릭으로 브라우저에서 바로 열린다. 서버 불필요, 외부 스크립트 없음.

## 원본 대비 변경
| 항목 | 내용 | 이유 |
|---|---|---|
| 문서 구조 | `<title>`·스타일을 `<head>` 로 옮기고 `lang="ko"` 추가 | Artifact 는 호스트 래퍼가 head 를 감싸 주지만 로컬 파일은 직접 갖춰야 함 |
| `roundRect` 폴리필 | Canvas `roundRect` 가 없는 구형 브라우저용 대체 구현 | 로컬 브라우저 버전 차이 대비(최신 Chrome/Edge 는 원본 그대로 사용) |
| 캔버스 라벨 폰트 | `"Malgun Gothic"` 폴백 추가 | 오프라인일 때 한글 라벨 글꼴 보장 |

계획 데이터(`PLANS`)·애니메이션·표·본문은 원본 그대로.

## 오프라인 동작
Google Fonts(IBM Plex)만 외부 요청이다. 네트워크가 없으면 맑은 고딕 / Consolas 로 대체되어 동작에는 영향 없음.

## 검증
- 인라인 스크립트 `node --check` 구문 검사 통과.
- 브라우저 화면 확인은 미실시(chrome-devtools 브라우저가 다른 세션에서 사용 중).
