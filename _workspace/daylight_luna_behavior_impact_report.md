# [daylight] 주변 동작 사후점검 보고서

CLAUDE.md 5번 규칙. 변경 지점(레벨 조명)의 **인접 호출·UI/입력·저장/로드·렌더/액터 상태**를 QA·사후 영향도와 독립적으로 교차 점검한다.
점검 환경: `-game` 인스턴스(RPC 13511, 신 조명). 실행 중 패키지(13510)는 **읽기 전용**으로만 접근.

## 1. 인접 호출

| 경계면 | 점검 방법 | 결과 |
|--------|----------|------|
| `preset.create` | `offset`/`faceCount`로 6면 프리셋 생성 | **통과** — idx=1, Preset_001, xSize 2.5 / zSize 5 정상 |
| `preset.list` | 생성 후 목록 조회 | **통과** — 1건 반환 |
| `preset.rebuildAll {useDecal:true}` | 데칼 뷰 리빌드 | **통과** — count=1, useDecal=true, decalThickness=10 |
| `measure.setTargetPoint` → `measure.angles` | 타겟 설정 후 각도 | **통과** — vertical 22.86°, horizontal 0 |
| `measure.distance` | 수평/3D 거리 | **통과** — 11.86 / 12.87 |
| `measure.cameraHeight` | 카메라 높이 | **통과** — 5 (설정값 일치) |
| `map.get` | 맵 크기 | **통과** — 160×160 (변경 없음) |

> `measure.angles`를 타겟 미설정 상태로 먼저 호출했을 때 `-32000 "타겟점 미설정 — measure.setTargetPoint 를 먼저 호출하세요."`가 반환됐다. 이는 **정상적인 선행조건 오류**이며 조명 변경과 무관하다(설정 후 재호출 시 정상).
