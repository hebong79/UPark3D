## 2. 남은 작업 (우선순위 순)

### P1. 토큰 활성화 + 브리지 3곳 배선 — 외부 개방의 전제

**토큰을 켜는 순간 로컬 브리지가 전부 401이 된다.** 실측 확인된 사항이며, 반드시 3곳을 동시에 바꾼다.

| 파일 | 넣을 것 |
|------|---------|
| `Park3D/Config/DefaultGame.ini` | `[RpcServer] Token=<값>` |
| `.mcp.json` | `park3d-rpc` env에 `PARK3D_RPC_TOKEN` |
| `.codex/config.toml` | 같은 값 |

**토큰 값 규칙**
- 허용 문자는 `[A-Za-z0-9_-]` 뿐. 콤마·괄호·공백을 넣으면 경로마다 다르게 잘려 **영구 401**이 되고, 토큰은 로깅 금지라 추적이 거의 불가능하다.
- **커맨드라인 `-RpcToken=`은 쓰지 말 것** — 엔진이 로그에 평문 에코한다(QA B-1 실측). ini 경로를 쓴다.
- 실제 값은 저장소에 커밋하지 않는다.

### P2. 방화벽 인바운드 규칙 (관리자 권한 필요)

```powershell
New-NetFirewallRule -DisplayName "Park3D RPC 13510" -Direction Inbound `
  -Protocol TCP -LocalPort 13510 -RemoteAddress <외부PC_IP> -Action Allow
New-NetFirewallRule -DisplayName "Park3D MCP 13520" -Direction Inbound `
  -Protocol TCP -LocalPort 13520 -RemoteAddress <외부PC_IP> -Action Allow
```

`-RemoteAddress`를 빼면 네트워크 전체에 열린다. **반드시 출발지를 한정한다.**
이 명령들은 `.claude/settings.json`에서 의도적으로 `ask`로 두었으므로 매번 승인 확인이 뜬다.

### P3. 외부 PC 실접속 검증

자기 LAN IP로 자기 접속하는 것은 **대체재가 아니다**(동일 호스트 트래픽이라 방화벽을 통과하지 않는다).
실제 다른 PC에서 아래 순서로 확인한다.

1. `curl http://<Park3D-PC-IP>:13510/health` → 200
2. 토큰 헤더로 `POST /rpc` `system.catalog` → 79개
3. 브리지 13520에 MCP 클라이언트 연결 → `park3d_catalog` 79개

### P4. 패키지 재빌드 — ⚠ 전체 재패키징

현행 배포본은 **인증 코드가 없는 2026-07-29 빌드**다.
**콘텐츠만 재쿠킹하면 "인증 없는 exe + bind=any ini" 조합**이 되어 79개 메서드가 LAN에 무인증 노출된다(사후영향 P-1).

재빌드 후 3단 검증:
1. 산출물 타임스탬프가 최신인지
2. `strings -el`로 `DeniedBadToken` / `x-park3d-token` 문자열이 exe에 있는지
3. 비루프백에서 무토큰 요청 시 401이 나오는지

> 참고: 패키지의 `Save/`는 `ProjectDir()` 밖(스테이지 루트)에 있다. Config는 pak에 쿠킹되므로 평문 ini 수정으로는 안 바뀐다.

## 5. 알아둬야 할 함정 (반복 사고 방지)

1. **헤더 키는 엔진이 소문자로 정규화한다.** 서버는 `x-park3d-token`으로 조회한다. `Request.Headers.Find(TEXT("X-Park3D-Token"))`은 항상 nullptr.
2. **`IsLoopbackAddress()`는 `FInternetAddr`에 없다.** Networking 모듈의 `FIPv4Address`에만 있다. 루프백 판정은 `GetRawIp()` 바이트 비교로 되어 있다.
3. **`Build.cs` 변경은 Live Coding으로 반영되지 않는다.** 전체 빌드 필요.
4. **`-RpcPort=0`은 이제 서버를 끈다.** Automation이 LAN에 포트를 여는 것을 막는 장치다.
5. **바인드 롤백은 `DefaultEngine.ini`의 `+ListenerOverrides` 한 줄 삭제 + 재기동.** `Saved/Config/**`에 잔여 없음을 실측 확인했다.
6. **승인 규칙에 포트 번호를 박지 말 것.** `http://localhost:*`로 끊는다. 과거에 13120이 박혀 있다가 포트 변경으로 3항목이 한꺼번에 죽은 사고가 있다.
