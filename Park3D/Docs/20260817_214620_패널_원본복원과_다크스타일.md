- 날짜: 2026-08-17
- 브랜치: `feat/panel-restore-and-style`
- 경위: UI 를 이전 BP 디자인으로 "재구성"했으나 **"가독성이 너무 떨어진다. 기존 것이 오히려 좋아 보인다"**
  는 판단이 나왔다. 원본 배치로 되돌리되 프레임·배경은 새 것(검은 카드)을 쓰기로 했다.
- 결과: 원본 3종 복원 + 스타일 적용 완료. 카메라 위치를 카메라 단위 속성으로 바꾸는 기능도 추가.

사용자가 "git 에 이전 정보가 있다"고 알려 준 뒤 찾아보니 이전 작업본에 그대로 있었다.

## 3. 스타일은 스크립트로 넣을 수 없는 것이 있다

아이콘 때와 같은 벽을 슬라이더·체크박스에서도 만났다.

| 대상 | `set_properties` 결과 |
|---|---|
| 글자색·폰트·패딩·배경 브러시 | 정상 반영 |
| **아이콘 브러시** | 값은 들어가는데 화면은 빈칸 |
| **슬라이더 스타일** | 값은 들어가는데 트랙·핸들이 안 그려짐 |
| **체크박스 스타일** | 값은 들어가는데 네모가 어두운 채 |

전부 C++ 로 옮겨 해결했다.

- 아이콘 → `UMainMenuWidget::SetButtonIcon`(`LoadObject` + `SetBrushFromTexture`)
- 슬라이더·체크박스 → **`Park3DPanelStyle::ApplyToTree(WidgetTree)`** (신규 헤더)

`Park3DPanelStyle` 은 엔진 기본 스타일에서 출발해 색·크기만 바꾼다. 처음부터 만들면
Hovered/Disabled 같은 상태를 놓친다. 트리를 순회하므로 위젯 이름을 나열하지 않아도 되고,
세 패널이 같은 함수를 불러 모양이 갈라지지 않는다.

요구대로 슬라이더 핸들은 **흰색 원형 1.5배**, 체크박스는 **흰 네모**다.

## 4. 카메라 위치를 카메라 단위 속성으로

**요구:** 높이·X·Z 는 카메라 선택에만 영향받아야 한다. 같은 카메라의 프리셋은 모두 같은 자리.
프리셋이 바꾸는 것은 Pan/Tilt/Zoom 뿐이다.

데이터는 `pos` 를 프리셋(`FCamDir`)마다 들고 있어 프리셋을 넘기면 카메라가 움직였다.
`UCameraControlWidget::SyncCameraPosAcrossPresets` 를 두고 세 지점에서 부른다.

| 시점 | 동작 |
|---|---|
| 위치가 바뀔 때 | `ApplyControlToCamera` 의 Height/X/Z 분기 — 그 카메라의 모든 프리셋에 같은 값 |
| 카메라를 바꿀 때 | 첫 프리셋 기준으로 통일 |
| 파일을 열 때 | 모든 카메라를 각자 첫 프리셋 기준으로 통일(예전 파일 정합) |

한 곳(`ApplyControlToCamera`)에 넣었으므로 슬라이더·입력칸·프리셋 수정 어느 경로로 바뀌어도 어긋나지 않는다.

**미검증:** `cam.applyPreset` RPC 는 위젯을 거치지 않아 이 로직을 확인할 수 없다.
화면에서 프리셋 콤보를 바꿔 보는 검증이 남아 있다.

## 5. 그 밖의 정리

- **VLA 버튼 2종 제거**(BindWidget·핸들러·BP 이벤트까지)
- **"생성" 버튼 제거** — "추가"와 같은 `AddCurrentPreset()` 을 부르던 중복이었다. C++ 과 위젯 양쪽에서 뺐다
- **카메라 패널 뷰어 이미지 제거** — 우하단 뷰어와 같은 그림이 두 번 나왔다
- **차량 랜덤 독 버튼 제거** — `InjectRenderButton()` 호출만 뺐다. 패널·핸들러는 남아 있어
  그 한 줄을 되살리면 다시 뜬다. **지금은 그 패널에 접근할 경로가 없다.**

## 6. 남은 것

- **카메라 패널 스크롤** — 높이를 900 으로 키웠는데도 마지막 줄이 잘린다. 내용이 창 높이(939)보다
  길어 카드를 더 키워도 화면을 넘는다. PTZ 제어 옆 빈 공간에 버튼을 옮기는 재배치가 필요하다.
- **패키지 미반영** — UI 변경은 WBP 와 C++ 양쪽이라 `Package/Windows` 에는 아무것도 들어 있지 않다.
  배포본에 넣으려면 재빌드해야 한다(DDC 가 채워져 있어 약 3분).
- 차량 색상·번호판 콤보는 여전히 없다(현재 C++ 에 대응 항목 없음).
