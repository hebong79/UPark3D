## 2. 백엔드 (기존 재사용, 신규 액터 0)

- 권위: `ACameraControlManager`(`Cameras` 배열 = car/preset 패턴, 이미 존재). AddCamera/RemoveCameraAt/GetCamera/SelectCamera.
- 액터: `APTZCameraActor`(SetCameraWorldLocation/SetPanTilt/SetZoom/GetZoom, `Capture` 공개).
- pan/tilt 추출: `UCameraControlLibrary::RotatorToPanTilt(Capture->GetRelativeRotation())`.
- **매니저/액터 코드 무수정** — RPC 모듈에서 기존 API 호출만(회귀면 최소).
- camId = 배열 index + 1(Unity 1-based 규약).

## 3. 구현 매핑

| method | 결선 | 상태 |
|---|---|---|
| create/delete/select/list/get | 매니저 Add/Remove/Select/Get + CamDto | ✅ |
| setPosition/setHeight | 미터→월드 변환 → SetCameraWorldLocation | ✅ |
| setPTZ/getPTZ | SetPanTilt+SetZoom / RotatorToPanTilt+GetZoom | ✅ |
| setPan/setTilt | 현재 반대축 유지 + SetPanTilt | ✅ |
| setZoom/setFOV | SetZoom / Capture->FOVAngle 직접 | ✅ |
| **captureJPG/capturePNG** | 렌더타깃 캡처+JPG/PNG 인코딩 파이프라인 부재 | ✗ -32000 |
| **savePreset/loadPreset/applyPreset** | per-camera 프리셋 메모리+apply 의미 부재 | ✗ -32000 |

CamDto: `{camId, name("Camera-N"), pos{x,y,z}(Unreal 미터 월드), pan, tilt, zoom}`.

- **빌드**: UBT 정식 빌드 성공(경고 없음, 첫 시도 — Phase 1~2 교훈으로 include·shadowing 사전 회피).
- **자동화(EXIT CODE 0)**: `Park3D.Rpc.*` **7개** 전부 Success — 기존 6 + **CamModule**(create→camId1→list1→setPTZ→getPTZ(zoom≈2)→captureJPG(-32000)→savePreset(-32000)→delete(마지막1대 거부)).
- **HTTP 스모크(실서버)**: catalog **74개**, `cam.create`→{camId:1}, `cam.setPTZ`→ok, `cam.getPTZ`→**{pan:90,tilt:15,zoom:3} 정확 왕복**, `cam.captureJPG`→-32000.
- 상세: `_workspace/rpc_phase3_impact_post.md`, `_workspace/rpc_phase3_luna_behavior_impact_report.md`.

## 5. 사용 예

```powershell
$b = @{ jsonrpc="2.0"; id=1; method="cam.create"; params=@{} } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:13110/rpc" -Method Post -Body $b -ContentType "application/json"
$b = @{ jsonrpc="2.0"; id=2; method="cam.setPTZ"; params=@{ camId=1; pan=90; tilt=15; zoom=3 } } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:13110/rpc" -Method Post -Body $b -ContentType "application/json"
```

## 6. 알려진 제약 / 미구현
- **캡처**(captureJPG/PNG, `/stream`): 렌더타깃 픽셀 읽기 + 이미지 인코딩 파이프라인이 필요(Phase 4 별도).
- **카메라 프리셋**(savePreset/loadPreset/applyPreset): per-camera 프리셋 인메모리 저장소 + 파일 I/O + apply 의미 설계 필요.
- pan/tilt 표현: `Capture` 상대회전 기반([-180,180] 계열). Unity localEuler([0,360))와 표기 차이 가능(의미 동일).
