# JSON 저장을 UTF-8(BOM 없음)로 강제

- 날짜: 2026-08-13
- 대상: `Park3D/Source/Park3D/CameraControlLibrary.cpp`, `CameraViewerWidget.cpp`, `CarPlacementLibrary.cpp`, `PresetMakerWidget.cpp`

## 문제

`FFileHelper::SaveStringToFile(Json, *Path)` 는 인코딩 인자를 생략하면
`EEncodingOptions::AutoDetect` 로 동작한다. AutoDetect 는 문자열에 비-ASCII 문자가
**한 글자라도** 있으면 파일 전체를 **UTF-16LE(BOM 포함)** 로 쓴다.

따라서 아래 경우 JSON 파일이 조용히 UTF-16 이 되었다.

- 프리셋/차량/카메라 이름이나 파일명에 한글이 들어간 경우
- 예: `CamPos_40Face_동대문.json` 같은 경로 문자열이 JSON 값으로 직렬화될 때

UE 자신은 `LoadFileToString` 이 BOM 을 보고 되읽지만, 외부 도구(파이썬 스크립트,
Unity 원본, 텍스트 에디터, git diff, RPC 브리지)에서는 깨져 보이거나 파싱이 실패한다.

`Park3D/Source/Park3D/Config/Park3DAppConfig.cpp` 와 `Map/MapFloorLibrary.cpp`,
`Light/LightControlLibrary.cpp`, `Sim/ParkingSimManager.cpp` 는 이미
`ForceUTF8WithoutBOM` 을 쓰고 있었고, 나머지 4곳만 빠져 있던 상태였다.

## 변경 내용

4개 저장 함수의 `SaveStringToFile` 호출에 인코딩 인자를 명시했다.
동작·형식·경로는 그대로이고 바뀐 것은 파일 인코딩뿐이다.

| 파일 | 함수 | 저장 대상 |
|------|------|-----------|
| `CameraControlLibrary.cpp:227` | `UCameraControlLibrary::SaveToJson` | 카메라 위치 목록(CamPos_*.json) |
| `CameraViewerWidget.cpp:324` | `UCameraViewerWidget::SaveSizeConfigToPath` | 뷰어 표시 크기(ViewerSize.json) |
| `CarPlacementLibrary.cpp:280` | `UCarPlacementLibrary::SaveCarDatasToJson` | 차량 배치(CarPos_*.json) |
| `PresetMakerWidget.cpp:967` | `UPresetMakerWidget::SavePresetsToJson` | 주차 프리셋(Unity 스키마) |

```cpp
// 인코딩을 명시하지 않으면 AutoDetect 가 비-ASCII 한 글자에도 UTF-16 으로 쓴다.
if (!FFileHelper::SaveStringToFile(Json, *Path, FFileHelper::EEncodingOptions::ForceUTF8WithoutBOM))
```

BOM 을 붙이지 않는 쪽(`ForceUTF8WithoutBOM`)을 고른 이유는 프로젝트의 기존
4개 저장 경로가 모두 그 형태이기 때문이다. 파일 간 인코딩이 갈리지 않게 통일했다.

## 호환성

- **기존 UTF-16 파일은 계속 읽힌다.** `FFileHelper::LoadFileToString` 이 BOM 으로
  판별하므로 이번 변경은 읽기 경로에 영향을 주지 않는다.
- 기존 파일을 한 번 저장하면 그때부터 UTF-8 로 바뀐다.
- 테스트 코드(`Source/Park3D/Tests/*`)의 픽스처 기록은 건드리지 않았다.
  로드 동작을 검증하는 임시 파일이라 저장 규약과 무관하다.

### 실제 파일 바이트 확인 (2026-08-13 19:17 추가)

패키지 exe 를 수정본으로 교체·재기동한 뒤 `car.save` 로 실제 저장해 바이트를 비교했다.
데이터의 `prefabName` 에 한글(`BMW_1시리즈`, `기아_카니발`)이 들어 있는 상태다.

| | 첫 4바이트 | 판정 |
|---|---|---|
| 수정 전(구 exe) | `FF FE 7B 00` | **UTF-16LE + BOM** |
| 수정 후(신 exe) | `7B 0D 0A 09` (`{\r\n\t`) | **UTF-8, BOM 없음** |

수정 후 파일을 UTF-8 로 디코드해 `"prefabName": "기아_카니발"` 이 그대로 읽히는 것도 확인했다.
