# 자전거 바퀴살 모형 city·sport 추가 (보드 #1794)

- 날짜: 2026-11-03
- 브랜치: `feat/agent-bicycle` (main `e860f1e` 기준)
- 요청: baro-settingmgr-27 → 마스터 원문 「시뮬 담당(w-sim-unreal)에게 바퀴살 있는 자전거 모형을 요청해줘. ( .10시뮬레이터 이용)」
- 빌드 승인: PM pm-e4 (빌드 2종 + Automation + 작업본 13540 캡처). 머지·push·정본 반영은 별도 명령.

## 1. 왜

`agent.create {kind:"bicycle"}` 의 모형은 `simple` 하나였다. 바퀴는 검은 원판, 프레임은 막대 몇 개뿐이었다.
그래서 SettingManager 쪽 YOLO 가 자전거로 잡지 못했다. 요청 조건은 다음과 같다.

- Camera-1 1280×720 캡처의 12~25 m 거리에서 바퀴살이 보일 것
- 타이어·림·바퀴살·허브가 있고, 프레임·포크·핸들·안장·크랭크·페달·체인링이 실물에 가까울 것
- 실물 크기일 것: 바퀴 지름 0.66~0.70 m, 길이 약 1.7 m
- `simple` 은 남길 것
- `agent.list` 에 모델이 나올 것
- 탑승자가 제대로 앉을 것
- `agent.move` 가 그대로 동작할 것
- 기존 params·필드는 바꾸지 않을 것

## 2. 바뀐 것

### 2.1 모델 `city`·`sport` (ParkAgentActor.cpp)

- 엔진 기본 도형(`/Engine/BasicShapes/Cube`·`Cylinder`)만 쓴다. 재쿡은 필요 없다.
  - 정본 패키지에 이미 쿡돼 있다. 작업본 패키지에서 exe 만 바꿔 모형이 보이는 것을 확인했다.
- 부품은 수백 개(바퀴 하나에 타이어 40 + 림 40 + 바퀴살 18)다. 그래서 같은 도형·색끼리 `UInstancedStaticMeshComponent` 하나로 묶는다(`AddShapeSet`).
  - 컴포넌트는 자전거 하나에 5개다: 프레임색·고무·금속·짙은 회색 상자, 허브 원통.
- 치수(cm, 액터 +X = 앞, 원점 = 바닥 가운데)

  | 부품 | 값 |
  |---|---|
  | 바퀴 | 바깥 반지름 34(지름 0.68 m), 축간 106, 앞뒤 끝 사이 약 1.74 m |
  | 타이어 | 30.8~34.0, 폭 3.6, 검정 |
  | 림 | 28.6~30.6, 은색 |
  | 바퀴살 | 18개, 굵기 0.9, 허브 플랜지 ±2 cm 에서 림 가운데로(앞에서 보면 V 자) |
  | 허브 | 원통 지름 6 × 11 |
  | 프레임 | 뒤 삼각형(체인·시트 스테이 양쪽 두 줄), 시트 튜브, 헤드 튜브, 포크 두 줄 |
  | sport | 다이아몬드(탑 튜브 + 다운 튜브), 평 핸들 56 cm + 그립 |
  | city | 스텝스루(굽은 다운 튜브 + 낮은 보강), 뒤로 휜 핸들, 흙받이, 뒤 짐받이, 앞 바구니(철망 테두리 + 세로·바닥 살) |
  | 구동계 | 체인링(반지름 10, 5 갈래), 뒤 스프라킷, 체인 위·아래, 크랭크 17 cm 두 개, 페달 |
  | 안장 | 윗면 z 88.5 (`SeatCm = (-14, 0, 88.5)` 로 simple 과 같다) |

- **바퀴살 굵기를 실물(2 mm)보다 굵게 0.9 cm 로 둔 이유**
  - Camera-1(zoom 1.724)은 25 m 에서 1 px 가 약 1.2 cm 다.
  - 실물 굵기로는 픽셀 아래로 사라져 바퀴가 빈 원으로 보인다.
- 프레임 색은 id 해시로 고른다.
  - sport: 빨강·파랑·검정·흰색
  - city: 아이보리·검정·하늘·분홍

### 2.2 모델 선택 (SetupBicycle)

- `model` 이 `city|sport|simple` 이면(대소문자 무시) 그 모델을 쓴다.
- 생략하면 id 해시로 city·sport 중 하나를 고른다. simple 은 이름을 줄 때만 나온다.
  - **바뀐 동작**: 이제까지 생략은 항상 simple 이었다. 이제 생략하면 바퀴살 모형이 나온다. 요청 취지(YOLO 대상)에 맞춘 것이다.
- 자전거 에셋 경로(`GApBicycleAsset`)를 넣으면 그 에셋이 우선이다. 지금은 비어 있다.

### 2.3 `agent.create` 응답 `modelFallback` (추가만)

이전에는 없는 모델 이름을 주면 조용히 다른 모델로 바뀌었다. 이제는 응답에 그 사실을 싣는다. 요청 이름이 맞으면 필드 자체가 없다.

```json
"modelFallback": [
  {"param":"model","requested":"bmx","available":["city","sport","simple"]},
  {"param":"riderModel","requested":"zzz","available":["manny","quinn"]}
]
```

### 2.4 탑승 자세 (ApplyRidePose) — 오토바이 탑승자에도 적용

이전 자세(상체 −12°, 위팔 55°, 아래팔 75°)는 팔을 수평으로 뻗었다. 그래서 손이 자전거 핸들보다 약 40 cm 위에 떴다(simple 도 같았다).

- 새 값: 상체 −25°, 위팔 35°, 아래팔 50°
- 4K 캡처에서 손은 핸들 위 약 14 cm 까지 내려왔다. 남은 차이는 어깨 높이 때문이다. 팔 각도로는 2~3 cm 밖에 더 안 줄어 여기서 멈췄다.
- 오토바이(스쿠터) 탑승자는 손이 핸들 높이 근처에 온다. 전후 캡처: `Docs/shots/20261103_bicycle_spokes/detail_4k_*`

### 2.5 도움말

`RpcHelpTable.cpp` 의 `agent.create` 항목을 고쳤다.

- model 설명에 `bicycle: city|sport|simple` 를 넣었다.
- 응답 설명에 `modelFallback?` 를 넣었다.
- note 의 자전거 문장을 새 모형 설명으로 바꿨다.
