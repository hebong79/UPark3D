# Park3D 배포용(패키징) 빌드 방법

- 작성일: 2026-07-01
- 대상: Park3D (Unreal Engine 5.8, C++ 프로젝트, Win64)
- 게임 타겟: `Park3D.Target.cs` (Runtime)

## 1. 배포용 구성 개념

| 구성 | 용도 | 특징 |
|------|------|------|
| **Shipping** | 실제 배포 | 로그·디버그 콘솔·개발용 코드 제거, 최적화 최대 |
| Development | 내부 테스트 | 로그/콘솔 유지, 디버깅 편의 |
| Debug | 디버깅 | 최적화 최소, 심볼 최대 |

배포용은 반드시 **Shipping** 을 사용한다.

## 2. 방법 1 — 에디터 GUI

1. 상단 **Platforms(플랫폼) ▸ Windows ▸ Binary Configuration ▸ Shipping** 선택
2. **Platforms ▸ Windows ▸ Package Project** 클릭
3. 출력 폴더 지정 → 쿠킹/빌드/패키징 자동 진행
4. 결과물: `<선택폴더>\Windows\Park3D.exe`

## 3. 방법 2 — RunUAT 커맨드라인 (자동화·재현용, 권장)

PowerShell:

```powershell
& "C:\Program Files\Epic Games\UE_5.8\Engine\Build\BatchFiles\RunUAT.bat" `
  BuildCookRun `
  -project="d:\Work\Unreal\Project\Parking\Park3D 5.8\Park3D.uproject" `
  -noP4 -platform=Win64 -clientconfig=Shipping `
  -cook -build -stage -pak -archive `
  -archivedirectory="d:\Work\Unreal\Project\Parking\Build"
```

| 옵션 | 의미 |
|------|------|
| `-clientconfig=Shipping` | 배포용 구성 (테스트면 Development) |
| `-cook` | 콘텐츠 쿠킹 |
| `-build` | 코드 컴파일 |
| `-stage` / `-archive` | 산출물 정리/복사 |
| `-pak` | pak 패키징 |

결과물: `d:\Work\Unreal\Project\Parking\Build\Windows\`

## 4. Park3D 프로젝트 주의사항

1. **ModelContextProtocol(MCP) 플러그인**
   - 기존: 모든 타겟에 활성 → Shipping 패키징에서 컴파일/쿠킹 에러 위험
   - 조치(2026-07-01 적용): `Park3D.uproject`의 해당 플러그인에 `"TargetAllowList": ["Editor"]` 추가
   - 효과: 에디터에서는 MCP 자동화 유지, Shipping 빌드에서는 자동 제외
   - `ModelingToolsEditorMode`는 이미 Editor 전용으로 제한되어 있어 문제없음
2. **경로 공백**: 엔진 경로 및 `Park3D 5.8` 폴더명에 공백이 있으므로 CLI에서 반드시 `"..."` 로 감쌀 것
3. **첫 패키징 시간**: 셰이더 컴파일로 오래 걸림(정상)

## 5. 영향도

- 변경 파일: `Park3D.uproject` (플러그인 로드 범위만 조정)
- 코드/에셋 로직 변경 없음 → 에디터 동작에 영향 없음
- Shipping/배포 타겟에서 MCP 관련 심볼이 제외되어 패키징 안정성 향상
