## 2. 구현 내용 (Unity → Unreal 매핑)

### 2.1 데이터 모델 정합 (`SDPresetInfo` → `FParkingPreset`)
- `dirType(int)` → `EFaceDirType`(Default/Dir) — 기존 잘못된 5방향 콤보를 2개로 교체.
- 기본값을 Unity 기준으로: `xSize=2.5`(폭), `zSize=5.0`(길이), `camIdx=1`.
- 필드: idx/name/faceCount/offset/faceRot/groupRot/xSize/zSize/dirType/useBaseWidth/camIdx/use3D.

### 2.2 기하 계산 (`CParkingGeometry` → `UParkingGeometryLibrary`)
- `GetSingleParkingDimensions(angle,w,L)` : bounding box `bw=|w·cos|+|L·sin|`, `bh=|w·sin|+|L·cos|`.
- `GetMultiParkingDimensions(N,angle,w,L)` : `stepW=w/cos`, `totWidth=bw+(N-1)·stepW`, `oneH=bh`.
- `CalculateRotatedWidth(w,h,angle)=w/cos(angle)` (사선 폭 보정).

### 2.3 주차면 번호 할당 (`CalculateParkingSpaceAssignments`)
- 우선순위 **camIdx ↑ → presetIdx ↑ → 내부 1..faceCount**, 전역 1부터 연속.
- 리스트 항목에 `[시작~끝]` 표시 + `RecalcParkingNumbers()`(생성 버튼 시 호출) 콘솔 로그.

### 2.4 폼 동작 (`CPresetMakerDlg`)
- **실시간 폭 표시**(`UpdateFaceWidthDisplay`): Add/Edit/Select 시 좌측 하단 라벨 갱신
  - `Lbl_LaneWidth`="주차면 폭(step): N.NNm", `Lbl_PresetWidth`="프리셋 폭: N.NNm", `Lbl_Speed`="각도 N° · 세로 N.NNm".
  - `useBaseWidth=false`면 폭/길이 축 교환, `Dir`타입은 각도 0으로 계산.
- **추가**: 빈 인덱스 탐색 + 이름 자동 `Preset {idx}`.
- **수정**: 인덱스 변경 시 중복 검사.
- 폼 표시 3자리 소수(F3).
