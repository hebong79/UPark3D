## 2. 바꾼 것

스플라인 고리를 격자 칸에 옮긴다. 레벨별 예외는 없다.

|---|---|
| 닫힌 고리 + 안에 주차면 있음 | 바깥벽. 모든 바깥벽 밖을 막는다 |
| 닫힌 고리 + 안에 면 없음 | 고리 안을 막는다(건물·기둥) |
| 열린 스플라인 | 선이 지나는 칸을 막는다 |

- 면이 하나라도 바깥벽 밖에 있으면 바깥벽 막기만 생략하고 `agent.grid` `note` 로 알린다.

- `agent.grid` 응답에 `splineWallCells` 를 추가했다. `buildingCells` 뜻은 그대로다.
