# Ctrl+좌클릭으로 선택 프리셋을 클릭 지점으로 이동

- 작성일: 2026-06-23 14:37:08
- 작업 유형: 신규 기능(월드 클릭 → 위치 지정). C++ 재빌드 필요.
- 대상: `Park3D/Source/Park3D/PresetMakerWidget.cpp` `NativeTick()`
- 설계서: `.claude/skills/parking-dev-orchestrator/_workspace/clickmove_architect_design.md`

## 1. 요구사항
offsetPick 제어 ON 상태에서 **Ctrl + 마우스 좌클릭** → 선택된 프리셋(주차면 그룹)의 Offset을 **클릭한 월드 지점**으로 이동.

## 2. 분석
- 클릭 지점은 UI가 아니라 **월드 바닥** → 위젯 마우스 핸들러(마우스가 위젯 위일 때만 발생)로는 수신 불가.
- 게임 입력은 PlayerController가 수신 → 위젯이 PC로 입력 폴링 + 커서 트레이스.
- 프리셋 상태는 위젯이 보유 → 위젯 내부 처리(폰 결합 없음).

## 3. 구현 (NativeTick, offsetPick ON일 때)
```cpp
const bool bCtrl = PC->IsInputKeyDown(LeftControl) || PC->IsInputKeyDown(RightControl);
if (bCtrl && PC->WasInputKeyJustPressed(LeftMouseButton) && Presets.IsValidIndex(SelectedIndex))
{
    FHitResult Hit;
    if (PC->GetHitResultUnderCursor(ECC_Visibility, false, Hit) && Hit.bBlockingHit)
    {
        float U = (Mgr->MetersToUU != 0) ? Mgr->MetersToUU : 100;  // 기본 100
        P.Offset.X = Hit.Location.X / U;   // 월드(UU) → m 역변환
        P.Offset.Y = Hit.Location.Y / U;   // 높이(Z)는 유지
        ApplyToFields(P); UpdateFaceWidthDisplay(P); RefreshView(); Notify(...);
    }
}
```
- Offset 단위 m(렌더는 Offset×MetersToUU) → 역변환으로 m 저장(좌표/단위 규약 일치).
- bMoveMode와 무관(명시적 위치 지정). 포커스와 무관(카메라 사용 후에도 동작).

## 4. 영향도
- `PresetMakerWidget::NativeTick` 본문만 추가. 헤더·신규 UPROPERTY·매니저 변경 없음.
- 기존 동작 무영향: 패널 드래그(LMB, Ctrl 없음)·카메라(RMB)·키보드 이동/회전과 충돌 없음.
- JSON/저장 데이터 스키마 불변(Offset 값만 갱신, 기존 필드).

## 5. 검증 상태 (정직 보고 — 미완료)
1. **재빌드 미수행**: 본 변경은 함수 본문만이나, 선행 단계(AParkFlyPawn 등 신규 UCLASS/UPROPERTY) 미빌드가 남아 함께 전체 재빌드 필요. 현재 미컴파일.
2. **수동 검증(재빌드 후)**:
   - offsetPick ON + 프리셋 선택 + 바닥에 Ctrl+좌클릭 → 그룹이 클릭 지점으로 이동(필드 X/Y·3D뷰 갱신).
   - offsetPick OFF 또는 프리셋 미선택 → 무동작.
   - Ctrl 없이 좌클릭 → 이동 안 함(기존 패널 드래그 등 유지).
   - PIE 크래시 이력 → standalone 권장.

## 6. 가정/한계
- 바닥이 **ECC_Visibility 채널을 막는다**고 가정(일반 StaticMesh/Plane). 안 막으면 트레이스 실패 → 이동 안 함. 필요 시 Deproject+평면(Z) 교차 폴백으로 보강 가능.
- Ctrl+좌클릭을 UI 패널 위에서 하면 커서 트레이스가 패널 뒤 월드를 맞힐 수 있음(권장 사용은 바닥 클릭). 필요 시 UI 위 클릭 차단 보강 가능.
- 높이(Offset.Z)는 변경하지 않음(수평 위치만 지정).
