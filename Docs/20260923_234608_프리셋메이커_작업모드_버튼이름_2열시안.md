# 프리셋 메이커 — "Offset Pick" → "작업모드 시작/종료" + 2열 배치 시안

## 요청
1. UI 시안의 주차면 프리셋 패널(목록·버튼·입력 폼 부분)을 기존과 비슷한 배치로 다시.
2. "오프셋 피킹"은 차량 패널 "배치 시작"과 같은 역할 → 이름을 "작업모드 시작"으로, 누르면 "작업모드 종료".

## 2. 버튼 이름 — 구현

대상: `Park3D/Source/Park3D/PresetMakerWidget.cpp` (WBP·헤더 무수정, UPROPERTY 추가 없음)

- `NativeConstruct`: 기존 `BindWidgetOptional Txt_OffsetPick`(버튼 안 글자)의 원래 색을 저장한 직후 글자를 `작업모드 시작` 으로 덮는다. WBP 에 그 글자가 없으면 경고 로그 1줄.
- `SetOffsetPickControl(bEnable)`: 기존 색 토글(켜짐=빨강)에 글자 토글 추가 — 켜짐 `작업모드 종료`, 꺼짐 `작업모드 시작`.
- 알림 문구도 `키보드 제어 ON/OFF` → `작업모드 시작 (이동: WASD/방향키 …)` / `작업모드 종료`.
- 동작(키보드로 선택 프리셋 이동·회전, `OnOffsetPick` BP 훅)은 그대로. RPC·저장 형식 무관.

### 검증
- `Build.bat Park3D` / `Park3DEditor` Win64 Development 둘 다 Succeeded.
- **실기 화면 미확인.** 프리셋 패널은 독 버튼을 눌러야 열리는데, 사용자가 이 PC 를 쓰는 중이라 합성 클릭을 하지 않았다. 확인할 것: 패널을 열면 버튼이 `작업모드 시작`, 누르면 빨간 `작업모드 종료`, 다시 누르면 복귀. 글자가 그대로 "Offset Pick" 이면 로그에 `[PresetMaker] Txt_OffsetPick 이 WBP 에 없어` 경고가 있어야 한다(그 경우 WBP 버튼 글자 이름 확인 필요).

## 1. 2열 배치 시안

캔버스 https://claude.ai/artifact/DnXVtWCbXgtZ29eq86FJ8w 의 "주차면 프리셋 — 2열 배치 (수정안)".

원래 WBP 구조(`Docs/20260618_001321_*` 3절)를 그대로 따랐다.
- 왼쪽(`LeftPanel_VBox`): 프리셋 리스트 → 추가/수정/삭제/리셋 → 선택바 숨기기 → 프리셋 이동(이동/회전) → 속도·주차면 폭·프리셋 폭 안내.
- 오른쪽(`RightForm_VBox`, 라벨-입력 한 줄씩): 프리셋 번호 · 면 수 · 오프셋(x,y,z) · 그룹 면 회전 · 면 회전 · 박스 크기(x,z) · 방향(Default…) · 폭 기준 · 카메라 + 3D 사용 · 이름. 기본값은 원 문서 값(1, 7, 0, 5/2.5, Preset 1).
- 아래: 선 두께·데칼·주차면 번호, 하단 줄 `작업모드 시작` + 저장/열기/초기화.
- 패널 폭은 2열이라 328 → 500.
- 5종 아트보드의 같은 버튼 글자도 `작업모드 시작` 으로 맞췄다.
