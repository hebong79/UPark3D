# PresetMaker UI 글자 크기 17 변경

- 작성일: 2026-06-22 15:37:32
- 대상: `WBP_PresetMaker` (UMG 위젯 에셋) + `PresetMakerWidget.cpp` (리스트 항목 동적 라벨)
- 작업 유형: UI 스타일 상수 변경 (폰트 크기 16 → 17, 구조 변경 없음)
- 처리 방식: parking-dev-orchestrator (사소 변경 → 설계 게이트 생략, 검증·문서화·영향분석 규칙 준수)

## 1. 요구사항

PresetMaker UI의 글자 크기를 **17**로 통일한다. 기존 UI 전체가 폰트 **16**으로 통일돼 있었다(C++ 주석으로 확인).

## 2. 변경 내용

### 2-1. WBP_PresetMaker.uasset — 텍스트 보유 위젯 41개 폰트 16 → 17

| 위젯 종류 | 개수 | 변경 속성 경로 | 비고 |
|-----------|------|----------------|------|
| TextBlock | 29 | `Font.Size` | Title_Text(Bold) 포함, 서체·색상 보존 |
| EditableTextBox | 11 | `WidgetStyle.TextStyle.Font.Size` | 입력 필드, Regular 서체 보존 |
| ComboBoxString | 1 | `Font.Size` | Combo_DirType |

**TextBlock(29):** Title_Text, Lbl_PresetListTitle, Txt_Add/Edit/Delete/Reset, Lbl_HideBar, Lbl_MoveTitle, Lbl_Move, Lbl_Rotate, Lbl_Speed, Lbl_LaneWidth, Lbl_PresetWidth, Lbl_PresetIdx, Lbl_FaceCount, Lbl_Offset, Lbl_GroupFaceRotate, Lbl_FaceRotate, Lbl_BoxSize, Lbl_DirType, Lbl_IsBaseWidth, Lbl_CameraIdx, Lbl_Use3D, Lbl_PresetName, Txt_Save/Open/Init/Create/OffsetPick

**EditableTextBox(11):** Field_PresetIdx, Field_FaceCount, Field_OffsetX/Y/Z, Field_GroupFaceRotate, Field_FaceRotate, Field_BoxSizeX, Field_BoxSizeZ, Field_CameraIdx, Field_PresetName

**ComboBoxString(1):** Combo_DirType

> 부분 속성 지정(`{"Font":{"Size":17}}`)으로 폰트의 다른 필드(FontObject=Roboto, TypefaceFontName, 색상 등)는 **딥 머지로 보존**됨을 검증.

### 2-2. PresetMakerWidget.cpp — 리스트 항목 동적 라벨

`RefreshPresetList()`에서 런타임에 생성되는 주차면 리스트 항목 라벨의 폰트 크기.

// 변경 전 (PresetMakerWidget.cpp:203-205)

// 변경 후
// 리스트 항목 폰트 크기를 UI 전체와 동일하게 17으로 맞춘다.

## 4. 영향도 분석

- **에셋:** `WBP_PresetMaker` 단일 에셋 변경. 위젯 트리 구조·바인딩(BindWidget) 변경 없음 → `PresetMakerWidget.h`의 `meta=(BindWidget)` 멤버와의 연동 영향 없음.
- **C++ 모듈:** `PresetMakerWidget.cpp` 1줄(상수) + 주석 변경. 시그니처·로직 흐름 불변 → 다른 매니저/타입(ParkingPresetManager, ParkingPresetTypes)에 영향 없음.
- **레이아웃:** 폰트 1pt 증가로 텍스트 높이가 미세 증가. 행 높이가 자동(Auto) 슬롯이면 정상 흡수되나, 고정 크기 슬롯이 있으면 클리핑 가능성 있음 → 아래 "남은 확인" 참조.
- **기능:** 폰트 크기만 변경, 입력/저장/3D 생성 로직과 무관.

## 5. 남은 확인 사항 (미완료 — 정직 보고)

1. **C++ 재빌드 필요:** `PresetMakerWidget.cpp` 변경은 소스 수정 단계까지만 완료. 런타임에 리스트 항목 라벨이 17로 보이려면 **Live Coding 또는 빌드**가 필요(현재 미빌드).
2. **실제 렌더 확인 미수행:** 에디터 PIE 시작은 크래시 이력([[mcp-pie-start-crash]])으로 자동 검증에서 제외. WBP 디자이너/Standalone에서 육안 확인 권장.
3. **레이아웃 클리핑:** 17pt 적용 후 버튼/행에서 글자 잘림이 없는지 디자이너 미리보기에서 확인 권장.
