## 2. 2차 — JSON 저장/열기 (`CSavePresetData`)

- `FParkingPresetDatas`(= `{ datas: [...] }`)를 `FJsonObjectConverter`로 직렬화/역직렬화.
- `SaveToJsonFile(Path)` / `LoadFromJsonFile(Path)` — `FFileHelper`로 파일 IO.
- 기본 경로: `GetDefaultPresetFilePath()` = `Saved/3D/Preset/preset.json` (Unity `./Save/3D/Preset` 대응).
- **저장/열기 버튼**(`Btn_Save`/`Btn_Open`)이 실제 파일 저장/로드를 수행(기존 빈 훅 → 동작 구현). 열기 시 목록 교체 + 첫 항목 선택 + 뷰 갱신.

### 2.1 JSON 스키마(생성 결과)
```json
{ "datas": [ {
  "presetIdx": 1, "presetName": "Preset 1", "faceCount": 7,
  "offset": { "x": 0, "y": 0, "z": 0 },
  "faceRotate": 0, "groupFaceRotate": 0,
  "boxSizeX": 2.5, "boxSizeZ": 5,
  "dirType": "Default", "bIsBaseWidth": true, "cameraIdx": 1, "bUse3D": false
} ] }
```
> 카메라는 `cameraIdx`만 직렬화(설계 방침대로 camPos/camRot/fov 제외).

## 3. 3차 — 3D 주차라인/큐브 생성 (`AParkingPresetManager`)

Unity `CPMakerParkSpaceUI.MakeFaceRect`(§6-1) + `MoveByFaceDirType`(§6-2) + `MakeLineQubeBox`(§6-4) 포팅.
라인은 **영구 디버그 라인**(`DrawDebugLine`, persistent)으로 그린다(Unity LineRenderer 대응, 에디터/게임 모두 표시).

### 3.1 생성 파이프라인
- **좌표/단위**: 미터→cm(×100). Unity(x, y_up, z) → UE(x, z, y_up=Z). 면은 UE XY평면, 높이 Z.
- **개별 면 회전(faceRot)**: Z축 회전(면 로컬). **그룹 회전(groupRot)**: Z축 회전(Origin 기준). 두 회전 분리.
- **사선 스텝 보정**: Default+|cos|>0이면 `폭/cos(faceRot)`로 간격 확장(겹침 방지). `useBaseWidth`로 폭 기준축(X vs Y) 선택.
- **방향 반전**: faceRot 정규화값 > 180°이면 진행 방향 반전(Unity eulerAngles.y>180).
- **Dir 타입**: 면 로컬 right/forward 방향으로 진행.
- **3D 큐브**: 바닥 4점 + 높이(2.5m=250cm) 압출 + 수직 4모서리.
- **선택 강조**: 선택 프리셋은 주황(`SelectColor`), 나머지 녹색(`LineColor`).

### 3.2 위젯 연동
- `RefreshView()`가 `AParkingPresetManager`(없으면 자동 스폰)를 찾아 `RebuildAll(Presets, SelectedIndex, Use3D)` 호출.
- 추가/수정/삭제/선택/초기화/생성/Use3D 토글/JSON 열기 시 자동 갱신.
