# 자전거 바퀴살: 검은 원판 확인

- 날짜: 2026-11-04
- 조치: **코드 변경 없음.** 렌더링 문제로 볼 근거가 없어 PM(pm-ea)이 조사를 종료했다.

## 마스터 원문

- 「.10 시뮬레이터 테스트할때 보니 자전거 바퀴살이 안보인다. 확인해줘.」
- 「.10 시뮬레이터 옷 랜덤 입히기할때 확인함.」
- 보신 바퀴 모양: 「검은 원판」

## 원인

**`simple` 모델의 원래 모습이다.**

- `simple` 은 #1794(2026-11-03)에서 처음 간이 모형을 일부러 남긴 것이고, 바퀴가 검은 원판이다.
- `city`·`sport` 에는 바퀴살 18개가 있다.
- `model` 을 생략하거나 없는 이름을 주면 `city`·`sport` 중에서만 고른다(`GApBicycleDefaultCount = 2`). `simple` 은 이름으로 지정할 때만 나온다.

## 옷 테스트에서 simple 이 나온 경로

옷·손잡이 시험 스크립트가 `agent.create {kind:"bicycle", model:"simple"}` 로 직접 지정했다. 손잡이를 자전거 3종 모두 확인하려던 것이다.

| 항목 | 값 |
|---|---|
| 인스턴스 | 에디터 `-game` 13530(`UnrealEditor.exe Park3D.uproject -game -RpcPort=13530`), 서신지구대 |
| 지정 값 | `model:"simple"`, `riderModel:"manny"`(수정 시험에서는 `"quinn"` 도) |
| 재쿡 없는 작업본 13540 | 자전거를 만들지 않았다(걷는 사람·오토바이만) |
| 정본 13510 | 이 시험에서 agent 를 만들지 않았다 |

- 13530 은 이 PC(.10) 화면에 창으로 떠 있었다. 마스터가 그 창을 보셨는지는 확인하지 못했다.
- 그때 찍은 `Docs/shots/20261104_agent_outfit/` 에도 `*_simple_*` 은 검은 원판이다.

## 앞으로

- 마스터 확인용 시험과 캡처에는 자전거를 `city`·`sport` 만 쓴다.
- `simple` 은 손잡이·발 회귀 확인에 쓸 때만 넣고 표시한다.
- `simple` 모델과 기본값 코드는 바꾸지 않는다.

## 하지 않은 것

스트림 경로 비교, 거리별 비교, 48d55e5 와 코드 대조는 PM 지시로 하지 않았다. 스트림 프레임에서 바퀴살이 보이는지는 여전히 확인한 기록이 없다.
