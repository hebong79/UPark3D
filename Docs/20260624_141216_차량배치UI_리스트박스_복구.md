# 차량배치 대화상자 — 차량 오브젝트 리스트 박스 복구

- **일시**: 2026-06-24 14:12
- **요구**: 스크린샷과 차량배치UI.jpg 비교 시 "차량 오브젝트" 리스트 박스가 빠져 있음 → 복구.
- **결과**: ✅ 리스트 영역을 고정 크기 보이는 박스로 복구. 컴파일·저장 성공.

---

## 1. 원인

- `Row_List`는 `[CarList_Scroll | VB_Detail]` 구조였으나, **`CarList_Scroll`(ScrollBox)이 비어 있고 크기 지정이 없어** 폭·높이가 0으로 접힘 → 화면에서 사라지고 상세 필드(VB_Detail)만 보였다.
- ScrollBox는 `MinimumDesiredWidth`/높이 속성이 없어 콘텐츠가 없으면 0 크기가 된다.

## 2. 수정 (목업 구조 정합)

- `Row_List` 왼쪽(index 0)에 **`Box_List`(SizeBox, 160×200)** 추가 → 그 안에 **`Border_List`(배경, `(0.22,0.27,0.28)`)** → 그 안으로 `CarList_Scroll`을 **이동**.
- 결과 트리:
  ```
  Row_List
   ├ Box_List (SizeBox 160×200)
   │   └ Border_List (Border, 리스트 배경)
   │       └ CarList_Scroll (ScrollBox)   ← 실행 시 차량 항목 채움
   └ VB_Detail (Idx/Preset Id/Face Id/Rot Y/Front·Back/수정)
  ```
- 빈 상태에서도 리스트 영역이 박스로 보이며, 실행 시 `RebuildCarList`가 항목(버튼 엔트리)을 이 박스에 추가.

## 3. 검증

- 컴파일·저장 성공. 디자이너에서 "차량 오브젝트" 좌측 리스트 박스 + 우측 상세 필드 동시 표시 확인(`_workspace/wbp_carplacement_listbox.png`).
- BindWidget `CarList_Scroll` 이름 유지(이동만) → C++ 바인딩 무영향, 무변경. 테스트 영향 없음.

## 4. 참고

- 실행 중 PIE는 WBP 변경 미반영 → **▶ Play 재실행** 후 차량 배치 대화상자에서 리스트 박스 확인(자동생성/열기 시 항목 표시).
- 리스트 박스 크기(160×200)는 조정 가능.
