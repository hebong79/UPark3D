작성일: 2026-07-25

참조 원본: `unity/20260724_224837_RPC_전체_API_레퍼런스.md` (91 method)
설계서: `_workspace/rpcserver_architect_design.md`

## 1. 요청 요약

Unity에서 쓰던 RPC(91 method, 포트 13110)를 **Unreal에서 사용할 수 있도록 RPC 서버를 만들고, md의 RPC를 동일하게 Unreal로 구현**. 방식은 표준 오케스트레이터(설계→영향도→구현→QA→문서), Phase 1 범위는 사용자 승인대로 **서버 코어(완전) + 백엔드 실재 34개 표면**.

## 2. 결과 — 무엇이 동작하는가

### 서버 코어 (Unity 프로토콜과 동일)
- **`URpcServerSubsystem`**(`UGameInstanceSubsystem`, DontDestroyOnLoad 대응): GameInstance 기동 시 **포트 13110** HTTP 리스너 시작.
- 엔드포인트: `POST /rpc`(단건+배치), `GET /health`(`{ok:true}`), `GET /rpc/catalog`(`{methods:[]}`), `OPTIONS`(CORS 204). 모든 응답에 CORS 헤더.
- JSON-RPC 2.0: `{jsonrpc,id,method,params}` → `{jsonrpc,id,result|error}`. 에러코드 동일(ParseError -32700 / MethodNotFound -32601 / Domain -32000 / MainTimeout -32003). **핸들러 실패는 전부 -32000 Domain**(Unity와 동일한 "message로 구분" 계약).
- 씬 게이트: `system.*` 영속(RegisterPersistent), `car.*`/`random.*` 비영속(Register/ClearSceneModules).

### 구현 method 34개 (catalog 노출)
| 도메인 | 개수 | 상태 |
|---|---|---|
| `system.*` | 3 | ping/health/catalog — **전부 실동작** |
| `car.*` | 21 | **20 실동작** + `car.setMetallic` 미구현(-32000, 포트에 metallic 파라미터 없음) |
| `random.*` | 10 | **5 실동작**(pickCount/camXZ/hideNoise/recreateCars/toggleCars) + 5 미구현(-32000) |

미구현 5(random): `slotPlace`/`placeInView`/`slotJitter`/`frontBack`/`randomizeAll` — 슬롯(CFaceRect)/PTZ 뷰포트/앰비언트 백엔드가 Unreal 포트에 없어 이름만 등록하고 정직한 `-32000 미구현`을 반환(표면 유지·무크래시).

## 3. 구조 (신규 `Source/Park3D/Rpc/`)

| 파일 | Unity 대응 | 역할 |
|---|---|---|
| `Park3DRpcTypes.h` | CRpcProtocol | 에러코드/FRpcError/핸들러 typedef |
| `RpcParamUtil.h/.cpp` | CRpcParamUtil | Get/Require 파라미터 헬퍼 |
| `RpcDispatcher.h/.cpp` | CRpcDispatcher | 레지스트리(영속/비영속)·Dispatch·catalog |
| `RpcModuleSupport.h/.cpp` | — | 모듈 베이스(매니저 획득)+DTO 빌더 |
| `RpcServerSubsystem.h/.cpp` | CRpcServerHost+CRpcServer | HTTP 호스트·라우팅·CORS·system.* |
| `Modules/CarRpcModule.h/.cpp` | CCarRpcModule | car.* 21 |
| `Modules/RandomRpcModule.h/.cpp` | CRandomRpcModule | random.* 10 |

- **백엔드 결선**: car/random 핸들러는 `ACarPlacementManager`(없으면 스폰) + `DT_CarCatalog`에 위임. 이전 작업에서 만든 랜덤 함수군(`SpawnRandomCarsInLine`/`HideRandomCars`/`ToggleRandomCars`/`HideRandomNoiseCars`/`RebuildAllRandomMesh`)을 그대로 사용.
- **매니저 보강(추가형)**: `RemoveCarById`/`IndexOfNameId`/`GetCars`.
- **스레드**: UE `FHttpServerModule` 요청 콜백은 게임 스레드 → 액터 접근 안전(Unity의 메인스레드 디스패치/타임아웃 불필요).

## 4. 검증 — 전부 통과

- **빌드**: `Park3DEditor` UBT 정식 빌드 성공(경고 없음).
- **자동화(EXIT CODE 0)**: `Park3D.Rpc.Dispatcher`/`ParamUtil`/`CarModule`/`RandomModule` 4개 Success(스킵 없음).
- **HTTP 스모크(실서버 curl)**: `/health`·`system.ping`(에코)·`system.health`(port 13110)·`/rpc/catalog`(**34개** 정렬) 정상. 종료 시 포트 해제 확인.
- 상세: `_workspace/rpcserver_qa_report.md`, 영향도 `_workspace/rpcserver_impact_post.md`, 주변동작 `_workspace/rpcserver_luna_behavior_impact_report.md`.

## 5. 사용법

```powershell
# 헬스체크
Invoke-RestMethod -Uri "http://localhost:13110/health"
# system.catalog
$b = @{ jsonrpc="2.0"; id=1; method="system.catalog"; params=@{} } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:13110/rpc" -Method Post -Body $b -ContentType "application/json"
# 차량 생성
$b = @{ jsonrpc="2.0"; id=2; method="car.create"; params=@{ prefabId=2; presetId=1; pos=@{x=5.0; z=3.0} } } | ConvertTo-Json -Depth 5
Invoke-RestMethod -Uri "http://localhost:13110/rpc" -Method Post -Body $b -ContentType "application/json"
```
서버는 PIE 또는 패키지 실행(GameInstance 기동) 시 자동 시작된다. 브라우저 `fetch`도 CORS 개방으로 직접 호출 가능.

## 6. 영향도 요약
- 신규 격리 모듈 + 엔진 `HTTPServer` 사설 의존 추가. 기존 public API 무변경 → 회귀 위험 없음.
- 서버는 모든 GameInstance에서 13110 자동 리슨. 동시 2개 인스턴스 시 두 번째는 포트 획득 실패 로그 후 미기동(게임 자체는 정상) — Phase 2에서 설정화 검토.

## 7. 미구현(후속 Phase) — 정직 보고
아직 Unreal 포트에 백엔드가 없어 제외한 항목(총 91 - 34 = 57 + 미구현 6):
- `preset.*`(18)·`cam.*`(18)·`pole.*`(3)·`map.*`(4)·`measure.*`(5)·`center.*`(3)·`scene.*`(4)·`roi.*`(2): 각 도메인 매니저/데이터 계층 결선 또는 신규 서브시스템 필요.
- `/stream` MJPEG·카메라 캡처(`cam.captureJPG/PNG`)·`scene.load` 레벨 스트리밍: 카메라/캡처/레벨 백엔드 필요.
- `car.setMetallic`·`random`(slotPlace/placeInView/slotJitter/frontBack/randomizeAll): 도색 metallic/슬롯/PTZ/앰비언트 백엔드 필요.

Phase 2에서 도메인별로 백엔드부터 설계→결선하면 동일 서버 코어 위에 이름만 추가 등록하면 된다(카탈로그 자동 확장, 클라이언트 수정 불필요).
