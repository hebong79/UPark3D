# sim.slots 가 면의 실제 바닥 높이(z)를 낸다 (보드 #1718, ROI-11 floor fix A)

## 요청과 원인

- 요청: pm-221 #1718 (마스터 결정 #1717 c3148 「A+B 둘 다 (권장)」 중 A).
- 증상: .10 서신지구대(LV_Park_01) 레벨 주차면은 z = 0.101 m 이다.
  - `preset.numbers` pos.z 는 23면 모두 0.101 이고, 차량 z 는 0.100~0.103 이다.
  - 그런데 `sim.slots` 는 면 중심 z 를 0 으로 냈다.
  - SM 과 SimBench 판정 정답(`truthRoi.ts:80`)이 이 z 를 그대로 써서, .10 의 ROI·정답이 페인트보다 10~30 px 아래로 그려졌다(1920×1080 기준, #1717 c3141).
- 원인: [SimRpcModule.cpp](../Park3D/Source/Park3D/Rpc/Modules/SimRpcModule.cpp) 의 `SimSlotToDto` 가 `center` 를 `Vec3(x, y, 0.0)` 으로 고정해 냈다.
  - 그 앞 단계 `ParkSimLot::CollectSlots` 도 바닥 번호 목록(`FParkingSlotNumberInfo::Center`)에서 X·Y 만 옮기고 Z 는 버렸다.

## 변경

| 파일 | 내용 |
|---|---|
| `Sim/ParkSimLot.h` | `FParkSimLotSlot::FloorZ`(면 중심 높이, 월드 미터) 추가 |
| `Sim/ParkSimLot.cpp` | `CollectSlots` 가 `S.FloorZ = I.Center.Z / 100` — `preset.numbers` 와 같은 값 |
| `Rpc/Modules/SimRpcModule.cpp` | `SimSlotToDto` 의 `center.z = FloorZ`, 메서드 설명에 `center(z=면 바닥 높이)` |
| `Rpc/RpcHelpTable.cpp` | `/help` 의 `sim.slots` 노트에 center.z 의미 추가 |
| `Tests/ParkingDecalTest.cpp` | 신규 `Park3D.Sim.SlotsFloorZ` |

`sim.plan` 응답의 `slot.center` 도 같은 DTO 를 쓰므로 함께 바뀐다.

**바꾸지 않은 것**: `sim.gates`·`sim.lanes`·계획 `polyline`·`laneRoute.pts` 는 여전히 z = 0 이다.
- 이것들은 주차면이 아니라 경로 점이라 #1718 범위 밖으로 두었다.
- #1718 c3151 에 "필요하면 말해 달라" 고 적었다.
