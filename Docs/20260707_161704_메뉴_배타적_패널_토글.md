# 메뉴 UI 배타적 패널 토글 — 구현·검증 보고서

- 작성일: 2026-07-07
- 작업 유형: 동작 변경(다중 패널 동시 표시 → 배타적 단일 표시)
- 대상 파일: `Park3D/Source/Park3D/MainMenuWidget.cpp`, `MainMenuWidget.h`
- 오케스트레이터: `parking-dev-orchestrator` (설계→구현→검증→영향도→문서 5규칙 준수)

## 1. 요구사항
1. 메뉴 버튼 클릭 시 대응 대화상자 1개만 출력, 나머지는 숨김(배타적).
2. 출력된 대화상자의 버튼을 다시 클릭하면 그 대화상자도 숨김(토글 오프 → 0개).
3. 화면에는 항상 최대 1개의 대화상자만.
4. (검증) 버튼 최소 2회 클릭, 항상 1개(또는 토글오프 시 0개)만 표시.

## 2. 원인 (변경 전)
기존 `TogglePanel`은 각 패널을 독립 토글 → 프리셋/차량/카메라를 각각 열면 여러 패널이 **동시에 뷰포트에 잔존**했다.

## 3. 변경 내용
`UMainMenuWidget::TogglePanel` 로직을 배타적 토글로 교체. 시그니처·헤더 멤버 구조는 불변.

```cpp
void UMainMenuWidget::TogglePanel(TSubclassOf<UUserWidget> WidgetClass)
{
    UUserWidget* Panel = GetOrCreatePanel(WidgetClass);
    if (!Panel) { UE_LOG(...패널 클래스 미지정...); return; }

    // 배타적 토글: 클릭한 패널의 현재 표시 여부를 먼저 기록한다.
    const bool bWasVisible = Panel->IsInViewport();

    // 캐시된 모든 패널을 숨겨 항상 최대 1개만 표시되도록 보장한다.
    for (const TPair<TSubclassOf<UUserWidget>, TObjectPtr<UUserWidget>>& Pair : Panels)
    {
        if (Pair.Value && Pair.Value->IsInViewport())
        {
            Pair.Value->RemoveFromParent();
        }
    }

    // 숨겨져 있던 패널이면 표시. 이미 표시 중이던 패널을 다시 누른 경우는
    // 위 루프에서 함께 숨겨졌으므로 재표시하지 않는다(토글 오프 → 패널 0개).
    if (!bWasVisible)
    {
        Panel->AddToViewport(10);
    }
}
```
- 헤더 주석도 실동작에 맞춰 갱신(“배타적 패널 토글 … 항상 최대 1개”).

## 4. 설계 근거 (대안 비교)
- 대안 A(ActivePanel 포인터 유지): 상태 멤버·동기화 필요, 토글오프 별도 분기, 외부 RemoveFromParent와 불일치 위험.
- **대안 B(채택): 매 클릭마다 전체 숨김 후 조건부 표시.** 상태 멤버 불필요(패널 3개, 순회 저렴), 재클릭 토글오프 자연 처리, 외부 상태와 항상 일치, 단순성(CLAUDE.md 규칙 2).

## 5. 검증 (실PIE, 사용자 실클릭 + MCP 상태검증)
> 제약: SlateInspector 합성 클릭은 PIE 게임 UMG의 `OnClicked` 미발화(포커스만) → **버튼 클릭은 사용자 실입력**, 패널 개수 검증은 MCP `Snapshot` 자동. Live Coding 컴파일 후 PIE 재시작하여 반영.

| 단계 | 조작(사용자 클릭) | 기대 | 결과 |
|------|------------------|------|------|
| 0 | (초기) | 패널 0 | ✅ 0개 |
| 1 | 프리셋 메이커 | 프리셋 1개 | ✅ PresetMaker만 |
| 2 | 차량 배치 | 프리셋 숨김·차량 1개 | ✅ CarPlacement만(배타 전환) |
| 3 | 차량 배치(재클릭) | 전부 숨김 | ✅ 0개(토글오프) |
| 4 | 카메라 컨트롤 | 카메라 1개 | ✅ CameraControl만(0→1 재개) |
| 5 | (카메라 상태서) 프리셋 메이커 | 카메라 패널+미리보기 제거·프리셋 1개 | ✅ 미리보기까지 정리, PresetMaker만 |

→ **어느 단계에서도 동시 2개 이상 없음.** 요구사항 1·2·3·4 모두 충족.

## 6. 영향도 분석
- `TogglePanel` 호출부는 `HandlePresetMaker/HandleCarPlacement/HandleCamera` 3곳뿐, 시그니처 불변 → 회귀 안전.
- **카메라 독립 미리보기(`ViewerInstance`, AddToViewport(5))**: `Panels` 맵 밖이지만, `UCameraControlWidget::NativeDestruct`가 패널 제거 시 미리보기도 함께 제거한다. UMG `RemoveFromParent()`→`NativeDestruct` 연쇄로 배타적 숨김이 미리보기까지 정리(기존 토글오프가 의존하던 동일 메커니즘, 신규 위험 아님). 검증 5단계에서 라이브 확인.
- 범위 밖: `Btn_MapSize/DistFeature/VlaTrain/VlaSim`(BlueprintImplementableEvent, BP측)·Exit는 C++ `Panels` 배타 대상 아님. 이들이 BP에서 여는 UI는 별도 검토 대상(현 요구는 C++ 3패널 기준).
- 빌드: 단일 함수 본문 + 헤더 주석 변경, 멤버 레이아웃 불변 → Live Coding 안전(반영 확인).
