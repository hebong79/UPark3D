# 주차 출차 시뮬레이션 구현 (feat/sim-exit-drive)

작성일: 2026-08-12
브랜치: `feat/sim-exit-drive` (기준: `main` 3a23c13)

주차면에 서 있던 차량 1대가 **출구로 나가서 사라지는** 출차 시뮬레이션을 추가했다.
기존 입차 시뮬레이션(`Docs/20260811_195500_주차진입시뮬레이션_구현.md`)의 경로·주행·로그·리플레이를
그대로 뒤집어 쓰고, 출구 도착 시 차량을 제거하는 것만 새로 넣었다.

## 3. 설계 — 입차 경로를 뒤집는다

경로 골격은 두 방향이 완전히 같다. 대상 면의 "열린 쪽"(맞은편 열에 막히지 않은 쪽) 판정,
진입점, 통로점 계산은 입차 코드를 그대로 쓴다.

```
입차 : 입구 ──▶ 통로 ──▶ 진입점 ──▶ 주차면 중심          (끝나면 차량이 면에 남는다)
출차 : 주차면 중심 ──▶ 진입점 ──▶ 통로 ──▶ 출구          (끝나면 차량을 제거한다)
```

실측 예 (프리셋 3 / 3번 면, 전면주차 출차):

```
주차면 (14.94, -3.07)
진입점 ( 8.94, -3.07)
통로   ( 8.94, 38.64)
출구   (-2.22, 38.64)
```

### 3.1 후진 구간의 일반화

기존에는 `bBackIn`(후면주차면 마지막 구간이 후진) 불리언 하나였다. 방향이 둘이 되면서
**후진 구간의 인덱스**로 바꿨다.

| 방향 | 주차 자세 | 후진 구간 | 이유 |
|------|----------|----------|------|
| 입차 | 후면주차 | 마지막(진입점→면 중심) | 통로에서 돌아선 뒤 후진으로 들어간다 |
| 입차 | 전면주차 | 없음 | 그대로 밀고 들어간다 |
| 출차 | 후면주차 | 없음 | 코가 이미 통로 쪽이라 전진으로 나온다 |
| 출차 | 전면주차 | 첫 구간(면 중심→진입점) | 코가 면 안쪽이라 후진으로 빠져나온다 |

같은 이유로 "슬롯 안팎을 오가는 저속 구간"도 인덱스(`SlotLegIndex`)로 뒀다 —
입차는 마지막 구간, 출차는 첫 구간이 `FinalSpeedMps`(1 m/s), 후진이면 `ReverseSpeedMps`(0.6 m/s)다.

### 3.2 상태와 종료

- 상태는 기존 그대로 **이동 / 정지 / 주차** 에 **출차** 하나를 더했다.
  "정지"는 별도 스크립트가 아니라 주행 규칙에서 나온다 — 조향 오차가 30°를 넘으면 속도를 0으로
  떨어뜨려 제자리 선회한다. 출차에서는 진입점에서 통로로 꺾을 때와 통로에서 출구로 꺾을 때 두 번 걸린다.
- 출구에 닿으면 `상태 이동 → 출차` 전이 후 차량을 제거하고 `결과: 출차완료` 로 기록을 닫는다.

### 3.3 리플레이

리플레이는 기록된 프레임을 시간 보간해 재생하므로 방향과 무관하게 같다. 다만 출차 기록은
차량이 이미 없으므로 **재생용으로 첫 프레임 위치에 1대를 되살리고, 재생이 끝나면 다시 제거**한다
(`Record.simMode == "출차"` 로 판정 — 파일에서 읽은 기록도 같게 동작한다).

## 4. RPC — `sim.exit`

```jsonc
// 요청
{"method": "sim.exit", "params": {
  "presetId": 0,        // 0=전체에서 랜덤
  "slotIndex": 0,       // 0=랜덤(1-based)
  "seed": 0,            // 0=비결정
  "parkMode": "rear",   // 기본 후면주차. front / random / 전면 / 후면 도 받는다
  "replay": false,      // true 면 출차 완료 후 자동 재생까지 예약
  "replayDelaySec": 1.5,
  "replaySpeed": 1.0
}}

// 응답(요약)
{"ok": true, "simMode": "출차", "state": "이동", "phase": "주행",
 "presetId": 4, "slotIndex": 4, "parkMode": "후면주차", "carId": "0-09.41.52",
 "entrance": {"x": -2.2165, "y": 38.644, "z": 0},
 "waypoints": [{"role":"주차면",...},{"role":"진입점",...},{"role":"통로",...},{"role":"출구",...}]}
```

호출은 즉시 반환하고 진행은 `sim.status` 의 `phase` 로 본다:
`주행 → 출차 → (리플레이대기 → 리플레이) → 완료`.
`sim.status`/`sim.start`/`sim.scenario`/`sim.stop`/`sim.replay` 응답에는 `simMode`(입차/출차)가 추가됐다.

## 7. 남은 것 / 주의

- **경로 탐색(A*)은 여전히 없다.** 입차와 같은 4점 경로라 같은 한계를 그대로 가진다 —
  열이 3줄 이상 겹쳐 통로가 막히는 배치에서는 통로 구간이 면 위를 지날 수 있다(현재 6프리셋에서는 미발생).
- 차량 간 충돌 회피 없음(1대 전제). 실차식 사선 후진이 아니라 제자리 선회 + 직선 후진이다.
- 출차는 **한 번에 1대**다. 여러 대가 차례로 나가는 시나리오는 미착수.
- 단축키는 패널 입력란(EditableTextBox)에 포커스가 있으면 문자 키가 Slate 에 먹히지만,
  펑션키(F8/F9/F10)는 통과한다(기존과 동일).
- 패키지 빌드는 갱신하지 않았다. 이번 검증은 전부 `-game` 인스턴스 기준이다.

### 빌드 함정 하나

멤버 이름을 `Dir` 로 두면 `WriteLogFiles()`/`LoadLatestRecord()` 안의 지역변수 `const FString Dir` 와
겹쳐 **C4458(선언이 이전 지역 선언을 숨김)** 이 에러로 승격돼 빌드가 깨진다.
멤버를 `RunDir` 로 바꿔 해결했다. 엔진 설정상 이런 섀도잉은 경고가 아니라 에러다.
