# Offset Pick 키보드 제어 정제 — 이동/회전 동작 + 속도 조절(Ctrl+M/N)

- 작성일: 2026-06-22 21:55:47
- 작업 유형: 기존 기능 정제·확장(부분 재실행). C++ 재빌드 필요.
- 선행: [20260622_170657 Offset Pick 토글](20260622_170657_OffsetPick_키보드제어토글_글씨색.md)

## 1. 요구사항 (사용자 확정)
- offsetPick ON 시 **기본 '이동' 체크**. 이동키(WASD/방향키) → 선택 프리셋 주차면 이동.
- '회전' 체크 + **좌우 키** → 각 주차면이 각도(FaceRotate)대로 회전.
- 속도 조절: **Ctrl+M 증가 / Ctrl+N 감소** (이동·회전 스텝 배율).

## 2. 변경 내용 (`PresetMakerWidget.h` / `.cpp`)

### 추가 멤버
- `float OffsetPickSpeedScale = 1.0f;` — 기본 스텝에 곱하는 속도 배율.

### SetOffsetPickControl(enable)
- ON 진입 시 **이동 모드 기본 체크**: `bMoveMode=true`, `Radio_Move=ON`, `Radio_Rotate=OFF`.
- 안내 알림에 조작법 표기(이동/회전/속도).

### NativeOnKeyDown (제어 ON일 때)
| 입력 | 동작 |
|------|------|
| Ctrl+M | 속도 배율 ×1.5 (최대 20) — 프리셋 선택과 무관, 즉시 알림 |
| Ctrl+N | 속도 배율 ÷1.5 (최소 0.1) |
| 이동 모드: W/↑=+Y, S/↓=-Y, D/→=+X, A/←=-X | Offset 변경 (스텝 `0.1m × 배율`) |
| 회전 모드: D/→=+, A/←=- (**좌우 키만**) | FaceRotate 변경 (스텝 `1.0° × 배율`) |

- 처리 시 `ApplyToFields` + `UpdateFaceWidthDisplay`(각도/세로 라벨) + `RefreshView` 후 키 소비.
- 회전에서 상/하 키는 더 이상 사용하지 않음(요구사항: 좌우 키).

## 3. 영향도
- 이전 단계에서 추가된 `UPROPERTY`(BindWidget) 포함 → **전체 재빌드 필요**(Live Coding 불가). 이번 추가 멤버는 일반 멤버라 별도 리플렉션 영향 없음.
- `Lbl_Speed`는 기존 "각도·세로" 표시 용도 유지 → 속도 배율은 라벨 대신 **알림(Notify)** 으로 표시(충돌 방지).
- 카메라(AParkFlyPawn)와 분리: 제어 ON 중 위젯이 키 소비.
- JSON/매니저/기타 위젯 무관.

## 4. 검증 상태 (정직 보고 — 미완료)
1. **재빌드 미수행**: 에디터 실행 중 + 직전 UCLASS/UPROPERTY 변경으로 전체 재빌드 필요. 현재 미컴파일.
2. **수동 검증(재빌드 후)**:
   - offsetPick 클릭 → 이동 라디오 자동 체크 + 글씨 빨강.
   - 이동 모드 + 프리셋 선택: WASD/방향키로 주차면 이동(3D뷰·필드 갱신).
   - 회전 모드: 좌/우 키로 각 면 회전, 상/하는 무동작.
   - Ctrl+M/Ctrl+N: 알림에 배율·스텝 표시, 이동/회전 폭이 실제로 커짐/작아짐.
   - 재클릭 → 원래색 + 제어 OFF.

## 5. 잔여/확인
- 축 매핑(상=+Y, 우=+X), 회전 부호(우=+)는 직관 기본값 — 실제와 반대면 피드백으로 조정.
- 속도 배율 범위 0.1~20, 배수 1.5는 임의 — 조정 가능.
