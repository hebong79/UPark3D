## 1. 서버 개요

### 접속 정보

| 항목 | 값 | 설정 위치 |
|---|---|---|
| 기본 포트 | `13110` | `CRpcServerHost.m_Port` (`[SerializeField]`) |
| 바인드 주소 | `localhost` | `CRpcServerHost.m_BindAddress` |
| 설정 파일 오버라이드 | `config01_preset_maker.json`의 `sim_server_url` | 있으면 시작 시 주소·포트를 덮어씀 |

> 외부 PC에서 접속하려면 `m_BindAddress`를 `localhost` → LAN IP 또는 `0.0.0.0`으로 변경한다.
> 기존 카메라 REST 서버(포트 `13100`, `CWebCamCtrlServer`)와는 **별개로 병존**한다.

### HTTP 엔드포인트

| 엔드포인트 | 메서드 | 용도 |
|---|---|---|
| `/rpc` | POST | JSON-RPC 2.0 요청 처리 (단건 객체 또는 배열 배치) |
| `/health` | GET | `{"ok":true}` 고정 반환 — 헬스체크 |
| `/rpc/catalog` | GET | 등록된 method 이름 목록 JSON |
| `/stream` | GET | MJPEG 스트리밍 (`multipart/x-mixed-replace; boundary=frame`) |
| (모든 경로) | OPTIONS | CORS preflight → 204 No Content |

- `/rpc`에 POST 외 메서드 → 405 + `MethodNotFound`
- 미등록 경로 → 404 + `MethodNotFound`

### CORS

모든 응답에 아래 헤더가 추가된다 (`AddCorsHeaders()`).

```
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST, OPTIONS
Access-Control-Allow-Headers: Content-Type
```

### MJPEG 스트림 (`GET /stream`)

| 쿼리 파라미터 | 타입 | 기본값 | 의미 |
|---|---|---|---|
| `cam_idx` 또는 `camId` | int | 0 | 캡처 카메라 ID. 0이면 현재 선택 카메라 |
| `preset_idx` | int | 1 | 프리셋 인덱스 |
| `pan` | float | 0.0 | Pan 각도 |
| `tilt` | float | 0.0 | Tilt 각도 |
| `zoom` | float | 0.0 | Zoom 배율 |

- 기본 FPS: `m_StreamFps = 10` → 프레임 간격 100ms
- **동시 스트림 최대 4개** (`MaxConcurrentStreams`). 초과 시 503 + Domain 에러
- 사용 예: `<img src="http://localhost:13110/stream?cam_idx=1&preset_idx=1">`
- 데모 페이지: `Assets/Scripts/99_Network/NetworkRpc/webviewer.html`

## 2. JSON-RPC 2.0 프로토콜

### 요청 패킷

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "car.list",
  "params": { "presetId": 1 }
}
```

배열로 감싸면 배치 요청이 된다.

### 성공 응답

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "cars": [ ... ] }
}
```

### 에러 응답

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": { "code": -32000, "message": "...", "data": null }
}
```

### 에러 코드

| 상수 | 코드 | 발생 조건 |
|---|---|---|
| `ParseError` | `-32700` | JSON 파싱 실패 |
| `MethodNotFound` | `-32601` | 미등록 method / 허용되지 않은 HTTP 메서드(405) / 미등록 경로(404) |
| `InvalidParams` | `-32602` | **정의만 존재, 실제 사용 안 됨** (아래 주의 참조) |
| `Domain` | `-32000` | 도메인 오류 — **핸들러의 모든 예외**가 여기로 매핑 |
| `MainTimeout` | `-32003` | 메인스레드 디스패치 타임아웃 (기본 5000ms) |

> ⚠️ **주의:** `-32602 InvalidParams`는 `CRpcErrorCode`에 정의되어 있으나 현재 디스패치 경로에서 사용되지 않는다.
> 파라미터 누락·타입 불일치로 발생하는 `ArgumentException`도 **`-32000 Domain`으로 반환**된다.
> 클라이언트는 에러 코드가 아니라 `message` 문자열로 원인을 구분해야 한다.

### 예외 → 에러 코드 매핑

| 예외 | 코드 |
|---|---|
| JSON 파싱 실패 | `-32700` |
| method 미등록 | `-32601` |
| `TimeoutException` | `-32003` |
| `ArgumentException` · `InvalidOperationException` · `KeyNotFoundException` · 기타 전부 | `-32000` |

## 3. 씬 게이트 규칙

RPC method는 **영속(persistent)** 과 **비영속(scene)** 으로 나뉜다.

| 구분 | 등록 방식 | 씬 전환 시 | 대상 |
|---|---|---|---|
| **영속** | `RegisterPersistent()` | **유지됨** | `system.*` (3), `scene.*` (4) |
| **비영속** | `RegisterModule()` → `Register()` | `ClearSceneModules()`로 제거 후 재등록 | 나머지 84개 |

`CRpcDispatcher`는 `m_PersistentMethods` HashSet으로 구분하며, `ClearSceneModules()`는 이 집합에 없는 핸들러만 제거한다.

**대부분의 비영속 method는 `CDataMgr.Inst.pmakerScene`(01_PresetMaker 씬)을 요구**하며, null이면 `InvalidOperationException` → `-32000`을 반환한다. 예외는 아래 표 참조.

### 씬 무관하게 호출 가능한 method

| method | 비고 |
|---|---|

`roi.*` 2개는 **01_PresetMaker 또는 06_PtzCameraSimulator** 에서만 동작하며 씬별로 다른 경로를 탄다.

## 9. cam.* (18)

모듈: `CCameraRpcModule`. **전부 01_PresetMaker 필요**.

### 공통 응답 — CamDto

```
{ camId:int, name:string, pos:{x,y,z}, pan:float, tilt:float, zoom:float }
```

- `pos.x`, `pos.z`: **localPosition** (부모 기준) / `pos.y`: **worldPosition** (절대 높이) — 혼합 좌표계 주의
- `pan`, `tilt`: `localEulerAngles` 기반 → **항상 [0, 360)**
- `zoom`: FOV에서 역산한 배율 [1, 36]

### ⚠️ 각도 정규화 (중요)

`cam.getPTZ`·`cam.list`·`cam.get`이 반환하는 `pan`/`tilt`는 **Unity `localEulerAngles`의 고유 동작으로 항상 [0, 360) 범위**다.

```
cam.setTilt(camId, -15)  →  cam.getPTZ  →  tilt: 345
```

모듈 코드에 별도 정규화 로직은 없다. Unity 엔진 특성이다. 클라이언트가 음수 각도를 기대한다면 `value > 180 ? value - 360 : value`로 변환해야 한다.

### 값 범위 제한

| 값 | clamp | 근거 |
|---|---|---|
| `zoom` | **[1, 36]** | `SetZoomByFOV()` 내 `Mathf.Clamp` (`CObjCamera.cs:237`) |
| `quality` (JPG) | **[1, 100]** | `Mathf.Clamp` (`CCameraRpcModule.cs:253`) |
| `pan` · `tilt` | 없음 (Unity 0~360 정규화만) | `CStaticCam.cs:82,92` |
| `fov` | 없음 (Unity 내부 ~0.00001~179°) | `CObjCamera.cs:260` |

### 생성 · 선택 · 조회

| method | 파라미터 | 응답 | 위임 |
|---|---|---|---|
| `cam.create` | 없음 | `{camId:int}` | `SetCameraObjectAndRenderTexture(PTZ, "Camera-N")` (`CPCamObjListUI.cs:288`) |
| `cam.delete` | `camId`(필수) | `{ok:bool}` — **카메라 1개 이하면 false** | `RemoveCameraAt()` (`:412`) |
| `cam.select` | `camId`(필수) | `{ok:true}` | `SetSelectCamera()` (`:359`) |

`cam.create`는 1920x1080 RenderTexture를 연결하고 이름을 `Camera-N`(N=목록 수+1)으로 자동 부여한다.
