## 4. 설계 원칙
1. **거짓 동작 금지**: 백엔드 없는 method는 등록 시 `-32000 미구현`, 아니면 미등록.
2. **서버 코어 완성**: 프로토콜/라우팅/CORS/에러/디스패처/씬게이트 완비.
3. **낮은 확장 비용**: 도메인 백엔드 제작 후 모듈 `Register`만 하면 catalog 자동 확장(클라이언트 무수정 — `system.catalog` 동적 조회).
4. **데이터 권위 필요**: RPC가 헤드리스로 조작하려면 월드에 런타임 권위가 있어야 함(car=`ACarPlacementManager.Cars`, preset=`AParkingPresetManager.StoredPresets`, map=`AMapFloorActor`, cam=`ACameraControlManager.Cameras`, measure=모듈 세션상태). pole/center/roi는 이 권위부터 설계 필요.
