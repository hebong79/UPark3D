# 시작 슬롯 — 수동은 갯수만큼만, 자동은 끝까지(갯수 무시)

작성 2026-09-08 (같은 날 `20260908_121500_시작슬롯_수동모드_갯수_강제부여.md` 의 정정)

## 1. 요청

> 1. 수동모드일때는 개수만큼만 변경되고 나머지 뒷번호가 자동으로 변경되면 안된다.
> 2. 현재상태는 자동모드나 똑같다.
> 3. 확실히 확인 테스트 까지 해줘. (실행파일은 별도로 생성해서 테스트)

직전 커밋(`4231753`)은 "갯수 N 은 모드 무관 N 장, 빈칸일 때만 갈린다" 로 만들었다. 그러면 갯수를 넣는 순간
수동과 자동이 같은 결과를 내서 스위치가 무의미하다 — 그것이 지적 2 의 실체다. 직전 문서 2절에 가정으로
남겨 둔 "자동이 무엇을 더 해야 하는가" 에 대한 답이 이번 지시다.

## 2. 결정

| 자동 | 갯수 | 바뀌는 면 |
|------|------|-----------|
| 꺼짐(수동, 기본) | N | **기준 면 포함 N 장만**. 뒤 면은 절대 손대지 않는다 |
| 꺼짐(수동, 기본) | 빈칸(0) | 기준 면 한 장 |
| 켜짐(자동) | (무시) | 기준 면부터 **묶음 끝까지** +1 씩 |

- 번호 중복은 어느 모드에서도 막지 않는다(오전 결정 유지).
- 자동일 때 갯수는 아무 데도 쓰이지 않으므로 패널의 갯수 칸을 **잠근다**(값은 지우지 않는다). 수동이면 열린다.
  오전 문서의 "안 쓰이는 칸은 잠근다" 원칙을 방향만 뒤집어 적용한 것이다.
- 묶음 경계(프리셋 면 → 레벨 면)에서 끊기는 규칙, 같은 면에 기준점이 둘이면 뒤가 이기는 규칙은 그대로.

```cpp
// AParkingPresetManager::ApplyNumberAnchors
Remaining = A->bAuto ? 무한 : (A->Count > 0 ? A->Count : 1);
```

예) 면 1..6, 기준 면 2, 시작 10, 갯수 3

- 수동: `1, 10, 11, 12, 5, 6`
- 자동: `1, 10, 11, 12, 13, 14` (갯수 3 은 무시)

## 3. 변경 파일

| 파일 | 변경 |
|------|------|
| `ParkingPresetManager.cpp` | `Remaining` 식 — 자동이면 갯수를 보지 않는다 |
| `ParkingPresetManager.h` / `CameraControlTypes.h` | `Count`·`bAuto` / `start_count`·`auto_renumber` 주석 |
| `CameraControlWidget.h/.cpp` | 갯수 칸 `SetIsEnabled(!auto)` — `FillStartSlotRow` 와 `HandleStartAutoChanged`(복원, 방향 반대) |
| `Rpc/Modules/CamRpcModule.cpp` | 주석만. 파라미터·응답 필드(`startCount`, `autoRenumber`) 불변 |
| `Tests/ParkingDecalTest.cpp` | TN-9 자동+갯수3 기대값 `1,10,11,12,5,6` → `1,10,11,12,13,14` |

파일 형식(`CamPos_*.json`)·RPC 계약은 바뀌지 않았다. 옛 파일(`auto_renumber` 없음 = 수동, `start_count` 없음 = 0)은
기준 면 한 장만 바뀐다 — 09-08 오전 이후 어느 시점의 동작과도 같다.

## 4. 검증 (별도 실행파일)

`Park3DEditor`·`Park3D` 두 타깃 빌드 성공, 자동화 테스트 **104/104**(`Park3D.ParkingDecal.SlotNumbers` 포함, 실패 0).

실기는 정본(13510)을 건드리지 않고 **패키지 복제본 `Package/Work13520`** 에 12:48 빌드의 exe·pdb 만 갈아끼워
RPC 13520 으로 띄웠다(서신지구대, 레벨 면 23개). 판정은 `preset.numbers` 의 번호 배열 + 창 캡처.

### RPC 경로 (`cam.savePreset` → `preset.numbers`, 기준 면 `level:BP_ParkingSlot_C_1#0` = 5번)

| 호출 | 바닥 번호 |
|------|-----------|
| 수동, 시작 100, 갯수 3 | `1,2,3,4,100,101,102,8,9,…,23` — **세 장만** |
| 수동, 시작 1, 갯수 2 | `1,2,3,4,1,2,7,…,23` — 중복 허용 |
| 수동, 시작 100, 갯수 0 | `1,2,3,4,100,6,…,23` — 한 장 |
| **자동, 갯수 3** | `1,2,3,4,100,101,…,118` — **갯수 무시, 끝까지**(수동과 다르다) |
| 자동, 갯수 0 | `1,2,3,4,100,101,…,118` |
| 시작 0(해제) | `1,…,23` |

### 패널 경로 (`car.hideAll` 로 차량을 숨겨 바닥 번호를 보이게 한 뒤, 실제 마우스·키 입력)

1. 바닥 11번 면을 LShift+클릭 → 칸에 `11`, 문구 `기준 면 #11 → '수정'` (캡처)
2. 시작 슬롯 칸에 `50` 타이핑 — 칸에 이미 `11` 이 있어 `1150` 이 됐다(자동화가 값을 지우지 않은 탓, 기능과 무관), 갯수 `3`, 자동 꺼짐
3. '수정' → `…,10,1150,1151,1152,14,15,…,23` — **세 장만, 14번부터 원래 번호** (바닥 캡처에서도 `1150 1151 1152 14` 확인)
4. `자동` 체크 → **갯수 칸이 즉시 회색으로 잠긴다**(값 3 은 남아 있다, 캡처) → '수정' → `…,10,1150,…,1162` — 끝까지
5. `자동` 해제 → '수정' → 다시 `…,1150,1151,1152,14,…` (3번과 동일)
