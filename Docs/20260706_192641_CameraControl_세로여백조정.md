# WBP_CameraControl 상하 컴포넌트 세로 여백 조정

- 작성일: 2026-07-06
- 대상: `/Game/UI/WBP_CameraControl` (C++ 베이스 `UCameraControlWidget`)
- 요청: "상하 컴포넌트들의 여백을 주어서 보기 편하게 조절"

## 1. 구조 파악

레이아웃은 C++가 아니라 WBP 디자이너에 정의됨. 계층:

```
RootCanvas > RootBorder > Scroll_Root(ScrollBox) > VBox_Root(VerticalBox)
  └ 14개 상위 그룹(각 VerticalBoxSlot_0..13)
```

VBox_Root 직속 자식 14개:
| slot | 위젯 | 내용 |
|------|------|------|
| 0 | TitleBar (HBox) | "카메라 컨트롤" 제목 |
| 1 | Lbl_Camera | "카메라 리스트" 라벨 |
| 2 | Row_CamCombo (HBox) | 카메라 콤보 + 추가/삭제 |
| 3 | Lbl_Preset | "Preset ID" 라벨 |
| 4 | Row_PresetId (HBox) | 프리셋 필드 |
| 5 | Row_PresetBtns (HBox) | 프리셋 콤보 + 추가/수정/삭제 |
| 6~11 | Ctrl_H/X/Z/Pan/Tilt/Zoom (VBox) | 6개 슬라이더 그룹(각 Min/Cur/Max + Slider) |
| 12 | Row_Buttons (HBox) | 저장/열기/초기화/피킹 |
| 13 | Btn_ShowPole | "카메라 위치 보기" |

## 2. 변경 전 패딩(현황)

- slot 0~5 (제목·카메라·프리셋): 패딩 **0** → 상단이 빽빽함.
- slot 6~11 (슬라이더 6그룹): `{top:8, bottom:4}` → 약 12px 간격 존재.
- slot 12~13: 0.

## 3. 설계 (일관된 세로 리듬)

원칙: **라벨은 바로 아래 컨트롤에 밀착**, **섹션 사이는 넓게**, **슬라이더 그룹은 균일 간격**.

| slot | 위젯 | Padding(L,T,R,B) | 의도 |
|------|------|------------------|------|
| 0 | TitleBar | 0,0,0,10 | 제목 분리 |
| 1 | Lbl_Camera | 0,0,0,3 | 라벨→콤보 밀착 |
| 2 | Row_CamCombo | 0,0,0,14 | 카메라 섹션 끝 |
| 3 | Lbl_Preset | 0,0,0,3 | 라벨 밀착 |
| 4 | Row_PresetId | 0,0,0,6 | |
| 5 | Row_PresetBtns | 0,0,0,14 | 프리셋 섹션 끝 |
| 6~11 | Ctrl_* (6개) | 0,0,0,12 | 슬라이더 그룹 균일 12px |
| 12 | Row_Buttons | 0,6,0,8 | 버튼줄 상하 분리 |
| 13 | Btn_ShowPole | 0,0,0,0 | 마지막 |

## 4. 적용 방법 (UE 5.8 네이티브 MCP)

> **중요:** 이 프로젝트는 UE 5.8 네이티브 **AI Toolset Registry MCP**(`http://localhost:8000/mcp`)를 사용한다.
> 기존 스킬(`unreal-umg-designer`)의 옛 `unreal_mcp` 도구(`add_widget`/`set_slot_properties`)는 **존재하지 않음**.
> 게이트웨이 `call_tool(toolset_name, tool_name, arguments)` 로 실제 도구를 호출한다.

- 트리 조회: `UMGToolSet.UMGToolSet.GetWidgets`
- 슬롯 속성: `editor_toolset.toolsets.object.ObjectTools.get_properties` / `set_properties`
  - `get_properties`: `{instance:{refPath}, properties:["Padding"]}`
  - `set_properties`: `{instance:{refPath}, values:"{\"Padding\":{...}}"}` (values는 **JSON 문자열**)
- 컴파일: `UMGToolSet.UMGToolSet.CompileWidgetBlueprint`

## 5. 검증

- 각 슬롯 set 결과 `returnValue:true`.
- 적용 후 14개 슬롯 Padding 재조회로 확인.
- 컴파일 성공 → 저장.
- 시각 확인은 WBP 디자이너 재오픈 또는 PIE 재실행으로 사용자 확인.

## 6. 영향도

- **C++ 무영향:** BindWidget 이름·타입 변화 없음(슬롯 Padding만 조정). `UCameraControlWidget` 재컴파일 불필요.
- **다른 위젯 무영향:** WBP_CameraControl 단독 에셋 변경.
- **런타임 무영향:** 시각적 여백만 변경, 로직/데이터 흐름 동일.
