# PresetMaker 폰트 DPI 보정 — 화면 렌더 17px 목표

- 작성일: 2026-06-22 15:56:02
- 선행 문서: [20260618 폰트 16→17 변경](20260622_153732_PresetMaker_글자크기_17_변경.md)
- 대상: `WBP_PresetMaker` (41개 텍스트 위젯) + `PresetMakerWidget.cpp` (리스트 항목 라벨)

## 1. 문제 상황

재빌드 후 사용자가 "UI 폰트가 22.67로 보인다, 17로 맞춰야 한다"고 보고.

## 2. 원인 진단 (추측 아님 — 측정/조회로 확인)

| 확인 항목 | 결과 |
|-----------|------|
| WBP 저장 폰트 값 | **17 (논리값 정상)** — 재빌드 후에도 유지됨 |
| Config DPI/ApplicationScale | INI 별도 설정 없음 (엔진 기본 DPI 커브) |
| 측정값 역산 | 22.67 ÷ 17 = **1.3333 (= 4/3)** |

- **22.67은 위젯에 저장된 값이 아니라 "화면 렌더 픽셀 크기"**다.
- Slate는 폰트 포인트(pt)를 그릴 때 전역 **DPI 스케일(현재 1.333배)** 을 곱한다. → 17pt × 1.333 = 22.67px.
- 즉 폰트 값 17은 올바른 상태였고, 22.67은 DPI 스케일의 정상 결과.

## 3. 사용자 결정

선택지 제시 후 **"화면에 17px로 보이게"** 선택 (전역 DPI 스케일은 건드리지 않음).

## 4. 처리 — 폰트 값을 DPI 보정값으로 변경

화면 17px = 폰트값 × 1.333 → **폰트값 = 17 ÷ (4/3) = 12.75pt**

- `FSlateFontInfo.Size`가 **float**를 허용함을 확인(12.75 저장 검증). → 정확히 12.75 적용 가능.

| 대상 | 변경 | 결과 |
|------|------|------|
| WBP TextBlock 29개 | `Font.Size` 17 → **12.75** | ✅ 전건 success |
| WBP EditableTextBox 11개 | `WidgetStyle.TextStyle.Font.Size` 17 → **12.75** | ✅ |
| WBP ComboBoxString 1개 | `Font.Size` 17 → **12.75** | ✅ |
| 위젯 BP 컴파일·저장 | — | ✅ compiled / saved |
| [PresetMakerWidget.cpp:204-207](../Park3D/Source/Park3D/PresetMakerWidget.cpp#L204) | `EntryFont.Size = 12.75f` + 주석 | ✅ (소스 수정) |

검증: Title_Text 재조회로 `Size=12.75`(반올림 없음), Bold/FontObject 보존 확인.

## 5. ⚠️ 중요 한계 (정직 보고)

1. **해상도 의존성**: 12.75pt → 17px는 **DPI 스케일이 1.333인 현재 해상도에서만** 성립한다. 다른 해상도/모니터에서 DPI 스케일이 달라지면 렌더 px도 달라진다.
   - 해상도와 무관하게 17px를 보장하려면 전역 DPI 스케일을 1.0으로 고정(폰트 17 유지)하는 방식이 견고하나, 이는 프로젝트 전체 UI에 영향이 있어 사용자가 선택하지 않음.
2. **C++ 재빌드 필요**: 리스트 항목 라벨(C++) 반영은 Live Coding/빌드 후 적용. 현재 미빌드.
3. **육안 확인 미수행**: PIE 시작 크래시 이력으로 자동 검증 제외. WBP 디자이너/Standalone 확인 권장.

## 6. 영향도

- `WBP_PresetMaker` 단일 에셋 + C++ 1줄(상수)·주석. 위젯 트리/바인딩/로직 불변.
- 폰트 1pt 미만 축소(17pt→12.75pt 논리값)지만 **렌더 결과는 22.67px→17px로 축소**되어 레이아웃이 더 여유로워짐(클리핑 위험 감소).
