# 바퀴가 노면 도색 위에서 하얗게 보이는 현상 조사

- 날짜: 2026-11-04
- 요청: pm-ea 경유 마스터 「1, 2, 3 모두 진행해줘. 권장대로 해줘.」(2 = 재현·원인 조사). `.125` 제보는 w-sim-unreal-125.
- 범위: 조사만 했다. 코드·재질·레벨·빌드·정본은 바꾸지 않았다.
- 환경: 에디터 `-game -NoCamStream` 13530, 서신지구대(`LV_Park_01`). 정본 13510 은 쓰지 않았고 `agent` 도 만들지 않았다.

**사진 위치:** 저장소에는 `Docs/shots/20261104_wheel_decal/` 의 모음 시트와 대표 사진만 넣었다. 나머지 원본은 git 제외 폴더 `_workspace/wheel_decal_20261104_backup_originals/` 에 같은 하위 경로로 옮겼다(이 PC 에만 있다). 아래에서 「원본 폴더」로 표시한다.

## 1. 결론

**재현됐고, 원인은 도색 데칼이 그 위에 있는 물체에 함께 찍히는 것이다.** 자전거·오토바이만의 문제가 아니며 차와 사람에도 같이 나타난다.

- 흰 화살표 등 도로 표시 일부는 메시가 아니라 데칼 액터(`BP_Decal_C` 등, 레벨에 18개)다.
- 데칼 상자는 바닥 위아래로 약 15 cm 를 차지한다(`DecalSize.X` 5 × 스케일 3). 이 안에 들어온 물체 표면에도 흰색이 찍힌다.
- 프로젝트 소스에 `bReceivesDecals`·`SetReceivesDecals` 호출이 하나도 없어 모두 엔진 기본값으로 데칼을 받는다.

## 2. 근거

### 2.1 데칼을 숨기면 사라진다

같은 시점, 같은 위치에서 `env.hide` 로 `BP_Decal_C_5`·`BP_Decal_C_8` 만 숨겼다. 도색과 함께 바퀴의 흰색도 사라졌다. 오토바이·자전거 모두 확인했다.

- 오토바이: `cause/moto_decal_on.jpg`, `cause/moto_decal_off.jpg`, 되돌린 뒤 `cause/moto_decal_on2.jpg`(원본 폴더)
- 자전거: `cause/h_sport_on.jpg`, `cause/h_sport_off.jpg`(원본 폴더)

### 2.2 메시로 된 주차면 선에서는 나타나지 않는다

주차면 선(`BP_ParkingSlot`, x≈16.66)에 바퀴를 올려도 흰색이 없다(원본 폴더 `cause/slotline2_scooter3.jpg`, `cause/slotline2_sport_top.jpg`). 이 자리에 서 있던 차 2대는 13530 안에서만 지웠고 저장하지 않았다.

### 2.3 설정값

읽기 전용 커맨드릿으로 `LV_Park_01` 을 열어 읽었다.

| 항목 | 값 |
|---|---|
| 데칼 컴포넌트 | 18개: `BP_Decal` 11, `BP_Decal_Stop_Line` 5, `BP_Decal_Zebra` 2 |
| `DecalSize` | (5, 250, 250) 전부 같음 |
| 투영축 스케일 | 3.0 이 16개, 2.294 가 2개 |
| 상자 위끝 | 데칼 중심 z=10 cm(노면 높이)에서 위로 15 cm(엔진 `GetTransformIncludingDecalSize` = 스케일 × `DecalSize`) |
| 재질 | `M_Markings_Decal`, Deferred Decal |

재질의 데칼 반응(`MaterialDecalResponse`)은 읽은 재질 61개가 모두 `MDR_COLOR_NORMAL_ROUGHNESS` 다. `BasicShapeMaterial`(자전거), `M_GLTF`·`M_Default`(오토바이·차), `M_AgentOutfit`(사람)에 차이가 없다. 그래서 대상에 따라 받고 안 받는 차이는 없다.

### 2.4 차와 사람이 그동안 드러나지 않은 이유

주차된 차는 메시로 된 주차면에 서 있고 도로 표시 위에 잘 서지 않는다. 사람은 발 높이만 걸린다. 다만 이것은 위 관찰에서 나온 해석이며 이력을 따로 확인하지는 않았다.
