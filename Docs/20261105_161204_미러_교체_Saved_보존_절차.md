# 미러 교체 때 Saved 보존 절차와 교체 전후 비교

2026-11-05, w-sim-unreal2(.125). 마스터가 이 창에서 「1, 2 진행해줘」라고 지시했다. 재발 방지안 1(교체 명령 고정)과 2(교체 전후 비교)로 이해하고 진행했다.

## 1. 배경

.125 메인 뷰는 10-23 에 `Package\Windows\Park3D\Saved\Config\Windows\Game.ini` 로 1280×720·AA 켬이 되었다(게시판 #1760 c5120). 11-05 확인에서는 이 파일이 없고 960×540·AA 꺼짐이었다.

절차서 `PROCEDURE.md` 에는 미러 교체 명령이 없었다. `Saved` 를 빼라는 내용은 `CLAUDE.md` 변경 이력의 함정 문구로만 있었다.

## 2. 파일이 사라진 시점

정확한 시각은 찾지 못했다.

| 시점 | 근거 | 의미 |
|---|---|---|
| 10-23 18:10 | `Package\Work13560` 의 사본 시각 | #1760 의 생성 기록과 맞음 |
| 11-03 15:51 | `Windows.bak_20261103` 설정 폴더 생성 시각, `Game.ini` 없음 | 폴더가 나중에 다시 만들어진 듯해 원본 기록으로 믿기 어려움 |
| 11-04 16:50 | 현재 정본 설정 폴더 생성 시각, `Game.ini` 없음 | 늦어도 이때는 이미 없었음 |

11-04 21:13 교체는 원인이 아니다. `/MIR /XD Save Saved` 로 실행했고 설정 폴더가 그보다 먼저 있었다. 11-03~11-04 16:50 사이의 정본 교체가 유력하지만 추정이다. 이 PC 에 11-03 교체 기록 문서가 없다.

## 3. 변경

대상은 `.claude/skills/park3d-ops-sonnet/PROCEDURE.md` 하나다.

- 5절에 「6) 교체 전후 비교」 추가: `cam.streamStatus` 의 메인 뷰 크기·AA, `Game.ini` 유무·SHA256 을 교체 전후로 비교한다. 다르면 고치지 말고 보고한다.
- 6절 신설 「재쿡 결과 미러 교체」: `robocopy $new $root /MIR /XD Save Saved` 로 고정하고, 종료 코드 8 이상을 실패로 본다.

## 4. 검증

임시 폴더에서 실제 `robocopy` 로 시험했다. 정본은 건드리지 않았다.

| 조건 | `Saved\...\Game.ini` | `Save\Config\config.json` | 낡은 `stale.pak` | 종료 코드 |
|---|---|---|---|---|
| `/MIR /XD Save Saved` | 남음 | 남음 | 지워짐 | 3 |
| `/MIR` 만(대조군) | **지워짐** | 지워짐(EXTRA 출력 기준) | 앞에서 이미 지워짐 | 3 |

재쿡 폴더가 `Package\<태그>\Windows` 구조인 것은 `Package\Rel20261104` 로 확인했다.

**미검증:** 실제 정본 교체에는 아직 쓰지 않았다.
