# UI 에디트박스 글자색 변경 (검정에 가까운 진회색)

작성일: 2026-06-23
대상: `PresetMakerWidget` (WBP_PresetMaker 베이스 클래스)
작업 유형: UI 스타일 수정 (사소 변경 — 설계 게이트 경량 처리)

---

## 1. 요구사항
- WBP_PresetMaker UI의 입력 에디트박스 글자색을 **검정에 가까운 회색**으로 변경.

## 2. 설계 생략 사유 (CLAUDE.md 0번 규칙)
- 자료구조/인터페이스/흐름 변경 없음. 위젯 글자색 상수 일괄 적용만 해당하는 사소 변경이므로
  전체 설계서 작성을 생략하고 본 문서에 결정 근거만 기록함.

## 3. 변경 방식 결정
- 에디트박스 글자색은 본래 WBP 에셋의 `EditableTextBox` 스타일(ForegroundColor)에 정의된다.
- 에셋 대신 **C++ `NativeConstruct`에서 일괄 지정**하는 방식 선택.
  - 근거: ① 11개 필드에 동일 색을 코드 한 곳에서 보장(일관성), ② 코드라 버전관리/리뷰 추적 가능,
    ③ `UEditableTextBox::SetForegroundColor(FLinearColor)` API가 UE 5.7에 존재.

## 4. 구현 내용
파일: [PresetMakerWidget.cpp](../Source/Park3D/PresetMakerWidget.cpp)
함수: `UPresetMakerWidget::NativeConstruct()`

```cpp
// 모든 입력 에디트박스의 글자색을 검정에 가까운 진회색으로 통일(가독성).
{
    const FLinearColor FieldTextColor(0.1f, 0.1f, 0.1f, 1.0f);
    UEditableTextBox* Fields[] = {
        Field_PresetIdx, Field_FaceCount, Field_OffsetX, Field_OffsetY, Field_OffsetZ,
        Field_GroupFaceRotate, Field_FaceRotate, Field_BoxSizeX, Field_BoxSizeZ,
        Field_CameraIdx, Field_PresetName
    };
    for (UEditableTextBox* Box : Fields)
    {
        if (Box) Box->SetForegroundColor(FieldTextColor);
    }
}
```

- 적용 색상: `FLinearColor(0.1, 0.1, 0.1, 1.0)` — 순수 검정(0,0,0)이 아닌 진회색.
- 대상 필드(11개): PresetIdx, FaceCount, OffsetX/Y/Z, GroupFaceRotate, FaceRotate,
  BoxSizeX/Z, CameraIdx, PresetName.
- 각 포인터는 `if (Box)` 가드로 null 안전 처리(BindWidget 누락 대비).

## 5. 검증 (CLAUDE.md 1·2번 규칙)
- **컴파일**: Live Coding 컴파일 성공 확인 — `Park3D.log`: `06:50:02 Live coding succeeded`.
- **동작 확인(미완)**: 글자색은 `NativeConstruct` 시점(위젯 생성 시) 적용되므로,
  이미 화면에 떠 있는 기존 위젯 인스턴스에는 즉시 반영되지 않는다.
  → **WBP_PresetMaker UI를 다시 열거나 Play 시 새로 생성될 때 진회색으로 표시됨.**
  시각적 확인은 사용자가 UI를 재오픈하여 진행 필요(자동 PIE 검증은 크래시 이슈로 미수행).
- 단위 테스트: UMG 색상은 시각 속성이라 별도 자동화 단위 테스트 미작성(검증은 시각 확인으로 대체).

## 6. 영향도 분석 (CLAUDE.md 4번 규칙)
- **범위**: `PresetMakerWidget.cpp` 단일 파일, `NativeConstruct` 한 블록 추가. 헤더 변경 없음.
- **의존성**: 추가 include 불필요(`Components/EditableTextBox.h` 이미 포함).
- **기존 기능 영향**: 없음. 색상만 변경하며 입력값 파싱/저장/뷰 로직과 무관.
  Offset Pick 글씨색(`Txt_OffsetPick`, TextBlock)은 별도 위젯이라 영향 없음.
- **패키징**: 코드 변경만으로 에셋 의존성 변화 없음. 빌드 영향 없음.
- **회귀 위험**: 낮음. 색상이 너무 어둡거나 배경과 대비가 약하면 가독성 저하 가능 →
  값(0.1)은 코드 상수이므로 한 줄 수정으로 조정 가능.

## 7. 조정 방법(참고)
- 더 밝게: 값을 키움 (예: `0.2`).  더 어둡게(거의 검정): 값을 낮춤 (예: `0.05`).
- 위치: [PresetMakerWidget.cpp](../Source/Park3D/PresetMakerWidget.cpp) `FieldTextColor` 상수.
