## 2. 설계 요약

상세 설계는 `_workspace/parkingview_architect_design.md` 참조. 핵심만 정리한다.

### R1 — 라인 색상 (고대비)
- `LineColor`(비선택) = `FColor(0, 90, 255)` 강한 청색
- `SelectColor`(선택) = `FColor(255, 0, 170)` 마젠타-레드
- 근거: 베이지(따뜻·고휘도) 대비 **보색 + 저휘도 이중 대비**로 가시성 확보.

### R2 — 반투명 채움(fill)
- `DrawDebugMesh`로 선택 프리셋 바닥 사각형을 **삼각형 2개**로 채움.
- `SelectFillColor` = `FColor(0, 150, 255, 80)` (알파 80)
- `SelectFillZBias` = `-1.0` (라인과의 Z-fighting 회피용 오프셋)

### R3 — 두께 UI
- `WBP_PresetMaker`에 `USlider`(**Slider_LineThickness**, min 1 / max 15 / step 1 / 기본 3) + `UTextBlock`(**Lbl_LineThickness**) 배치.
- `RefreshView`가 재그리기 직전 슬라이더 값을 `Mgr->LineThickness`에 반영.

## 4. 로직 상세

### 4.1 `DrawFilledQuad` (반투명 면 채움)
- 입력: 사각형 4개 코너 정점(월드 좌표), 색상.
- 삼각형 인덱스 `{0,1,2, 0,2,3}`으로 사각형을 2개 삼각형으로 분할해 `DrawDebugMesh` 호출.
- `SelectFillZBias(-1.0)`로 바닥 라인보다 살짝 아래/위로 밀어 Z-fighting을 방지.

### 4.2 `DrawPreset` 통합
- `bSelected == true`인 프리셋에 대해, **바닥 사각형에만** fill을 그린다(벽/기둥 등 다른 면 제외).
- 호출 순서: **fill을 먼저** 그리고 그 직후 라인을 그려, 라인이 면 위에 얹혀 보이도록 한다.

### 4.3 라인 두께 UI 연동
- `NativeConstruct`: 슬라이더 min 1 / max 15 / step 1 / 기본값 3 설정 후 `OnValueChanged`를 `HandleLineThicknessChanged`에 바인딩.
- `HandleLineThicknessChanged`: 라벨 텍스트 갱신 및 재그리기 트리거.
- `RefreshView`: 재그리기 직전에 슬라이더 현재값을 `Mgr->LineThickness`에 대입 → 라인 두께가 실시간 반영.
- 위젯은 `BindWidgetOptional`이라 WBP에 위젯이 없어도 컴파일·구동은 정상(널 체크 전제).

## 5. 미완료 · 후속 작업 (은폐 금지 — 반드시 처리 필요)

| 항목 | 상태 | 필요 조치 |
|------|------|-----------|
| **C++ 재컴파일** | 미완료 | C++ 시그니처 추가로 재컴파일 필요. 핫컴파일 MCP 트리거 불가 → **사용자가 Ctrl+Alt+F11(Live Coding)** 수행해야 반영됨 |
| **WBP 슬라이더 위젯 미추가** | 미완료 | 이 세션에 Unreal MCP 미연결로 `WBP_PresetMaker`에 Slider/TextBlock을 아직 못 넣음. `BindWidgetOptional`이라 컴파일·구동은 정상이나, **WBP에 위젯 추가 전에는 두께 슬라이더가 화면에 안 보이고 두께는 기본 3 고정.** → MCP 연결 환경에서 `Slider_LineThickness`·`Lbl_LineThickness` 추가 필요 |
| **반투명 렌더 미검증** | 미검증 | `DrawDebugMesh`가 쓰는 `GEngine->DebugMeshMaterial`이 Opaque면 알파(80)가 무시돼 **불투명하게 보일 수 있음**. 컴파일·PIE 후 "바닥 체크무늬가 면 너머로 비치는지" 확인 필요. 불투명이면 **폴백(반투명 머티리얼 메시 컴포넌트)** 으로 전환 (설계서 §5 폴백 리스크) |
