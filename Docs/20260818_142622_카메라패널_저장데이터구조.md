# 카메라 패널 저장 데이터 구조 (질문 답변)

작성: 2026-08-18 14:26:22 / 대상: 카메라(Camera) 패널 저장·열기

## 1. 결론

존재한다. 전용 `USTRUCT` 5종이 **`Park3D/Source/Park3D/CameraControlTypes.h`** 한 파일에 모여 있고,
저장/로드는 **`UCameraControlLibrary::SaveToJson` / `LoadFromJson`**
(`Park3D/Source/Park3D/CameraControlLibrary.cpp:216 / :237`)이 담당한다.
UI(패널)는 `UCameraControlWidget`(`CameraControlWidget.h:138`)이 멤버 `FCameraPosList CamData` 하나로 들고 있다.

## 2. 파일 위치

| 항목 | 경로 |

## 3. 클래스(구조체) 계층

```
FCameraPosList          // JSON 루트  = 파일 전체
├─ bool  isUnreal       // true = pos 가 Unreal 미터 좌표 (없거나 false = Unity legacy)
└─ TArray<FCameraPos> datas          // 카메라 대수만큼

   FCameraPos           // 카메라 1대
   ├─ float target_pos
   └─ TArray<FCamDir> datas          // 그 카메라의 프리셋 목록

      FCamDir           // 프리셋 1개  (= 패널 화면 1세트)
      ├─ int32    idx          // 프리셋 순번(0부터)
      ├─ FString  sname        // "Preset 1"
      ├─ int32    cam_id       // 카메라 id (1부터)
      ├─ int32    preset_id    // 프리셋 id (1부터)  ← 패널 "Preset ID"
      ├─ FCamVec3 pos          // x=좌우, y=앞뒤, z=높이 (Unreal 미터)
      ├─ FCamVec3 rot          // x=tilt, y=pan, z=0
      ├─ float    pan          // = rot.y
      ├─ float    tilt         // = rot.x
      ├─ float    zoom         // 배율 1~36 (FOV 아님)
      ├─ FCamPtz  ptzmin       // 슬라이더 최소 {p,t,z}
      └─ FCamPtz  ptzmax       // 슬라이더 최대 {p,t,z}

FCamVec3 { float x, y, z }
FCamPtz  { float p, t, z }   // Pan / Tilt / Zoom
```

멤버명이 전부 **소문자**인 이유: `FJsonObjectConverter` 가 멤버명을 그대로 JSON 키로 쓰므로,
Unity 원본(`CSaveInitCampPos.cs` 의 `SCameraPosList/SCameraPos/SCamDir`)과 키를 100% 맞추기 위함이다.
`FVector` 를 그대로 쓰면 키가 대문자 `X/Y/Z` 가 되어 호환이 깨진다.

## 4. 패널 UI ↔ 필드 매핑

| 패널 항목 | 저장 필드 |
|---|---|
| Camera 리스트 | `FCameraPosList.datas[i]` (i = 카메라 인덱스), `cam_id` |
| Preset 콤보 / Preset ID | `FCameraPos.datas[j]`, `sname`, `preset_id` |
| Camera 높이 | `pos.z` |
| Camera X축 이동(좌우) | `pos.x` |
| Camera Z축 이동(앞뒤) | `pos.y` ← 주의: UI "Z" 가 구조체 `y` |
| PTZ P / T / Z | `pan`(=`rot.y`) / `tilt`(=`rot.x`) / `zoom` |
| 슬라이더 Min/Max | `ptzmin` / `ptzmax` |

매핑 근거: `CameraControlWidget.cpp:851 CollectDirFromControls`, `:818 SyncCameraPosAcrossPresets`.
`pos` 는 프리셋이 아니라 **카메라의 속성**이라 같은 카메라의 모든 프리셋에 동일 값이 복사된다.

## 5. 저장/로드 동작에서 주의할 점

- 저장 시 `isUnreal` 을 **항상 true 로 강제**하고 `ForceUTF8WithoutBOM` 으로 쓴다
  (인코딩 생략 시 비-ASCII 한 글자에도 파일 전체가 UTF-16 이 된다).
- 로드 시 `NormalizeLoaded` 보정: `isUnreal` 이 없으면 Unity→Unreal 좌표 변환,
  `ptzmax.z` 가 36 초과/0 이하면 36, `preset_id` 0→1, `zoom` 1 미만→1,
  마지막에 `pan=rot.y`, `tilt=rot.x` 로 동기화(중복 저장 필드의 단일 진실 근원은 `rot`).
- 시작 시 자동 로드는 `config_pmaker.json` 의 `camerapos_file` 을 읽어
  `Park3DGameMode.cpp:480` 에서 `UCameraControlWidget::LoadFromJsonFile` 로 적용한다.
