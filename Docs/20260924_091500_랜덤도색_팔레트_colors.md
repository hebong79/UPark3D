## 2. RPC 계약

### `car.setRandomColor { carNameId?, carNameIds?: string[], colors?: (int|string)[] }`
- `colors`: ECarColor 정수(0~9) 또는 이름(대소문자 무시): white(0) black(1) silver(2) gray/grey(3) red(4) blue(5) green(6) yellow(7) orange(8) purple(9). 정수 문자열("4")도 허용. 중복은 한 번만. 없거나 빈 배열 = 10종(기존).
- 모르는 이름·범위 밖·소수·배열 아님 → `-32000`, 메시지에 문제 값 원문. 아무것도 칠하지 않는다.
- id 둘 다 없음(또는 빈 배열) → 가시 차량 전부(기존). 있으면 그 차들만(`carNameId` + `carNameIds` 합집합).
- 균등 추첨 후 `SetColorByEnum` + `CarData.color` 기록 → `car.save`·재생성 유지.
- 응답 `{ ok:true, colorsHonored:true, applied:[{carNameId, color:int}], notFound:[string] }`.
- 변경점: 예전엔 단일 `carNameId` 경로가 `CarData.color` 를 안 썼다 → 이제 쓴다. 없는 차는 예전처럼 오류 없이 건너뛰고 `notFound` 로 알린다.

### `car.resetRandom { mode?, count?, colors? }`
- 모든 모드(color / objectAndColor / countObjectAndColor)의 색 단계가 `colors` 에서만 뽑는다. 응답에 `colorsHonored:true` 추가.

### `car.placeAtSlot { ..., randomColor:true, colors? }`
- `randomColor:true` 일 때만 `colors` 를 쓴다(값 검증은 항상). 응답에 `colorsHonored:true` 추가.
