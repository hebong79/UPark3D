## 2. 기능 매핑

| method | params | 응답 | 상태 |
|---|---|---|---|
| `measure.setTargetPoint` | `pos`{x,z 필수,y?} | `{ok:true}` | ✅ 타겟점 저장·활성화 |

## 3. 백엔드 (기존 재사용, 신규 액터 0)

- 계산은 전부 `UCameraControlLibrary` 순수함수: `DistanceXZ`/`Distance3D`(거리), `VertHorzAngleToTarget`(각도), `TargetLineAngles`(타겟라인), `WorldCentimetersToMeters`(cm→m), `UnrealMetersToWorld`(pos→월드).
- 카메라 권위 = `ACameraControlManager`(`Cameras`), 위치 = `APTZCameraActor::GetActorLocation()`.
- **매니저/액터/라이브러리 코드 무수정** — RPC 모듈에서 기존 API 호출만.

### 세션 상태 (Unity CPCamDistDlg 인스턴스 상태 대응)
모듈 멤버로 보관(GameInstance 수명 영속, 월드 액터 스폰 없음):
- `TargetWorld`(타겟점 UE 월드) + `bTargetActive`(활성 여부)
- `VerticalPosWithCam`(수평각 0° 기준점 — `measure.targetLine`이 수선의 발로 설정)

## 4. Unity 예외 이식 (선후관계)

- `distance`·`angles`는 `setTargetPoint` 선행 필수 → 미설정 시 **-32000**(Unity InvalidOperationException).
- `targetLine`은 `camId` 없이 **현재 선택 카메라**(`SelectedIndex`) 사용. 카메라 0대 → -32000.
- `targetLine` `start≈end`(수평거리 < 0.001m) → **-32000**(Unity ArgumentException).

## 5. cameraHeight 이식 방침

Unity는 `m_SelectableLayer` 하방 Raycast → "Floor" 태그. Unreal의 `AMapFloorActor`는 **NoCollision**(순수 시각)이라 실제 콜리전 지표면은 Landscape(Z=0). 따라서:
- 카메라에서 하방(-Z) `ECC_Visibility` 트레이스(자기 액터 무시) → 히트 시 `hit.Distance`, 미검출 시 카메라 Z 폴백.
- 바닥이 Z=0이면 두 경로가 동일값(높이=카메라 Z) → 의미 보존.

## 6. 좌표 규약 (중요)

이 프로젝트 pos 규약은 **JSON x·y = 지면(UE X·Y), JSON z = 높이(UE Z)** 이며 `cam.setPosition` 등 Phase 1~3 전 위치 메서드와 동일하다. measure도 같은 변환을 써서 카메라↔타겟이 동일 UE 공간에 놓인다.

> ⚠️ **Unity 레퍼런스 원 규약(x·z 지면, y 높이)과 축 대응이 다름.** Phase 1에서 정해진 전역 규약이라 measure만 다르게 매핑하면 sibling 메서드와 어긋난다. Unity 클라이언트 원본 좌표를 그대로 쓰려면 **전역 좌표 어댑터를 별도 과제**로 도입해야 한다(measure 국소 수정 대상 아님). → 사용 시 **높이는 z 필드**에 넣을 것.

  - `measure.cameraHeight` → **`12`** (폴백=카메라 Z 정확)

## 8. 사용 예

```powershell
# 카메라 높이 12m (규약: z=높이)
$b = @{ jsonrpc="2.0"; id=1; method="cam.setPosition"; params=@{ camId=1; pos=@{x=0;y=0;z=12} } } | ConvertTo-Json -Depth 6
Invoke-RestMethod -Uri "http://localhost:13110/rpc" -Method Post -Body $b -ContentType "application/json"
# 타겟점 지면(9,0)
$b = @{ jsonrpc="2.0"; id=2; method="measure.setTargetPoint"; params=@{ pos=@{x=9;y=0;z=0} } } | ConvertTo-Json -Depth 6
Invoke-RestMethod -Uri "http://localhost:13110/rpc" -Method Post -Body $b -ContentType "application/json"
# 거리/각도
$b = @{ jsonrpc="2.0"; id=3; method="measure.distance"; params=@{ camId=1 } } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:13110/rpc" -Method Post -Body $b -ContentType "application/json"
```
