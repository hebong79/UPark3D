### 엔드포인트

| 경로 | 메서드 | 인증 | 용도 |
|------|--------|------|------|
| `/rpc` | POST | **필요** | JSON-RPC 본체(단건·배치 모두 지원) |
| `/rpc` | OPTIONS | 불필요 | CORS preflight (204) |
| `/health` | GET | **불필요** | 생존 확인 `{"ok":true}` |
| `/rpc/catalog` | GET | **필요** | 메서드 목록(정찰 정보라 인증 대상) |

**로컬**: `http://localhost:13510/rpc`
**외부 PC에서**: `http://192.168.0.125:13510/rpc`

### 인증

- 헤더 이름: `X-Park3D-Token` (수신 시 엔진이 소문자 정규화 → 서버는 `x-park3d-token`으로 조회)
- 현재 서버 토큰: `DefaultGame.ini` `[RpcServer] Token=apark3d` — **저장소에 커밋되어 있다**(3장 경고 참조)
- 판정 순서 (`RpcAuth.cpp:89-113`)
  1. `Origin` 헤더가 있으면 → 무조건 거부 (브라우저 차단, D11)
  2. 토큰이 설정돼 있으면 → **루프백이라도 토큰 검사**
  3. 토큰 미설정이면 → 루프백(127.x/::1)만 허용, 외부는 401
- 실패 응답: HTTP 401 + JSON-RPC error(사유는 서버 로그에만 남고 클라이언트에는 구분되지 않음)

### 포트 결정 우선순위

`-RpcPort=` 커맨드라인 > `DefaultGame.ini [RpcServer] Port` > 소스 기본값 13510
`-RpcPort=0`은 **서버 미기동**(리스닝 소켓 자체를 만들지 않음)을 뜻한다.

> ⚠ `-RpcPort=`로 포트를 바꾸면 `ListenerOverrides`의 `Port=13510`과 매칭되지 않아 **조용히 localhost로 폴백**한다.
> 기동 로그의 `[RPC] JSON-RPC 서버 시작: ... (bind=any, auth=token, method 79개)` 줄에서 `bind=` 값으로 확인할 것.

## 3. 보안 경고 — 진행 전에 반드시 읽을 것

1. **토큰 값이 저장소에 평문 커밋돼 있다.** `DefaultGame.ini:20` `Token=apark3d`.
   같은 파일 19행 주석이 "실제 토큰 값은 저장소에 커밋하지 않는다"라고 못박고 있는데 위반 상태다.
   바인드가 `any`이므로 **저장소를 볼 수 있는 사람 = LAN에서 79개 메서드를 전부 호출할 수 있는 사람**이다.
   외부 개방 전에 토큰을 재발급하고 ini에서 값을 빼는 것을 권장한다(로컬 전용 override 또는 `-RpcToken=`).
   단 `-RpcToken=`은 엔진이 로그에 평문 에코하므로(QA B-1 실측) 그 자체로 완전한 해법은 아니다.
2. **토큰 문자셋은 `[A-Za-z0-9_-]` 뿐이다.** 콤마·괄호·공백이 들어가면 경로마다 다르게 잘려
   (커맨드라인은 절단, ini는 원문 보존, 헤더는 콤마 분할) **영구 401**이 되고 토큰은 로깅 금지라 추적이 거의 불가능하다.
   위반 시 기동 로그에 Error가 남는다.
3. **`/health`와 OPTIONS는 무인증 + CORS `*`** 다. 바인드 개방 상태에서는 LAN 존재 오라클이 된다(미결 P-3).
4. **인터넷 경유 포트포워딩 금지.** VPN(Tailscale/WireGuard) 또는 SSH 터널을 쓴다.

## 4. 외부 PC 접속 — A안: RPC를 직접 호출 (권장)

```
[외부 PC]                                    [Park3D PC 192.168.0.125]
클라이언트/브리지 ──HTTP:13510──────────────> Park3D /rpc
```

### 4-1. Park3D PC — 방화벽 인바운드 허용 (관리자 권한)

**출발지 IP를 반드시 한정한다.** `-RemoteAddress`를 빼면 네트워크 전체에 열린다.

```powershell
New-NetFirewallRule -DisplayName "Park3D RPC 13510" -Direction Inbound `
  -Protocol TCP -LocalPort 13510 -RemoteAddress <외부PC_IP> -Action Allow
```

이 명령은 `.claude/settings.json`에서 의도적으로 `ask`로 두었으므로 매번 승인 확인이 뜬다.

**롤백**: `Remove-NetFirewallRule -DisplayName "Park3D RPC 13510"`
**바인드까지 되돌리려면**: `DefaultEngine.ini`의 `+ListenerOverrides` 한 줄 삭제 + 재기동.

### 4-2. Park3D 기동

에디터 PIE 또는 패키지 exe가 떠 있어야 13510이 리슨한다. 기동 후 확인:

```powershell
netstat -ano | Select-String "13510"     # 0.0.0.0:13510 LISTENING 이어야 함
```

로그에서 `[RPC] JSON-RPC 서버 시작: http://0.0.0.0:13510/rpc (bind=any, auth=token, ...)` 확인.
`bind=localhost`로 나오면 외부에서 절대 붙지 않는다.

### 4-3. 외부 PC에서 확인

```powershell
# ① 생존 확인 (무인증)
curl http://192.168.0.125:13510/health

# ② 인증 포함 RPC 호출
curl -X POST http://192.168.0.125:13510/rpc `
  -H "Content-Type: application/json" `
  -H "X-Park3D-Token: apark3d" `
  -d '{"jsonrpc":"2.0","id":1,"method":"system.catalog"}'
```

②가 79개 메서드 배열을 돌려주면 성공. 401이면 토큰, 무응답/타임아웃이면 방화벽 또는 바인드 문제다.

> ⚠ **자기 LAN IP로 자기 자신에게 접속하는 것은 검증 대체재가 아니다.**
> 동일 호스트 트래픽은 방화벽을 통과하지 않으므로 반드시 다른 PC에서 확인한다.

### 4-4. 외부 PC의 MCP 설정 (Claude Code)

외부 PC에도 `server.py`를 복사해 두고(uv가 로컬에서 실행하므로):

```json
{
  "mcpServers": {
    "park3d-rpc": {
      "type": "stdio",
      "command": "uv",
      "args": ["run", "<외부PC의 server.py 경로>"],
      "env": {
        "PARK3D_RPC_URL": "http://192.168.0.125:13510",
        "PARK3D_RPC_TOKEN": "apark3d",
        "PARK3D_RPC_TIMEOUT": "30"
      }
    }
  }
}
```

- `PARK3D_RPC_TIMEOUT`: 기본 15초. 원격 + `cam.captureJPG` 같은 무거운 호출을 감안해 30 권장.

## 5. 외부 PC 접속 — B안: MCP 브리지를 HTTP로 노출 (13520)

외부 PC에 파이썬/uv를 깔기 싫거나, RPC 포트를 열지 않고 MCP 경계만 열고 싶을 때.

```
[외부 PC]                        [Park3D PC 192.168.0.125]
MCP 클라이언트 ──HTTP:13520──> server.py ──localhost:13510──> Park3D
```

### Park3D PC에서 브리지 기동

```powershell
$env:PARK3D_MCP_TRANSPORT   = "http"
$env:PARK3D_MCP_HOST        = "0.0.0.0"
$env:PARK3D_MCP_PORT        = "13520"
$env:PARK3D_MCP_TOKEN       = "<MCP 경계 토큰>"          # 비루프백 바인드에서는 필수
$env:PARK3D_MCP_ALLOWED_HOSTS = "192.168.0.125:13520"    # DNS 리바인딩 보호. 비우면 보호가 조용히 꺼진다
$env:PARK3D_RPC_URL         = "http://localhost:13510"
$env:PARK3D_RPC_TOKEN       = "apark3d"                  # http 모드에서는 필수
uv run D:/Work/UnrealWork/Parking/park3d-rpc-mcp/server.py
```

- **2홉 독립 인증**: MCP 경계(13520)와 RPC 경계(13510)가 각각 별도 토큰을 검사한다. 두 토큰을 같게 두지 말 것.
- `PARK3D_MCP_ALLOWED_HOSTS`가 비면 DNS 리바인딩/Origin 보호가 **경고 없이** 꺼진다(미결 P-4). `0.0.0.0` 바인드 시 반드시 지정한다.
- 방화벽도 13520에 대해 4-1과 동일하게 출발지 한정 규칙을 추가한다.

외부 PC의 MCP 클라이언트는 `http://192.168.0.125:13520/mcp`에 `X-Park3D-Token: <MCP 경계 토큰>` 헤더로 붙는다.

## 6. 외부 PC 접속 — C안: SSH 터널 (가장 안전 / 포트 개방 불필요)

방화벽에 아무것도 열지 않고, 바인드가 `localhost`로 돌아가더라도 동작한다.

```powershell
# 외부 PC에서
ssh -N -L 13510:localhost:13510 user@192.168.0.125
```

이러면 `PARK3D_RPC_URL`은 `http://localhost:13510` 그대로 두면 된다.
터널의 마지막 구간을 sshd가 Park3D PC **내부에서** 접속하므로 RPC 서버 입장에서는 로컬 요청으로 보인다.
단, **토큰이 설정돼 있으면 터널 경유라도 `X-Park3D-Token`은 여전히 필요하다**(루프백 우회 없음).

Park3D PC 사전 준비 (관리자 권한, 이전 실측상 sshd는 설치됨 / Stopped / Manual):

```powershell
Start-Service sshd
Set-Service sshd -StartupType Automatic
```

## 8. 운용상 주의점

1. **Park3D가 실행 중이어야 한다.** 꺼져 있으면 브리지는 연결 실패 error를 반환한다.
2. **패키지 exe는 아직 구버전이다.** 2026-07-29 빌드 = 포트 13120 + 인증 코드 없음.
   콘텐츠만 재쿠킹하면 "인증 없는 exe + bind=any ini" 조합이 되어 79개 메서드가 LAN에 무인증 노출된다. **전체 재패키징**이 필요하다.
3. **캡처 응답 크기.** `cam.captureJPG/PNG`는 base64 이미지를 반환한다(실측 48,842B). 원격이면 전송량·타임아웃을 함께 고려한다.
4. **`unreal` MCP(8000)는 별개다.** 언리얼 에디터 조작용이며 이 설정과 무관하다.
5. **승인 규칙에 포트 번호를 박지 말 것.** `.claude/settings.json`은 `http://localhost:*`로 끊는다.
   과거 13120이 박혀 있다가 포트 변경으로 3항목이 한꺼번에 죽은 사고가 있다.
