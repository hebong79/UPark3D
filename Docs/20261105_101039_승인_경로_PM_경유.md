# 머지·푸시·재쿡·정본 교체·재기동 승인을 PM 경유로

마스터 지시(2026-11-05): 「다른쪽 워커의 머지, 푸시,교채, 재기동은 pm이 마스터 한테 승인을 받고 진행할수 있게 설정해줘. ( 워커가 직접 승인을 안받아도 pm이 승인을 받으면 진행할수있게 변경 )」

## 바뀐 것

- 전: 마스터가 워커 창에서 직접 승인해야 했다. PM 이 전한 승인은 인정하지 않았다.
- 후: PM 이 마스터에게 승인을 받아 대상과 마스터 원문을 적어 명령하면 워커는 다시 묻지 않고 진행한다. 마스터가 워커 창에서 직접 승인해도 된다.
- 그대로: 재빌드는 PM 승인, 실행은 Sonnet 서브에이전트. 원문 없는 명령이나 다른 세션이 전한 말은 승인이 아니다.

재쿡은 마스터 문장에 없지만 같은 규칙에 묶인 단계라 함께 옮겼다.
