# [질문 답변] unreal-umg-designer 스킬을 다른 UI 대화상자에 적용 가능한가?

- **일시**: 2026-06-24 15:24
- **질문**: 이 스킬은 다른 UI 대화상자를 만들 때 적용 가능한가?

---

## 결론: 가능 (대부분 범용)

`unreal-umg-designer` 스킬의 기법은 **위젯 타입 기반의 일반 UMG/MCP 방법**이라 차량배치 대화상자에 한정되지 않는다. 새 대화상자에서는 **위젯 이름과 에셋 경로만 교체**하면 동일하게 재현된다.

### 그대로 재사용되는 것(범용)
- 구조: `add_widget`(루트/컨테이너/위젯, index 순서, BindWidget 이름 규약), `move_widget`(재구성)
- 위치: CanvasPanelSlot `LayoutData`(Anchors/Alignment/Offsets), 우상단/고정패널
- 크기: `MinimumDesiredWidth`, `SizeBox`(WidthOverride/HeightOverride), Fill
- 패딩: 슬롯 `Padding`(행/열/라벨 간격)
- 폰트: 타입별 경로(TextBlock `Font` / EditableTextBox `WidgetStyle.TextStyle.Font` / ComboBox `Font`)
- 색상: `ColorAndOpacity`, Border `BrushColor`, 콤보 `ItemStyle`(흰 배경+검정)
- 정렬: 라벨 `MinDesiredWidth`
- 워크플로/함정: compile→save→screenshot, PIE 중 `open_asset` 실패, screenshot 모드

## 상황별 보강 포인트
| 상황 | 대응 |
|------|------|
| 새 위젯 타입(Slider/ProgressBar/ListView/WrapBox/UniformGridPanel 등) | 폰트·색상·스타일 속성 **경로가 타입마다 다름** → `get_widget_properties`로 경로 확인 후 스킬에 케이스 추가 |
| C++ 바인딩 없는 순수 BP 대화상자 | BindWidget 이름 규약 불필요, 부모 `UserWidget`로 자유 구성 |
| 다른 프로젝트 | 예시 경로(`/Script/Park3D.*`, `/Game/UI/*`)·DPI 1.333·Live Coding 전제만 교체 |

## 운영 방식(스킬을 키우는 법)
- 새 위젯 타입을 만나면 7절(색상)·6절(폰트)처럼 **타입별 함정/속성 경로를 한 줄씩 추가** → 점진적으로 더 강력한 범용 스킬이 된다.
- 핵심: **기법은 범용, 위젯 타입별 속성 경로만 그때그때 확인·보강**.
