# 레벨 액터 이동 config `levels[].move_actors` — 객리단길 무인정산기 오른쪽 이동

- 날짜: 2026-09-30
- 브랜치: `feat/level-actor-move`
- 요청: "건물(무인정산기)을 오른쪽으로 이동해줘" → "진행해줘"(재기동해도 유지되게)

## 1. 대상

| 항목 | 값 |
|---|---|
| 레벨 | `LV_Park_03`(객리단길) |
| 액터 | `StaticMeshActor_128` (라벨 `SM_ParkingBooth2`, 메시 `/Game/Environment/Props/RoadProps/SM_ParkingBooth`) |
| 원래 위치 | (−7.8135, −33.3348, 0.005) m, yaw −19° |
| 새 위치 | (−7.3165, −31.7978, 0.005) m, yaw 유지 |
| 이동 | 도로축(yaw 72.09°) 방향 +1.615 m = UE Δ(+0.497, +1.537) m |

위치 근거: 정산기는 5번 면 끝(도로축 s = −36.67 m)과 7번 면 시작(s = −28.34 m) 사이 8.33 m 빈 칸(6번 건너뜀)에서
5번 쪽(1번 폴대 옆, s = −34.12)에 붙어 있었다. 메인 뷰(yaw 2.9°)의 화면 오른쪽 ≈ +Y ≈ 도로축 방향이므로 도로축을 따라
빈 칸 가운데(s = −32.51)로 옮겼다. 거리는 사용자가 지정하지 않아 "빈 칸 가운데"로 정했다.

yaw −19° 근거: 레벨 액터 회전을 알려주는 RPC 가 없어, 같은 메시를 yaw 0 으로 스폰해 원 바운즈 1.859×1.483 m 를 재고
현 바운즈 2.240×2.007 m 에서 |yaw| = 19° 를 풀었다. 부호·180° 모호성은 원본 위에 겹쳐 캡처해 가렸다(−19° 는 완전히 겹침,
161° 는 두 개가 어긋나 보임). 기동 로그의 실제 회전도 −19.00 이었다.

## 2. 왜 코드가 필요했나

- `env.update` 는 `env.create` 로 만든 프롭(`EnvProp` 태그)만 옮긴다 — 레벨 액터는 `프롭 없음` 으로 거부.
- 레벨 `.umap` 은 에디터 없이 못 고치고 `Content/` 는 git 밖이다.
- 그래서 `hide_actors`·`slot_file` 과 같은 "레벨 에셋을 안 고치고 기동 때 런타임에 덮는" 규약으로 config 키를 추가했다.

## 3. 변경

### `Config/Park3DAppConfig.h/.cpp`
- `FPark3DActorMove { Name, PosM(미터), TOptional<float> Yaw }` 신설(USTRUCT 아님 — JSON 파서 전용).
- `FPark3DLevelOption::MoveActors` 추가(비-UPROPERTY). `levels[].move_actors` 파싱:
  `name` 과 `pos{x,y,z}` 가 **모두** 있어야 받고(한 축만 빠져 0 으로 날아가는 사고 방지), 없으면 경고 후 건너뜀. `yaw` 는 선택.
- **최상위 키는 두지 않았다** — 액터 이름은 레벨마다 달라서(같은 `StaticMeshActor_128` 이 다른 레벨에선 다른 물체) 주차장 항목에만 둔다.

### `Park3DGameMode.h/.cpp`
- `ApplyConfigMovedActors()` 신설, BeginPlay 에서 `ApplyConfigHiddenActors()` 바로 뒤에 호출.
- 현재 레벨의 `levels[]` 항목을 `ApplyLevelOverrides` 로 찾아 이름이 맞는 액터를 옮긴다.
- 레벨의 StaticMeshActor 는 **Static** 이라 그대로 `SetActorLocation` 하면 거부된다 → 루트가 Static 이면 Movable 로 바꾼 뒤 옮김.
- 로그: 액터마다 `[Env] config move_actors: <이름> → (x, y, z) m, yaw …`, 끝에 `적용(<주차장>): n/m 이동 — 못 찾음: …`.

### `Tests/Park3DAppConfigTest.cpp`
- `Park3D.AppConfig.MoveActors` 신설 — 정상 2건, pos.z 없는 항목·name 없는 항목 버림, 이름 공백 제거, yaw 선택, 키 없는 항목은 빈 목록.

### `Save/Config/config_pmaker.json`
객리단길 항목에 추가:
```json
"move_actors": [ { "name": "StaticMeshActor_128", "pos": { "x": -7.3165, "y": -31.7978, "z": 0.005 } } ]
```

## 5. 정본 반영 시 주의

- 정본(13510)에는 이 작업 중 RPC 로 임시 처리가 걸려 있다: `StaticMeshActor_128` `env.hide` + 프롭 `ParkingBooth2_Moved` 스폰. 재기동하면 둘 다 사라지고 config 가 대신한다.
- **exe 와 `Save/Config/config_pmaker.json` 을 함께** 바꿔야 한다. config 만 먼저 넣으면 옛 exe 는 모르는 키라 무시(무해),
  exe 만 먼저 넣으면 정산기가 원래 자리.
- 이동 거리를 바꾸려면 config 의 `pos` 만 고치고 재기동(또는 레벨 재진입)하면 된다.
