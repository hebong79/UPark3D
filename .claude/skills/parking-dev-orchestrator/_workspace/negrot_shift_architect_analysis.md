# 분석/설계 — 음수 회전 시 위치 이동 버그

## 증상
FaceRotate가 음수일 때 주차면 그룹이 제자리 회전하지 않고 반대편으로 평행이동.

## 근본 원인 (DrawPreset)
면 누적 배치량 `Disp = Step * j * Sign`. `Sign`이 0~360 정규화 각도로 계산됨:
```
Norm = fmod(FaceRot,360); if(Norm<0) Norm+=360; Sign = (Norm>180)? -1 : +1;
```
- 음수 각도(-θ)는 360-θ로 정규화 → >180 → Sign=-1 → 배치 방향 반전 → 그룹 위치가 Origin 반대편으로 이동.
- `Step`은 `Xs/|cos|`로 부호 대칭이므로 간격은 동일, **방향만** 뒤집혀 위치가 틀어짐.
- Dir 모드도 Disp에 Sign이 곱해져 동일 영향.

## 수정안 (최소·외과적)
배치 진행 방향은 회전 부호와 무관해야 한다(제자리 회전). `Sign` 반전 제거 → `Disp = Step * j`.
- 양수(<180) 케이스는 원래 Sign=+1 → 영향 없음(회귀 없음).
- 음수/>180 케이스만 +방향으로 교정 → 양수와 대칭 제자리 회전.
- 사용되지 않게 된 Norm/Sign 변수 제거(CLAUDE.md 3번).

## 대안 비교
| 방안 | 채택 | 사유 |
|------|------|------|
| Sign 반전 제거(상수 +1) | ○ | 양수 영향 0, 음수 대칭 교정, 최소 변경 |
| 부호있는 각도로 Sign 재정의 | ✕ | 제자리 회전 요구상 방향은 상수여야 함 |
| Step에 부호 반영 | ✕ | 간격(절댓값)과 방향은 별개, 부적절 |

## 영향
- DrawPreset 시각화만 변경(저장 데이터/JSON 스키마 불변).
- GroupFaceRotate·Default/Dir 모두 동일 적용.

## 테스트 포인트
- +θ와 -θ에서 그룹 위치 동일(Origin 시작), 면 틸트만 반대.
- 0°에서 변화 없음.
- FaceCount>1에서 면들이 같은 +방향으로 누적.
- 재빌드 후 음수 회전 시 위치 고정 확인.
