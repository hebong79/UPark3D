## 2. 무엇을 더 남기나 (`_inventory.json` 스키마 변화)

| 위치 | 키 | 내용 | 단위 |
|---|---|---|---|
| 액터 | `rotation`, `scale` (신규) | 액터 월드 회전(roll,pitch,yaw)·스케일. 기존엔 `location` 만 있었다 | deg / 배율 |
| ISM·HISM·FoliageISM 컴포넌트 | `instance_transforms` (신규) | 인스턴스마다 `{loc, rot, scale}` — **월드 공간**(`world_space=True`). 개수는 기존 `instances` 와 같다 | cm / deg / 배율 |
| ISM 컴포넌트 | `instance_error` (실패 시만) | 예외 문자열. 이번 실행 0건 | |
| SplineMeshComponent | `spline` (신규) | `start_pos/start_tangent/end_pos/end_tangent`(컴포넌트 로컬, cm), `start_scale/end_scale`(2D), `forward_axis`(`X`/`Y`/`Z`) | cm |

기존 키(`world_location/world_rotation/world_scale`, `mesh`, `materials`, `instances`, `local_bounds_cm` …)는 그대로다. 소비자 쪽 조립 규칙:
- 일반 `StaticMeshComponent` → 컴포넌트 `world_*` 로 배치.
- ISM 계열 → `instance_transforms[i]` 가 곧 월드 변환이라 컴포넌트 변환을 **다시 곱하지 않는다**.
- SplineMesh → 메시 원형을 `spline` 의 양 끝 파라미터로 변형하고, 그 결과를 컴포넌트 `world_*` 로 배치한다(스플라인 파라미터는 로컬).

### 3.1 월드 공간 검증
인스턴스 위치가 액터 바운즈(`get_actor_bounds`) 안에 드는지 전수 대조(여유 50 cm): **2,261 중 2,198 안쪽**, 63 바깥. 바깥 63 은 전부 **액터 바운즈 자체가 퇴화한 액터**다 — `InstancedFoliageActor0`(바운즈 0, 45건), `BP_Barrier_Sidewalk_Fence`·`BP_UtilityPole`·`BP_Road_Creator5/12`(origin == extent 꼴로 `get_actor_bounds` 가 ISM 인스턴스를 바운즈에 안 넣은 것, 18건). 즉 변환이 로컬로 잘못 나온 것이 아니라 대조 기준이 빈 것이다. 로컬 공간이었다면 건물 1,980개가 액터 원점 근처(수 m)에 몰렸을 텐데 실제로는 레벨 전역(수십 m)에 퍼져 있다.

## 4. 밟은 것 / 알아 둘 것

1. **`get_instance_transform` 반환형이 버전에 따라 다르다** — 5.8 은 `Transform`(실패 시 None)을 돌려주지만 예전 바인딩은 `(bool, Transform)` 튜플이다. 스크립트는 둘 다 받는다(`_instance_transforms`).
2. **`get_actor_bounds` 는 ISM 인스턴스를 안 센다**(3.1). 이전 문서의 `bounds_cm` 를 "액터가 차지하는 영역" 으로 믿으면 건물·전봇대·펜스에서 틀린다 — 영역이 필요하면 `instance_transforms` 에서 직접 계산할 것.
3. 열거형은 `str(enum)` 이 `<SplineMeshAxis.X: 0>` 로 나온다 → `.name` 으로 `X`. 첫 실행이 이 꼴로 나와 한 번 더 돌렸다(2회차가 최종 파일).
4. commandlet 로그의 `BP_PlayerController` 컴파일 에러 26건(`OpenFileDialog`/`SaveFileDialog` 없음)은 **`-DisablePlugins=EasyFileDialog` 때문에 나는 기존 잡음**이며 인벤토리에 영향 없다(이전 export 도 같은 인자였다).
5. `MaterialEditingLibrary.get_used_textures` 는 5.8 에서 deprecated 경고(대체 `GetMaterialUsedTextures`)만 내고 동작한다 — 이번 범위 밖이라 두었다.
6. 이 작업본(`UnrealWork2`)에는 이전 세션의 `Saved/USDExport/Env` 산출물(메시 120·텍스처 34)이 없다. USD 메시 라이브러리가 필요하면 `run_export_env.py` 를 인자 없이 다시 돌려야 한다(인벤토리는 이제 있으므로 export 단계부터 진행된다).
7. 팀 보드(baro_memo)는 이 PC 에 토큰 설정(`~/.config/baro-memo/env`)이 없어 검색·기록을 못 했다.

## 5. 검증된 것 / 안 된 것

**검증:** 파이썬 문법, commandlet 정상 종료(`Python script executed successfully`), 인스턴스 수 = 변환 수(2,261), `instance_error`·`spline_error` 0건, 알려진 수치(차단봉 82·스토퍼 46)와 일치, 월드 공간 여부(3.1).
**미검증:** Omniverse 쪽에서 이 JSON 으로 조립한 화면 — 이 PC 에 Omniverse 가 없다. 스플라인 메시 파라미터(로컬 좌표)를 소비자 쪽이 어떻게 변형하는지는 UPark3D 구현에 달려 있다.
