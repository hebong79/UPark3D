# Content 폴더 사용/미사용 분류

- 일시: 2026-08-16 18:51 (KST)
- 대상: `Park3D/Content` (5,395개 패키지 / 6,606 MB)
- 목적: 콘텐츠 교체 후 무엇이 실제로 쓰이는지 가려, SVN 커밋 범위와 정리 범위를 정하기 위함
- **삭제는 하지 않았다.** 분류·집계만 했다.

## 1. 방법

에디터 없이 `.uasset`/`.umap` 패키지에서 참조 패키지 경로(`/Game/...`)를 직접 뽑아
루트에서 BFS 했다. UE 는 FName 을 순수 ASCII 면 ANSI, 아니면 UTF-16LE 로 저장하므로
**두 인코딩을 모두 훑는다**(`기아_EV6` 같은 한글 에셋명 때문에 필수 — ASCII 만 훑으면 차량이
전부 미사용으로 잘못 나온다).

문자열 스캔이라 하드 레퍼런스뿐 아니라 소프트 레퍼런스·문자열 경로도 잡힌다.
= 실제 의존성의 **상위집합** → "사용 중"을 넓게 잡는, 삭제 판단에 안전한 방향으로 틀린다.

스크립트: `_workspace` 밖(임시)에서 실행. 결과 목록은 아래 §5.

| 액터 | 개수 | 용량 |
|---|---:|---:|
| LandscapeStreamingProxy | 128 | 30.20 MB |
| Landscape | 1 | 0.01 MB |
| DirectionalLight / SkyLight / SkyAtmosphere | 각 1 | ~0 |
| ExponentialHeightFog / VolumetricCloud | 각 1 | ~0 |

**즉 원래 이 맵에는 Landscape 지표면이 있었다.** 그리고 코드가 그걸 전제로 한다 —
`AMapFloorActor` 는 일부러 `NoCollision` 이고, 커서 피킹과 거리 측정은 Landscape 를 히트하도록
설계돼 있다:

- `MapFloorActor.h:4` — "커서 트레이스(ECC_Visibility)는 기존대로 Landscape 를 히트한다"
- `MapFloorActor.cpp:79` — "콜리전을 켜면 커서 피킹 6곳이 Landscape 대신 바닥을 히트해 pos.y 가 드리프트"
- `MeasureRpcModule.cpp:92`, `ViewRpcModule.cpp:265` — "지면은 Landscape 가 받는다"
- `MapFloorLibrary.h:19` — "MaxSizeM=500 은 Landscape 평탄 구간의 실측 한계"

`__ExternalActors__` 가 빠지면서 Landscape 도 같이 사라졌으므로,
**커서 피킹 6곳 · `measure.*` · `view.pick` 이 지금 지면을 못 잡을 가능성이 높다.**
(런타임 미검증 — 추론이다. 조명과 달리 이건 코드로 보완하지 않았다.)

한편 이 조사로 **`__ExternalActors__` 복원이 새 콘텐츠 판정을 바꾸지 않는 것도 확인**됐다.
그 138개 패키지가 참조하는 `/Game` 에셋은 자기 레벨(`/Game/Maps/PresetMaker1`) 하나뿐이라,
복원해도 Environment 등이 "사용 중"으로 바뀌지 않는다.

## 6. 실행 — 미사용분 분리 (19:0x 추가)

사용자 결정: `__ExternalActors__`/`__ExternalObjects__` 는 복원하지 않고 **새로 구성**한다.
현재 구조를 중심으로 두고, **현재 사용 중인 것만 남기고 나머지는 전부 분리**한다.

### 한 일

`Park3D/Content` → `Park3D/_UnusedContent` 로 **이동**(삭제 아님). 기준은 §2 의 75개.

| | 개수 | 용량 |
|---|---:|---:|
| `Content/` 에 남김 | 75 | 796 MB |
| `_UnusedContent/` 로 이동 | 5,322 | 5,811 MB |

이동 대상에는 에디터가 되만든 `__ExternalActors__/Maps/PresetMaker1/A/RP/...` 스텁 1개와
에셋이 아닌 잔여물(`Road_Creator_Pro/Blueprints/Decals/Decals.rar`)도 포함된다.
빈 디렉터리 517개를 정리했다(최상위 `Collections/`·`Developers/` 도 비어 있어 함께 제거 — UE 가 필요 시 다시 만든다).

### 정리 후 Content 구조

```
Content/
  Actors/Car/{Meshs, Materials, Textures, Plates/{Meshs,Materials,Font,Textures}}
  Environment/Masters          (M_World + 기본 텍스처)
  M/{, Decal}                  (바닥·데칼 머티리얼)
  Maps/                        (PresetMaker1 + HLOD)
  Road_Creator_Pro/Textures/Asphalt
  UI/
```

### 왜 `_UnusedContent` 인가

UE 는 `<Project>/Content` 만 스캔한다. `<Project>/_UnusedContent` 는 프로젝트 폴더 안이라
찾기 쉬우면서도 **엔진이 로드하지 않는다**. `.gitignore` 에 추가해 git 에도 안 잡힌다.

### 되돌리기

```
python Park3D/_UnusedContent/restore_unused.py     # 전체 복원
```
개별 복원은 `Park3D/_UnusedContent/_manifest.json` 의 `moved` 목록에서 상대경로를 보고
같은 경로로 `Content/` 에 되옮기면 된다.

### 검증 (실측)

- 에디터 기동 로그: **이동으로 인한 신규 누락 0건.** 뜨는 `LoadErrors` 2건은 분리 전부터 있던
  기존 끊어진 참조다(`WBP_CarPlacement→DT_CarCatalog`, `PresetMaker1→외부 액터 스텁`).
- PIE: `[CarPlacement] 메시 프리로드 23개`, `[ParkingManager] 데칼 92개 활성`, 조명 4종 생성 —
  분리 전과 동일.
- `cam.capturePNG` 캡처 결과가 분리 전과 육안으로 동일(차량·주차면 선·바닥·그림자).

## 7. 판단이 필요한 것 (아직 아무것도 지우지 않음)

1. **`_UnusedContent` 5.7GB 를 지울 것인가.** 아직 지우지 않았다. `Content/` 는 git 제외이고
   SVN 에도 극히 일부(`Camera`·`UI`·`M`·`__ExternalActors__`·`__ExternalObjects__`)만 있어
   **지금 이 PC 가 나머지의 유일한 사본일 수 있다** → 지우면 복구 불가. 백업 후 판단할 것.
2. **새 무대를 만들 때 필요한 자산이 `_UnusedContent` 에 있다.** 건물·도로·소품·하늘(UDS)이
   전부 그쪽으로 갔다. 필요해지면 §6 의 복원 방법으로 개별로 꺼내 쓰면 된다.
3. **Landscape 가 없다** (§4). 커서 피킹·`measure.*`·`view.pick` 이 지면으로 쓰던 것이
   `__ExternalActors__` 와 함께 사라졌고, 사용자 결정에 따라 복원하지 않는다.
   새 무대를 구성할 때 **지면 콜리전을 무엇이 받을지 정해야 한다**(Landscape 를 새로 깔거나,
   `AMapFloorActor` 의 `NoCollision` 을 재검토하거나). 이건 코드로 아직 보완돼 있지 않다.
