# UE 5.8 업그레이드 후 프로젝트가 안 열리는 원인 분석

- **일시**: 2026-06-26 16:11
- **증상**: UE 5.8로 업그레이드 후 Park3D 프로젝트(C++ 프로젝트)가 열리지 않음.
- **결론**: 에디터 C++ 모듈 **재빌드 실패** — 프로젝트 빌드 설정(`BuildSettingsVersion.V6`)이 설치형 UE 5.8 엔진의 **공유 빌드 환경 강제 규칙과 충돌**.

---

## 1. 근거 (UnrealBuildTool Log.txt, 2026-06-26 16:06)

```

Using EngineIncludeOrderVersion.Unreal5_7 for target Park3DEditor.Target.cs
...

  [ UnreachableCodeWarningLevel: Off != Error,

bOverrideBuildEnvironment = true ...
BuildException: ...
Result: Failed (OtherCompilationError)
```

## 2. 원인 체인

1. C++ 프로젝트라 5.8에서 열려면 에디터 모듈을 5.8용으로 **재빌드**해야 함.
2. `Source/Park3DEditor.Target.cs` / `Park3D.Target.cs`:
   ```csharp
   DefaultBuildSettings = BuildSettingsVersion.V6;            // 경고레벨 Off
   IncludeOrderVersion  = EngineIncludeOrderVersion.Unreal5_7;
   ```
   **V6**는 `UnreachableCodeWarningLevel / ReturnTypeWarningLevel / DanglingWarningLevel`을 **Off**로 설정.
3. 설치형 UE 5.8 엔진의 `UnrealEditor`는 5.8 새 기본값(위 경고들 = **Error**)으로 사전 빌드됨. 프로젝트 에디터 타깃은 그 엔진과 **빌드 환경(컴파일러 플래그 등)을 공유**.
4. **UBT 5.8부터** 프로젝트가 공유 환경 속성을 덮어쓰는 것을 **금지**(5.7까지는 경고 후 허용). → `Off != Error` → BuildException → 모듈 미빌드 → 에디터 미기동.

> 즉 엔진이 일반적으로 막은 게 아니라, **프로젝트 빌드 설정(V6/5_7)이 5.8 설치 엔진의 강제 규칙과 불일치**해 재빌드가 거부됨. 실패 대상은 복사본 `Park3D 5.8 - 2`(5.8 시험용 복제본). 원본 `Park3D`(5.7)는 정상.

## 3. 해결 방법

대상: 5.8 복사본의 `Source/Park3DEditor.Target.cs` + `Park3D.Target.cs`.

| 방법 | 변경 | 비고 |
|------|------|------|
| **권장** | `BuildSettingsVersion.V6` → **`V7`(또는 `Latest`)**, `Unreal5_7` → **`Unreal5_8`(또는 `Latest`)** | 5.8 기본값과 일치 → 충돌 해소. 단 새 엄격 경고(미도달코드/반환값/댕글링)가 **우리 C++ 또는 UnrealMCP 플러그인**에서 컴파일 에러로 표출될 수 있어 그건 추가 수정 필요 |
| 빠른 우회 | 두 타깃 생성자에 **`bOverrideBuildEnvironment = true;`** | 기존 설정 유지하며 빌드 통과(경고 레벨 Off 유지). 가장 적은 변경 |
| 비권장 | `BuildEnvironment = TargetBuildEnvironment.Unique;` | 엔진을 프로젝트 전용으로 따로 빌드(무겁고 설치형엔 부적합) |

추가 점검(빌드 통과 후 가능):
- `.uproject` `EngineAssociation`을 `5.8`로 갱신.
- **UnrealMCP 플러그인**의 5.8 API 호환성(공유환경 에러를 넘기면 다음으로 플러그인/코드 컴파일 단계에서 막힐 수 있음).
- 5.8 `IncludeOrderVersion` 적용 시 인클루드 순서 변화로 인한 누락 헤더.

## 4. 권고 절차
1. 5.8 복사본 두 Target.cs를 **권장안**(V7/5_8 또는 Latest)으로 수정.
2. 생성된 솔루션/Binaries/Intermediate 정리 후 에디터로 열어 모듈 재빌드 유도(또는 UBT로 `Park3DEditor Win64 Development` 빌드).
3. 컴파일 에러가 나면 신규 엄격 경고·플러그인 호환성 항목을 개별 수정.
