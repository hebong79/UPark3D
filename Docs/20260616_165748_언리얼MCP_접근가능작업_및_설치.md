## 2. 최초 점검 결과 (설치 전 상태)

세션 진단 시 Unreal MCP 툴이 하나도 로드되어 있지 않았으며, 원인은 다음 2가지였다.

### 2.1 MCP 모듈 미설치
```
python -m unreal_mcp  →  No module named unreal_mcp
```
`.mcp.json`에 `unreal` 서버가 등록되어 있으나 실제 파이썬 패키지가 없어 서버가 기동되지 않았다.

### 2.2 `.mcp.json` JSON 문법 오류
```json
"UE_PROJECT": "D:\Work\Unreal\Test\Parking\Park3D/Park3D.uproject"
```
`\W`, `\T`, `\P` 는 JSON에서 잘못된 이스케이프 시퀀스라 파싱이 실패한다.
→ `\\` 이중 백슬래시 또는 `/` 슬래시로 교체해야 한다.

## 3. Unreal MCP로 할 수 있는 일 (정상 동작 시)

서버 구현마다 툴 이름은 다르지만, 대표적으로 다음 작업이 가능하다.

| 분류 | 가능한 작업 |
|------|-------------|
| 액터(Actor) 제어 | 레벨에 액터 스폰/삭제, 위치·회전·스케일 변경, 속성 조회/수정, 액터 목록 조회 |
| 레벨 / 뷰포트 | 레벨 액터 나열, 카메라 포커스 이동, 뷰포트 스크린샷 캡처 |
| 블루프린트(Blueprint) | BP 클래스 생성, 컴포넌트 추가, 변수·함수 추가, 노드 연결, 컴파일 |
| 에셋(Asset) | 메시/텍스처/머티리얼 임포트, 머티리얼 생성, 에셋 검색 |
| UMG / 위젯 | UI 위젯 블루프린트 생성 및 구성 |
| 에디터 파이썬 실행 | 에디터 내장 Python으로 임의 스크립트 실행 (가장 강력) |
| 빌드 | 프로젝트 컴파일/빌드 트리거 |

활용 예시: "주차장 차량 액터를 레벨에 배치 → 블루프린트 로직 작성 → 스크린샷으로 확인"
같은 작업을 대화로 지시 가능. 프로젝트 규칙(동작 확인, Play/Edit Mode 검증)과도 부합.

## 4. 설치한 패키지

- 패키지명: `unrealmcp` (PyPI)
- 용도: Unreal Engine 5용 MCP 브리지 (약 280개 명령 / 13개 카테고리)
- 실행 방식: 콘솔 스크립트 `unrealmcp` (검증 완료). 단, `python -m unrealmcp` 는 `__main__` 모듈이 없어 동작하지 않으므로 반드시 콘솔 스크립트를 사용해야 한다.
- 통신: UE 에디터 플러그인과 TCP(localhost:55557)로 JSON 통신

### 4.1 UE 측 추가 요구사항 (중요)
패키지만으로는 동작하지 않으며, **UE5 프로젝트에 C++ 에디터 플러그인 `UnrealMCPBridge` 설치가 필요**하다.
- 필요한 엔진 플러그인: `PythonScriptPlugin`, `EditorScriptingUtilities`, `EnhancedInput`
- 권장 엔진 버전: UE 5.7 (이전 5.x 일부 호환 가능)
- 플러그인이 TCP 55557 서버를 열고, 파이썬 MCP 서버가 여기에 접속한다.

## 5. 수정한 `.mcp.json`

```json
{
  "mcpServers": {
    "unreal": {
      "command": "unrealmcp",
      "env": {
        "UE_PROJECT": "D:/Work/Unreal/Test/Parking/Park3D/Park3D.uproject"
      }
    }
  }
}
```
- 잘못된 모듈명(`python -m unreal_mcp`) → 실제 콘솔 스크립트 `unrealmcp` 로 교체
- `UE_PROJECT` 경로의 백슬래시 → 슬래시로 교체하여 JSON 유효성 확보

## 6. 영향도 분석

- **설치 영향**: pip 전역(또는 사용자) 환경에 `unrealmcp` 및 의존성(mcp 등)이 추가된다. 코드/프로젝트 소스에는 영향 없음.
- **설정 영향**: `.mcp.json` 변경은 Claude Code 세션 재시작 후 적용된다. 기존 다른 MCP 서버 설정 없음.
- **런타임 영향**: 실제 작동은 UE 에디터가 켜져 있고 `UnrealMCPBridge` 플러그인이 활성화되어 TCP 55557을 리슨할 때만 가능.

## 7. 브리지 플러그인 설치 (완료된 작업)

플러그인 소스는 패키지 저자(Aadesh Yadav)의 GitHub 저장소에서 제공된다.
- 저장소: https://github.com/aadeshrao123/Unreal-MCP

### 7.1 수행한 작업
1. 저장소를 프로젝트 Plugins 폴더로 클론
   ```
   cd D:/Work/Unreal/Test/Parking/Park3D
   git clone --depth 1 https://github.com/aadeshrao123/Unreal-MCP.git Plugins/UnrealMCP
   ```
   → `Plugins/UnrealMCP/UnrealMCP.uplugin`, `Source/UnrealMCPBridge/` 확인됨
2. `Park3D.uproject` 의 Plugins 배열에 `UnrealMCP` 활성화 항목 추가 (JSON 유효성 검증 통과)
   - `.uplugin` 자체가 `EnabledByDefault: true` 이며 의존 플러그인
     (PythonScriptPlugin, EditorScriptingUtilities, EnhancedInput, Niagara)을 선언 → 자동 활성화

### 7.2 환경
- 프로젝트: C++ 프로젝트 (Source/ + Park3D.sln 존재) → 플러그인 컴파일 가능
- 엔진: UE 5.7 (`C:\Program Files\Epic Games\UE_5.7`) — 플러그인 권장 버전과 일치
- `UnrealMCPBridge` = Editor 타입 C++ 모듈 → **최초 1회 빌드 필요**

### 8.2 연결 확인 순서
1. 위 컴파일 성공
2. UE 에디터 실행 → UnrealMCPBridge 플러그인이 TCP 55557 리슨 시작
3. Claude Code 재시작 → `unreal` MCP 서버(`unrealmcp`)가 stdio로 붙어 55557에 연결
