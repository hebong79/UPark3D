# Park3D 실행파일(.exe) 빌드 방법

작성일: 2026-06-23
대상: Park3D (Unreal Engine 5.7, Win64)

---

## 0. 사전 정보 (이 프로젝트 기준)

| 항목 | 값 |
|------|-----|
| 엔진 버전 | UE 5.7 |
| 엔진 설치 경로 | `C:\Program Files\Epic Games\UE_5.7` |
| 프로젝트 파일 | `d:\Work\Unreal\Project\Parking\Park3D\Park3D.uproject` |
| 빌드 타깃 | `Park3D` (TargetType.Game) |
| 플랫폼 | Win64 |
| 빌드 구성 | Development / Shipping (배포용) |

> **용어:** 언리얼에서 "실행파일 만들기"는 보통 **패키징(Packaging)** 을 의미한다.
> 패키징 = 컴파일(Build) + 콘텐츠 변환(Cook) + 묶기(Stage/Package) 의 전체 과정이며,
> 결과물로 `Park3D.exe` 와 실행에 필요한 콘텐츠/DLL 묶음이 나온다.

---

## 방법 A. 에디터 GUI에서 패키징 (가장 간단)

1. Park3D 에디터를 연다 (`Park3D.uproject` 더블클릭).
2. 상단 메뉴 **Platforms ▸ Windows ▸ Package Project** 클릭.
   - (구버전 위치: **File ▸ Package Project ▸ Windows**)
3. 빌드 구성을 먼저 선택해 둘 수 있다: **Platforms ▸ Windows ▸ Build Configuration**
   - `Development`: 디버깅/내부 테스트용 (로그·콘솔 사용 가능)
   - `Shipping`: 최종 배포용 (최적화, 디버그 기능 제거)
4. 출력 폴더를 지정하면 패키징이 시작된다.
5. 완료 후 `<출력폴더>\Windows\Park3D.exe` 실행.

진행 상황은 에디터 우하단 알림 또는 **Output Log** 에서 확인한다.

---

## 방법 B. 명령줄(RunUAT BuildCookRun) — 권장(반복/자동화)

에디터 없이, 또는 스크립트로 빌드할 때 사용한다. PowerShell에서:

```powershell
& "C:\Program Files\Epic Games\UE_5.7\Engine\Build\BatchFiles\RunUAT.bat" `
  BuildCookRun `
  -project="d:\Work\Unreal\Project\Parking\Park3D\Park3D.uproject" `
  -noP4 `
  -platform=Win64 `
  -clientconfig=Development `
  -cook -build -stage -pak -archive `
  -archivedirectory="d:\Work\Unreal\Project\Parking\Build"
```

### 주요 옵션 설명
| 옵션 | 의미 |
|------|------|
| `-project=` | 대상 .uproject 경로 |
| `-platform=Win64` | 타깃 플랫폼 |
| `-clientconfig=` | 빌드 구성 (`Development` / `Shipping`) |
| `-build` | C++ 코드 컴파일 |
| `-cook` | 콘텐츠를 타깃 플랫폼용으로 변환 |
| `-stage` | 실행에 필요한 파일을 출력 폴더로 복사 |
| `-pak` | 콘텐츠를 .pak 하나로 묶음 |
| `-archive` `-archivedirectory=` | 최종 결과물을 지정 폴더로 보관 |
| `-noP4` | Perforce 미사용 |

> 배포용 최종본은 `-clientconfig=Shipping` 으로 바꿔 빌드한다.

결과물: `d:\Work\Unreal\Project\Parking\Build\Windows\Park3D.exe`

## 방법 C. 코드만 빌드 (Build.bat) — 실행파일 묶기는 안 함

C++ 컴파일만 확인하고 싶을 때 (cook/stage 없음):

```powershell
& "C:\Program Files\Epic Games\UE_5.7\Engine\Build\BatchFiles\Build.bat" `
  Park3D Win64 Development `
  -project="d:\Work\Unreal\Project\Parking\Park3D\Park3D.uproject" `
  -waitmutex
```

이건 "실행파일 배포본"이 아니라 모듈 DLL/에디터 바이너리만 만든다. 컴파일 검증용.

---

## ⚠️ 이 프로젝트에서 주의할 점

1. **UnrealMCP 플러그인**
   `Park3D.uproject` 에 `UnrealMCP` 플러그인이 활성화되어 있고 타깃 제한이 없다.
   - 이 플러그인은 에디터 자동화용(MCP 소켓 서버)이다. **배포(Shipping) 실행파일에는 불필요**하며,
     포함 시 빌드 실패하거나 불필요한 네트워크 포트를 열 수 있다.
   - 배포 빌드 전, 다음 중 하나를 검토할 것:
     - `Plugins` 항목에 `"TargetAllowList": ["Editor"]` 추가, 또는
     - 패키징 시 해당 플러그인 비활성화.
   - (`ModelingToolsEditorMode` 는 이미 `Editor` 전용으로 제한되어 있어 문제없음.)

2. **첫 패키징은 오래 걸림**
   셰이더 컴파일·DDC 생성 때문에 최초 cook은 수십 분이 걸릴 수 있다. 두 번째부터 빨라진다.

3. **MCP를 통한 검증 금지**
   게임 동작 검증은 에디터 PIE가 아닌 **패키징된 standalone 실행파일**로 한다.
   (MCP `execute_python` 안에서 PIE를 시작하면 에디터가 크래시하는 이슈가 있음.)

4. **빌드 산출물은 버전관리 제외**
   `Build/`, `Saved/`, `Intermediate/` 등은 .gitignore 대상이어야 한다.

---

## 검증 절차

1. 빌드 명령이 `BUILD SUCCESSFUL` 로 끝나는지 확인.
2. `Park3D.exe` 더블클릭 → 정상 실행/렌더링 확인.
3. 윈도우 모드 강제 실행 옵션 (검증 편의):
   ```powershell
   & "d:\Work\Unreal\Project\Parking\Build\Windows\Park3D.exe" -windowed -ResX=1280 -ResY=720 -log
   ```
   `-log` 로 콘솔 로그 창을 띄워 오류를 확인한다.

## 요약

- 가장 쉬운 방법: **에디터 ▸ Platforms ▸ Windows ▸ Package Project**
- 자동화/반복: **RunUAT.bat BuildCookRun** (방법 B)
- 배포본은 `Shipping` 구성 + **UnrealMCP 플러그인 제외** 검토 필수.
