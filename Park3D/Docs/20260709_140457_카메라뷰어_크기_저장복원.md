# 카메라 뷰어 표시 크기 저장/복원 기능

- 작성일: 2026-07-09 14:04
- 요청: "카메라 뷰에 크기를 조정하면 파일로 저장해서 다시 시작할 때 그 저장된 크기로 맞추게"
- 대상: `UCameraViewerWidget` (+ 유닛테스트 신규)

## 1. 설계

### 요구사항
1. 뷰어를 드래그로 **리사이즈하면** 그 크기를 **파일로 저장**한다.
2. **다시 시작(위젯 재생성)** 시 저장된 크기로 뷰어를 **복원**한다. 파일이 없으면 기본값(480×270).

### 데이터 구조
```cpp
USTRUCT()
struct FCameraViewerSizeConfig
{
    UPROPERTY() float width  = 480.f;
    UPROPERTY() float height = 270.f;
};
```
- 멤버명 소문자 시작 = 프로젝트 JSON 직렬화 관례(`FCamVec3`, `FCarData` 등과 동일).

### 인터페이스(static, 위젯 인스턴스 없이 테스트 가능)
| 함수 | 역할 |
|------|------|
| `FString GetSizeConfigPath()` | 저장 경로 `ProjectSaved/CameraViewer/ViewerSize.json` |
| `bool SaveSizeConfigToPath(Path, FVector2D Size)` | 크기 → JSON 저장 |
| `bool LoadSizeConfigFromPath(Path, FVector2D& Out)` | JSON → 크기 로드(파일 없으면 false) |

### 처리 흐름
- **저장:** `NativeOnMouseButtonUp` 에서 **리사이즈였던 경우에만** `SaveSizeConfigToPath(GetSizeConfigPath(), CurrentViewSize)`. 이동(위치 변경)은 크기 무관 → 저장 안 함. 매 프레임(`OnMouseMove`)이 아니라 드래그 종료 1회만 기록.
- **복원:** `NativeConstruct` 에서 `LoadSizeConfigFromPath` 성공 시 `width` 를 `[MinViewWidth(160), MaxViewWidth(1280)]` 로 clamp 후 16:9 높이 파생하여 `CurrentViewSize` 에 반영, 실패 시 `DefaultViewSize`. 이후 기존 `ApplyViewSize()` 로 캔버스 슬롯 크기 적용.

### 대안 비교
- **저장 위치:** (채택) `ProjectSaved/CameraViewer/*.json` — 기존 CameraPos/CarPos/Preset 관례와 일치, 런타임·패키지 모두 유효. / (기각) GConfig .ini(EditorPerProjectUserSettings) — 에디터 전용, 패키지 빌드에서 부적합.
- **직렬화:** (채택) `FJsonObjectConverter` — 프로젝트 전역 관례. / (기각) 수동 문자열 파싱 — 중복·오류 위험.
- **저장 트리거:** (채택) 리사이즈 종료 1회. / (기각) 매 이동 프레임 저장 — 디스크 I/O 과다.

| 파일 | 변경 |
|------|------|

| `Tests/CameraViewerWidgetTest.cpp` | 신규 — 저장/로드 라운드트립 + 파일없음 폴백 유닛테스트(`Park3D.CameraViewer.SizeRoundTrip`) |

## 3. 유닛테스트 (rule 1)

`FCameraViewerSizeRoundTripTest`:
1. 파일 없음 → `LoadSizeConfigFromPath` == false(기본값 폴백 보장).
2. `SaveSizeConfigToPath(640×360)` → 파일 생성 확인.
3. `LoadSizeConfigFromPath` → width/height 라운드트립 일치(tol 1e-3).
4. 임시 파일 정리.

실행: 에디터 자동화 → `Session Frontend > Automation > Park3D.CameraViewer.SizeRoundTrip` 또는
`UnrealEditor-Cmd Park3D.uproject -ExecCmds="Automation RunTests Park3D.CameraViewer; Quit" -unattended -nop4 -testexit="Automation Test Queue Empty"`.

## 4. 영향도 분석 (rule 4)

- **모듈 의존성:** `FJsonObjectConverter`(JsonUtilities), `FFileHelper`/`FPaths`(Core) — 모두 이미 Park3D 모듈이 사용 중(`CameraControlLibrary`). **Build.cs 변경 불필요.**
- **빌드:** USTRUCT 신규 + 신규 .cpp → **UHT 재생성 필요 = 풀 빌드 필수**(Live Coding 불가). 에디터 종료 후 일반 빌드.
- **기존 기능:** `NativeConstruct`/`NativeOnMouseButtonUp` 에 로직 추가만, 기존 이동·리사이즈·프레임 그리기 동작 불변. 이동 시 저장 안 하므로 위치는 비영속(요청 범위 = 크기만).
- **호환성:** 최초 실행(파일 없음)은 기본값 480×270로 동작 — 무해. 저장 파일이 손상/수동편집돼도 역직렬화 실패 시 기본값 폴백. clamp로 비정상 크기 방어.
- **다른 위젯/에셋:** 영향 없음. `WBP_CameraViewer` 디자이너 변경 불필요(런타임 `ApplyViewSize` 가 슬롯 크기 지배).
