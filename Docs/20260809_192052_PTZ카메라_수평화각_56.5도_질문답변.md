# 질문: 메인 카메라 외의 카메라는 FOV가 수평 56.5°인가?

작성: 2026-08-09 19:20:52 / 코드 확인 기준(파일 변경 없음, 질의응답 기록)

## 답

**"광각단(zoom=1)에서만" 수평 56.5°다.** 상수 56.5는 PTZ 카메라의 *기준 화각*이며, 실제 적용 화각은 배율에 따라 매 프레임 달라진다.

## 근거 (코드 위치)

| 항목 | 값 | 위치 |
|------|-----|------|
| PTZ 카메라 기본 수평 화각 | `DefaultHFov = 56.5f` | `Park3D/Source/Park3D/PTZCameraActor.h:60` |
| 라이브러리 기본 인자 2곳 | `DefaultHFov = 56.5f` | `CameraControlLibrary.h:52, 56` |
| 매니저 풀 공유값 | `CameraDefaultHFov = 56.5f` | `CameraControlManager.h:68` |
| 실행 설정 파일 오버라이드 | `camera.hfov_wide = 56.5` | `Park3D/Save/Config/config_pmaker.json:8` |

즉 코드 기본값·설정 파일 값이 모두 56.5로 일치하므로, 현재 빌드에서 스폰되는 모든 PTZ 카메라는 56.5°를 기준으로 시작한다.
출처는 실장비 휴컴스 HNR-2036LA 사양(광각 H 56.5° / V 33.63°, 광학 ×36). 구 Unity 상수 58°에서 정정된 값이다.

## 배율이 걸리면 56.5가 아니다

`APTZCameraActor::SetZoom` → `UCameraControlLibrary::ZoomToHFov` 로 탄젠트 광학 모델을 적용한다
(`PTZCameraActor.cpp:90`, `CameraControlLibrary.cpp:66`):

```
hfov = 2 · atan( tan(56.5°/2) / clamp(zoom, 1, 36) )
```

| zoom | 적용 수평 FOV |
|------|---------------|
| 1 | 56.500° |
| 2 | 30.076° |
| 2.4 | ≈ 25.23° |
| 6.0 | ≈ 10.24° |
| 36 | ≈ 1.710° |

저장 파일 `Park3D/Save/3D/CameraPos/CamPos_office.json` 의 프리셋들은 `zoom` 이 2.4 / 6.0 / 3.1 등으로 저장되어 있으므로,
프리셋을 적용한 상태의 카메라는 56.5°가 아니라 위 식으로 계산된 좁은 화각이다.

## 수직 화각

`USceneCaptureComponent2D::FOVAngle` 은 **수평** 화각이고, 수직은 렌더타겟 종횡비에서 파생된다.
기본 렌더타겟 1280×720(16:9)이므로 `2·atan(tan(28.25°)×9/16) = 33.63°` — 실장비 사양 V 33.63°와 일치한다.

## 메인 뷰는 별개

메인(자유비행) 뷰는 PTZ와 무관하게 **수직 45°** 고정이며, 16:9 환산 시 수평 ≈ 72.73°다
(`Park3DGameMode.h:61-67`, `MainViewVerticalFovDeg = 45.f`). 장비 사양 재현이 아니라 배치·검수용 작업 시점이라 값이 다르다.

## 요약

- 메인 뷰 외 PTZ 카메라의 **기준(광각단) 수평 화각 = 56.5°** → 맞다.
- 단, 현재 화각은 `zoom` 에 따라 56.5° ~ 1.71° 사이로 바뀐다. "항상 56.5°"는 아니다.
- 값은 `config_pmaker.json` 의 `camera.hfov_wide` 로 런타임 교체 가능(0 이하 = 미지정 시 코드 기본값 56.5 유지).
