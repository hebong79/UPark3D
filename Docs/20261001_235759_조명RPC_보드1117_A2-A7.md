### UDS 레벨의 진실(문서화만 하고 동작은 그대로)

`ApplySettings` 는 UDS 같은 통합 하늘 시스템이 있으면 태양·하늘빛·노출을 **적용하지 않고** 채움광 2종만 적용한다(2026-08-17 결정). 이전에는 그 사실이 응답에 없었다. 이제 `light.set` 응답에 `ignoredKeys`(받았지만 적용 안 된 키 이름)와 `externalSkySystem:true` 가 실린다. 보드에 적힌 "`light.set {sunAltitudeDeg:30}` 후에도 0" 은 버그가 아니라 이 설계다 — 다만 호출자가 알 길이 없었던 것이 문제였다.

### 값 규약(`doc` 에도 적음)

- `sunAzimuthDeg` — **빛이 나아가는(그림자가 향하는) 방향**의 UE yaw. 0=+X, +Y 쪽으로 증가(위에서 볼 때 시계방향). 태양이 있는 방향이 아니다. 로트 지도·`cam.setPan` 과의 부호 일치는 **확인하지 않았다**.
- `sunAltitudeDeg` 0..90, 지평선 아래 불가(잘림).
- `sunColor` 선형 0..1(엔진이 8비트 sRGB 로 저장 → 되읽기 ±1/255).
- `exposureEV100` 클수록 어둡다. 자동 노출을 끈 고정값(min=max).
- `shadowFillIntensity` = 그림자 없는 보조 DirectionalLight(전 대상), `carFillIntensity` = 라이팅 채널 1 의 같은 종류(차량만). 스트림 카메라에 메인 뷰와 같게 보이는지는 **측정하지 않았다**.
- `light.setDefault` 는 리셋이 아니라 "다음 기동 때 적용할 파일" 포인터(`_default.txt`)다 — doc 에 명시.

### 파일 정체

- `_UserBaseline.json` — 2026-08-06 조명 이식 때 만든 "이식 전 사용자 설정 보존본(롤백용)". 코드 참조 없음. `internal:true`.
- `LightSettings_Base.json` — config `levels[]` 기본맵의 `light_file`(2026-09-30). 내부 파일이 아니라 기본맵 시작 조명이다.
- `_default.txt` — 목록(`*.json`)에 나오지 않는다.

## 검증

- 게임·에디터 빌드 통과. Automation `Park3D` 전체 **156 성공·실패 0**(신규 `Park3D.Rpc.LightExt.{UnknownKey,FileKind,DeleteFile,Meta}`).
- 작업본(Work13520, 포트 13520, LV_Park_01=UDS 레벨)에서 실 RPC: `light.set {exposureEV100:1.5, shadowFillIntensity:3}` → 응답 `ignoredKeys:["exposureEV100"]`·`source:override`; `light.reset` 뒤 상태가 처음 `light.get` 과 **일치**(`source` 제외); `bogus` → -32602 키 이름 포함; `file.list light`·`light.save _probe`→목록에 추가→`light.deleteFile`→사라짐; 기본 파일 삭제 거절; 경로 탈출 거절; `file.list` 전체는 세 kind 그대로.
- **미검증**: ① **A7 실측**: 작업본에서 `system.ping` 자체가 2.1초 걸렸다 — 정본과 같은 GPU(RTX 2080 Super, VRAM 7.7/8 GB, 사용률 100%)를 두 인스턴스가 나눠 GPU 정체가 났고(로그에 GPU 브레드크럼 덤프) `light.set` 의 비용과 구분되지 않는다. 스트림 끊김·`cam.captureJPG` 지연은 측정하지 못했다. ② 비-UDS 레벨(기본맵)에서 reset 이 태양·노출을 실제로 되돌리는 화면 확인. ③ 패키지 빌드(새 .cpp 추가 — 유니티 충돌 점검). ④ 화면 캡처 비교.
- 정본(13510)에는 **배포하지 않았다**(이 변경 이전 빌드가 떠 있음).

## 함정

- 한 PC 에서 정본과 작업본을 동시에 띄우면 GPU(8 GB)가 포화해 작업본 RPC 가 2초씩 걸리고 GPU 정체 덤프가 남는다. 측정이 필요하면 정본이 한가할 때 하나만.
- `FJsonObject::Values` 의 키는 `FString` 이 아니라 `FJsonKey` 류라 `MakeShared<FJsonValueString>(Pair.Key)` 가 컴파일되지 않는다 → `FString(Pair.Key)`.
- 블록 주석 안의 `sun*/sky` 는 `*/` 로 주석이 닫힌다.
