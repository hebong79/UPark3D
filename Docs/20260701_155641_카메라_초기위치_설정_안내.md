# 카메라(초기) 위치 설정 위치 안내

- 날짜: 2026-07-01 15:56:41
- 유형: 질문 답변(문서화)
- 질문: "카메라 초기 위치값 설정하는 부분을 알려줘 (코드/에디터 모두)"

## 요약

Park3D에는 **카메라 초기 위치를 직접 지정하는 코드가 없다.** 게임의 카메라는 `AParkFlyPawn`(에디터 플라이캠처럼 동작하는 `DefaultPawn`)이며, **초기 위치·회전 = 이 폰이 스폰되는 지점**으로 결정된다.

- 게임모드 `APark3DGameMode`가 `DefaultPawnClass = AParkFlyPawn` 으로 지정 → 플레이 시작 시 `PlayerController`가 이 폰을 자동 스폰·빙의(possess).
- 스폰 위치는 **레벨의 `PlayerStart` 액터 Transform**(위치/회전)을 따른다. `PlayerStart`가 없으면 원점(0,0,0)에 스폰.
- 시작 맵: `Config/DefaultEngine.ini` → `EditorStartupMap` / `GameDefaultMap = /Game/Maps/PresetEditor`.
- 확인 결과 `Content/Maps/PresetEditor.umap` 에 `PlayerStart` 가 존재 → **이 PlayerStart의 Transform이 곧 카메라 초기 위치·바라보는 방향**이다.

## 1. 에디터에서 설정 (권장 — 코드 수정 불필요)

가장 간단한 방법은 레벨의 `PlayerStart`를 옮기는 것이다.

1. 레벨 `Content/Maps/PresetEditor` 열기.
2. **World Outliner**에서 `PlayerStart` 선택.
3. **Details 패널 → Transform**:
   - **Location**: 카메라가 시작할 월드 좌표(cm). 예) 위에서 내려다보게 하려면 X/Y 중앙 + Z를 높게.
   - **Rotation**: 카메라가 바라볼 방향. 내려다보려면 **Pitch = -90**(정면 아래) 근처, 비스듬히 보려면 Pitch -30~-60 정도.
4. 레벨 저장(Ctrl+S).

> 참고: `PlayerController`의 회전(ControlRotation)이 `PlayerStart`의 Rotation으로 초기화되므로, Pawn뿐 아니라 **카메라가 바라보는 각도**도 PlayerStart Rotation으로 잡힌다.

### 대안: Pawn을 레벨에 직접 배치
`AParkFlyPawn`(또는 그 BP)을 레벨에 직접 놓고 **Details → Pawn → Auto Possess Player = Player 0** 으로 설정하면, 그 액터의 Transform이 시작 위치가 된다. 이 경우 GameMode의 DefaultPawn 자동 스폰 대신 배치된 액터가 사용된다.

## 2. 코드에서 설정 (동적 제어가 필요할 때)

현재 코드에는 위치 지정이 없으므로, 코드로 강제하려면 아래처럼 추가한다. 파일: `Park3D/Source/Park3D/Park3DGameMode.cpp`.

### 방법 A) BeginPlay에서 스폰된 폰의 위치/회전을 지정
```cpp
void APark3DGameMode::BeginPlay()
{
    Super::BeginPlay();

    APlayerController* PC = UGameplayStatics::GetPlayerController(this, 0);
    if (PC)
    {
        if (APawn* P = PC->GetPawn())
        {
            const FVector  StartLoc(0.f, 0.f, 1500.f);   // 원하는 초기 위치(cm)
            const FRotator StartRot(-60.f, 0.f, 0.f);     // Pitch,Yaw,Roll
            P->SetActorLocationAndRotation(StartLoc, StartRot);
            PC->SetControlRotation(StartRot);             // 카메라(뷰) 회전도 맞춤
        }
    }
    // ... 기존 메뉴/입력 코드 ...
}
```
> 주의: 기존 `BeginPlay`의 메뉴 표시·입력 코드는 그대로 두고, 위 블록만 앞쪽에 추가하면 된다. `SetControlRotation`을 함께 호출해야 뷰 각도가 반영된다.

### 방법 B) 설정값을 에디터에 노출(EditAnywhere)
초기 위치를 BP/디테일에서 조정하고 싶으면 `Park3DGameMode.h`에 프로퍼티를 추가:
```cpp
UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Camera")
FVector CameraStartLocation = FVector(0.f, 0.f, 1500.f);

UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Camera")
FRotator CameraStartRotation = FRotator(-60.f, 0.f, 0.f);
```
그리고 BeginPlay에서 이 값으로 `SetActorLocationAndRotation` / `SetControlRotation` 호출.

## 5. 구현 완료 (코드 방식 §2-B 적용)

사용자 요청으로 §2 방법 B(에디터 노출 프로퍼티 + BeginPlay 적용)를 실제 구현했다.

### 변경 파일
- `Park3D/Source/Park3D/Park3DGameMode.h`
  - `bool bOverrideCameraStart = true` — true면 지정 시점 사용, false면 PlayerStart 유지.
  - `FVector CameraStartLocation = (-1500, 0, 1500)` (cm) — **임시 기본값, 프로젝트에 맞게 조정 필요**.
  - `FRotator CameraStartRotation = (Pitch -45, 0, 0)`.
  - `void ApplyCameraStart();` 선언 추가.
- `Park3D/Source/Park3D/Park3DGameMode.cpp`
  - `#include "GameFramework/Pawn.h"` 추가.
  - `BeginPlay()`에서 `CachedPC` 설정 직후 `ApplyCameraStart()` 호출.
  - `ApplyCameraStart()` 구현: `bOverrideCameraStart`가 true이고 PC가 유효하면 폰에 `SetActorLocationAndRotation`, 컨트롤러에 `SetControlRotation`(뷰 각도) 적용 + 로그.

### 동작
- 기본값 `bOverrideCameraStart=true` → 플레이 시작 시 PlayerStart 대신 지정 위치/회전으로 카메라 시작.
- 시점을 되돌리려면 `bOverrideCameraStart=false`로 두면 기존 PlayerStart 동작 복귀.

### 값 조정 방법
- 프로퍼티는 `EditDefaultsOnly`(기존 `MenuWidgetClass`와 동일 스타일). GlobalDefaultGameMode가 C++ 클래스(`/Script/Park3D.Park3DGameMode`)이므로 에디터에서 직접 편집하려면:
  - (A) `APark3DGameMode`의 **블루프린트 자식**을 만들어 값 조정 후, World Settings의 GameMode Override(또는 프로젝트 기본 게임모드)로 지정, 또는
  - (B) C++ 기본값을 수정 후 재컴파일.
- 원하는 좌표/각도가 정해지면 알려주면 기본값을 그 값으로 확정한다.

### 영향도
- 변경 범위: `Park3DGameMode` 한정. 기존 메뉴/입력 로직 앞에 시점 적용만 추가(순서 영향 없음).
- 신규 include 1개(`GameFramework/Pawn.h`). 시그니처/JSON/에셋 참조 영향 없음.
- `bOverrideCameraStart=false`로 기존 동작 완전 복귀 가능 → 회귀 위험 낮음.

### 검증
- Ctrl+Alt+F11 컴파일 후 Play → 로그 `[Park3DGameMode] 카메라 초기 시점 적용: Loc=... Rot=...` 확인, 화면 시점이 지정 위치/각도인지 확인.
- 폰 이동(RMB+WASD)·메뉴(M)·차량배치 등 기존 기능 정상 여부 회귀 확인.

## 4. 권장

- **일회성/고정 시작 시점**: 에디터에서 `PlayerStart` Transform 조정(§1) — 가장 단순, 코드 변경 없음(단순함 우선 원칙).
- **런타임 동적 제어(버튼으로 시점 리셋 등)가 필요**할 때만 코드(§2) 도입.
