# Park3D 변경 이력

전문은 같은 폴더의 `HISTORY.md` 에 있다. 한 행이 길어 통째로 읽지 않는다. 아래 제목으로 찾는다.

```
Grep pattern:"<제목 일부>" path:".claude/skills/park3d-history/HISTORY.md" output_mode:"content"
```

옛 기록의 「재쿡」은 지금 말로 「재패키징」이다. 찾을 때는 둘 다 찾는다.

상세는 `Docs/yyyyMMdd_HHmmss_*.md` 에 있고, 그보다 오래된 사정은 `git log` 로 본다.

## 새 기록을 적는 법

1. `HISTORY.md` 표 맨 위에 한 행을 넣는다(날짜 | 변경 내용 | 대상 | 사유). 수치·경위는 Docs 에 쓰고 행은 짧게.
2. 아래 알맞은 주제의 맨 위에 `- 날짜 제목` 한 줄을 넣는다. 제목은 그 행 안의 문자열 그대로.
