## 2. 위젯 기능 (UPresetMakerWidget 패턴)

- **BindWidget(22)**: Combo_Prefab/Combo_Type, Radio_Move/Rotate, Field_Rotate/Count/Spacing, Btn_AutoCreate, Check_Vertical, Btn_DeleteSel/PlaceStart, CarList_Scroll, Field_Idx/PresetId/FaceId/RotY, Radio_Front/Back, Btn_Modify/Save/Open/Init. (Optional: Check_PresetGroup, Txt_FileName, RootBorder)
- **NativeConstruct**: 타입 콤보(소형차~트럭) 채움, 프리팹 콤보(카탈로그) 채움, 기본값(개수5·간격2.5·회전5), 핸들러 바인딩.
- **자동생성**(AutoCreate): 개수·간격·세로 옵션 읽어 `UCarPlacementLibrary::AutoPlacePosition`으로 위치 산출 → `MakeCarId`로 id → `CarData`에 추가 → `RefreshView`.
- **선택/수정**: 리스트 엔트리 클릭(hover 판별) → 상세필드 채움 / 수정(ModifySelected) → CarData 갱신.
- **삭제/초기화**: DeleteSelected, InitAll.
- **저장/열기**: DesktopPlatform 파일 대화상자 + `UCarPlacementLibrary::Save/LoadCarDatasFromJson`. 타이틀 파일명 갱신.
- **표시 위임**: `GetCarManager()`(없으면 스폰) → `ACarPlacementManager::RebuildAll(CarData, 카탈로그, 선택)`.
- **패널 드래그**: RootBorder RenderTranslation(PresetMaker 동일).
- 이동/회전·전/후면 라디오 상호배제는 핸들러에서 수동 처리.
