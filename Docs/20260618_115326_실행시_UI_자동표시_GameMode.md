## 1. 요청 내용

> 실행할때 UI가 출력될수 있게 해줘.

기존에 `WBP_PresetMaker`(→ C++ `UPresetMakerWidget`) 위젯과 제어 로직은 구현돼 있었으나,
**게임을 실행(Play/Standalone)했을 때 이 위젯을 자동으로 화면에 띄워주는 코드가 없었다.**
지금까지는 블루프린트에서 수동으로 `Create Widget → Add to Viewport` 를 해야만 보였다.

---

## 2. 구현 방식 선택

| 방식 | 재빌드 | 비고 |
|------|--------|------|
| **C++ GameMode (채택)** | 필요 | 가장 견고/영구적. 맵에 무관하게 항상 적용. 프로젝트의 기존 C++ 패턴과 일치 |
| BP GameMode 그래프 | 불필요 | 현재 MCP/에디터 Python 도구로는 `CreateWidget` 같은 특수 K2 노드를 그래프에 자동 배선할 수 없음(직접 수작업 필요) |
| Live Coding | 불필요(시도) | 신규 UCLASS는 Live Coding 실패 가능성 → 결국 재시작 필요할 수 있음 |

사용자 선택에 따라 **C++ GameMode 방식**으로 진행했다.

---

## 3. 구현 내용

### 3.1 신규 클래스 `APark3DGameMode` (`AGameModeBase` 상속)
- 생성자에서 `ConstructorHelpers::FClassFinder` 로 `/Game/UI/WBP_PresetMaker` 위젯 클래스를 기본값으로 로드해
  `PresetWidgetClass`(EditDefaultsOnly) 에 지정. → 에디터에서 다른 위젯으로 교체 가능.
- `BeginPlay()` 에서:
  1. `PresetWidgetClass` 유효성 확인(없으면 경고 로그 후 반환)
  2. 0번 `PlayerController` 획득
  3. `CreateWidget<UUserWidget>(PC, PresetWidgetClass)` 로 위젯 생성
  4. `AddToViewport()` 로 화면에 표시
  5. `bShowMouseCursor = true` + `FInputModeGameAndUI`(위젯 포커스, 마우스 비잠금) 설정 → UI 조작 가능
  6. 성공 시 `LogTemp` 로그 출력(검증 신호로 사용)

각 실패 지점마다 `UE_LOG(Warning)` 으로 원인을 남겨 디버깅이 쉽도록 했다.

### 3.2 기본 게임모드 등록 (`DefaultEngine.ini`)
```ini
[/Script/EngineSettings.GameMapsSettings]
GameDefaultMap=/Engine/Maps/Templates/OpenWorld
GlobalDefaultGameMode=/Script/Park3D.Park3DGameMode
```
- `GlobalDefaultGameMode` 로 등록했기 때문에 **World Settings 에서 별도 GameMode 를 지정하지 않은 모든 맵**에 자동 적용된다.

## 5. 동작 검증 (실제 실행)

에디터 PIE 자동 실행은 MCP 브리지(백그라운드 창) 경로에서 트리거되지 않아(로그에 PIE 시작 흔적 없음),
**실제 게임을 Standalone(`-game`) 으로 실행**하여 검증했다. 이것이 "실행할때"에 가장 부합하는 테스트다.

```
UnrealEditor.exe Park3D.uproject -game -windowed -ResX=1280 -ResY=720 -abslog=verify_standalone.log
```

검증 로그(`Saved/Logs/verify_standalone.log`):

| 로그 라인 | 의미 |
|-----------|------|
| `LogLoad: Game class is 'Park3DGameMode'` | 실행 시 신규 GameMode 가 실제 적용됨 ✓ |
| `LogTemp: [Park3DGameMode] Preset Maker UI를 뷰포트에 표시했습니다.` | BeginPlay → 위젯 생성 + AddToViewport 성공 ✓ |
| `LogTemp: [PresetMaker] 추가됨: Preset 1 (총 1개)` … `Preset 2 (총 5개)` | 실행 중 화면의 "추가" 버튼 클릭이 정상 동작 → UI 상호작용 가능 ✓ |
| `LogExit: Game engine shut down` / `LogExit: Exiting.` | 크래시 없이 정상 종료 ✓ |

→ **실행 즉시 UI 가 화면에 표시되고, 클릭 등 상호작용까지 정상 동작**함을 결정적으로 확인.

## 6. 영향도 분석

- **신규 소스**: `Park3DGameMode.h/.cpp` 2개 추가. 기존 소스(`PresetMakerWidget.*`, `Park3D.*`)는 미변경.
- **설정 변경**: `DefaultEngine.ini` 에 `GlobalDefaultGameMode` 한 줄 추가.
  - 영향 범위: World Settings 에서 GameMode 를 별도 지정하지 않은 모든 맵의 기본 게임모드가 `Park3DGameMode` 로 바뀐다.
  - 특정 맵에서 다른 게임모드를 쓰려면 해당 맵 World Settings 의 `GameMode Override` 로 개별 지정하면 된다.
- **모듈 의존성**: 신규 코드는 이미 `Build.cs` 에 포함된 `UMG`(CreateWidget), `Engine`(GameplayStatics) 만 사용 → 의존성 추가 없음.
- **빌드 영향**: 신규 UCLASS 추가로 **에디터 재시작 + 재빌드 1회** 필요(완료). 이후로는 일반 변경과 동일.
- **위젯 교체 용이성**: `PresetWidgetClass` 가 `EditDefaultsOnly` 라, 추후 다른 시작 위젯으로 바꾸려면
  `Park3DGameMode` 를 블루프린트로 상속하거나 기본값만 변경하면 된다(코드 수정 불필요).

---

## 7. 사용/확장 메모

- 다른 맵에서 이 UI 가 자동으로 뜨길 원하면 별도 작업 불필요(글로벌 기본값).
- 특정 맵에서만 띄우고 싶으면: `GlobalDefaultGameMode` 를 제거하고, 원하는 맵의 World Settings 에서
  `GameMode Override = Park3DGameMode` 로 지정.
- 표시 직후 마우스 커서가 보이고 UI/게임 입력이 동시에 동작(`FInputModeGameAndUI`)한다.
  순수 UI 전용으로 바꾸려면 `FInputModeUIOnly` 로 교체하면 된다.
